## What this code means
The E2 or 6E2 error on a Samsung dryer indicates a keypad or button-input fault. The control board is detecting that one of the console buttons is stuck, jammed, or continuously pressed rather than releasing normally. This is not a heating or airflow problem. The dryer thinks a button is being held down when it should be free.

Samsung groups these codes with stuck-button and control-panel input issues. The fault can come from a physically stuck button, moisture or residue in the control area, a faulty user interface or keypad assembly, or a main control board misreading the input signal.

## Before You Replace Anything

Homeowners often replace the main control board first when the real culprit is a stuck or contaminated button on the user interface. Press and release each button carefully to check for binding, and inspect for moisture or detergent residue before ordering expensive boards.

## Common Causes

- **Physically stuck button** A button on the console is jammed, binding, or not springing back after being pressed.
- **Moisture or residue in the control panel** Detergent splashes, spills, or humidity have contaminated the keypad contacts and are bridging the input circuit.
- **Faulty user interface or keypad assembly** The button membrane or contact pad inside the console has worn out or failed, causing a continuous signal.
- **Main control board misreading the input** The control board itself is interpreting a healthy button signal as stuck, or the input path on the PCB has failed.
- **Wiring harness or connector fault** A loose, corroded, or damaged connector between the user interface and the main control board is sending an erratic signal.

## Step-by-Step Fix {#fix}

1. **Unplug the dryer** at the wall or switch off the circuit breaker so you are working with no power to the appliance.
2. **Wait at least 60 seconds**, then restore power and see if the E2 or 6E2 error returns immediately or clears on the first test cycle.
3. **Press and release every button on the console** one at a time, checking for any that stick, bind, or do not spring back normally.
4. **Inspect the control panel** for moisture, detergent splashes, or sticky residue around the buttons, and clean with isopropyl alcohol on a soft cloth if you find contamination.
5. **Remove the console cover** (consult your model's service manual for the exact screws or clips) to access the user interface assembly and look for corrosion, moisture, or a visibly damaged membrane.
6. **Test the wiring harness connectors** between the user interface and the main control board for tight seating, corrosion, or bent pins, and clean or re-seat them as needed.
7. **Replace the user interface or keypad assembly** if a button remains stuck or the membrane is worn, or replace the main control board if continuity testing shows the input path on the board side has failed.

## When to Call a Pro

Call a technician if you are uncomfortable removing the console cover, if you cannot identify which button is stuck, or if the error returns after you have cleaned the panel and replaced the user interface assembly. A tech will use continuity testing on the input path to isolate whether the fault is in the keypad side or the main control board side, and many Samsung models require model-specific test points that are documented in the service data. Also call a pro if you see signs of moisture damage inside the console that may have spread to other circuit boards or wiring.

**Rough cost:** DIY runs about $40–120 in parts, 30–60 min. A pro service call runs about $150–300.
