## Samsung Dryer E2 Error Code — What It Means

The E2 code (sometimes displayed as 6E2 on certain Samsung models) signals a button-input fault. The main control board detects that a button on the user interface panel is stuck, continuously pressed, or sending an invalid signal. This is not a heating, venting, or sensor issue. The control sees a constant button press that should not be there, so it throws the code and stops normal operation.

## Common Causes

- **Stuck or damaged button** A button on the console is physically jammed, broken, or binding so the control reads it as always pressed.
- **Moisture or residue on the keypad** Liquid spills, condensation, or cleaning product buildup around the control panel causes false button signals.
- **Failed user interface board** The keypad assembly itself has an internal failure and sends continuous input even when no button is touched.
- **Main control board misreading input** The main board or the harness connection between the UI and the board is faulty and interprets normal button signals incorrectly.

## Step-by-Step Fix {#fix}

1. **Unplug the dryer** or switch off the circuit breaker for a full 60 seconds to reset the control board and clear temporary faults.
2. **Press and release each button** on the control panel individually to check for sticking, binding, or physical damage.
3. **Inspect the console surface** for moisture, spills, or sticky residue and wipe it clean with a dry cloth, allowing the panel to dry completely if dampness is present.
4. **Restore power** and start a test cycle to see if the E2 code clears after the reset and button check.
5. **Check the wiring harness** between the user interface and the main control board for loose connectors or visible damage if the code returns immediately.
6. **Replace the user interface assembly** if a button is stuck, the keypad is damaged, or the code persists after reset and cleaning.
7. **Replace the main control board** if the new keypad still triggers the E2 code, indicating the board is misreading valid input signals.

## When to Call a Pro

Call a technician if the code returns after you have reset the machine, verified all buttons move freely, cleaned the panel, and the dryer still will not run. Diagnosing whether the fault is in the user interface or the main control board often requires testing the harness connections and checking signal continuity, which can be difficult without the service manual for your specific model. If you are not comfortable removing the console or handling ribbon-cable connectors, professional service will save time and avoid damage to the control components.
