## What this code means
A102 does not appear in published Weil-McLain boiler fault code tables. Weil-McLain controls use onboard diagnostics and fault history screens to display error numbers, but the exact code definitions and corrective actions are specific to each model and control platform. A102 has been documented as a Rheem water heater alarm in other contexts, so cross-brand confusion is possible if you are reading the wrong manual.

To identify the true fault, locate your boiler's exact model number (usually on a data plate on the jacket or inside the burner door), then retrieve the fault history from the control display and match the code to the table in that model's installation and service manual. Do not attempt repair based on generic code lists, because the same letters can mean different things on different platforms.

## Before You Replace Anything

Do not replace any component until you confirm the code is correct for your exact Weil-McLain model. Technicians sometimes swap igniters, flame sensors, or gas valves based on a misread display or the wrong manual, wasting hundreds of dollars on parts that were never the problem.

## Common Causes

- **Wrong manual or cross-brand confusion (~60%)** You are reading a Rheem water heater guide or a generic code list instead of the Weil-McLain manual for your specific boiler model.
- **Misread display (~25%)** The control is showing a different code (such as A10, A12, or a numeric fault) that looks like A102 on a dim or scratched screen.
- **Aftermarket or retrofit control (~10%)** A third-party or upgraded control board was installed that uses a different fault code scheme than the original Weil-McLain equipment.
- **Custom or regional code (~5%)** A very old or region-specific Weil-McLain controller uses a code table that was never widely published online.

## Step-by-Step Fix {#fix}

1. **Record the full code and boiler details.** Write down exactly what appears on the display, including any flashing segments or secondary messages, plus the boiler model number, serial number, and control brand.
2. **Retrieve the model-specific manual.** Go to the Weil-McLain website, navigate to the Literature Library or Support section, and download the installation and service manual that matches your model number and control type.
3. **Search the fault code table.** Open the manual PDF and use the search function to look for A102. If it does not appear, check the index for the fault code section and review the entire table.
4. **Access the boiler's fault history menu.** Follow the control operating instructions in the manual to enter service or diagnostic mode and display stored fault codes with timestamps.
5. **Cross-reference every displayed code.** Match each code in the fault history to the manual's table, noting the exact meaning, probable cause, and recommended corrective action for your model.
6. **Contact technical support if the code is not listed.** If A102 does not appear in any Weil-McLain documentation for your model, call Weil-McLain technical support with your model and serial number, or hire a licensed boiler technician to interpret the control.
7. **Do not replace parts without a confirmed diagnosis.** Wait until you have the correct fault definition and a step-by-step diagnostic procedure from the manufacturer before ordering or swapping any component.

## When to Call a Pro

Call a licensed boiler technician immediately if you cannot locate a Weil-McLain manual that lists A102, if the boiler is actively locked out or venting abnormally, or if you smell gas. Boiler diagnostics involve gas piping, combustion analysis, and sometimes high-voltage or low-voltage wiring that require specialized tools and training. A technician will bring the correct manuals, a combustion analyzer, and a multimeter to identify the true fault, verify safe operation, and replace only the failed component with the manufacturer-specified part number. Attempting repair without the correct code definition risks further damage, voided warranty, and unsafe operation.

**Rough cost:** A pro service call runs about $150-400.
