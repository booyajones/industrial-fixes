## GE Microwave F4 Error Code — What It Means

The F4 code on a GE microwave indicates that the electronic control has detected the humidity sensor circuit as open continuously for more than 5 seconds. The humidity sensor monitors moisture levels during certain cooking cycles, and when the control cannot read the sensor (because the circuit is open), it flags the fault and may stop the microwave from operating normally.

This code is specific to the humidity sensor circuit. It is not related to the temperature probe, touchpad, or thermal sensor faults, which trigger separate codes such as F6, F10, F1, and F2. GE's fault-code documentation states that these codes are built into the control and that a trained service technician should diagnose and correct the issue.

## Before You Replace Anything

Homeowners sometimes replace the control board first, assuming the error is a board fault. Before replacing the board, verify the humidity sensor tests open and check all wiring and connectors in the sensor circuit, because an open sensor or loose plug is far more common than a control board input failure.

## Common Causes

- **Failed humidity sensor (~60%)** The sensor itself has gone open internally and no longer provides a valid signal to the control.
- **Disconnected or loose sensor connector (~25%)** The plug at the sensor or at the control has come loose, creating an open circuit that the control reads as F4.
- **Open or damaged wiring harness (~10%)** A wire in the sensor circuit has broken, been pinched, or corroded, interrupting continuity between the sensor and the control.
- **Control board input fault (~5%)** The sensor and wiring test good but the control still reads the circuit as open, pointing to a failed input on the electronic control board.

## Step-by-Step Fix {#fix}

1. **Shut off power** at the circuit breaker or fuse panel supplying the microwave and wait 30 seconds to allow the control to reset.
2. **Restore power** and observe whether the F4 code reappears immediately or during the next cook cycle. If the code clears and does not return, the fault may have been a transient glitch.
3. **Unplug the microwave** and remove the outer cabinet panels to gain access to the humidity sensor and its wiring. Consult your model's service manual or wiring diagram to locate the sensor, which is typically mounted in the cavity airflow or on the interior wall.
4. **Inspect the sensor connector** at both the sensor and the control board. Push each plug firmly into place and look for corrosion, bent pins, or melted plastic that would create an open circuit.
5. **Test the humidity sensor** with a multimeter set to measure resistance. Disconnect the sensor from its harness, then measure across the sensor terminals. An open reading (infinite ohms) indicates the sensor has failed. If your service manual lists a specific resistance range, verify the sensor falls within it.
6. **Trace the sensor wiring** back to the electronic control board if the sensor tests good. Check for continuity along the harness and verify no wires are broken, pinched, or corroded. If continuity is intact but the control still flags F4, the control board input is faulty.
7. **Replace the failed component** (sensor, harness, or control board as identified), reassemble the microwave, restore power, and verify the F4 code does not return during a test cycle.

## When to Call a Pro

GE states that fault codes like F4 should be diagnosed and corrected by a trained service technician. The repair requires safely disassembling the microwave cabinet, working around high-voltage components (even when unplugged, the capacitor can hold a dangerous charge), identifying the humidity sensor location from the wiring diagram, and performing electrical continuity tests. If you are not comfortable de-energizing the unit, discharging the high-voltage capacitor, or tracing sensor circuits with a multimeter, call a qualified appliance technician. Professionals also have access to model-specific resistance specifications and OEM parts cross-references that are not published in consumer manuals.

**Rough cost:** A pro service call runs about $150–300.
