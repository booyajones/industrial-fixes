## Bosch Oven E101 Error Code — What It Means

The E101 error code on Bosch ovens typically indicates a problem with the temperature sensing or control circuit. Because Bosch uses different control systems across model lines, the exact meaning can vary. In many cases it points to a faulty temperature sensor (also called an oven probe or thermistor), a broken wire to that sensor, or a control board that cannot read the sensor signal. Some models may also throw E101 for a short circuit or open circuit in the temperature measurement path.

Because the precise definition depends on your oven's model and production year, consult your owner's manual or the wiring diagram inside the control panel. The manual will confirm whether E101 is a sensor fault, a control fault, or something else entirely. Do not assume the code means the same thing as on other brands or even other Bosch appliance types.

## Before You Replace Anything

Many people replace the control board first when the real problem is a failed temperature sensor or corroded connector. Use a multimeter to check the sensor's resistance at room temperature before buying any part.

## Common Causes

- **Failed temperature sensor (~50%)** The oven's thermistor probe drifts out of spec or opens completely, sending no signal or a nonsense reading to the control board.
- **Loose or corroded sensor connector (~20%)** The plug that joins the sensor wire to the control harness develops oxide buildup or backs out slightly, breaking the circuit.
- **Broken or chafed sensor wire (~15%)** The cable running from the sensor to the control board is pinched, cut, or has insulation worn through by a sharp edge.
- **Control board analog-to-digital converter fault (~10%)** The circuit on the main control that reads the sensor signal fails, even though the sensor itself is good.
- **Sensor mounting bracket corrosion (~5%)** Moisture or oven cleaner seeps into the bracket, creating a high-resistance ground path that corrupts the reading.

## Step-by-Step Fix {#fix}

1. **Disconnect power** at the breaker or unplug the oven so no voltage is present during the repair.
2. **Remove the back panel or control cover** to expose the control board and wiring harness, following your model's service manual.
3. **Locate the temperature sensor probe** inside the oven cavity, usually mounted on the upper rear wall behind a small bracket.
4. **Disconnect the sensor's wire connector** at the control board or junction point and inspect the pins for corrosion or soot.
5. **Measure the sensor resistance** with a digital multimeter set to ohms, probing the two sensor leads at room temperature and comparing to your model's specification.
6. **Replace the sensor** if the reading is open, shorted, or outside tolerance, threading the new probe through the same grommet and securing the mounting bracket.
7. **Reassemble the panels**, restore power, and run a test bake cycle to confirm the E101 code does not return.

## When to Call a Pro

Call a technician if you are not comfortable working inside the control panel, if the sensor tests good but the code persists, or if you suspect the control board itself has failed. A pro can perform live voltage checks on the board's input circuits and has access to factory diagnostic modes that pinpoint whether the fault is in the sensor loop or the microprocessor. Also call if your oven uses a high-voltage relay board that sits near the heating elements, since those circuits can be dangerous without proper training.

**Rough cost:** DIY runs about $30-80 in parts, 30-60 min. A pro service call runs about $150-250.
