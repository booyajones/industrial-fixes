## GE Dishwasher FF Error Code — What It Means

The FF code does not appear in GE's published dishwasher fault code list. GE dishwashers use codes like C1, C3, C5, C7, H2O, and PF, but not FF. FF is a GE refrigerator and freezer code that indicates the freezer compartment temperature has risen above safe limits and food may be thawing. If you see FF on your GE appliance, you are looking at a refrigerator or freezer display, not a dishwasher. The code signals a warm freezer condition that needs immediate attention to prevent food spoilage.

## Common Causes

- **Door not fully closed or gasket damaged** Warm air enters the freezer compartment when the door is ajar or the rubber seal is torn or worn.
- **Blocked vents or airflow obstructions** Items packed too tightly inside the freezer can block circulation vents and prevent cold air from reaching the sensor.
- **Recent power interruption** A power outage allows the freezer to warm up, and the FF code appears when power returns and the control detects the high temperature.
- **Evaporator fan failure** If the fan that circulates cold air stops running, the freezer compartment warms and triggers the FF alert.
- **Faulty temperature sensor or thermistor** A defective sensor may report incorrect freezer temperatures to the control board and cause a false or genuine FF alarm.

## Step-by-Step Fix {#fix}

1. **Verify the freezer is actually warm** by feeling packages and checking if ice cream is soft or frost is melting.
2. **Close the freezer door firmly** and inspect the rubber gasket all the way around for tears, gaps, or debris that prevent a tight seal.
3. **Clear all vents inside the freezer** by rearranging items so air can flow freely from the back wall to the front.
4. **Check for recent power loss** by looking for a PF code on the display or checking clocks in the house that may have reset.
5. **Reset the appliance** by pressing the System Check button on the control panel or unplugging the refrigerator for one minute and then restoring power.
6. **Monitor the freezer temperature** for the next two hours with the door closed to see if the compartment cools down and the FF code clears.
7. **Test the evaporator fan** by listening for airflow at the back of the freezer compartment or consulting your model's service manual for fan voltage tests if the FF persists after all other checks.

## When to Call a Pro

Call a qualified appliance technician if the FF code does not clear after you have confirmed the door seals properly, vents are open, and power has been stable for several hours. Diagnosing a failed evaporator fan or temperature sensor requires voltage tests and access to the evaporator compartment behind interior panels. A pro can also retrieve any stored fault history from the control board and cross-reference the exact model's wiring diagram to pinpoint the root cause without guessing.
