## Maytag Oven SAB Error Code — What It Means

The SAB, Sab, 5AB, or 5A6 display on a Maytag oven or range is not an error code. It tells you that Sabbath Mode is currently activated. In this mode, the appliance intentionally limits normal operation so that only the Bake cycle will run. Other cooking cycles, cleaning cycles, audible tones, and normal temperature display behavior are all disabled. The oven was placed into this mode either deliberately or through a prior control setting, not because of any sensor, relay, or board fault.

The fix is simply to exit Sabbath Mode using your model's specific control sequence. Most Maytag ovens allow you to leave the mode by pressing and holding the Clock pad for about 3 seconds. Once you exit, normal oven functions, tones, and display behavior will return. No parts need replacement in the typical case.

## Common Causes

- **Sabbath Mode was intentionally activated** A user pressed the control sequence to enable Sabbath Mode, or a previous setting remained active after a power event.
- **Clock pad was held accidentally** On many models, holding the Clock button for 3 seconds enters or exits Sabbath Mode, so an unintentional press can trigger the display.
- **Model-specific control sequence was used** Different Maytag models use different button combinations to enter Sabbath Mode, and the mode persists until manually exited.
- **Power was restored with Sabbath Mode stored** Some models remember the Sabbath Mode setting after a power outage or circuit breaker reset, so the code reappears when power returns.

## Step-by-Step Fix {#fix}

1. **Confirm the display** shows SAB, Sab, 5AB, or 5A6 and verify that oven functions are limited (only Bake works, no tones, no temperature changes shown).
2. **Locate your owner's manual** or visit the Maytag product support page for your specific model number to confirm the Sabbath Mode exit procedure.
3. **Press and hold the Clock pad** for approximately 3 seconds if your model uses that method to exit Sabbath Mode.
4. **Watch the display** to see if the SAB code clears and normal oven operation resumes, including audible tones and full cycle availability.
5. **Try a different button sequence** if Clock does not work, following your manual's instructions (some models use other pads or combinations).
6. **Power-cycle the oven** by turning off the circuit breaker for 1 minute, then restoring power, if the display still shows SAB after attempting the exit procedure.
7. **Test normal operation** by running a Bake cycle, verifying that tones sound, the display shows temperature changes, and all cooking modes are available again.

## When to Call a Pro

Call a qualified appliance technician if the SAB code remains on the display after you have tried the correct Sabbath Mode exit sequence for your model, power-cycled the oven, and consulted your owner's manual. Also call if the keypad does not respond to button presses or if the oven fails to restore normal Bake, Broil, and cleaning cycles after exiting the mode. Because SAB is a control mode rather than a component failure, most homeowners can resolve it without a service call. A pro is needed only when the control board or keypad hardware prevents the mode from being cleared.
