## Amana Dryer F28 Error Code — What It Means

The F28 code on an Amana dryer indicates a moisture sensor open fault. The dryer control is detecting an open circuit in the moisture sensor system during diagnostics. This points to a problem with the sensor strip itself, its wiring harness, or the control board's sensing input circuit.

Amana's product-help documentation confirms F28 as a dryer error code requiring a reset action. Whirlpool-family service references identify F28 specifically as a moisture sensor open condition on the dryer platform Amana uses. This is not a communication error, line voltage issue, or airflow restriction code. Those conditions trigger different Amana codes such as L2 for low line voltage or AF/F4E3 for restricted airflow.

## Before You Replace Anything

Many people replace the control board first. Before ordering a board, inspect the moisture sensor bars in the drum area and their wiring harness for physical damage, loose connectors, or corrosion. An open connection at the sensor or harness accounts for most F28 codes.

## Common Causes

- **Open or disconnected moisture sensor strip (~50%)** The sensor bars or contact strip at the drum bulkhead have broken away, corroded, or lost electrical continuity.
- **Loose, corroded, or damaged wiring harness (~30%)** The connector or wiring between the moisture sensor and the main control has become loose, corroded, or has a broken conductor that opens the circuit.
- **Failed control board input circuitry (~15%)** The main control board's sensing input for the moisture sensor has failed even though the sensor and wiring are intact.
- **Intermittent connection or control latch (~5%)** A temporary fault condition or software latch in the control that clears after a power reset but may return if the underlying connection issue persists.

## Step-by-Step Fix {#fix}

1. **Turn off power at the circuit breaker** for the dryer and wait a full 5 minutes. Amana explicitly recommends this reset step for F28.
2. **Restore power and check** whether the F28 code has cleared. If it stays clear through a test cycle, monitor for recurrence. If the code returns immediately, continue diagnostics.
3. **Access the dryer drum area** by opening the door and locating the moisture sensor strip or contact bars on the drum bulkhead. Inspect for physical damage, corrosion, or breaks in the sensor material.
4. **Inspect the wiring harness** that runs from the moisture sensor to the main control board. Check both ends for loose or corroded connectors, damaged pins, or broken wires that would open the circuit.
5. **Test or replace the moisture sensor** if you found visible damage to the strip or contacts. Remove the old sensor, install a new moisture sensor assembly, and reconnect the harness.
6. **Replace the main control board** if the sensor and wiring both test good and the F28 code persists. The board's sensing input circuitry may have failed.
7. **Run a diagnostic or timed dry cycle** after any repair to confirm the F28 code does not reappear and the dryer completes the cycle normally.

## When to Call a Pro

Call a qualified appliance technician if you are uncomfortable working inside the dryer cabinet, if the wiring diagnostics are unclear, or if you have replaced both the sensor and harness but the F28 code will not clear. A pro can perform circuit continuity tests at the control board level and confirm whether the board input has failed. Also call if the dryer is still under warranty or if you discover additional fault codes that point to multiple system failures.

**Rough cost:** DIY runs about $15-50 in parts, 30-60 min. A pro service call runs about $120-250.
