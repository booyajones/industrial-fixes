## Samsung Range E-55 Error Code — What It Means

The E-55 error code on a Samsung range typically indicates a problem with the oven temperature sensing circuit. This code appears when the control board detects an abnormal signal from the oven temperature sensor or when there is a communication fault within the temperature monitoring system. The range may stop heating or refuse to start a cook cycle when this fault is active.

Because Samsung uses different control architectures across its range lineup, the exact meaning of E-55 can vary by model. Consult your owner's manual or the wiring diagram inside the appliance to confirm the fault definition for your specific model number. In most cases the error points to the sensor, its wiring, or the main control board.

## Before You Replace Anything

Many people replace the control board first when the real problem is a faulty sensor or a loose connector at the sensor harness. Test the sensor resistance with a multimeter before buying any part.

## Common Causes

- **Faulty oven temperature sensor (~55%)** The sensor probe develops an open or short circuit, sending incorrect resistance values to the control board and triggering the error.
- **Loose or corroded sensor wiring (~25%)** The connector at the back of the range or the harness itself becomes oxidized or works loose, interrupting the signal path.
- **Failed main control board (~15%)** The microprocessor or analog-to-digital converter on the board fails and cannot read the sensor input correctly.
- **Damaged wiring harness (~5%)** Heat or rodent damage shorts or breaks the wires running from the sensor to the control board.

## Step-by-Step Fix {#fix}

1. **Disconnect power** at the circuit breaker or unplug the range from the wall outlet.
2. **Remove the rear access panel** by unscrewing the sheet-metal screws around the perimeter. Set the panel and screws aside.
3. **Locate the oven temperature sensor** at the back of the oven cavity. It is a metal probe that extends into the oven, with two wires running to a connector near the control board.
4. **Disconnect the sensor plug** and inspect both the plug and socket for corrosion, burn marks, or bent pins. Clean with electrical contact cleaner if needed.
5. **Test the sensor resistance** using a multimeter set to ohms. At room temperature the sensor should read in the range typical for thermistors. Consult your model's service manual for the exact specification.
6. **Replace the sensor** if the resistance is open, shorted, or far outside the expected range. Remove the mounting screw inside the oven, pull the old sensor out, and slide the new one into place. Secure with the screw and reconnect the plug.
7. **Reassemble the rear panel**, restore power, and run a bake cycle. The error should clear if the sensor was the problem. If the code returns, inspect the wiring harness for shorts or consider control board replacement.

## When to Call a Pro

Call a professional if you are uncomfortable working inside the range chassis, if you cannot locate the sensor or access the back panel, or if the error persists after replacing both the sensor and checking all wiring. A technician can perform circuit-level diagnostics on the control board and has access to the full wiring schematic for your model. Also call a pro if you smell gas, see sparking, or if the range shares a high-voltage connection you are not confident isolating safely.

**Rough cost:** DIY runs about $20-80 in parts, 30-60 min. A pro service call runs about $150-280.
