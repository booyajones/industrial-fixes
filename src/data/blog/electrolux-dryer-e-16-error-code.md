## Electrolux Dryer E16 Error Code — What It Means

The E16 error code on Electrolux dryers typically indicates a communication problem between the user interface control board and the main electronic control board, or an internal fault within one of the control boards. The exact meaning can vary by model, so consult your owner's manual or the wiring diagram on the back panel for specifics.

This code usually appears when the two boards cannot exchange data reliably, often due to a loose or corroded wire harness, a damaged connector, or a failed control board. The dryer may not start, or it may halt mid-cycle and display the code on the control panel.

## Before You Replace Anything

Many people replace the main control board first. Always inspect and reseat every harness connector and check for visible damage or corrosion before ordering any board, since a poor connection is far cheaper to fix.

## Common Causes

- **Loose or corroded wire harness (~50%)** The ribbon cable or plug connecting the UI board to the main control board works loose from vibration or develops corrosion at the pins, blocking communication.
- **Failed user interface control board (~25%)** The UI board stops sending or receiving signals due to a failed processor or cracked solder joint, triggering the communication fault.
- **Failed main electronic control board (~20%)** The main board's communication circuit fails, preventing it from talking to the UI board and logging the E16 code.
- **Damaged wire harness (~5%)** The ribbon cable or wiring inside the harness is cut, pinched, or frayed, breaking one or more data lines and stopping communication.

## Step-by-Step Fix {#fix}

1. **Disconnect power** by unplugging the dryer or switching off the circuit breaker at the panel.
2. **Remove the top or rear access panel** using a screwdriver or nut driver to expose the control boards and wiring harnesses.
3. **Locate the ribbon cable or wire harness** running between the user interface board (behind the control panel) and the main control board (usually on the rear or side wall).
4. **Disconnect and reconnect each connector firmly** at both ends, inspecting the pins for corrosion, bent contacts, or debris.
5. **Inspect the harness itself** for cuts, pinches, or frayed insulation, and replace the harness if any damage is visible.
6. **Restore power and run a test cycle** to see if the E16 code clears; if it does not, proceed to board replacement.
7. **Replace the user interface board first** if connectors are clean and intact, since it is easier to access and often the culprit; if the code persists, replace the main control board.

## When to Call a Pro

Call a technician if you are uncomfortable working with control boards or if the dryer exhibits other symptoms such as tripped breakers, burning smells, or intermittent power loss. A professional can use diagnostic software and a multimeter to isolate the faulty board quickly, saving you the cost of trial-and-error part swaps. If the dryer is still under warranty or you are unsure which board to replace, a service call will often pay for itself by ensuring the right repair the first time.

**Rough cost:** DIY runs about $80-200 in parts if a control board is needed, 45-90 min. A pro service call runs about $150-350.
