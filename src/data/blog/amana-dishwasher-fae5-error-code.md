## Amana Dishwasher FAE5 Error Code — What It Means

The FAE5 error code on an Amana dishwasher indicates that the cycle has ended, the machine has drained, and the control has detected a fault. Amana's official guidance is to press Cancel twice and then start a new cycle. This code appears on Amana, Whirlpool, Maytag, and JennAir dishwashers using the same control platform, which suggests it is a shared system fault rather than a unique Amana issue.

The manufacturer documentation does not specify the exact component or sensor involved. In practice, FAE5 often behaves like a transient control or communication glitch that clears after a reset. If the code returns immediately after restarting, it points to a real underlying hardware or wiring problem rather than a one-time event. Technicians sometimes see recurring FAE5 codes tied to water inlet issues or flood sensor activation, but those interpretations are not confirmed by Amana's published help and should be verified through model-specific diagnostics.

## Common Causes

- **Transient control glitch** A one-time communication or timing error in the control board that clears when you cancel and restart the cycle.
- **Wiring or harness issue** A loose connector or damaged wire between the control and another component, causing intermittent faults.
- **Water inlet system fault** A problem with the fill valve, supply hose, or household water pressure that prevents proper filling, though this is not manufacturer-confirmed for FAE5.
- **Flood sensor or base water** Water in the dishwasher base activating the anti-flood switch, though this explanation conflicts with other sources and is not verified by Amana.
- **Failed control board** A defective electronic control that repeatedly throws the code even after reset and power cycle.

## Step-by-Step Fix {#fix}

1. **Press Cancel twice** exactly as Amana instructs, then wait a few seconds and start a new wash cycle to see if the code clears.
2. **Turn off the dishwasher at the circuit breaker** for at least 60 seconds if the code returns immediately, then restore power and try another cycle.
3. **Watch the cycle timing** to confirm the dishwasher completes a full cycle, drains normally, and only then displays FAE5, which matches the manufacturer description.
4. **Check for standing water in the base** by removing the lower access panel or toe kick and inspecting for moisture or pooled water that might trigger a flood sensor.
5. **Inspect the water supply** by turning off power, disconnecting the inlet hose at the valve, and confirming household water pressure is adequate and the hose screen is not clogged.
6. **Run service diagnostics** using the tech sheet behind the door or inside the tub rim to enter diagnostic mode and check for stored fault codes or sensor readings.
7. **Replace the electronic control or implicated component** only after diagnostics confirm a specific failed part, since FAE5 does not uniquely identify a single replaceable item.

## When to Call a Pro

Call a professional if the FAE5 code returns after you press Cancel twice and power-cycle the dishwasher, or if you are not comfortable removing panels and testing electrical components. Because Amana's published help does not identify the specific sensor or part responsible, accurate diagnosis usually requires the model's tech sheet, a multimeter, and familiarity with the control platform. If you see water in the base, unusual noises, or the machine fails to fill or drain, a technician can run factory diagnostics and pinpoint the failed component without replacing parts by trial and error.
