## Maytag Dryer F28 Error Code — What It Means

The F28 error code on a Maytag dryer appears in the official error-code list but Maytag's published dryer help page does not define the exact circuit or component that failed. The page provides only a reset procedure, which suggests F28 is most likely a stored electronic fault or a communication glitch between control components rather than a sensor or airflow problem. Maytag directs you to power-cycle the dryer at the breaker, then start a Timed Dry cycle and watch for one minute to confirm the code does not return.

Because the official dryer documentation does not spell out the underlying cause, the exact meaning can vary by model family. If the code returns after the reset, the next step is to pull the service tech sheet (usually taped inside the console or drum) and consult the wiring diagram and fault table for your specific model number. Do not assume F28 has the same definition as washer codes or other brands' dryer codes.

## Before You Replace Anything

Some technicians replace the main control board or user-interface board without testing. Always perform the breaker reset and Timed Dry test first, then check connectors and harness continuity with a meter before ordering any board.

## Common Causes

- **Stored electronic fault or noise event (~40%)** A power surge, momentary brownout, or static discharge can leave a fault code in memory that clears with a proper breaker reset.
- **Loose or corroded harness connector (~25%)** Vibration can loosen the plug between the main control board and the user-interface board or between the control and the motor relay, triggering a communication fault.
- **Faulty main control board (~20%)** Solder cracks or failed relay drivers on the main control board can interrupt internal communication paths and log an F28.
- **Faulty user-interface board (~10%)** A failed membrane switch or microcontroller on the console board can prevent the main board from receiving button signals.
- **Damaged wire harness (~5%)** A pinched or chafed wire between control boards can create intermittent open or short circuits that the control interprets as a communication error.

## Step-by-Step Fix {#fix}

1. **Turn off both circuit breakers** (or unplug the dryer if it uses a cord) and wait a full five minutes to discharge capacitors and clear memory.
2. **Turn the breakers back on** and verify the console lights up normally.
3. **Select a Timed Dry cycle** (any heat setting) and press Start.
4. **Watch the display for one full minute** to confirm F28 does not reappear and the drum begins to tumble.
5. **If the code returns immediately**, unplug the dryer and open the console or rear panel to access the control boards.
6. **Inspect every harness connector** between the console board and the main control board for loose pins, corrosion, or melted plastic, and reseat each plug firmly.
7. **Check for pinched or chafed wires** along the harness routes, especially where the bundle passes through a metal bracket or behind the drum.
8. **If connectors and wiring are intact**, locate the service tech sheet (often taped inside the console or on the blower housing) and follow the F28 diagnostic table to test voltages or resistance values at the control boards.
9. **Replace only the component** identified by the tech sheet's test results, then repeat the breaker reset and Timed Dry test to verify the repair.

## When to Call a Pro

Call a technician if the code returns after the breaker reset and you do not have the service tech sheet for your model, or if you are uncomfortable working inside the control console with live 120 or 240 VAC present during voltage tests. A qualified appliance technician will have access to the model-specific wiring diagram and fault table, can perform live voltage measurements safely, and will order the correct board the first time. Professional diagnosis is especially important if your dryer is still under warranty, because opening the cabinet yourself may void coverage on control components.

**Rough cost:** DIY runs about $0–150 in parts if a connector or board is needed, 30–90 min. A pro service call runs about $150–350 for diagnosis and board replacement if required.
