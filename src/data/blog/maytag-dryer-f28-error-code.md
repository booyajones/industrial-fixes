## Maytag Dryer F28 Error Code — What It Means

The F28 error code on a Maytag dryer does not have a published fault definition in Maytag's official product help documentation. The manufacturer's guidance instructs you to perform a power reset by shutting off the circuit breaker for five minutes, restoring power, and then running a timed dry cycle for one minute to see if the code clears. If the code returns after the reset, the issue requires model-specific diagnostics using the technical service sheet or service manual, because Maytag does not publish detailed troubleshooting steps for F28 in public-facing support materials.

## Common Causes

- **Temporary control board glitch** A transient electronic fault in the main control board can trigger F28 and often clears with a full power reset.
- **Moisture sensor failure** Some third-party sources suggest F28 may relate to a faulty moisture sensor, though this is not confirmed in Maytag's official documentation.
- **Wiring harness issue** A loose or corroded connection in the moisture sensor wiring harness can send incorrect signals to the control board.
- **Faulty user interface control** The user interface board may fail to communicate properly with the main control, causing error codes to appear.
- **Thermistor or drive motor fault** In some cases, a defective thermistor or drive motor can trigger non-specific error codes on certain Maytag dryer models.

## Step-by-Step Fix {#fix}

1. **Turn off power at the circuit breaker** and wait a full five minutes to allow the control board to fully reset.
2. **Restore power** by switching the breaker back on and wait for the control panel to light up.
3. **Select a timed dry cycle** on the control panel and start the dryer.
4. **Monitor the cycle for one minute** to verify whether the F28 code reappears on the display.
5. **If the code clears**, run a full test load to confirm normal operation and that the error does not return.
6. **If F28 returns**, locate the technical service sheet (usually taped inside the front panel or console) and follow the model-specific diagnostic flowchart for F28.
7. **Check all wire harness connections** to the moisture sensor strips, thermistor, and control boards for looseness or corrosion, and re-seat connectors as needed.

## When to Call a Pro

Call a qualified appliance technician if the F28 code returns after a full power reset or if you are uncomfortable opening the dryer cabinet to access the technical service sheet. Because Maytag does not publish detailed F28 diagnostics for the public, a technician with access to model-specific service manuals and diagnostic software can pinpoint the exact sensor, board, or wiring fault. Professional diagnosis is especially important if you have already replaced common parts without success or if your dryer is still under warranty.
