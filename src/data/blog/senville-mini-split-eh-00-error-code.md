## Senville Mini Split EH 00 Error Code — What It Means

The EH 00 error code on a Senville mini split indicates an indoor unit EEPROM malfunction. The EEPROM is a memory chip on the indoor control board that stores operating data and system settings. When this code appears, the indoor PCB is unable to communicate properly with its EEPROM memory. In many cases, a simple power reset will clear a temporary glitch. If the code returns after the reset, the indoor main PCB has failed and must be replaced.

## Common Causes

- **Failed indoor EEPROM chip** The EEPROM memory on the indoor control board has stopped responding or has corrupted data, preventing normal operation.
- **Indoor main PCB failure** The entire indoor control board has failed, which includes the EEPROM component that stores system settings and operating parameters.
- **Temporary control glitch** A transient electrical event or brief power interruption has corrupted the board state, triggering the code without permanent damage.
- **Loose or corroded board connectors** Poor connections at the indoor PCB harness terminals can interrupt communication between the board and memory chip.

## Step-by-Step Fix {#fix}

1. **Shut off all power** to the mini split system at the breaker or disconnect switch and wait at least two full minutes to allow the control board to fully discharge.
2. **Restore power** and observe the display on the indoor unit to see if the EH 00 code has cleared.
3. **If the code is gone**, monitor the system over the next 24 hours to confirm it does not return during normal operation.
4. **If EH 00 remains or returns**, turn off power again and remove the front cover of the indoor unit to access the main control board.
5. **Inspect all wiring connectors** on the indoor PCB for looseness, corrosion, or physical damage, and reseat each connector firmly.
6. **Replace the indoor main PCB** if the code persists after verifying all connections, as the EEPROM fault cannot be repaired separately from the board.
7. **Reassemble the unit**, restore power, and verify the system operates normally without the EH 00 code displayed.

## When to Call a Pro

Call a qualified HVAC technician if the EH 00 code returns after a power reset or if you are not comfortable working with live electrical components and control boards. Replacing the indoor main PCB requires handling line-voltage connections and matching the correct replacement part to your exact model. A technician can also verify that the fault is truly an EEPROM issue and not a misdiagnosed wiring or communication problem elsewhere in the system.
