## Fujitsu E:33 Error Code — What It Means

The E:33 code on a Fujitsu mini split indicates the indoor unit is detecting a shorted room-air (return-air) thermistor or a sensor circuit reading abnormally low. The thermistor measures the temperature of the air returning to the unit so the system can regulate heating and cooling accurately. When the control board sees an electrical short or near-zero resistance on this circuit, it cannot trust the temperature reading and throws the E:33 fault to prevent improper operation.

This code prevents the system from maintaining correct room temperature because the indoor controller has lost reliable feedback from the room sensor. The fault may be in the thermistor itself, the wiring harness, the connector terminals, or less commonly the indoor control board misreading a good sensor signal.

## Common Causes

- **Failed room-air thermistor** The sensor itself develops an internal short and reads zero or near-zero resistance regardless of actual temperature.
- **Pinched or damaged sensor wiring** The thermistor harness is crushed, cut, or abraded during installation or service, creating a short to ground or between conductors.
- **Loose or corroded connector** The thermistor plug at the indoor PCB has corroded terminals, moisture ingress, or a loose contact that intermittently shorts the circuit.
- **Faulty indoor control board** The PCB input circuit is damaged or misreading the sensor signal even when the thermistor and wiring test normal.
- **Installation error or improper routing** The sensor lead was routed too close to high-voltage wiring or trapped under a sharp edge during unit assembly.

## Step-by-Step Fix {#fix}

1. **Power down the mini split** at the breaker or disconnect switch and wait two minutes, then restore power and check whether the E:33 code clears or returns immediately.
2. **Clean or replace the return-air filter** and confirm the indoor coil and blower are clean, since restricted airflow can create misleading temperature readings even if it does not directly cause the code.
3. **Remove the indoor unit cover** and locate the room-air thermistor, a small bead sensor clipped to the return-air path or mounted near the evaporator inlet.
4. **Inspect the thermistor body, harness, and connector** for visible breaks, pinch points, corrosion, moisture, or a loose plug at the indoor PCB.
5. **Disconnect the thermistor from the control board** and measure the resistance across the sensor leads with a multimeter, comparing the reading to the expected resistance at the current room temperature (consult your model's service manual for the resistance table).
6. **Replace the room-air thermistor** if the resistance reads near zero (shorted) or far below the expected value for ambient temperature.
7. **Test the indoor PCB input circuit** if the sensor and wiring measure correctly but the code persists, and replace the control board only after confirming the sensor path is intact.
8. **Restore power, clear the fault code** (if your model requires a manual reset), and run a heating or cooling cycle to verify proper operation and stable room-temperature readings.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working inside the indoor unit with power off, if you do not own a multimeter or cannot interpret resistance readings, or if the thermistor and wiring both test normal but the code persists. A qualified tech will have the factory resistance tables, the correct OEM replacement sensors, and the tools to safely diagnose control-board faults. Also call a pro if the code clears but returns intermittently, since that points to a wiring or connector fault that requires careful tracing and repair to prevent future failures.
