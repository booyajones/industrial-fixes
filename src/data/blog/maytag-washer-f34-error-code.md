## Maytag F34 Error Code — What It Means

The F34 error code (sometimes displayed as rL or F34) on a Maytag front-load washer indicates that the control has detected items inside the drum when it expected the tub to be empty. This code appears specifically during the Clean Washer cycle, which is designed to run on an empty tub to clean the washer itself. The control checks for load at the start of the cycle and will not proceed if it senses clothing or other objects inside.

This is not a sensor resistance fault or a pressure switch problem. Maytag treats F34 as a load or contents issue. The code is the washer's way of reminding you that the Clean Washer cycle must run without any laundry or other items in the drum. Once you remove everything and restart the cycle, the code should clear.

## Before You Replace Anything

Homeowners sometimes suspect the pressure switch or control board and replace them unnecessarily. Before ordering parts, simply open the door, check for forgotten clothing or small items, remove everything, and restart the Clean Washer cycle.

## Common Causes

- **Laundry left in the drum (~75%)** The most common reason for F34 is clothing or towels left inside the washer when the Clean Washer cycle was started.
- **Small items in the tub (~15%)** Socks, washcloths, or other small pieces can be hidden in the drum folds or against the door seal and are easily overlooked.
- **Forgotten non-clothing items (~8%)** Items such as toys, rags, or packaging material left in the tub will trigger the code during the Clean Washer cycle.
- **Control not reset after clearing the drum (~2%)** Even after removing items, the code may persist until you power-cycle the washer or reselect the cycle.

## Step-by-Step Fix {#fix}

1. **Open the washer door** and visually inspect the drum for any clothing, towels, or other items.
2. **Check the door seal and drum folds** carefully for small items such as socks or washcloths that may be hidden.
3. **Remove all items** from the washer, making sure the drum is completely empty.
4. **Close the door** and press the Clean Washer cycle button again to restart the cycle.
5. **Observe the display** to confirm the F34 code has cleared and the cycle begins.
6. **If the code persists**, unplug the washer from the wall outlet for about one minute to perform a power reset.
7. **Plug the washer back in**, reselect the Clean Washer cycle, and verify that the code does not return and the cycle runs normally.

## When to Call a Pro

Call a professional if the F34 code returns repeatedly after you have confirmed the drum is empty and performed a power reset. In rare cases, a model-specific control logic issue or a related input problem may require diagnostic software or a service manual to resolve. A technician can check the control board and related wiring if the code persists without an obvious cause. For the vast majority of F34 errors, however, simply removing items from the drum and restarting the Clean Washer cycle will clear the fault immediately.
