## What this code means
The PF code on an Amana washer stands for Power Failure. The control detected that the machine lost power or experienced an interruption while a cycle was running. This is usually a status indication of an external power event, not evidence of a failed washer component.

Amana uses the same PF definition across its top-load washers and dryers. The code appears when utility power drops, a breaker trips, or the plug momentarily loses contact. If PF shows up without any known outage, the issue is most likely in your house wiring or receptacle rather than inside the washer itself.

## Before You Replace Anything

Homeowners sometimes replace the control board when PF recurs, but the real culprit is usually a loose plug, weak receptacle, or tripped breaker. Check the power supply and connection first before ordering any parts.

## Common Causes

- **Utility outage or house power interruption (~50%)** A brief grid flicker, brownout, or full outage cuts power to the washer mid-cycle and triggers the code.
- **Tripped breaker or unstable household supply (~25%)** An overloaded circuit or weak breaker can trip momentarily and reset itself, leaving only the PF code as evidence.
- **Loose plug or poor receptacle contact (~15%)** A plug that is not fully seated or a worn outlet can create intermittent disconnects that the control reads as a power failure.
- **Power-line noise or voltage sag (~10%)** Amana mentions that controls may detect line noise during an outage on dryers, and the same mechanism can apply to washer controls when supply voltage dips.

## Step-by-Step Fix {#fix}

1. **Press and hold START** to restart the interrupted wash cycle, or press POWER to clear the PF code from the display.
2. **Check the plug connection** at the wall receptacle and make sure the cord is fully seated with no visible damage or burn marks.
3. **Verify the breaker** in your electrical panel has not tripped and that no other high-draw appliances share the same circuit.
4. **Remove any extension cords or power strips** and connect the washer directly to a grounded outlet rated for the washer's amperage.
5. **Test the receptacle** with a multimeter or plug-in tester to confirm stable 120 V AC and proper ground continuity.
6. **Run a short test cycle** to see if the PF code reappears under normal operating conditions.
7. **Call an electrician** if the code returns with no known outage, indicating unstable house wiring, a weak breaker, or a failing receptacle.

## When to Call a Pro

Call a licensed electrician if the PF code recurs with no known power outage and you have already verified a tight plug connection and stable breaker. Recurring PF with stable incoming power suggests hidden wiring faults, voltage sags under load, or a receptacle that intermittently loses contact. An electrician can measure voltage under load, test for line noise, and inspect connections inside the panel. If the electrician confirms clean, stable power and the code still appears, contact an appliance technician to test the control board for power-supply sensitivity or an internal fault, but that scenario is much less common than a house-wiring issue.

**Rough cost:** DIY runs about $0 if power-supply fix; $20-40 if replacing a cord or outlet. A pro service call runs about $100-200 for an electrician to diagnose unstable house wiring.
