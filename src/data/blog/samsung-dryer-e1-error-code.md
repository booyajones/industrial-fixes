## Samsung Dryer E1 Error Code — What It Means

The E1 error code on a Samsung dryer indicates that the thermistor resistance is too low or the thermistor circuit is shorted. The thermistor is a temperature sensor that monitors heat inside the drum. Samsung specifies that a healthy thermistor should read 50 kΩ at 20°C (68°F). This code can also be triggered by a restricted vent system or clogged lint filter that affects the sensor reading, because poor airflow changes the thermal environment the thermistor monitors.

## Common Causes

- **Clogged lint filter** A blocked lint filter restricts airflow and can cause incorrect thermistor readings that trigger the E1 code.
- **Restricted exhaust vent** Kinked, crushed, or lint-clogged vent ducting prevents proper exhaust and affects temperature sensor performance.
- **Shorted thermistor** Internal failure or damaged wiring in the thermistor circuit causes resistance to drop below the normal 50 kΩ specification.
- **Failed thermistor (single or Flex unit)** On Flex dryers, either the top or bottom thermistor may fail depending on which section shows the error.

## Step-by-Step Fix {#fix}

1. **Power down the dryer** and unplug it from the wall outlet, then wait 60 seconds before restarting to clear any transient fault.
2. **Remove and clean the lint filter** thoroughly under running water if fabric softener residue is present, then let it dry completely before reinstalling.
3. **Inspect the entire exhaust vent system** from the dryer outlet to the exterior hood, removing any kinks, crushing, or lint buildup that restricts airflow.
4. **Access the thermistor** by removing the rear or front panel (consult your model's service manual), then disconnect the two-wire connector from the thermistor.
5. **Measure thermistor resistance** with a multimeter set to ohms, confirming it reads 50 kΩ at room temperature (20°C or 68°F).
6. **Check the wiring harness** from the thermistor to the main control board for pinched, burnt, or bare wires that could create a short circuit.
7. **Replace the thermistor** if resistance is significantly below 50 kΩ or if continuity to ground indicates a short, then reassemble the dryer and run a test cycle.

## When to Call a Pro

Samsung recommends professional service if the E1 code persists after you have cleaned the lint filter and exhaust vent system. If you measure thermistor resistance and it falls outside the 50 kΩ specification but you are not comfortable working inside the dryer cabinet or handling live electrical connections, contact a Samsung-certified technician. On Flex dryers with separate top and bottom thermistors, identifying and replacing the correct sensor requires some disassembly experience, so professional help is a good choice if you are unsure which section is affected.
