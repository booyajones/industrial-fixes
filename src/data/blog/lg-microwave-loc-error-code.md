## LG Microwave LOC Error Code — What It Means

LOC on an LG microwave is not a fault code. It indicates the control lock or child lock feature is currently enabled. This is a user-activated safety feature that prevents accidental operation by locking the control panel. The microwave will not respond to any button presses except the unlock command while LOC is displayed.

LG states that LOC indicates the lock function is turned on. The unit is unlocked by pressing and holding the STOP/CLEAR button until the LOC message disappears from the display. This is a normal operating mode, not an internal component failure.

## Before You Replace Anything

Homeowners sometimes call for service or consider replacing the control board when LOC appears, thinking it is a failure code. Simply press and hold STOP/CLEAR to unlock before assuming any part has failed.

## Common Causes

- **Lock feature enabled by user (~85%)** Someone in the household pressed and held the lock button (STOP/CLEAR) long enough to activate the child-lock safety feature.
- **Accidental button hold (~10%)** A key was held long enough during cleaning or other contact to trigger the lock function on the model.
- **Stuck keypad button (~4%)** A mechanically stuck button on the control panel keeps the lock engaged or causes it to re-enable immediately after unlock.
- **Failing touch panel or control board (~1%)** The touch panel or main control board registers phantom presses that re-lock the unit even after the unlock procedure.

## Step-by-Step Fix {#fix}

1. **Verify the display** shows LOC and not another code. Confirm you are looking at the correct message on the control panel.
2. **Press and hold STOP/CLEAR** continuously until the LOC message disappears from the display. This typically takes 3 to 5 seconds.
3. **Test the microwave** by pressing any button. If the panel responds, the lock has been successfully deactivated and no further action is needed.
4. **Power-cycle the unit** if the lock does not clear. Unplug the microwave from the wall outlet, wait 30 seconds, plug it back in, and retry the unlock procedure.
5. **Inspect the keypad** for stuck or sticking buttons if LOC returns immediately. Press each key individually to check for mechanical binding or debris underneath.
6. **Consult the owner's manual** for your exact model if the unlock procedure differs. Some LG models may use a different button sequence, though STOP/CLEAR is standard.
7. **Call for service** if the lock will not clear after power cycling and the keypad shows no obvious stuck buttons. A failing touch panel or control board may require professional diagnosis and replacement.

## When to Call a Pro

Call a professional if the LOC code will not clear using the STOP/CLEAR button and a power cycle, or if the code returns immediately after unlocking. A technician can diagnose whether the issue is a stuck keypad, a failing touch panel, or a faulty main control board. Also call for service if you are uncomfortable working with the control panel or if the microwave is still under warranty. For a simple lock activation, no service call is needed. The unlock procedure is a normal user operation and does not require any tools or technical skill.

**Rough cost:** DIY runs about $0, 10 seconds. A pro service call runs about $0-150 if a stuck keypad requires service.
