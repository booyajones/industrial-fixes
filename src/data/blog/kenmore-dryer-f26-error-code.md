## Kenmore Dryer F26 Error Code — What It Means

The F26 error code on a Kenmore dryer indicates the control board is reading an open door-switch circuit or an invalid door-latch state. The control treats the door as not safely closed, so it will not allow any cycle to start.

This is a safety interlock fault. The door switch must report a closed state before the dryer can begin operation. When F26 appears, the dryer is protecting against drum rotation while the door is open or improperly latched.

## Before You Replace Anything

Homeowners often replace the control board first. Before ordering any electronics, test the door switch for continuity with a multimeter. A $15 door switch fixes most F26 faults.

## Common Causes

- **Failed door switch (~60%)** The switch fails to close the circuit when the door is latched, or it reads open in both positions.
- **Broken or misaligned door latch/striker (~25%)** The plastic latch hooks or striker are cracked, deformed, or missing, so the switch plunger is never fully pressed.
- **Open wiring harness connection (~10%)** A broken conductor or loose connector between the door switch and the control board interrupts the circuit.
- **Control-board fault (~5%)** If the switch, latch, and wiring all test good, the control electronics may not be reading the closed-door signal correctly.

## Step-by-Step Fix {#fix}

1. **Unplug the dryer** from the wall outlet to kill power before any disassembly or testing.
2. **Open and close the door slowly** and listen for a distinct latch click. Inspect the latch hooks and striker for cracks, deformation, or missing plastic pieces.
3. **Locate the door switch** (usually mounted near the door opening on the cabinet frame). Disconnect the wire-harness connector from the switch.
4. **Set a multimeter to continuity or resistance mode**. With the door open and the switch plunger released, probe the switch terminals. You should read open (infinite resistance). Press the plunger fully and confirm the meter shows continuity (near zero ohms). If the switch reads open in both positions or closed in both positions, replace the door switch.
5. **If the switch tests good, check harness continuity** from the door-switch connector pins back to the control-board connector. An open wire indicates a wiring-harness fault.
6. **Reassemble the harness and close the door**. If you have access to the control board, measure resistance between terminals P8-3 and P8-4 with the door properly closed. You should see about 0–2 ohms. A higher reading confirms an open in the door-switch circuit.
7. **Replace the faulty component** (door switch, latch assembly, or harness). Restore power and run a test cycle to verify the F26 code clears and the dryer starts normally.

## When to Call a Pro

Call a technician if you are not comfortable using a multimeter to test continuity, if you cannot access the door switch or control board safely, or if the switch and latch both test good but the code persists. A technician can verify harness integrity and control-board signal processing without bypassing the safety interlock. Do not bypass the door switch to run the dryer. It is a safety device that prevents drum operation with the door open.

**Rough cost:** DIY runs about $10–$30 in parts, 20–40 min. A pro service call runs about $120–$220.
