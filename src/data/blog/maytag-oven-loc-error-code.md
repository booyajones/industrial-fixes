## Maytag Oven LOC Error Code — What It Means

LOC on a Maytag oven is not a failure code. It means the Control Lock feature is enabled. When you see LOC, the oven's control pads are disabled and the oven door is locked to prevent unintended use. The display shows LOC any time you press a button while the control is locked, even though nothing is broken.

If the oven is already cooking, Maytag says the controls and door cannot be locked. This is a safety feature, not a component fault, and under normal conditions it requires no parts or repair.

## Before You Replace Anything

Homeowners sometimes replace the control board or user interface thinking LOC is a fault code. Always try the unlock sequence (hold START for 5 seconds) and a power reset before ordering any parts.

## Common Causes

- **Accidental Control Lock activation (~70%)** A user pressed and held the lock button or START key, locking the control panel and oven door.
- **Pressed buttons while already locked (~15%)** Touching any pad while the control is locked makes LOC appear again, giving the impression of a new fault.
- **Power interruption or nuisance state (~10%)** A brief power outage or surge left the control in a locked state that a power reset can clear.
- **Unresponsive control after correct unlock attempt (~5%)** If the standard unlock sequence and power reset do not clear LOC, the control panel or electronic control board may need troubleshooting.

## Step-by-Step Fix {#fix}

1. **Confirm the display shows only LOC** and no other fault code letters or numbers. If you see F1, F3, F9, or another code, this is not a Control Lock issue and you need to diagnose that specific fault.
2. **Turn off the oven and timer** if they are running. Maytag says you cannot unlock the control while a cycle is active.
3. **Press and hold the START button (or START/ENTER pad) for 5 seconds** until you hear a tone and LOC disappears from the display. On some models the unlock key may be labeled differently, so consult your Owner's Manual if START does not work.
4. **Test the control pads** by pressing any button. If the oven responds, the control is unlocked and no further action is needed.
5. **Reset power if the control does not respond**. Turn off the oven's circuit breaker at the electrical panel and wait one full minute. Restore power, then wait another minute and check if LOC has cleared.
6. **Verify normal operation** by selecting a function or temperature. If the oven accepts commands and heats, the issue is resolved.
7. **If LOC remains after unlock and power reset**, the control panel or electronic control board may have a fault. At this point the problem is no longer a simple lock condition and you should consult the service data for your model or call a technician to troubleshoot the keypad interface and control wiring.

## When to Call a Pro

Call a technician if the standard unlock sequence (hold START for 5 seconds) and a full power reset do not clear LOC, or if the control panel remains unresponsive after those steps. At that stage the issue is no longer a simple Control Lock condition and requires diagnosis of the keypad interface, control board, and wiring harness using the model's service manual. Also call a pro if you see LOC together with another fault code, because that combination may indicate a more complex control failure. For a straightforward LOC message with no other symptoms, unlocking the control is a simple DIY task that takes under five minutes and costs nothing.

**Rough cost:** DIY runs about $0, 1-5 minutes. A pro service call runs about $75-150 service call if unlock fails and control requires troubleshooting.
