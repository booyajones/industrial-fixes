## Maytag Refrigerator dE Error Code — What It Means

The dE code is a door error indication. The refrigerator's control board is not receiving the door switch signal it expects, or it detects an abnormal door-related input. This typically means the door switch is faulty, the door is not closing properly, or the wiring harness at the hinge is damaged. The code can also appear if the door gasket is bad or the cabinet is not level, preventing a complete seal.

[Jump to Fix](#fix)

## Common Causes

- **Defective door switch** The switch is stuck, physically damaged, or failing to report the correct open/closed state to the control board.
- **Door not closing or sealing** A bad gasket, cabinet out of level, misaligned door, or obstruction prevents the door from making full contact.
- **Pinched or broken wiring harness** Wires at the door hinge flex area can break or short, interrupting the door-switch signal path.
- **Door misalignment or hinge issue** Loose hinges or a sagging door prevent the switch from actuating correctly when the door closes.
- **Control or user-interface board fault** If the switch and harness test good, the UI or main control board may have a door-input circuit failure.

## Step-by-Step Fix {#fix}

1. **Unplug the refrigerator** for at least 5 to 10 minutes to reset the control, then restore power and verify the dE code clears or returns.
2. **Inspect door closure mechanically** by confirming the door shuts fully, nothing blocks the seal, and the cabinet is level front to back and side to side.
3. **Check the door gasket** all the way around for tears, gaps, or a weak magnetic seal that would let the door hang open slightly.
4. **Test the door switch** with a multimeter for continuity when actuated, and confirm it clicks or changes state when the door opens and closes.
5. **Examine the hinge wiring harness** for pinched, broken, or corroded wires where the harness flexes between the cabinet and door.
6. **Replace the faulty component** (switch, gasket, or harness) after confirming which input path is open or shorted.
7. **Consult the tech sheet** for your model number if the fault persists after mechanical and electrical checks, then consider replacing the user interface or main control board.

## When to Call a Pro

Call a technician if you are not comfortable working with live voltage or if the dE code returns after you have confirmed the door closes fully, the switch tests good, and the harness has no visible damage. Control-board diagnosis requires a tech sheet and sometimes a scan tool to read door-input status. If your refrigerator is still under warranty, contact Maytag service before replacing any boards to avoid voiding coverage.
