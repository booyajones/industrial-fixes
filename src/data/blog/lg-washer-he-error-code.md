## What this code means
HE on an LG washer indicates a temporary heater error. The code is specific to the heating system in the washer or, on combo washer-dryer units, the dryer heating section. LG does not publish detailed subcodes or component breakdowns for HE in consumer support materials, so the code alone confirms a heater-related fault but does not identify the exact failed part.

LG's official guidance is clear: if the code repeats after a reset, the washer needs professional service rather than further user troubleshooting. The fault may be in the heater element, its wiring harness, a thermal safety device, or the control board's heater command circuit. On combo units, the fault may be in the drying heater rather than the wash heater.

## Before You Replace Anything

Homeowners sometimes replace the control board first when the real fault is a failed heater element or corroded connector. Before ordering parts, a technician should test heater-circuit continuity and inspect all harness connections.

## Common Causes

- **Heater circuit interruption (~50%)** An open or high-resistance heater element, failed thermal cutout, or loose connector prevents current flow and triggers the code.
- **Damaged or corroded heater wiring (~25%)** Intermittent connections in the heater harness produce temporary faults that log as HE.
- **Control board heater-command failure (~15%)** The main control may fail to drive or read the heater circuit correctly, which is why LG advises service if the code persists.
- **Combo-unit drying heater fault (~10%)** On washer-dryer combos, the HE code can originate in the drying heater rather than the wash heater.

## Step-by-Step Fix {#fix}

1. **Power off and unplug** the washer completely. Wait at least 10 seconds to allow the control board to reset.
2. **Restore power** and restart the cycle. Check whether the HE code clears and the cycle runs without interruption.
3. **Select a heated cycle** (hot wash or, on combo units, a drying cycle) to confirm the fault appears under heat demand, not just at startup.
4. **If HE returns**, stop the cycle and contact service. LG's guidance is that a repeating HE code requires professional diagnosis and repair.
5. **For technicians:** disconnect power, access the heater assembly, and measure element resistance and harness continuity. Inspect all connectors for corrosion or looseness.
6. **Replace the failed component** (heater element, thermal cutout, or wiring harness) or repair the wiring connection if continuity or insulation is compromised.
7. **Reassemble and retest** by running a full heated cycle. Verify the washer completes without re-logging HE.

## When to Call a Pro

Call a professional when the HE code returns after a reset. LG explicitly recommends service rather than DIY troubleshooting when the fault persists, because diagnosis requires testing the heater circuit under load, verifying element resistance and harness continuity, and confirming control-board heater-command signals. On combo washer-dryer units, a technician will need to isolate whether the fault is in the wash heater or the drying heater. These checks require disassembly, test equipment, and familiarity with LG's heater-circuit design. Heater-element replacement also involves working with live wiring and ensuring proper grounding and thermal-sensor placement, all of which are safer and faster in professional hands.

**Rough cost:** A pro service call runs about $150–350.
