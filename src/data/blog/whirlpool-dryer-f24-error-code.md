## Whirlpool Dryer F24 Error Code — What It Means

F24 is a generic dryer control fault code that Whirlpool does not tie to a specific component failure in its public help documents. The control has detected an internal fault or invalid operating condition. Whirlpool recommends a full power cycle and retest under load to determine whether the fault is transient or persistent.

[Jump to Fix](#fix)

## Common Causes

- **Transient control glitch** A stored fault in memory that clears after a complete power cycle, often caused by a brief voltage spike or random software hiccup.
- **Intermittent wiring or connector issue** Loose, corroded, or vibrating connectors at the main control or harness can trigger false faults under heat or motion.
- **Main control board fault** If the code returns immediately after reset, the control board itself has likely failed and needs replacement.
- **Moisture or heat damage** Water intrusion or excessive heat near the control enclosure can create short circuits or component failures that generate F24.

## Step-by-Step Fix {#fix}

1. **Turn off power at the circuit breaker(s)** and wait a full 5 minutes to allow the control to fully discharge and reset stored faults.
2. **Restore power at the breaker(s)** and check that the control panel lights come on normally.
3. **Start a Timed Dry cycle** using the dryer's standard controls and let it run for at least 1 minute.
4. **Watch for F24 to reappear.** If the code does not return and the dryer runs normally, the fault was transient and no further action is needed.
5. **If F24 returns immediately**, turn off power again and inspect all connectors at the main control board for loose pins, corrosion, or visible heat damage.
6. **Check supply voltage at the terminal block** with a multimeter to confirm the dryer is receiving proper line voltage (240 V AC for most models).
7. **Replace the main control board** if all wiring and voltage checks are normal and the code persists after reset.

## When to Call a Pro

If the F24 code returns after a power reset and you are not comfortable working inside a 240 V appliance, call a qualified technician. Diagnosing control faults requires safe access to live circuits, harness inspection, and board-level troubleshooting. Whirlpool recommends professional service when the code persists after the reset procedure. A technician can test supply voltage, inspect all connectors under the control panel, and determine whether the main control board or another component is at fault.
