## Fujitsu E:79 Error Code — What It Means

The E:79 code is not universally defined across all Fujitsu mini-split models, so its exact meaning depends on your specific unit and controller type. Fujitsu uses a code-family and sub-code system for fault reporting, and E:79 typically falls into the sensor or control circuit family. Based on similar Fujitsu fault patterns, this code likely indicates a problem with a thermistor (temperature sensor), its wiring harness, connectors, or the control PCB that reads the sensor signal. Always verify the code definition in your model's service manual before starting diagnosis, because fault codes vary between Fujitsu series and controller generations.

## Common Causes

- **Open or shorted thermistor** A temperature sensor that has failed internally shows infinite resistance (open) or near-zero resistance (short), triggering a circuit fault.
- **Loose or corroded connector** Moisture, dirt, or oxidation at the sensor plug or harness connector interrupts the signal path and mimics a sensor failure.
- **Damaged sensor harness** Wiring rubbed against sharp edges, chewed by pests, or pinched during installation creates an open circuit or intermittent connection.
- **Control PCB input failure** The circuit on the main or outdoor control board that reads the thermistor can fail even when the sensor and wiring test correctly.
- **Connector contamination or moisture** Water intrusion or debris in the outdoor unit compartment can bridge connector pins and short the sensor circuit.

## Step-by-Step Fix {#fix}

1. **Verify the exact model and controller type** by checking the indoor unit nameplate or wired remote, then look up E:79 in that model's service manual to confirm the fault definition.
2. **Power-cycle the system once** by turning off the breaker for 60 seconds, then restore power and note whether the E:79 code returns immediately or after a delay.
3. **Inspect all sensor connectors and harnesses** at the outdoor unit and affected indoor unit for loose plugs, corrosion, moisture, pinched wires, or damage from pests or installation.
4. **Measure the suspect thermistor resistance** by disconnecting the sensor and using a multimeter to compare the reading at current ambient temperature against the thermistor characteristics table in your service manual.
5. **Check harness continuity** from the sensor plug to the control board connector to confirm no open or high-resistance sections in the wiring.
6. **Test the control PCB input circuit** if the sensor and harness both measure correctly, because the board can fail to read a good sensor signal.
7. **Replace the failed component** only after electrical confirmation: swap the thermistor if it reads out of range, repair or replace the harness if continuity is lost, or replace the control PCB if the sensor circuit input is defective.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working with live 240 V circuits, do not have a multimeter and thermistor resistance chart for your model, or if the code persists after you have verified connectors and sensor readings. Misdiagnosing control board faults and swapping expensive parts without electrical confirmation wastes money. A qualified tech has the factory service manual, correct replacement sensors, and board-level diagnostic tools to pinpoint the root cause quickly and safely.
