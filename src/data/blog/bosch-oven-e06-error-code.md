## Bosch Oven E06 Error Code — What It Means

The E06 error code on a Bosch oven typically indicates a fault in the temperature sensing circuit. This can mean the oven temperature sensor (also called an RTD probe) is reading out of range, has failed, or has a wiring problem. The control board cannot accurately monitor oven temperature, so it stops heating and displays the code to protect the appliance.

Because Bosch uses different control systems across its oven models, the exact definition of E06 can vary. Always consult your specific model's service manual or wiring diagram to confirm the code meaning. In most cases, the problem is either a faulty sensor, a loose or corroded connector, or less often, a failed control board.

## Before You Replace Anything

Many people replace the control board first, which can cost over $200, when a simple sensor swap or connector cleaning would have fixed the issue. Test the sensor's resistance with a multimeter before buying a board.

## Common Causes

- **Failed temperature sensor (~55%)** The oven temperature sensor (RTD probe) has drifted out of specification or failed internally, sending incorrect resistance readings to the control board.
- **Loose or corroded sensor connector (~20%)** The plug between the sensor and the main wiring harness has oxidized contacts or has vibrated loose, creating an intermittent or open circuit.
- **Damaged sensor wiring (~12%)** The wire leading from the sensor to the control has been pinched, cut, or melted by heat from the oven cavity.
- **Failed control board (~10%)** The electronic control board has a faulty input circuit that cannot read the sensor correctly, even when the sensor itself is good.
- **Poor ground connection (~3%)** A corroded or loose ground wire prevents the control from completing the sensor circuit, causing erratic readings.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker and unplug the oven from the wall outlet if accessible.
2. **Remove the rear access panel** using a screwdriver, and locate the oven temperature sensor probe mounted inside the oven cavity (it looks like a thin metal rod protruding into the oven).
3. **Disconnect the sensor connector** from the wiring harness and inspect both the plug and socket for corrosion, burned contacts, or bent pins.
4. **Measure sensor resistance** using a multimeter set to ohms. At room temperature, consult your model's wiring diagram for the expected value (often around 1000-1100 ohms for RTD sensors).
5. **Inspect the sensor wire** along its entire length for cuts, pinches, or heat damage, especially where it passes through the oven wall.
6. **Replace the sensor** if resistance is out of range or if the wire is damaged. Match the part number stamped on the old sensor or use your oven's model number to order the correct replacement.
7. **Reassemble and test** by restoring power, setting the oven to bake at a moderate temperature, and confirming the error does not return and the oven heats normally.

## When to Call a Pro

Call a professional if you are uncomfortable working with electrical components or if you have tested the sensor and all connectors and they appear normal but the error remains. A technician can perform advanced diagnostics on the control board, check for voltage issues, and confirm the problem before ordering expensive parts. Also call a pro if the oven is still under warranty, as DIY repairs can void coverage.

**Rough cost:** DIY runs about $30-80 in parts, 30-60 min. A pro service call runs about $150-280.
