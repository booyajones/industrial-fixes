## Whirlpool Range LOC Error Code — What It Means

LOC on a Whirlpool range is not a fault code. It means the Control Lock feature is active. When LOC appears, the control pads are disabled and the oven door is locked to prevent unintended use. Whirlpool states that LOC can also appear when any command pad is pressed while the control is already locked.

This is a user-activated control state, not a component failure. The range is functioning as designed. To lock or unlock the controls, the oven and timer must be off. Touch and hold START/ENTER for 5 seconds. LOC appears when locked and disappears when unlocked. If the oven is currently in use, the controls and door cannot be locked.

## Before You Replace Anything

Homeowners sometimes replace the main control board or keypad thinking LOC is a fault code. Always attempt the unlock sequence (START/ENTER held 5 seconds) and a 1-minute breaker reset before replacing any parts.

## Common Causes

- **Accidental activation of Control Lock (~70%)** The START/ENTER pad was held long enough to enable the lock feature, either by a user or by something pressing against the control.
- **Pressing a pad while already locked (~15%)** A user pressed any keypad while the control was already in lock mode, which makes LOC reappear on the display.
- **Temporary electronic state after power interruption (~10%)** A power outage or breaker trip left the control in a locked state, which requires a deliberate unlock or power reset to clear.
- **Stuck or damaged keypad (~3%)** A keypad button is stuck in the pressed position or the membrane is damaged, causing the control to interpret a continuous lock command.
- **Control board misinterpreting keypad signals (~2%)** The main control board is reading erratic input from the user interface, triggering the lock state without a valid command.

## Step-by-Step Fix {#fix}

1. **Turn off the oven and timer.** Whirlpool states that the controls cannot be unlocked while the oven is in use. make sure no cooking cycle or timer is active.
2. **Press and hold START/ENTER for 5 seconds.** This is the model-correct unlock command. Watch the display. LOC should disappear when the lock is released.
3. **Test the keypad.** Press several buttons to confirm all pads respond and no error reappears. If LOC returns immediately, a button may be stuck or the control is reading phantom input.
4. **Perform a power reset if LOC persists.** Turn off the range circuit breaker at the panel. Wait 1 full minute. Restore power and let the control boot for 1 minute.
5. **Attempt the unlock sequence again.** With power restored, press and hold START/ENTER for 5 seconds. Check that LOC clears and the keypad functions normally.
6. **Inspect the keypad for stuck buttons.** Press each button individually. Look for any that do not spring back or feel spongy. Clean around the edges with a damp cloth if needed.
7. **Replace the user interface or control board if LOC returns.** If the unlock and reset steps do not resolve the issue, the problem is no longer the lock feature itself. A stuck keypad, damaged user interface, or control board fault is indicated. Consult your model's service manual for the correct replacement part number.

## When to Call a Pro

Call a technician if the unlock sequence and breaker reset do not clear LOC, or if LOC returns repeatedly after successful unlock. A pro can test the user interface ribbon cable, check for voltage irregularities at the control board, and confirm the door lock mechanism is not mechanically stuck. If you are uncomfortable working inside the control panel or identifying which board to replace, a service call will save you from ordering the wrong part. Technicians can also verify that the issue is truly LOC and not a different error code that looks similar on your display.

**Rough cost:** DIY runs about $0, 5 min if unlock works; $150-300 in parts if control board or keypad replacement is needed. A pro service call runs about $100-250 service call if unlock and reset fail.
