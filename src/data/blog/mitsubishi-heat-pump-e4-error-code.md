## Mitsubishi E4 Error Code — What It Means

On many Mitsubishi Electric heat pump models, the E4 error code indicates a remote controller transmission or signal receiving fault. The system detects this error when the main or sub remote controller cannot receive normal communication from the indoor unit (refrigerant address 0) for three continuous minutes. The outdoor unit LED board typically displays E4, while the remote controller itself may show E0. This is a communication fault, not a refrigeration or compressor problem. The exact meaning of E4 can vary across Mitsubishi model families, so always confirm the definition against your specific unit's service manual before starting repairs.

## Common Causes

- **Miswired remote controller connections** Incorrect polarity, crossed wires, or improper terminal assignments on the remote controller transmission wiring prevent normal signal flow.
- **Defective remote controller circuit** Failed transmitting or receiving circuit inside the remote controller itself stops communication with the indoor unit.
- **Faulty indoor controller board** The transmit or receive circuit on the indoor unit controller board for refrigerant address 0 has failed or degraded.
- **Loose or damaged wiring** Open connections, frayed insulation, pinched conductors, or corrosion along the remote controller transmission wire interrupt the signal.
- **Electrical noise or interference** EMI from nearby motors, fluorescent lights, or other sources corrupts the low-voltage communication signal on the remote controller wire.

## Step-by-Step Fix {#fix}

1. **Power cycle the system** by switching off the breaker for three minutes, then restore power and check whether the E4 code returns after the system restarts.
2. **Inspect all remote controller wiring** for loose connections, correct polarity, crossed wires, or physical damage along the entire run from indoor unit to remote.
3. **Verify wiring against the diagram** in your service manual to confirm each wire lands on the correct terminal and that no wires are swapped or shorted together.
4. **Test with a known-good spare remote controller** if available to isolate whether the fault is in the remote itself or in the indoor board and wiring.
5. **Check for electrical interference** by temporarily moving any motors, dimmers, or fluorescent fixtures away from the remote controller wire, and separate the communication wire from high-voltage lines.
6. **Replace the remote controller** if substitution testing confirms it is defective or if the transmit-receive circuit shows no continuity or abnormal readings.
7. **Replace the indoor controller board** if all wiring checks out and a new remote controller still triggers E4, indicating a failed transmit-receive circuit on the board for refrigerant address 0.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working with low-voltage wiring or interpreting wiring diagrams. Professional diagnosis is strongly recommended if basic power cycling and visual wiring checks do not resolve the fault, if you lack a spare remote controller for substitution testing, or if the indoor controller board requires replacement. Technicians have the correct Mitsubishi service manuals, diagnostic tools, and genuine replacement parts to pinpoint whether the fault lies in the remote, the board, or the wiring. Misdiagnosis or incorrect wiring can damage expensive control boards or void your warranty.
