## Samsung Dishwasher HE Error Code — What It Means

Samsung identifies the HE code as a heater error tied to incorrect temperature detection. The dishwasher control is not seeing the expected temperature rise during the wash cycle. The heating element is either not warming the water properly, or the thermistor (temperature sensor) is not reporting the change the control expects within the programmed time window.

This code stops the cycle because the dishwasher cannot complete the wash or dry phases without proper water temperature. Samsung's support guidance recommends emptying the dishwasher and running a normal cycle as a first test. If the error returns, the heating circuit needs service.

## Before You Replace Anything

Many people replace the control board first when the heater element or thermistor is actually faulty. Test the heater for continuity and the thermistor for stable resistance with a multimeter before ordering a new control board.

## Common Causes

- **Heating element open or weak** The heater has failed electrically and no longer warms the water, so the control never sees the expected temperature rise.
- **Thermistor out of range** The temperature sensor reads incorrectly or does not change as water warms, so the control thinks the heater is not working.
- **Loose or corroded wiring** Harness connectors to the heater or sensor are damaged, corroded, or not seated, breaking the circuit intermittently.
- **Control board heater relay failed** The main board cannot drive the heater or cannot interpret the sensor signal, even though the heater and thermistor test good.
- **Very cold inlet water** In rare cases extremely cold incoming water (well below typical household supply) can delay the expected temperature rise and trigger the code.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker or unplug the dishwasher and wait two minutes to reset the control.
2. **Empty the dishwasher** completely and run a Normal wash cycle without dishes to see if the HE code returns.
3. **Access the heater and thermistor** by removing the lower front panel or the dishwasher's base, depending on your model layout (consult your service manual for exact location).
4. **Inspect all wiring** to the heater and sensor for burn marks, corrosion, or loose connectors, and reseat every plug firmly.
5. **Test the heating element** with a multimeter set to resistance mode. If the element reads open (infinite resistance) or far outside the model's specification, replace it.
6. **Test the thermistor** by measuring its resistance and checking for a stable reading. If the value is out of range or jumps erratically, replace the sensor.
7. **Check the control board** if both the heater and thermistor test good. Look for burned traces, damaged solder joints, or a failed heater relay, and replace the board if defective.
8. **Reassemble and run a test cycle** with the tub empty to confirm the HE code does not reappear and water temperature rises normally.

## When to Call a Pro

Call a technician if you are not comfortable working with electrical components, if you cannot access the heater or thermistor location on your model, or if the heater and sensor both test within specification but the code persists. The repair involves disconnecting power, removing panels, and using a multimeter to test live and isolated circuits. A qualified appliance tech has the service manual, correct resistance tables, and tools to diagnose control-board faults safely. If the dishwasher is still under warranty, contact Samsung or an authorized service center before opening the machine.

**Rough cost:** A pro service call runs about $150-350.
