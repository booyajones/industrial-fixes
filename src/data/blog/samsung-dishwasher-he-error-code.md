## Samsung Dishwasher HE Error Code — What It Means

Samsung dishwasher HE, HE1, HE2, and HE3 codes all signal a heater error. The dishwasher has detected abnormal temperature in the heating circuit, either too hot or not heating correctly. Samsung's support documentation describes it as incorrect temperature detection, meaning the control board sees a temperature reading that falls outside normal operating limits.

The error can stem from the heating element itself, the temperature sensor (thermistor or thermostat), damaged wiring or connectors in the heater circuit, or occasionally a failed relay or output circuit on the main control board. In some cases, the code appears simply because very hot inlet water or residual heat from a recent cycle causes a false over-temperature trip.

## Before You Replace Anything

Many owners replace the main control board first, but a simple resistance test of the heating element (should read about 13.5 Ω) and a visual check of the heater wiring and connectors will identify the real fault in most cases.

## Common Causes

- **Faulty heating element (~40%)** The heater coil has failed open, shorted, or is drawing abnormal current, causing the control board to detect incorrect temperature or no heat rise.
- **Bad temperature sensor or thermistor (~25%)** The thermistor or thermostat is reading out of range or has failed, so the control sees abnormal temperature even when the heater is working correctly.
- **Loose, burned, or corroded heater wiring and connectors (~20%)** Damaged terminals or broken conductors in the heater circuit prevent proper current flow or cause intermittent resistance, triggering the error.
- **Overheating from hot inlet water or recent cycle (~10%)** Very hot water supply or residual heat from a prior wash can cause a false over-temperature trip until the tub cools down.
- **Failed main control board heater relay or output circuit (~5%)** The board's heater relay is stuck or the output drive circuit has failed, preventing proper heater operation or voltage delivery.

## Step-by-Step Fix {#fix}

1. **Confirm the error and clear false trips.** Empty the dishwasher, let it cool for at least 30 minutes, then run a normal cycle to see if the code returns.
2. **Inspect heater circuit wiring first.** Disconnect power, then check the heater terminals, wire harness, and control-board connectors for corrosion, burnt terminals, loose pins, or broken wires. Repair or replace damaged wiring before proceeding.
3. **Test the heating element resistance.** Disconnect the heater leads and measure resistance across the two heater terminals with a multimeter. A typical Samsung dishwasher heater reads about 13.5 Ω. If the reading is markedly different or infinite (open), replace the heater assembly.
4. **Verify heater output voltage from the control board.** With the dishwasher running (and proper safety precautions), measure AC voltage at the board heater output points (for example T101 and T102 on some models). You should see 120 VAC when the heater is energized. If voltage is present but the heater does not work, the heater or harness is faulty. If voltage is absent, suspect the main control board.
5. **Evaluate the temperature sensor if the heater tests good.** Samsung's error description points to abnormal temperature detection, which can mean a failed thermistor, thermostat, or sensor circuit. Consult your model's service data for the correct sensor resistance at room temperature, or replace the sensor if the heater and wiring are confirmed good.
6. **Replace the failed component and retest.** Install the new heater, sensor, harness, or control board as indicated by your test results, then run a full wash cycle to confirm the code does not return.

## When to Call a Pro

Call a professional if you are not comfortable working with 120 VAC or testing live circuits with a multimeter. The heater and control-board diagnostics require power-on voltage checks that carry shock risk. A technician has the tools and experience to safely measure heater output voltage, test the temperature sensor against factory specs, and trace wiring faults without damage. Professional service also makes sense if you have already replaced the heater and sensor but the code persists, since the fault may be in the control board's heater relay or a less obvious wiring path that requires a schematic and advanced troubleshooting.

**Rough cost:** A pro service call runs about $150-300.
