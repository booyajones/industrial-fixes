## Welbilt Ice Machine Error Codes — What They Mean

Welbilt is the parent company of Manitowoc Ice and Multiplex, two major commercial ice machine brands. Welbilt ice machines use the same error code conventions across Manitowoc Indigo and NEO series machines. This guide covers error codes across both Welbilt ice machine platforms.

## Most Common Welbilt/Manitowoc Ice Machine Fixes {#fix}

### Codes 1-3 / E01-E02 — Cycle Faults
Start with condenser cleaning — it resolves the majority of cycle fault calls. Clean condenser fins with a brush and compressed air. Verify condenser fan runs. Check ambient temperature (must be below rated max, typically 100°F for air-cooled).

### E04/E05 — High Condenser / High Pressure
Dirty condenser or failed condenser fan. Same root cause as cycle faults but more severe. Clean condenser and verify fan before calling for refrigerant service.

### E06 — Low Pressure
Low refrigerant. Find the leak and repair before recharging. Requires EPA 608-certified tech.

### Code 6 / E03 — Water Fill
Check supply shutoff is fully open, pressure is 20-80 PSI, and inlet valve screen is clean. Test solenoid coil resistance.

## When to Call a Pro

E05/E06 refrigerant faults require EPA 608 certification. All Welbilt/Manitowoc refrigerant work requires a certified technician.
