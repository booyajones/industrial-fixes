## GE Oven F96 Error Code — What It Means

The F96 code on GE wall ovens and double ovens indicates a cooling fan speed detection fault. The control board is trying to verify that the upper cooling fan is running at the correct speed, but it is not receiving the expected signal from the fan's speed sensor or tachometer circuit. The oven shuts down operation as a safety measure because it cannot confirm proper cooling airflow.

In practice, this means either the fan motor itself has failed and is not spinning, the hall-effect sensor board attached to the fan is not reporting speed correctly, or the wiring between the fan assembly and the control board has been disconnected or damaged. The fan system uses both a power connection to run the motor and a separate sensor connection to report rotational speed back to the control board. When that speed feedback is missing or out of range, the F96 fault is logged.

## Before You Replace Anything

Many homeowners replace the main control board first, assuming the error is electronic. Check the fan motor and sensor board wiring and test the fan assembly before replacing the control board, which is rarely at fault if the fan itself does not spin freely or is not properly connected.

## Common Causes

- **Failed cooling fan motor (~50%)** The upper oven cooling fan motor may hum, stall, or not start at all, preventing the control board from detecting rotation.
- **Failed hall-effect sensor or sensor board (~25%)** The speed-sensing board attached to the fan assembly can fail and stop reporting RPM data to the control board.
- **Loose, disconnected, or damaged harness (~15%)** The fan power or sensor connector may have been left unplugged, miswired, or corroded during prior service or installation.
- **Mechanical obstruction or binding (~7%)** Debris, a damaged fan wheel, or seized bearings can prevent the fan from reaching normal speed and generating proper feedback.
- **Faulty control board (~3%)** The main control board or interface board may fail to recognize a good fan signal, though this is rare if the fan assembly tests correctly.

## Step-by-Step Fix {#fix}

1. **Disconnect power** at the circuit breaker or unplug the oven completely before removing any panels or touching internal components.
2. **Locate and record your model number**, then pull up the GE parts breakdown for your exact double oven to identify the upper cooling fan assembly and any separate sensor board.
3. **Remove trim and access panels** as required for your installation to reach the upper oven cavity and the cooling fan mounting area.
4. **Inspect the fan mechanically** by checking for broken blades, foreign objects, or a wheel that will not spin freely by hand, and note whether the motor hums or is silent when powered.
5. **Check all electrical connections** to the fan motor and to the sensor or hall-effect board, verifying that both the power harness and the sensor harness are fully seated and that pins are not corroded or pushed back.
6. **Replace the upper cooling fan assembly** if the motor does not run or the sensor board is visibly damaged, transferring the sensor board to the new motor if your model uses a separate board.
7. **Restore power briefly** and listen for the fan to start, then check that the F96 code clears before reinstalling all panels and testing a full heating cycle.

## When to Call a Pro

Call a professional appliance technician if you are uncomfortable working around 240 V wiring, if the oven is built into cabinetry in a way that makes panel removal difficult, or if you have replaced both the fan assembly and the sensor board but the F96 code still appears. A technician can perform live voltage tests on the control board's fan output and sensor input to pinpoint a board-level fault without guessing. Also call for service if the oven is still under warranty, since DIY repairs can void coverage on newer GE wall ovens.

**Rough cost:** DIY runs about $80–$180 in parts, 1–2 hours. A pro service call runs about $200–$400.
