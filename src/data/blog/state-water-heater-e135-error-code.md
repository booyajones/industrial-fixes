## State Water Heater E135 Error Code — What It Means

E135 does not appear in verified State Water Heater manufacturer documentation as an official error code. State directs all users to scan the QR code printed on the unit's rating plate to access the model-specific manual, fault code list, and troubleshooting instructions. Without confirmation of what E135 means for your exact model, attempting repairs based on assumptions can lead to wasted time, incorrect part replacement, or safety hazards. The code may be specific to a particular series, a software revision, or even entered incorrectly during a service mode diagnostic. Always start by retrieving the official manual for your model number before interpreting any fault code.

## Common Causes

- **Code not recognized in manufacturer materials** E135 is not listed in the available State support documentation, so the meaning is unverified.
- **Model-specific code variation** Different State series use different fault code sets, and E135 may only exist in certain tankless or electronic models.
- **Display or control board misread** A partial display failure or button sequence may show an incorrect code that does not match the actual fault.
- **Manual or QR code not yet consulted** The rating plate QR code links to the exact manual and code definitions for your serial number and model.

## Step-by-Step Fix {#fix}

1. **Locate the rating plate** on the side or front of the water heater and find the model and serial number.
2. **Scan the QR code** on the rating plate with your smartphone to open the State support page and download the correct manual.
3. **Look up E135** in the fault code table of that manual to confirm its meaning, causes, and reset procedure.
4. **Record the operating conditions** when the code appeared, including whether the unit was heating, the inlet water temperature, and any unusual sounds.
5. **Perform any basic checks** listed in the manual, such as gas supply valve position, circuit breaker status, and water inlet filter condition.
6. **Follow the manual's reset instructions** exactly, then monitor the unit through a full heating cycle to see if the code returns.
7. **Contact State technical support** or a licensed technician if the manual does not list E135 or if the fault persists after following all steps.

## When to Call a Pro

Call a licensed plumber or gas technician immediately if you cannot locate your model manual, if E135 does not appear in that manual, or if the code returns after following all manufacturer reset steps. Any work on gas connections, venting, or electronic controls requires proper licensing and tools. Do not attempt to bypass safety interlocks or replace control boards without confirming the exact part number and fault condition. A technician can also contact State technical support directly with your serial number to obtain code definitions and service bulletins not available to the public.
