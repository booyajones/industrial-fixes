## LG Dishwasher CE Error Code — What It Means

The CE code points to a motor error or a loss of communication between the main control board and the motor sub-board. The dishwasher stops because the two boards are no longer talking, often from a wiring fault, a struggling pump motor, or a failed board.

[Jump to Fix](#fix)

## Common Causes

- **Loose board connector** A connector between the main board and the sub-board worked loose and broke the link.
- **Damaged wiring harness** Chafed or corroded wires between the boards and the motor drop the signal.
- **Motor overcurrent** A pump motor drawing too much current can force the boards to fault out with CE.
- **Failed sub-board** The motor or display sub-board can fail and stop responding to the main board.
- **Failed main control board** A bad main PCB loses its handshake with the rest of the system.
- **Power surge** A surge or brownout can scramble the board communication until reset.

## Step-by-Step Fix {#fix}

1. Press POWER off, then switch the dishwasher breaker off for 10 seconds
2. Turn the breaker back on, power up, and start a new cycle to clear a glitch
3. If CE returns, open the door panel and reseat the connectors between the boards
4. Inspect the wiring harness from the boards to the motor for chafing or corrosion
5. Check the pump motor for a jam that could be pulling excess current
6. Replace the control board if wiring and motor both test good
7. Run a cycle and confirm CE stays clear

## When to Call a Pro

If reseating connectors and checking wiring does not clear CE, board-level diagnosis is the next step. A technician can confirm whether the main board, the sub-board, or the motor is the failed part before you replace expensive electronics.
