## LG Range E4 Error Code — What It Means

On LG ranges, E4 typically indicates a thermistor or oven temperature sensor fault. LG's official range error documentation lists thermistor errors as a key fault category, though E4 is not universally defined across all LG appliances. If your unit is an LG Styler rather than a range, E4 means the heater inside the steaming device has failed. For an actual range, the code points to a problem in the oven's temperature sensing circuit, which prevents the control board from accurately monitoring or regulating oven heat.

## Common Causes

- **Failed oven thermistor or temperature sensor** The sensor that monitors oven temperature has shorted, opened, or drifted out of specification, which is the primary replaceable part identified in LG's range support material.
- **Damaged or loose sensor wiring** The harness between the sensor and control board has corroded terminals, pinched insulation, heat damage, or a loose plug, preventing accurate signal transmission.
- **Connector or pin corrosion** Moisture or heat has corroded the sensor connector pins or the mating socket on the control board, creating an open or high-resistance path.
- **Control board or control system fault** The main oven control or appliance manager board has a failed sensor input circuit or damaged trace, misinterpreting a healthy sensor as faulty.
- **Incorrect code interpretation** If your appliance is an LG Styler, E4 means the steaming heater has failed due to mineral scale, poor water quality, or detergent contamination, not a range thermistor issue.

## Step-by-Step Fix {#fix}

1. **Turn off power at the breaker** for 30 seconds, then restore power and test the range, following LG's reset procedure for range errors.
2. **Verify your model and appliance type** by checking the rating plate to confirm you have an LG range and not a Styler or other product, since E4 definitions vary by product line.
3. **Access and inspect the oven temperature sensor**, usually a metal probe mounted in the rear oven wall, and examine its two-wire harness for burns, cuts, loose terminals, or corrosion at the plug.
4. **Disconnect the sensor connector** and measure resistance across the sensor leads using a multimeter, comparing the reading to your model's specification table (consult your service manual if available).
5. **Inspect all harness routing and control-board connectors** for pinched wires, charred insulation, loose plugs, or corroded pins where the sensor harness meets the main control board.
6. **Replace the oven sensor** if it reads open, shorted, or out of range, or if visual inspection reveals damage, using an exact or manufacturer-approved replacement part.
7. **Replace the control board** only after confirming the sensor and wiring are intact and the fault persists, since the control input circuit may be damaged.

## When to Call a Pro

Call a technician if the error returns after a full breaker reset, if you are uncomfortable working inside an appliance with live 240-volt circuits, or if replacing the sensor does not clear the code. A qualified service provider has the correct wiring diagrams, model-specific resistance tables, and the tools to safely diagnose control-board faults. Professional help is also essential if you own an LG Styler and the E4 code persists after cleaning the water system, since heater replacement on that appliance requires disassembly and calibration.
