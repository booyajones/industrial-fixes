## Samsung Refrigerator 1E Error Code — What It Means

Samsung's 1E error code is not consistently defined across all refrigerator models. On many Samsung units, manufacturer documentation identifies 1E as a freezer temperature sensor fault, specifically an open sensor circuit (readings below -50°C trigger the code, while a short-circuit sensor fault appears as 1C). The sensor monitors freezer temperature to regulate cooling. However, some repair sources describe 1E or IE as a display alert that appears after a power outage, brownout, or voltage spike and can be cleared by a simple reset.

Because the same code has two different meanings depending on the model, always verify your specific refrigerator's service manual or wiring diagram before ordering parts. If your unit recently experienced a power interruption, the code may be only a temporary alert. If the code persists after a power cycle, treat it as a freezer sensor circuit problem and inspect the thermistor, harness, and control board connections.

## Before You Replace Anything

Many owners replace the main control board first when the real problem is a bad sensor or loose connector. Always test the freezer thermistor resistance and inspect the harness connections before ordering a new board.

## Common Causes

- **Failed freezer thermistor** The sensor develops an open or short circuit and sends out-of-range readings to the control board, triggering the 1E fault.
- **Loose or corroded sensor connector** The plug between the thermistor harness and the main board works loose or corrodes, breaking the signal path and simulating an open sensor.
- **Damaged sensor wiring harness** The wires between the freezer compartment and the control board are pinched, chafed, or pulled loose during previous service.
- **Recent power outage or surge** A brief interruption or voltage spike causes the display to show 1E as an alert, even though the sensor circuit is intact.
- **Faulty main control board input** The sensor and harness test good but the control board cannot read the signal correctly due to a damaged input circuit.

## Step-by-Step Fix {#fix}

1. **Unplug the refrigerator** from the wall outlet and wait two full minutes to discharge residual power and reset the control board.
2. **Plug the unit back in** and observe the display. If the 1E code does not reappear and cooling resumes normally, the fault was a temporary alert and no further repair is needed.
3. **Locate the freezer temperature sensor**. On most Samsung models it is mounted inside the freezer compartment, often behind the rear evaporator cover or clipped to the evaporator coil.
4. **Inspect the sensor connector** at the main control board (usually behind the top-front panel or inside the fresh-food section). Unplug the connector and check both the plug and receptacle for corrosion, moisture, or bent pins. Clean and reseat firmly.
5. **Test the thermistor resistance** using a multimeter. Disconnect the sensor, place the probe in ice water (0°C), and measure resistance. Consult your model's wiring diagram for the expected value. An open circuit (infinite resistance) or short (near-zero resistance) indicates a failed sensor.
6. **Replace the freezer temperature sensor** if it tests out of specification. Route the new harness along the original path, secure any clips, and reconnect the plug at the control board.
7. **Restore power and monitor** the refrigerator for 12–24 hours. The 1E code should clear, and both freezer and fresh-food compartments should reach target temperatures. If the code returns immediately with a known-good sensor, inspect the harness for damage or replace the main control board.

## When to Call a Pro

Call a professional if you are uncomfortable working behind panels with live 120 V connections, if the freezer evaporator cover is frozen in place and requires defrosting to access the sensor, or if you have already replaced the sensor and harness but the 1E code persists. A technician can perform board-level diagnostics, trace the sensor circuit with specialized meters, and determine whether the main control board input has failed. Also call if the refrigerator is still under warranty, since DIY repairs may void coverage.

**Rough cost:** DIY runs about $15–50 in parts, 30–60 min. A pro service call runs about $150–280 service call including sensor and labor.
