## Samsung Refrigerator 1E Error Code — What It Means

The 1E code is a freezer room sensor fault. The thermistor that tells the main board how cold the freezer is has gone out of range, shorted, or lost connection.

Without a trusted reading the board cannot regulate the freezer, so it flags 1E and stops cooling correctly.

[Jump to Fix](#fix)

## Common Causes

- **Failed thermistor** The freezer room sensor has drifted out of spec or opened internally and no longer reports a usable temperature.
- **Loose connector** The sensor harness backed out of its plug from vibration so the board reads an open circuit.
- **Pinched or chafed wire** A wire near the evaporator cover rubbed through and shorted against metal.
- **Frost on the sensor** Heavy frost buildup around the sensor body can push the reading outside the valid window.
- **Power glitch** A surge or brownout can latch the code until the board is power cycled.
- **Main board fault** In rare cases the sensor input on the control board itself has failed.

## Step-by-Step Fix {#fix}

1. Unplug the refrigerator for 5 minutes, then restore power to clear a one time glitch.
2. If 1E returns, unplug again before working inside the freezer.
3. Empty the freezer and remove the rear evaporator cover panel.
4. Find the freezer room sensor in the upper right area and reseat its connector.
5. Set a multimeter to ohms and read the thermistor, expecting roughly 5k ohms at room temperature.
6. Replace the freezer room sensor if it reads open, shorted, or far off that value.
7. Reassemble, restore power, and confirm the code is gone after the freezer cools.

## When to Call a Pro

If the new sensor reads correct but 1E keeps returning, the fault points to the main control board. Board level diagnosis and replacement is a good time to bring in an appliance technician.
