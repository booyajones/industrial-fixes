## Maytag Dryer F2E1 Error Code — What It Means

The F2E1 code on a Maytag dryer indicates a keypad fault. The control board is detecting a stuck button, a shorted key, invalid input from the console, or a communication problem between the user interface panel and the main control. This is not a mechanical or airflow problem. It is an electrical issue isolated to the control panel or its wiring.

Maytag lists F2E1 as "Keypad" in their dryer help documentation. In the field, technicians see this code when a button on the console is physically stuck, when moisture or detergent residue has contaminated the keypad, or when the ribbon cable connecting the user interface board to the main control has loosened or corroded. Less commonly, the user interface board itself has failed, or the main control board is misreading a valid keypad signal.

## Before You Replace Anything

Homeowners sometimes replace the main control board when the real fault is a stuck button or loose ribbon cable at the keypad. Always power-reset the dryer and inspect every button and connector before ordering any board.

## Common Causes

- **Stuck or damaged button (~40%)** A button on the console is physically stuck down, cracked, or intermittently responsive, causing the control to see a continuous or invalid input.
- **Moisture or residue on the keypad (~25%)** Spilled detergent, fabric softener, or humidity has seeped into the console, creating false signals or causing a button to hang.
- **Loose or corroded ribbon cable (~20%)** The flat ribbon cable or harness between the user interface board and the main control has worked loose, corroded, or suffered pin damage, interrupting communication.
- **Failed user interface board (~10%)** The keypad assembly itself has an internal short, failed trace, or component damage unrelated to the buttons.
- **Main control board misreading input (~5%)** The main control board is faulty and incorrectly interprets valid keypad signals as errors, though this is less common when buttons and wiring check out.

## Step-by-Step Fix {#fix}

1. **Turn off power at the circuit breaker** for a full 5 minutes to reset the control, then restore power and start a timed dry cycle to see if the F2E1 code returns.
2. **Press each button on the console individually** and feel for any that stick, do not click, or respond intermittently.
3. **Inspect the console area for moisture or residue** around the buttons and clean with a cotton swab dipped in isopropyl alcohol if you find contamination.
4. **Remove the console or control panel** by unscrewing the retaining screws (typically along the top or back edge of the control panel) and carefully tipping it forward to access the back.
5. **Locate the ribbon cable or harness** that connects the user interface board to the main control board and check that both ends are firmly seated, with no bent pins, corrosion, or damage to the cable.
6. **Reseat all connections** by unplugging and firmly re-plugging each connector, then reassemble the console and run another test cycle.
7. **If the error persists and buttons and cables are confirmed good**, replace the user interface board (the entire console assembly in many models). If a new UI board does not resolve the code, replace the main control board.

## When to Call a Pro

Call a technician if you are uncomfortable removing the console or working around 120-volt connections inside the dryer. Also call if you have replaced the user interface board and reseated all cables yet the F2E1 code still appears. At that point, the main control board is the likely culprit, and a technician can verify the diagnosis with a known-good test board before you invest in the part. If your dryer is still under warranty, contact Maytag or an authorized service center before opening the console, since DIY disassembly may void coverage.

**Rough cost:** DIY runs about $60–150 in parts (user interface assembly), 30–60 min. A pro service call runs about $150–300 including service call and part.
