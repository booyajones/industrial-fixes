## Maytag Dryer F2E1 Error Code — What It Means

The code you're seeing is most likely **F2E1**, not FCE1. Maytag dryer F2E1 indicates the control board has detected a stuck, jammed, or electrically shorted button on the user interface keypad. The control sees a button input that shouldn't be active or won't change state properly.

This fault belongs to Maytag's F#E# family of control-system errors, which signal a hardware or communication problem requiring service. The dryer may refuse to start, cycle unexpectedly, or display the code immediately at power-up when a keypad defect is present.

## Common Causes

- **Stuck or jammed keypad button** A physical button on the touchpad is stuck down, blocked by debris, or has lost proper spring return and sends a continuous signal to the control.
- **Faulty user interface board** The touchpad or user interface circuit board has failed internally and generates a false button-press signal even when no button is touched.
- **Loose or corroded connector** The wiring harness connector between the user interface and the main control board is loose, corroded, or making intermittent contact.
- **Damaged interface wiring** Harness wires between the keypad assembly and control are pinched, frayed, or shorted, causing the control to see phantom button inputs.
- **Main control board fault** If the keypad and wiring test good, the main control board itself may be misreading the user interface signals due to internal failure.

## Step-by-Step Fix {#fix}

1. **Disconnect power** at the circuit breaker or unplug the dryer cord, then wait a full 5 minutes to allow the control system to reset completely.
2. **Restore power** and observe whether the F2E1 code reappears immediately or during normal button presses.
3. **Inspect each keypad button** by pressing firmly and releasing to check for sticking, poor travel, or buttons that don't spring back.
4. **Remove the console or top panel** (consult your model's service manual for fastener locations) to access the user interface board and wiring connectors.
5. **Check all harness connectors** at the user interface and main control board for loose pins, corrosion, or damage, and reseat each connector firmly.
6. **Replace the user interface assembly** if buttons remain unresponsive, if the code returns after a reset, or if you found physical keypad damage.
7. **Run a test cycle** after reassembly to confirm the F2E1 code does not return and all buttons respond normally.

## When to Call a Pro

Call a qualified appliance technician if you are uncomfortable working with live 240 V circuits, if the fault returns after you've replaced the user interface, or if diagnostic steps reveal possible main control board failure. Technicians have model-specific wiring diagrams and tools to isolate whether the fault lies in the keypad, harness, or main board without unnecessary parts replacement. If your dryer is still under warranty, professional service may be required to preserve coverage.
