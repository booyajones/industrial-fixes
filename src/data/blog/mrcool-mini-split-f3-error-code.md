## MRCOOL F3 Error Code — What It Means

On MRCOOL mini splits, F3 indicates a compressor discharge temperature sensor TP open circuit or short circuit according to the manufacturer's error code list. This means the outdoor control board cannot read the discharge-pipe temperature sensor correctly because the sensor itself has failed, the wiring is damaged, or the board input circuit is faulty. A conflicting source lists F3 as an outdoor fan speed malfunction, but the manufacturer's own documentation points to the discharge sensor as the primary definition. The discharge temperature sensor monitors the temperature of the refrigerant leaving the compressor and protects the system from overheating.

## Common Causes

- **Failed discharge temperature sensor** The thermistor itself has gone open or shorted, which is the most direct match to the F3 code definition.
- **Damaged sensor wiring or connector** Broken wires, corroded terminals, or a loose plug between the sensor and the outdoor PCB will trigger the same open-circuit fault.
- **Faulty outdoor PCB** The control board input circuit may be misreading the sensor voltage even when the sensor and wiring are intact.
- **Sensor not mounted correctly** If the sensor has come loose from the discharge pipe or clamp, it may lose electrical contact or read incorrectly.
- **Outdoor fan speed malfunction (model-specific)** Some MRCOOL models or firmware variants may use F3 to indicate a fan-motor or fan-speed control issue instead of a sensor fault.

## Step-by-Step Fix {#fix}

1. Power down the system completely at the breaker before touching any wiring or components to avoid shock and board damage.
2. Inspect the outdoor unit wiring harness for loose connectors, damaged insulation, pinched wires, or corrosion at the discharge sensor plug and PCB terminals.
3. Locate the discharge pipe temperature sensor TP on the compressor discharge line and verify it is physically mounted and secure on the pipe or clamp point.
4. Measure the sensor resistance at the sensor terminals and compare the reading to the temperature-resistance chart in your model's service manual to check for an open or shorted sensor element.
5. Check continuity from the sensor plug to the outdoor PCB connector if the sensor itself tests good, looking for breaks or high resistance in the harness.
6. Replace the discharge temperature sensor TP if it measures out of spec, or repair and replace the wiring harness if the harness is damaged.
7. Replace the outdoor PCB if both sensor and wiring test good but the code persists, indicating a faulty board input circuit.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working with live voltage, measuring sensor resistance, or identifying the correct discharge sensor location. Misdiagnosing a sensor fault can lead to unnecessary part replacement or further damage to the outdoor board. A technician has the factory resistance tables, proper multimeter tools, and refrigerant recovery equipment to safely diagnose and repair the system. If the code returns after you replace the sensor or wiring, a professional can test the PCB input circuit and check for intermittent faults that are harder to trace.
