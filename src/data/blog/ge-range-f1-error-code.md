## What this code means
On most GE ranges and ovens, the F1 error code indicates the electronic oven control has detected a fault in the keypad or control module itself. This is typically described as a shorted keypad or failed control board rather than a cooking or temperature problem. GE publishes limited public documentation on this code, and the exact meaning can vary by model, so always check your unit's tech sheet or service manual if available. In some models, F1 may be tied to a temperature sensor circuit issue, but that interpretation is less common and model-dependent.

The code usually appears when a key on the touch panel is stuck or shorted, or when the main electronic oven control board has failed due to heat stress, moisture, or component degradation. Because the fault is in the control electronics rather than a sensor or heating element, the range may beep repeatedly or lock out oven functions until the problem is resolved.

## Before You Replace Anything

Homeowners sometimes replace the oven temperature sensor first, but F1 on GE ranges usually points to the control board or keypad assembly. Before ordering parts, disconnect the keypad from the board and retest to isolate which component is actually faulty.

## Common Causes

- **Failed electronic oven control board (~50%)** The main control board develops heat damage, burned components, or circuit failures, especially after self-clean cycles or prolonged use.
- **Shorted or stuck keypad (~35%)** The touch-panel membrane shorts internally or a key remains stuck, signaling a continuous fault to the control.
- **Moisture or heat stress on control assembly (~10%)** Steam, spills, or repeated high-heat exposure degrade solder joints or circuit traces on the control board or keypad connector.
- **Temperature sensor circuit fault (model-specific) (~5%)** On certain GE models the F1 code can indicate a sensor open or short, but this is less common and must be confirmed by the model tech sheet.

## Step-by-Step Fix {#fix}

1. **Disconnect power** by unplugging the range or switching off the dedicated circuit breaker at your panel.
2. **Wait five minutes**, then restore power to see if the F1 code clears on its own (power-cycle reset).
3. **Locate the model and serial tag** (usually inside the oven door or on the frame) and find the tech sheet, often attached to the back panel or inside the control console.
4. **Remove the control-console cover** by taking out the screws along the top or front edge, then lift or tilt the panel forward to access the control board and keypad.
5. **Inspect the control board** for burn marks, discolored solder joints, swollen capacitors, or damaged ribbon-cable connectors.
6. **Disconnect the keypad ribbon cable** from the board (note the orientation first), then restore power briefly. If F1 reappears without the keypad connected, the board is faulty. If the code does not return, the keypad is the problem.
7. **Order and install the replacement part** using your full model number. Transfer any mounting brackets or connectors from the old board or keypad, reconnect all wiring, reassemble the console, and test the oven functions.

## When to Call a Pro

Call a service technician if you are uncomfortable working with line voltage (typically 240 V on ranges), if the control board is difficult to access or integrated with other components, or if the fault persists after replacing both the keypad and control board. A technician can use the factory tech sheet and diagnostic mode to pinpoint intermittent faults, verify sensor circuits on models where F1 is sensor-related, and make sure all wiring connections are correct. Professional diagnosis is also worthwhile if your range is still under warranty or if you need the repair documented for a warranty claim.

**Rough cost:** DIY runs about $100–250 in parts, 1–2 hours. A pro service call runs about $200–400.
