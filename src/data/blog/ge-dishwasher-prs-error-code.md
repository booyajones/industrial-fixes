## GE Dishwasher PrS Error Code — What It Means

The PrS code on a GE dishwasher indicates that the control board is receiving an invalid signal from the pressure sensor. This sensor monitors water level and pressure inside the tub. When the fault is present, the dishwasher cannot start a cycle or will cancel the cycle mid-run. GE defines this as a pressure sensor signal fault, meaning the sensor itself or the communication path to the control is compromised.

## Common Causes

- **Failed pressure sensor** The pressure sensor assembly has failed internally and is no longer sending a valid signal to the control board.
- **Damaged or loose wiring harness** The connector or wiring between the pressure sensor and the control board is loose, corroded, or has damaged insulation.
- **Blocked or clogged sensor area** Debris, mineral buildup, or food particles are blocking the pressure-sensing path or the sensor port at the sump.
- **Corroded sensor connector pins** Moisture or detergent residue has corroded the pins inside the sensor connector, preventing proper electrical contact.

## Step-by-Step Fix {#fix}

1. **Disconnect power** at the breaker or unplug the dishwasher for two full minutes, then restore power to see if the code clears on its own.
2. **Access the pressure sensor** by removing the lower front kick panel and the lower access panel to expose the sensor mounted near the sump at the bottom of the tub.
3. **Inspect the wiring harness and connector** at the pressure sensor for loose pins, damaged wires, corrosion, or a connector that is not fully seated.
4. **Check the sensor area for blockage** by examining the sensor port and surrounding sump area for debris, mineral deposits, or food buildup, and clean or clear any obstructions.
5. **Replace the pressure sensor assembly** if the wiring is intact and the sensor area is clean, as the sensor itself is most likely faulty.
6. **Reconnect all harnesses** and reassemble the panels, then run a test cycle to confirm the PrS code is cleared and the dishwasher fills and operates normally.
7. **Enter diagnostic mode** (if your model supports it) to run a service test cycle and verify that the pressure sensor is now reporting valid signals to the control.

## When to Call a Pro

Call a professional if the PrS code returns immediately after replacing both the pressure sensor and inspecting all wiring, or if you are not comfortable working with electrical connectors and disassembling the lower panels of the dishwasher. A technician can enter full diagnostic mode to isolate whether the fault lies in the control board itself rather than the sensor circuit. If your dishwasher is still under warranty, contact GE or an authorized service provider before attempting any repairs to avoid voiding coverage.
