## GE Dishwasher PrS Error Code — What It Means

The PrS fault code on a GE dishwasher indicates the pressure sensor is sending an invalid signal to the main control board. The pressure sensor monitors water level inside the dishwasher, and when the control cannot interpret the sensor's signal correctly, it displays PrS and may refuse to start a cycle or cancel the cycle mid-run.

GE identifies the most likely causes as a problem with the wiring harness to the sensor or the pressure sensor itself. Contamination or blockage in the sensor area can also distort the signal. A simple power reset may clear a transient fault, but if the code returns, service is required.

## Before You Replace Anything

Homeowners sometimes replace the main control board first, but a visual inspection of the pressure sensor wiring and connector often reveals the real problem at a fraction of the cost.

## Common Causes

- **Faulty pressure sensor (~45%)** The pressure sensor assembly itself has failed and no longer sends a valid signal to the control board.
- **Damaged or loose wiring harness (~30%)** The connector or wire harness to the pressure sensor is loose, corroded, or has an open circuit.
- **Contamination or blockage at the sensor (~15%)** Debris, food particles, or mineral buildup in the sensor area or sump can distort water-level sensing and produce an invalid signal.
- **Intermittent connection at the control board (~10%)** The sensor harness plug at the main control board is not fully seated or has corroded pins.

## Step-by-Step Fix {#fix}

1. **Disconnect power and water** by unplugging the dishwasher or turning off the circuit breaker, and closing the water supply valve under the sink.
2. **Perform a power reset** by leaving the machine unplugged for two minutes, then restoring power and checking if the PrS code returns.
3. **Access the pressure sensor** by removing the toe-kick panel or tilting the dishwasher back to reach the underside where the sensor is mounted near the sump.
4. **Inspect the wiring harness and connector** at the pressure sensor for loose, corroded, or damaged contacts; also check the connector at the main control board.
5. **Check for contamination** around the pressure sensor and sump area; clean away any visible debris, food particles, or mineral buildup that could affect sensing.
6. **Replace the pressure sensor assembly** if the wiring checks good and the code persists; verify the part number by your dishwasher's model number before ordering.
7. **Reassemble and run a test cycle** to confirm the PrS code is cleared and the dishwasher fills and operates normally.

## When to Call a Pro

Call a professional if you are not comfortable tilting the dishwasher or removing access panels, if the wiring inspection reveals complex control-board damage, or if the code persists after you have replaced both the sensor and checked all connections. A technician has diagnostic tools to verify signal continuity and can rule out a main control board fault. Also call if the dishwasher is still under warranty, since self-service may void coverage.

**Rough cost:** DIY runs about $50-120 in parts, 1-2 hours. A pro service call runs about $150-300.
