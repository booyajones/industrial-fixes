## Bosch Oven E02 Error Code — What It Means

The E02 error code on Bosch ovens typically indicates a problem with the oven's temperature sensing system. The exact meaning can vary by model, so consult your owner's manual or the wiring diagram inside the appliance for confirmation. In most cases, the control board is not receiving the correct signal from the temperature sensor, or the sensor itself has failed. This prevents the oven from regulating heat properly and triggers the fault code.

The error may appear during preheat or while the oven is in use. Some models will shut down heating entirely when E02 displays, while others may continue to operate erratically. Check your specific model documentation to understand whether the code refers to the main oven sensor, a secondary probe, or a related circuit fault.

## Before You Replace Anything

Many people replace the control board first when the sensor or its wiring is actually at fault. Test the sensor's resistance with a multimeter at room temperature and compare it to your model's specification table before buying any board.

## Common Causes

- **Failed temperature sensor (~55%)** The oven temperature sensor probe has drifted out of specification or shorted internally, sending incorrect readings to the control board.
- **Damaged sensor wiring (~20%)** Wires running from the sensor to the control board are broken, pinched, or corroded, interrupting the signal.
- **Loose or corroded connector (~10%)** The plug where the sensor harness meets the control board has oxidized or worked loose over time, causing intermittent contact.
- **Control board fault (~10%)** The circuit on the main control board that reads the sensor signal has failed, even though the sensor itself is good.
- **Incorrect sensor installation (~5%)** The sensor probe is not seated properly in its mounting bracket or has been bent away from the oven cavity wall, giving false readings.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker or unplug the oven to eliminate all voltage to the appliance.
2. **Remove the oven racks** and locate the temperature sensor probe, usually mounted at the upper rear wall of the oven cavity.
3. **Disconnect the sensor** by pulling the wire connector from the back of the oven or control housing, depending on your model's layout.
4. **Test the sensor resistance** with a multimeter set to ohms. At room temperature, consult your model's specification table for the expected value.
5. **Inspect the wiring** from the sensor to the control board for any breaks, abrasion, or burn marks, and check the connector terminals for corrosion.
6. **Install the new sensor** if the old one is out of specification or damaged, routing the wire carefully away from heating elements and sharp edges.
7. **Restore power** and run a test cycle. Clear the error code if necessary using the control panel reset procedure in your owner's manual.

## When to Call a Pro

Call a professional if you are uncomfortable working inside the oven cabinet or if voltage measurements are required at the control board. A technician should also handle the repair if the sensor and wiring both test good but the error persists, since that points to a control board fault requiring board-level diagnostics. If your oven is still under warranty, contact Bosch service directly rather than attempting any repair yourself, as DIY work may void coverage. Finally, if you find evidence of arcing, melted insulation, or repeated component failures, a pro can trace the root cause and check for upstream electrical problems.

**Rough cost:** DIY runs about $30-80 in parts, 30-60 min. A pro service call runs about $150-300.
