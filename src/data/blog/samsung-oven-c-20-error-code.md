## Samsung Oven C-20 Error Code — What It Means

Samsung identifies C-20 as a sensor malfunction code on its ovens and ranges. Repair technicians treat C-20 specifically as an oven temperature sensor or probe circuit fault. The sensor circuit is either reading open, shorted, or outside the expected resistance range, preventing the control board from accurately monitoring oven temperature.

Samsung groups C-20 together with C-21 and C-22 as sensor faults that can often be cleared by a power reset. If the code returns after reset, the oven temperature sensor, its wiring harness, or the main control board sensor input circuit requires diagnosis and repair.

## Before You Replace Anything

Homeowners sometimes replace the main control board first when the real fault is a bad sensor or damaged harness. Always measure the sensor resistance and inspect the wiring connectors before replacing any circuit board.

## Common Causes

- **Open, shorted, or out-of-spec oven temperature sensor** The sensor thermistor fails and no longer delivers a valid resistance reading to the control board.
- **Loose, damaged, or burned wiring connectors** Harness plugs at the sensor or control board develop poor contact, burned pins, or broken conductors.
- **Physical damage to the sensor lead or harness** Wiring in the rear cavity or behind the control panel can be pinched, melted, or chewed by rodents.
- **Control board misreading the sensor circuit** After a power disturbance or when the code persists after reset, the main PCB sensor input may require replacement.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker or unplug the range completely before beginning any diagnostic or repair work.
2. **Perform a power reset** by leaving the unit disconnected for 30 seconds or more, then restore power and check whether the C-20 code returns.
3. **Access the oven temperature sensor** by removing the rear panel, side panel, or oven cavity back cover according to your model's service instructions.
4. **Disconnect the sensor harness connector** and measure the resistance across the sensor terminals using a multimeter. Consult your model's wiring diagram or service table for the expected resistance at room temperature.
5. **Inspect the sensor wiring harness and connectors** from the sensor probe to the main control board for burned spots, broken conductors, poor pin fit, or physical damage.
6. **Replace the oven temperature sensor** if the resistance reading is open, shorted, or out of specification, or if the sensor probe shows physical damage.
7. **Reassemble the oven**, restore power, and run a test bake cycle to verify the C-20 code does not return and the oven heats normally.

## When to Call a Pro

Call a professional if you are uncomfortable working with 240-volt power, if the diagnostic steps do not isolate a clear fault, or if the code persists after you have replaced the sensor and verified the wiring. A qualified appliance technician can perform advanced diagnostics using the oven's built-in diagnostic mode, measure sensor circuit voltages at the control board, and safely replace the main PCB if the sensor input circuit has failed. Professional service is also recommended if your range is still under warranty or if you lack the tools or service manual needed to access internal components.

**Rough cost:** DIY runs about $20–80 in parts, 30–90 min. A pro service call runs about $150–300.
