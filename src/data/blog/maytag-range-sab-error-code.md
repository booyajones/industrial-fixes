## Maytag Range SAB Error Code — What It Means

The SAB, Sab, 5AB, or 5A6 display on your Maytag range is not an error code. It indicates that Sabbath Mode has been activated. This is a deliberate feature that restricts the range so only the Bake cycle will operate. All other cooking and cleaning cycles are disabled, no tones or beeps sound, temperature changes do not appear on the display, and oven lights and door actions behave differently than normal.

Sabbath Mode is typically activated by accident when a specific key sequence is pressed on the control panel, most commonly by holding the Clock button for about 3 seconds. The range is functioning as designed in this mode. Your goal is simply to exit Sabbath Mode using the correct keypad sequence for your model.

## Common Causes

- **Sabbath Mode accidentally enabled** The Clock button was held for 3 seconds or a similar keypad sequence was pressed, placing the range into Sabbath Mode.
- **Intentional activation without awareness** Someone in the household turned on Sabbath Mode for religious observance and did not communicate it or forgot to disable it afterward.
- **Keypad contact or stuck button** A stuck or intermittent Clock button can trigger the Sabbath Mode sequence unintentionally during cleaning or normal use.
- **Control interface sensitivity** Touching multiple buttons or pressing Clock during a power surge or cycle can activate the mode without deliberate intent.

## Step-by-Step Fix {#fix}

1. **Confirm the display** shows SAB, Sab, 5AB, or 5A6, and verify that the oven still heats in Bake mode but other functions are disabled.
2. **Locate your owner's manual** or search online for your exact Maytag model number to find the Sabbath Mode exit sequence, as it varies slightly by model.
3. **Press and hold the Clock button** for approximately 3 seconds, which is the most common method to toggle Sabbath Mode on and off on Maytag ranges.
4. **Watch the display** for the SAB code to disappear and the normal time or temperature readout to return, confirming the mode has been disabled.
5. **Test all functions** by selecting Broil, Clean, or another cycle that was previously unavailable, and verify that control tones and lights work normally.
6. **Power cycle the range** if the display does not clear after the keypad sequence by turning off the circuit breaker for 60 seconds, then restore power and retry the Clock hold.
7. **Inspect the Clock button** for sticking or damage if Sabbath Mode re-engages repeatedly, and clean around the keypad to rule out debris causing false contacts.

## When to Call a Pro

Call a professional appliance technician if you cannot exit Sabbath Mode using the documented keypad sequence and a power cycle, or if the SAB code returns immediately after clearing. A tech will test the user interface board and electronic control for stuck inputs or firmware issues. Also call if the range exhibits other fault codes (F-series) or operational problems after exiting Sabbath Mode, as that points to a separate control or sensor issue unrelated to the mode itself.
