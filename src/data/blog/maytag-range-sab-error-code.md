## Maytag Range SAB Error Code — What It Means

SAB, Sab, 5AB, 5A6, or 5Ab on your Maytag range display is not a fault code. It means Sabbath Mode has been activated. In this mode the oven intentionally limits operation to comply with religious observance requirements. Only the Bake cycle will work. All other cooking and cleaning functions are disabled. The control will not sound tones, will not display temperature changes during use, and the oven light and heating behavior are altered. This is a control setting, not a hardware problem.

Maytag's product documentation lists these displays as the indication that the range has entered Sabbath Mode. The most common reason you see this code is that the mode was turned on by accident during normal use or intentionally by another user. Your owner's manual provides the exact entry and exit procedure for your specific model. Once you exit Sabbath Mode using the correct key sequence, all normal oven functions, tones, display features, and cleaning cycles will return.

## Before You Replace Anything

Homeowners sometimes call for service or consider replacing the control board thinking the oven is broken. Check your owner's manual and try the Sabbath Mode exit procedure before ordering any parts.

## Common Causes

- **Sabbath Mode activated unintentionally (~85%)** The user pressed a key combination by accident or another household member turned on the mode without informing others, triggering the SAB display and function lockout.
- **Sabbath Mode intentionally enabled and forgotten (~10%)** The mode was turned on for religious observance and the user later forgot it was active, leading to confusion when normal functions did not work.
- **Control interface stuck or shorted key (~4%)** A stuck button or moisture under the keypad membrane caused the control to register the Sabbath Mode entry sequence on its own.
- **Control board software glitch (~1%)** A power surge or transient electrical event caused the control to enter Sabbath Mode without user input, though this is rare.

## Step-by-Step Fix {#fix}

1. **Verify the display** shows SAB, Sab, 5A6, or 5Ab and confirm the oven otherwise behaves like a Sabbath Mode lockout (only Bake works, no tones, no temperature display updates).
2. **Locate your owner's manual** and turn to the Sabbath Mode section to find the exact entry and exit procedure for your Maytag range model.
3. **Press and hold the Clock pad** for approximately 3 seconds if your model uses that method, watching for the display to clear and normal operation to resume.
4. **Check all functions** after the display clears: verify that timed bake, convection, broil, self-clean, tones, and temperature indication all work normally.
5. **Cycle power at the circuit breaker** if the code does not clear with the keypad procedure, wait 60 seconds, restore power, and retry the exit sequence.
6. **Inspect the control keypad** for stuck buttons, spills, or moisture under the membrane if the code reappears on its own or will not clear.
7. **Call a qualified service technician** if the SAB display persists after following the manual procedure, power cycling, and cleaning the keypad, as the control board or user interface may require professional diagnosis.

## When to Call a Pro

Call a professional appliance technician if the SAB code remains on the display after you have followed the owner's manual exit procedure, cycled power at the breaker, and inspected the keypad for stuck keys or debris. If the control will not respond to any keypad commands or if the code reappears immediately after clearing, the user interface or control board may have an internal fault that requires diagnostic tools and part replacement. A technician can test the control circuit, verify the keypad membrane integrity, and install the correct factory replacement board for your model. Because this is normally a mode setting rather than a component failure, most service calls for SAB codes are resolved by walking the homeowner through the correct exit sequence rather than replacing parts.

**Rough cost:** DIY runs about $0, 1-2 minutes. A pro service call runs about $0 (no repair needed once mode is exited).
