## Electrolux Dryer E91 Error Code — What It Means

E91 on an Electrolux dryer indicates a communication or configuration fault between the main electronic control board and the user interface or display board. Electrolux groups E90 through E94 as configuration and communication problems with the electronic parts. In practical terms, the dryer's logic boards are not exchanging valid data, or the machine cannot recognize the user interface configuration correctly.

This code does not point to drain, pump, sensor, or airflow issues. It is a board-to-board communication error that may be caused by loose connections, a software glitch, or a failed control module.

## Before You Replace Anything

Many people replace the main control board first when E91 appears. Always reseat and inspect the wiring harness connectors between the main board and the display panel before ordering any boards, because a loose or corroded plug often causes the same symptom at no cost.

## Common Causes

- **Loose, corroded, or damaged wiring harness connections (~40%)** The ribbon cable or plug between the main control board and the user interface board can work loose from vibration, develop corrosion on pins, or suffer damaged terminals, breaking communication between the two boards.
- **Failed user interface board (~30%)** The display panel or control-panel board can fail internally, preventing it from sending or receiving valid data to the main board, especially when buttons are unresponsive or the display is dead.
- **Failed main electronic control board (~20%)** The main logic board may lose its ability to communicate with the user interface even when wiring is intact, often due to component failure or heat damage on the board itself.
- **Temporary power glitch or software fault (~10%)** A brief surge, power interruption, or software lockup can trigger a transient E91 code that clears after a full power reset without any physical damage.

<details class="dtree"><summary>Does the error clear after a full power reset (unplug for five minutes)?</summary>

## Step-by-Step Fix {#fix}

1. **Disconnect power** by unplugging the dryer or switching off the circuit breaker, then wait at least five minutes to allow the control boards to fully reset.
2. **Restore power** and check whether the E91 code clears and the dryer operates normally. If the fault was a temporary glitch, the reset may resolve it.
3. **Remove the top or rear access panel** (consult your model's service manual for screw locations) to expose the main control board and the wiring harness that runs to the user interface board.
4. **Inspect all connectors** between the main board and the display panel for looseness, corrosion, bent pins, or burn marks. Unplug each connector, examine the terminals, and firmly reseat them.
5. **Check for visible damage** on the boards themselves, including discolored components, burnt traces, or heat damage near connectors. Document any damage for parts ordering.
6. **Replace the user interface board** if the display is unresponsive or if the connectors are intact but the code persists. Remove mounting screws, unplug the harness, install the new board, and reconnect all plugs.
7. **Replace the main electronic control board** if the user interface functions normally but communication still fails after wiring checks and a UI board replacement. Transfer any relays or jumpers from the old board to the new one, reconnect all harnesses, and test the dryer in a normal cycle to confirm the code clears.

## When to Call a Pro

Call a professional if you are uncomfortable working inside the dryer cabinet with live circuits nearby, if you cannot locate or access the control boards on your model, or if the fault persists after you have reseated all connectors and replaced both the user interface board and the main control board. A technician has diagnostic software to read stored fault logs and can verify board-to-board communication with a multimeter and signal tests. Also call for service if you see widespread heat damage or burned components, which may indicate a larger electrical fault that requires tracing wiring through the entire machine.

**Rough cost:** DIY runs about $50-150 in parts (user interface or main board), 30-60 min. A pro service call runs about $150-350 including service call and board replacement.
