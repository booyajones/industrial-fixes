## What this code means
The E91 error code indicates a communication failure between the Main Electronic Control Board (the dryer's main computer) and the User Interface Board (the display panel and control buttons). These two boards need to exchange data constantly. When the handshake protocol times out or is interrupted, the dryer cannot operate and displays E91.

This is not a mechanical problem like a broken heating element or drum belt. It is a digital logic failure where the two microcontrollers cannot talk to each other. The cause is usually a loose or corroded wire connection, a failed interface board, or a temporary software glitch that can be cleared with a power reset.

## Before You Replace Anything

Homeowners often replace the User Interface Board first without checking the ribbon cable connection. Before buying any parts, unplug the dryer for 10 minutes and reseat the cable connectors. Many E91 errors are fixed by simply reseating the harness.

## Common Causes

- **Loose or corroded ribbon cable connection (~45%)** The wire harness or ribbon cable connecting the User Interface to the Main Board becomes loose, pinched, or corroded from heat and humidity, blocking the signal path.
- **Temporary power surge or software glitch (~25%)** Voltage spikes or logic errors corrupt the communication protocol, causing a soft E91 that clears after a full power cycle.
- **Defective User Interface Board (~15%)** The control panel itself fails internally and can no longer send valid signals to the Main Board.
- **Defective Main Electronic Control Board (~10%)** The main board fails to read or acknowledge signals from the User Interface, though this is less common initially.
- **Physical damage to the wire harness (~5%)** The harness may be pinched by the drum or damaged during previous repairs, breaking the data lines.

## Step-by-Step Fix {#fix}

1. **Unplug the dryer** from the wall outlet or turn off the circuit breaker and wait 10 minutes to drain residual power and reset the boards.
2. **Plug the dryer back in** and attempt to run a test cycle to see if the error has cleared.
3. **If E91 persists, unplug again** and remove the top or rear panel (consult your model's service manual for access instructions).
4. **Locate the ribbon cable or wire harness** connecting the User Interface Board (front panel) to the Main Electronic Control Board (usually mounted at the rear or side).
5. **Unplug and firmly reseat both ends** of the ribbon cable, checking for bent pins, corrosion, or damage to the cable itself.
6. **Reassemble the dryer**, plug it in, and test. If E91 is gone, the connection was the problem.
7. **If the error remains**, replace the User Interface Board first (it is the more vulnerable component), then test. If still no success, replace the Main Electronic Control Board.

## When to Call a Pro

If you are uncomfortable removing panels or working near electrical control boards, or if the error persists after you have reseated the ribbon cable and replaced the User Interface Board, call a qualified appliance technician. They have diagnostic tools to measure the voltage signals on the communication lines and can confirm which board has failed. Technicians can also enter factory diagnostic modes to isolate the fault more precisely and avoid unnecessary part swaps.

**Rough cost:** DIY runs about $80-180 in parts (board), 30-60 min. A pro service call runs about $150-350.
