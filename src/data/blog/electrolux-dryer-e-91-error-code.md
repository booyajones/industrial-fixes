## Electrolux Dryer E91 Error Code — What It Means

E91 on an Electrolux dryer is a communication or configuration fault between the main electronic control board and the user interface (display panel). Electrolux support guidance confirms that E90/E91/E92/E93/E94 codes all point to configuration or communication problems with the electronic parts. In dryer-specific repair references, E91 is commonly described as a communication failure between the main control board and the UI/display assembly.

This is a board-to-board communication fault rather than a mechanical or sensor problem. The two boards cannot exchange data properly, either because of a temporary software glitch, a loose or corroded connector, damaged wiring, or a failed board. Because many E91 faults are temporary glitches or stored faults after a power event, Electrolux recommends a power reset first before calling service.

## Before You Replace Anything

Many people replace the main control board first without checking connections. Always reseat every connector between the UI and main board and perform a hard power reset before ordering any board.

## Common Causes

- **Loose or corroded connector between UI and main board (~35%)** Ribbon cables and harness plugs between the display panel and control board can work loose over time or develop corrosion on pins, breaking communication.
- **Temporary software glitch or stored fault (~25%)** A power event or voltage spike can leave a stored fault code in memory even after the actual problem clears, which is why a hard reset is the first step.
- **Defective user interface board (display panel) (~20%)** The UI board itself can fail and lose the ability to communicate with the main control, especially if connectors or traces are heat-damaged.
- **Defective main electronic control board (~15%)** The main control board can develop a communication circuit fault or damaged connector sockets that prevent signal exchange with the UI.
- **Burned or damaged wiring harness (~5%)** Wires or ribbon cables can develop breaks, burn marks, or insulation damage from heat or abrasion, interrupting the communication path.

## Step-by-Step Fix {#fix}

1. **Disconnect power** by unplugging the dryer or switching off the circuit breaker, then wait at least 10 minutes to allow all capacitors to discharge and any stored fault to clear.
2. **Restore power** and check whether the E91 code reappears on the display. If the code is gone and the dryer operates normally, the fault was a temporary glitch and no further repair is needed.
3. **Access the control boards** by removing the dryer's top or rear service panel (consult your model's service manual for the exact fastener locations and panel-removal sequence).
4. **Inspect every connector** between the user interface board (behind the display panel) and the main electronic control board. Look for loose plugs, corroded pins, burn marks, or damaged ribbon-cable ends.
5. **Reseat all connectors** by unplugging each harness and ribbon cable, inspecting the pins and sockets, then firmly reseating them until you hear or feel a positive click.
6. **Check the wiring harness** along its entire length for visible damage such as cuts, abrasion, melted insulation, or pinched wires. Replace any damaged harness sections or the entire harness if multiple points show damage.
7. **Replace the user interface board** if all connections are sound and the E91 code persists. The UI board is the most common electronic component failure for communication faults and is usually easier to access than the main control board.
8. **Replace the main electronic control board** if a new UI board does not clear the fault, or if diagnostic testing points to the control board as the source of the communication failure.

## When to Call a Pro

Call an authorized Electrolux service technician if the E91 code remains after you have performed a hard power reset and reseated all connectors, or if you are not comfortable removing panels and handling control boards. Electrolux's own support guidance recommends professional service for persistent configuration and communication faults. A technician can enter the dryer's diagnostic mode to confirm the stored fault, measure communication signals with a multimeter or scope, and determine definitively whether the UI board or main control board has failed. Professional diagnosis is also advisable if you see evidence of arcing, burned components, or heat damage, since these conditions can indicate a larger electrical problem that may damage new parts if not corrected.

**Rough cost:** DIY runs about $80–200 in parts (UI or control board), 30–90 min. A pro service call runs about $150–350 depending on which board needs replacement.
