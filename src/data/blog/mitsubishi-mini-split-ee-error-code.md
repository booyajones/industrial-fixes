## Mitsubishi Mini Split EE Error Code — What It Means

The EE error code on Mitsubishi Electric mini-split systems indicates a communication failure between the indoor and outdoor units. The two halves of your system cannot exchange control signals, so the unit shuts down to protect itself. This is different from codes like E6 or E7, which also relate to communication on some models, so always verify your exact model family before diagnosing. Some third-party repair sources mention control-board memory or EPROM issues under similar code names, but Mitsubishi's manufacturer documentation defines EE specifically as an indoor-outdoor communication error.

## Common Causes

- **Damaged or miswired interconnect cable** The low-voltage control wiring between indoor and outdoor units is loose, corroded, pinched, or connected to the wrong terminals.
- **Incorrect power supply or phase** Voltage issues or wrong phase wiring at the outdoor unit prevent proper board operation and trigger communication faults.
- **Failed outdoor control board** The outdoor unit's main board has failed or a protection device on that board has tripped, breaking the communication link.
- **Failed indoor controller board** The indoor unit's controller or remote-controller interface board has failed and cannot send or receive signals.
- **Moisture intrusion or component damage** Water, heat, or lightning has damaged the communication circuitry on either the indoor or outdoor board.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working with line voltage, if the wiring diagram is unclear, or if you cannot safely access both the indoor and outdoor control boards. Also call a pro if you have verified wiring and supply voltage but the fault returns after clearing, because isolating a board-level communication failure requires model-specific diagnostic tools and firmware knowledge. If your system is still under warranty, contact a Mitsubishi-authorized service provider so you do not void coverage by attempting the repair yourself.
