## LG Washer LE Error Code — What It Means

An LE error code on an LG washer means the machine has detected a locked motor or tub-not-spinning condition. The tub fails to spin and the motor cannot operate properly, triggering the fault. LG's own support documentation identifies this code as a signal that the motor is being overstrained or the drum cannot rotate normally.

The code appears when the control board senses that the motor is drawing excessive current or the Hall sensor feedback signal indicates the rotor is not turning as commanded. This can result from mechanical obstructions, electrical sensor faults, or control glitches.

## Before You Replace Anything

Many people replace the main control board first, but a failed Hall sensor or damaged motor wiring harness is the usual culprit when basic checks pass. Test the Hall sensor feedback signal and inspect all connectors at the motor before replacing the board.

## Common Causes

- **Overloaded wash load (~40%)** Too much laundry prevents the drum from accelerating and strains the motor until the control stops the cycle and throws the LE code.
- **Foreign object lodged in the tub (~25%)** Coins, buttons, or small items wedged between the drum and outer tub stop rotation and lock the motor.
- **Failed Hall sensor or speed sensor (~15%)** The Hall sensor provides motor-position feedback to the control, and when it fails the board cannot confirm the rotor is turning.
- **Damaged motor wiring harness (~10%)** Broken wires or loose connectors between the motor and main control interrupt the feedback signal and motor power.
- **Temporary control fault (~5%)** A transient glitch in the main control board can trigger the error even when all mechanical and sensor components are good, and a power reset clears it.
- **Worn or defective rotor or stator (~5%)** On direct-drive models, a damaged rotor magnet array or contaminated stator windings can prevent smooth motor operation and trigger the locked-motor fault.

## Step-by-Step Fix {#fix}

1. **Unplug the washer** and wait five minutes to clear any temporary control fault, then plug it back in and attempt a spin cycle with a small, balanced test load.
2. **Open the door and remove at least half the laundry** if the drum was overloaded, redistribute the remaining items evenly, and retry the cycle.
3. **Inspect the drum interior** for coins, buttons, or small objects lodged in the holes or around the rubber door seal, and remove anything you find.
4. **Rotate the drum by hand** with the machine empty and unplugged to check for mechanical resistance, scraping, or binding that would prevent normal spin.
5. **Remove the rear access panel** (on direct-drive models) to expose the rotor, stator, and motor connectors, and visually inspect for loose plugs, frayed wires, or debris.
6. **Test the Hall sensor feedback circuit** by slowly turning the rotor by hand while measuring the sensor output with a multimeter set to DC volts (expect a pulsing signal up to about 10 VDC if the sensor and harness are good).
7. **Replace the failed component** identified in your tests (Hall sensor, motor wiring harness, rotor, or stator assembly), reassemble the machine, and run a test cycle to verify the repair.

## When to Call a Pro

Call a professional if you are not comfortable removing the rear panel, working with the direct-drive motor components, or using a multimeter to test the Hall sensor signal. A qualified appliance technician has the tools to safely diagnose the motor feedback circuit, verify rotor and stator condition, and replace the correct component without risking further damage. If you have already replaced the Hall sensor and wiring harness but the LE code persists, the main control board may be at fault and a technician can confirm that diagnosis with manufacturer-level test equipment.

**Rough cost:** DIY runs about $20–80 in parts, 45–90 min. A pro service call runs about $150–300.
