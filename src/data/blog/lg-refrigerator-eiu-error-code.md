## LG Refrigerator EIU Error Code — What It Means

The EIU error code on an LG refrigerator indicates a freezer compartment ice maker assembly failure. LG's own support documentation maps this code directly to a fault in the ice maker assembly located in the freezer. You can display the code manually by pressing and holding ICE PLUS + FREEZER for 2 seconds. LG provides no detailed troubleshooting beyond a reset and defrost cycle. If the code persists after that, the unit requires professional service.

[Jump to Fix](#fix)

## Common Causes

- **Failed ice maker assembly** The freezer ice maker module itself has failed internally and can no longer cycle or produce ice.
- **Ice or frost buildup interfering with mechanism** Heavy frost around the ice maker can jam the ejector or motor, triggering the fault code.
- **Faulty motor or mold heater inside the assembly** Internal components of the ice maker module (motor, heater, ejector) may have burned out or stopped working.
- **Damaged or corroded wiring harness** Loose pins, corrosion, or broken wires at the ice maker connector prevent proper communication.
- **Control board communication fault** The main board may not be sending correct signals to the ice maker assembly, even if the assembly itself is functional.

## Step-by-Step Fix {#fix}

1. **Verify the error code** by pressing and holding ICE PLUS + FREEZER for 2 seconds to confirm EIU is displayed.
2. **Power off the refrigerator** by unplugging it or switching off the circuit breaker for at least 2 minutes to reset the control board.
3. **Restore power and allow defrost** by leaving the refrigerator powered on for several hours so any frost buildup can melt away from the ice maker area.
4. **Check if the code returns** after the defrost cycle by entering the display function again or watching for the error to reappear on the panel.
5. **Inspect the freezer ice maker assembly** for physical damage, jammed ice, abnormal noise, or signs the mechanism is not cycling.
6. **Examine the wiring harness and connectors** at the ice maker for loose pins, corrosion, or damaged insulation that could interrupt signals.
7. **Replace the ice maker assembly** if the code persists and all connections are sound, as LG directs that continued EIU faults require service and component replacement.

## When to Call a Pro

Call a professional if the EIU code returns after a full power reset and defrost cycle. LG states that there are no user troubleshooting steps beyond that point, and the freezer ice maker assembly will likely need diagnosis and replacement. A qualified technician can verify the assembly is truly failed (rather than a wiring or board issue), source the correct part for your model, and install it safely. If you are not comfortable working inside the freezer compartment, dealing with electrical connectors, or removing the ice maker module, professional service is the right choice.
