## Frigidaire Dishwasher LOC Code — What It Means

On Frigidaire dishwashers, LOC is a control lock status indicator, not a fault code. The display is telling you the lock function is active. This is the Control Lock or Child Lock feature designed to prevent unintended operation by locking the control panel buttons. Frigidaire's own support documentation states that LOC indicates the door is locked, which refers to the user-lock condition on the console that prevents the dishwasher from being started or settings from being changed.

In normal operation, the lock can be intentionally enabled by pressing and holding a button sequence on the control panel. The dishwasher will continue to display LOC until the lock is deliberately turned off using the same unlock procedure. Some models tie this status to the door latch mechanism, while others purely lock the touchpad. The code does not indicate a broken component unless the lock will not clear after following the correct unlock steps.

## Before You Replace Anything

Homeowners sometimes replace the control board or door latch assembly thinking LOC is a failure code. Before ordering parts, perform a power reset and try the unlock button sequence, which clears the lock on most units at no cost.

## Common Causes

- **Control Lock or Child Lock enabled (~70%)** The lock feature was activated by a button press or hold sequence, either intentionally or by accidental contact with the panel.
- **Stuck or contaminated button (~15%)** Moisture, food residue, or a stuck key on the touchpad keeps the lock signal active even after an unlock attempt.
- **User interface or control board fault (~10%)** The UI board or main electronic control board fails to accept or process the unlock command, leaving the lock status displayed.
- **Harness or connector issue (~5%)** A loose or corroded connection between the control panel and the main board prevents the unlock signal from being transmitted.

## Step-by-Step Fix {#fix}

1. **Locate the Control Lock button** on the control panel, often labeled Lock or marked with a padlock symbol, and press and hold it for approximately 3 seconds until the LOC code disappears from the display.
2. **Check the fascia or door edge** for printed instructions if no dedicated lock button is visible, since some Frigidaire models use a two-button combination to unlock.
3. **Perform a power reset** if the unlock sequence does not clear the code by switching off the dishwasher circuit breaker or unplugging the unit, waiting 60 seconds, then restoring power.
4. **Retry the unlock command** after the power reset and observe whether the LOC code clears when the panel is powered back on.
5. **Inspect the control panel** for stuck buttons, spilled liquid, food residue, or damaged membrane switches that might hold a key in the pressed state.
6. **Test each button** on the touchpad individually to confirm none are physically stuck or unresponsive, cleaning around the button areas with a damp cloth if needed.
7. **Check the wiring harness** between the user interface board and the main control board for loose connectors, corrosion, or damaged wires if the code persists after cleaning and resets, then replace the user interface or control board as directed by your model's service manual.

## When to Call a Pro

Call a professional if the LOC code does not clear after you have tried the unlock button sequence, performed a full power reset, and inspected the control panel for stuck keys or contamination. A technician can test the user interface board, check the wiring harness and connectors, and verify whether the main electronic control board is correctly processing lock and unlock commands. Also call for service if you are uncomfortable removing the control panel or if your dishwasher is still under warranty, since opening the unit may void coverage.

**Rough cost:** DIY runs about $0 if unlocking works, $80-180 for control panel or touchpad if stuck, 15-45 min. A pro service call runs about $120-250 for service call and control panel replacement.
