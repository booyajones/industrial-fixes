## Maytag Dryer F4E2 Error Code — What It Means

F4E2 does not appear in Maytag's published dryer error code list. The manufacturer documents F3E2 (moisture sensor issue when five consecutive loads run without sensor data) and F4E3/AF (restricted airflow from clogged lint screen or vent problems) for dryers. F4E2 appears in Maytag service literature as a dishwasher code for a stuck heater relay on the control board, not a dryer fault.

If your dryer console truly displays F4E2, verify the exact model number and re-check the displayed characters before ordering parts. The most likely explanation is a misread code or a mix-up between F3E2 or F4E3. Use the model's service sheet or wiring diagram to confirm the code definition for your specific dryer before diagnosing further.

## Before You Replace Anything

Homeowners often replace the moisture sensor or main control board when the real issue is a clogged vent or misread error code. Write down the exact code from the display and cross-check it against your model's service manual before buying any parts.

## Common Causes

- **Misread or confused error code (~50%)** The console may show F3E2 (moisture sensor) or F4E3 (airflow) but be read as F4E2, which is not a Maytag dryer code.
- **Clogged lint screen or vent (if code is F4E3/AF) (~25%)** Lint buildup in the screen, vent duct, or exterior vent hood restricts airflow and triggers the F4E3 or AF code.
- **Moisture sensor not detecting contact (if code is F3E2) (~15%)** Small loads, unlevel dryer, or sensor bar contamination prevents the moisture sensor from registering data over multiple cycles.
- **Crushed, kinked, or overly long vent duct (if code is F4E3/AF) (~10%)** A vent line that is pinched, has too many turns, or exceeds recommended length creates back-pressure and airflow faults.

## Step-by-Step Fix {#fix}

1. **Write down the exact code** displayed on the console, character by character, and locate your dryer's model number on the serial tag inside the door or on the frame.
2. **Cross-check the code** against the service sheet, wiring diagram, or owner's manual for your specific model to confirm whether F4E2 is valid or if the display shows F3E2 or F4E3.
3. **If the code is F4E3 or AF**, turn off the dryer, pull the lint screen, and vacuum the screen housing and the entire vent duct from the dryer to the exterior hood, then inspect the duct for kinks, crushing, or excessive length.
4. **If the code is F3E2**, press the Power button to clear the code, check that the dryer is level by placing a spirit level on top of the cabinet, and adjust the front leveling feet if needed.
5. **Power cycle the dryer** by switching off the circuit breaker for five minutes, then restore power and run a timed dry cycle with a normal-sized damp load to see if the code reappears.
6. **If the code returns**, and you have confirmed it is F3E2, wipe the two moisture sensor bars inside the drum with a cloth dampened with rubbing alcohol to remove detergent film, then test again.
7. **If no combination of F3E2 or F4E3 matches** and the display truly shows F4E2, contact Maytag service or a qualified technician with your exact model number to verify the code definition before ordering any control board or sensor.

## When to Call a Pro

Call a qualified appliance technician if the displayed code cannot be matched to any Maytag dryer fault in your model's service literature, if the moisture sensor bars test good with a multimeter but F3E2 persists, or if you suspect the main control board has failed. A technician will confirm the exact code definition, use factory diagnostic mode to read sub-codes, and verify wiring harness continuity before replacing expensive boards. Also call a pro if the dryer shares a gas line or 240 V circuit with other appliances and you are uncomfortable working around those connections.
