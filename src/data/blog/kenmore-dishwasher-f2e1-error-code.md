## Kenmore Dishwasher F2E1 Error — What It Means

F2E1 on a Kenmore dishwasher indicates a stuck key condition on the user interface control panel. The control board detects one or more buttons as continuously pressed or electrically shorted, even when nothing is touching the keypad. This is not a water-level, pump, or heating fault. The error triggers because a physical button is jammed, moisture has entered the membrane keypad, or the user interface electronics have failed.

## Common Causes

- **Physically stuck or jammed button** A button on the keypad is physically stuck down due to debris, dried spills, or mechanical damage.
- **Moisture intrusion into console** Water or condensation has entered the control panel area and shorted the membrane keypad circuits.
- **Failed user interface board** The user interface control panel electronics have failed, causing a false stuck-key signal.
- **Debris or contamination on keypad** Grease, food residue, or cleaning chemicals have contaminated the button contacts and prevented normal operation.
- **Loose or corroded wiring connector** The ribbon cable or harness connector between the user interface and main control board is loose, corroded, or damaged.
- **Damaged membrane switch layer** The thin membrane switch layer inside the control panel has torn or delaminated, creating a permanent short.

## Step-by-Step Fix {#fix}

1. **Disconnect power at the circuit breaker** and wait 5 minutes to clear any temporary fault, then restore power and test whether F2E1 reappears.
2. **Press each button on the control panel** individually and check for any that feel stuck, unresponsive, or mechanically different from the others.
3. **Turn off power again** and remove the screws securing the dishwasher's outer door panel or console trim to access the user interface assembly and wiring behind the control panel.
4. **Inspect the user interface area** for visible moisture, water stains, debris, or corrosion on the membrane keypad and circuit board.
5. **Disconnect and reseat the ribbon cable or wiring harness** connector between the user interface board and the main control board, checking for bent pins, corrosion, or damage.
6. **Replace the user interface control panel assembly** if the fault persists, a button remains stuck, or moisture damage is present, as individual membrane keys cannot be repaired in the field.
7. **Restore power and run a test cycle** to verify all buttons respond normally and the F2E1 code does not return.

## When to Call a Pro

Call a professional if you are uncomfortable working with electrical components or disassembling the dishwasher door and console. A technician should also diagnose the fault if F2E1 persists after replacing the user interface assembly, since the main control board may require testing or replacement. If moisture intrusion is severe or recurring, a tech can trace the leak source and prevent future control failures.
