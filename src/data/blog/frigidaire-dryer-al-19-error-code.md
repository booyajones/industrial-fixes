## Frigidaire Dryer AL-19 Error Code — What It Means

Frigidaire does not publish an AL-19 error code in standard service documentation. This code may be model-specific, a misread display, or a door-related fault showing on your control board. The most common Frigidaire dryer door error is code "dr," which indicates the door is not closing properly, the door switch has failed, or the control board is not reading the door-switch signal. If you see AL-19 on your display, treat it as an unverified code until you confirm the exact model number and symptoms.

Before ordering parts, perform a hard reset by unplugging the dryer for several minutes. If the code returns and the dryer will not start, begin by inspecting the door latch and testing the door switch. Frigidaire door switches are tested for continuity between the common and normally open terminals with the door closed. If the switch tests open with the door closed, it has failed. If the switch tests good and the door closes fully, suspect a control board problem.

## Common Causes

- **Door not fully closed** Something is blocking the door latch or the door is not pushed firmly into the catch.
- **Failed door switch** The switch does not show continuity when the door is closed, preventing the start signal.
- **Defective control board** The board does not recognize a good door-switch signal and displays a fault code.
- **Misread or model-specific code** AL-19 may be a platform-specific alarm not covered in general Frigidaire documentation.

## Step-by-Step Fix {#fix}

1. Unplug the dryer and wait three to five minutes to perform a hard reset, then restore power and test.
2. Inspect the door latch and strike to confirm nothing is preventing full closure and the latch engages completely.
3. Unplug the dryer again before electrical testing.
4. Locate the door switch (usually mounted near the door strike on the dryer frame) and disconnect the wire harness.
5. Set your multimeter to continuity or resistance and probe the common and normally open terminals on the switch.
6. Close the door manually or press the switch actuator and confirm the meter shows continuity (a good switch will close the circuit when actuated).
7. If the switch tests open when closed, replace the door switch. If the switch tests good and the door closes fully, replace the control board.

## When to Call a Pro

Call a technician if you cannot locate AL-19 in your model's use-and-care guide, if the code persists after a hard reset and door-switch replacement, or if you are not comfortable working with control boards and wiring harnesses. A qualified service provider can look up model-specific fault-code tables and use diagnostic mode to confirm the exact failure. If your dryer is still under warranty, contact Frigidaire or an authorized service center before replacing any parts.
