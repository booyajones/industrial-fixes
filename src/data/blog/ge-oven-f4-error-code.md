## GE Oven F4 Error Code — What It Means

The F4 error code on a GE oven indicates an oven temperature-sensing fault. The electronic range control has detected that the oven temperature sensor circuit is shorted or reading resistance below the normal range. This code is part of the F3/F4 family that monitors the oven sensor circuit, with F4 specifically flagging a shorted or low-resistance condition in the sensor probe, its wiring harness, or the control board input circuit.

The temperature sensor is a resistive temperature device (RTD) that changes resistance as oven temperature changes. At room temperature (around 70–72°F) the sensor should measure approximately 1000–1100 ohms. When the control board sees a resistance far below that range or a dead short to ground, it throws F4 and shuts down the oven to protect the circuit. The code will remain on the display until you clear it by cutting power at the breaker or until the underlying fault is repaired.

## Before You Replace Anything

Many people replace the electronic range control board first, but the sensor itself fails far more often. Always test the sensor resistance with a multimeter and inspect the wiring harness before buying a new board.

## Common Causes

- **Failed oven temperature sensor probe (~65%)** The sensor probe degrades over time and reads out of spec or shorts internally, triggering the F4 code.
- **Damaged or loose sensor wiring harness (~20%)** Pinched, burnt, melted, or loose wires between the sensor and control board create a short or intermittent connection.
- **Shorted or corroded sensor connector (~10%)** The plug that joins the sensor to the range harness can corrode or develop a pin-to-pin short that mimics a failed sensor.
- **Failed electronic range control board (~5%)** A fault in the sensor input circuit on the ERC itself can incorrectly read the sensor as shorted even when the sensor and harness are good.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker that feeds the range and wait one minute, then restore power to clear the code from memory and see if it returns immediately.
2. **Pull the range forward** far enough to access the rear panel or open the back service panel to reach the oven temperature sensor and its wiring.
3. **Disconnect the sensor** from the wire harness by unplugging the two-pin connector near the sensor or at the control board end, depending on your model.
4. **Test sensor resistance** with a digital multimeter set to ohms. Touch the probes to the two terminals on the sensor itself (not the harness). At room temperature (70–72°F) you should read approximately 1000–1100 ohms. If the reading is below 900 ohms, infinite, or jumps erratically, replace the sensor.
5. **Inspect the sensor wire harness** from the sensor all the way to the control board. Look for pinched insulation, burnt or melted wire, loose spade terminals, or corrosion inside the connector plug. Repair or replace the harness if you find damage.
6. **Reinstall or replace the sensor** by sliding the new probe into the mounting bracket at the back of the oven cavity and plugging the connector back in. Make sure the sensor tip does not touch the oven wall.
7. **Restore power** and run a test bake cycle. If F4 does not return and the oven heats normally, the repair is complete. If the code reappears and the sensor and harness both tested good, replace the electronic range control board.

## When to Call a Pro

Call a professional if you are uncomfortable working inside the range cabinet, testing components with a multimeter, or handling the control board. A technician should also diagnose the fault if the sensor and wiring both test good but the F4 code returns after every power reset, since that points to a control board issue that requires proper part matching and sometimes a wiring-diagram review. If you see evidence of arcing, heavy corrosion, or repeated board failures, a pro can trace whether a separate electrical problem (such as a loose neutral or ground fault) is damaging the control circuit.

**Rough cost:** DIY runs about $20–50 in parts, 30–60 min. A pro service call runs about $150–280.
