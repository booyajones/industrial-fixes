## Cooper & Hunter F0 Error Code — What It Means

The F0 code on Cooper & Hunter mini splits indicates the refrigerant-collection or pump-down function is active. This is not a fault code in the traditional sense. The unit displays F0 when the collect refrigerant mode has been activated, typically during service work before disconnecting the outdoor unit. The system is gathering refrigerant into the outdoor condenser so technicians can safely close the service valves and remove piping or components without losing the refrigerant charge.

If you see F0 and you did not intentionally start a service procedure, someone may have accidentally triggered the pump-down function using the indoor unit or remote control. In the Victoria series, the Light button sequence activates this mode. The unit will remain in F0 until the function is canceled or the service valves are closed and the system is powered down. This is a controlled state, not a malfunction, low refrigerant alarm, or compressor failure on Cooper & Hunter equipment.

## Common Causes

- **Intentional pump-down activation** The refrigerant-collection function was started using the indoor unit Light button sequence or remote control before servicing the system.
- **Accidental service-mode trigger** Someone pressed the button sequence on the indoor unit by mistake, putting the system into pump-down mode without intending to service it.
- **Service interrupted mid-procedure** A technician began the refrigerant-collection process and did not complete or cancel it, leaving the display showing F0.
- **Controller or remote malfunction** A faulty indoor controller or remote sent the pump-down command unintentionally, activating F0 mode without user input.

## Step-by-Step Fix {#fix}

1. **Cancel the pump-down function** using the indoor unit or remote control if the code appeared unexpectedly and no service work is planned.
2. **Power the system off** completely at the breaker or disconnect switch if the cancel command does not clear F0, then restart the unit after 30 seconds.
3. **Verify cooling mode is active** before intentionally starting refrigerant collection if you are performing service work, as the Victoria-series procedure requires the unit to be in cooling mode.
4. **Attach manifold gauges** to the outdoor unit service valves if you are completing the pump-down, monitoring both liquid and gas line pressures.
5. **Close the liquid-line service valve** first using an Allen wrench, then watch the gas-line pressure drop on your gauges.
6. **Close the gas-line service valve** only after the gas-line pressure drops to zero or below, then cancel the refrigerant-collection function.
7. **Disconnect refrigerant lines** and proceed with outdoor unit removal or indoor unit repair once both valves are closed and the system is powered down.

## When to Call a Pro

Call a licensed HVAC technician if you see F0 and have no intention of servicing the unit, especially if powering off and restarting does not clear the code. Pump-down involves closing service valves under pressure and handling refrigerant, both of which require EPA certification and gauges. If you suspect a controller fault is triggering F0 randomly, or if the unit will not return to normal operation after canceling the function, a professional can diagnose the board and wiring. Always use a qualified technician for any work that involves opening refrigerant lines or removing the outdoor unit.
