## MRCOOL EH 0E Error Code — What It Means

The EH 0E code on a MRCOOL mini split indicates a water-level alarm malfunction in the indoor unit. This is a condensate removal fault. The system detects that water is not draining properly from the indoor drain pan, or the level-sensing circuit is not reporting correctly. MRCOOL defines this code specifically as a water-level alarm issue, not to be confused with the E0 EEPROM error on other models.

The alarm exists to prevent water overflow. When the float switch or sensor believes the pan is full or the drain is blocked, it trips this fault. The unit is protecting your home from water damage by shutting down or alerting you before the pan overflows.

## Common Causes

- **Clogged or restricted condensate drain line** The most common trigger for a water-level alarm is a blocked drain path that causes the pan to back up and trip the sensor.
- **Failed or stuck water-level float switch** The float or sensor in the drain pan can stick in the alarm position or fail electrically, falsely reporting high water even when the pan is dry.
- **Bad indoor PCB or control board input** If the indoor board cannot read the level sensor correctly or does not respond to the remote, MRCOOL requires indoor PCB replacement.
- **Loose or damaged wiring to the level sensor** A connector issue or broken wire between the float switch circuit and the indoor board can cause intermittent or permanent alarm faults.

## Step-by-Step Fix {#fix}

1. **Confirm the code is real.** Check that the display shows EH 0E and not a temperature reading or garbled code, since MRCOOL notes the display can show undefined codes.
2. **Test remote control response.** Try to operate the unit with the remote. If the indoor unit does not respond to any remote commands, the indoor PCB requires replacement per MRCOOL troubleshooting guidance.
3. **Inspect the condensate drain pan and line.** Power off the unit, remove the indoor unit cover, and check for standing water in the pan. Look for blockages, kinks, or improper slope in the drain line and clear any obstructions.
4. **Check the water-level float or sensor.** Locate the float switch assembly in the drain pan. Gently move the float to verify it is not stuck. Look for debris or buildup around the sensor.
5. **Inspect wiring and connectors.** Trace the wires from the level sensor to the indoor board. Check for loose, corroded, or damaged connectors and restore secure connections.
6. **Clear the drain path completely.** Flush the condensate line with warm water or a wet-dry vacuum to make sure full flow. Reattach the line and verify proper slope away from the unit.
7. **Restore power and retest.** Turn the unit back on and monitor for the EH 0E code. If the alarm clears and the unit operates normally, the repair is complete. If the code returns and the remote test failed, replace the indoor PCB.

## When to Call a Pro

Call a qualified HVAC technician if the unit does not respond to the remote control, if you are not comfortable working with refrigerant system components or electrical boards, or if the code returns after clearing the drain and checking the float. Indoor PCB replacement requires proper handling of control wiring and may involve refrigerant system shutdown. If you see refrigerant leaks, ice buildup, or unusual noises along with this code, stop using the unit and get professional help. Licensed technicians have the tools to test the level-sensing circuit, verify board inputs, and safely replace control boards without damaging the unit.
