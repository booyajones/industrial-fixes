## Kenmore Dryer E4A Error Code — What It Means

The E4A error code on Kenmore dryers is not universally defined across all models. Different Kenmore dryer platforms may assign this code to different faults, ranging from thermistor failures to control board communication errors. Without documentation specific to your model number, the exact meaning cannot be stated with certainty.

Because Kenmore sources dryers from multiple manufacturers (Whirlpool, LG, and others), the diagnostic tree for E4A varies. Always consult your owner's manual or the wiring diagram inside the cabinet to confirm what E4A indicates for your specific unit before replacing parts.

## Before You Replace Anything

Many homeowners replace the main control board when they see an error code, but a failed thermistor or loose wiring harness is often the real culprit. Use a multimeter to test sensor resistance and check connectors before swapping the board.

## Common Causes

- **Failed thermistor or temperature sensor (~35%)** A thermistor that reads out of range or open circuit will trigger communication or sensor fault codes on many Kenmore dryers.
- **Loose or corroded wiring harness connector (~30%)** Vibration and heat can loosen connectors between the control board and sensors, causing intermittent communication errors.
- **Failed main control board (~20%)** If the control board cannot read sensor inputs correctly or has internal faults, it will post an error code.
- **Damaged wiring harness (~10%)** Worn insulation or pinched wires between the control board and sensor circuits can create open or short conditions.
- **Faulty user interface board (~5%)** In models with separate UI and main boards, a communication breakdown between them can present as a sensor or system error.

## Step-by-Step Fix {#fix}

1. **Unplug the dryer** from the wall outlet and leave it unplugged for at least 60 seconds to reset the control board.
2. **Remove the top or rear panel** (consult your model's service manual for access) to expose the control board and sensor wiring.
3. **Inspect all wiring harness connectors** at the control board, thermistor, and any other temperature sensors for looseness, corrosion, or burnt contacts, and reseat each one firmly.
4. **Locate the thermistor or temperature sensor** (usually mounted on the blower housing or exhaust duct) and disconnect its connector.
5. **Test the sensor resistance** with a multimeter set to ohms. Compare the reading at room temperature to the specification table in your service manual (typical range is several thousand ohms at 70°F, but this varies by model).
6. **Replace the sensor** if it reads open, shorted, or far outside the expected range. If the sensor tests good, inspect the wiring harness for breaks or shorts.
7. **Reconnect all wiring**, reassemble the panels, plug in the dryer, and run a test cycle to verify the error code is cleared.

## When to Call a Pro

Call a qualified appliance technician if you are not comfortable using a multimeter to test sensor resistance or if the error persists after replacing the sensor and inspecting all wiring. A pro can use advanced diagnostics to test control board outputs, check communication buses between boards, and verify that the heating element and blower circuits are not creating noise that corrupts sensor signals. If your dryer is still under warranty or a service contract, contact Kenmore or your retailer before opening the cabinet.

**Rough cost:** DIY runs about $25-90 in parts, 30-60 min. A pro service call runs about $120-250.
