## Mitsubishi E2 Error Code — What It Means

On Mitsubishi Electric heat pumps, E2 is a remote controller or controller-board fault, not a refrigerant or compressor problem. Mitsubishi's published troubleshooting references list E2 as a remote controller control board error. In practical terms, the fault sits on the controls side: the wired or handheld remote controller, its internal board, or the indoor-unit control interface that reads it. The code often appears when the controller's clock function stops operating normally or after a power event disrupts the controller's memory.

## Common Causes

- **Defective remote controller or failed controller PCB** The handheld or wired remote has an internal board failure, often in the clock circuit, preventing normal operation.
- **Poor connection or damaged wiring between controller and indoor unit** Loose terminals, corroded connectors, or broken wiring interrupt communication and trigger the fault.
- **Power outage or surge** A power event can leave the controller's clock or memory faulted, and the code persists even after power returns.
- **Indoor-unit control or interface board fault** Less commonly, the indoor unit's control board or the circuit that reads the remote develops a communication issue.
- **Noise or interference in the control circuit** Electrical noise or miscommunication in the low-voltage control wiring can contribute to controller-side faults.

## When to Call a Pro

Call a qualified HVAC technician if the code returns after a power reset, if you are not comfortable working with low-voltage control wiring, or if replacing the remote controller does not clear the fault. Mitsubishi's published troubleshooting guidance instructs homeowners to stop and call for repair when a code other than 00 is present. A technician has the diagnostic tools and service manuals to test the indoor control board, verify communication between components, and properly clear error history after the repair is complete.
