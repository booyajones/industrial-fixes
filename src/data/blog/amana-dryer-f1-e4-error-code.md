## Amana Dryer F1 E4 Error Code — What It Means

Amana does not document an F1 E4 code in its dryer service literature. The code Amana dryers display for power-supply problems is F4 E4, which means low or no line voltage reaching the dryer. If your display shows F1 E4, verify the exact code in your owner's manual or on the wiring diagram inside the dryer cabinet, because code definitions vary by model and year.

If the code is actually F4 E4, it signals that the dryer's control board is not seeing the full 240-volt supply required to energize the heating element. The most common reason is that one of the two circuit breakers or fuses feeding the dryer has tripped or blown. Because electric dryers run on a split 240-volt circuit with two hot legs, one breaker powers the motor (allowing the drum to turn) while the other powers the heater. When only one trips, the drum still spins but the dryer produces no heat and the control logs a low-voltage fault.

## Before You Replace Anything

Homeowners often order a new control board or heating element when they see a fault code, but F4 E4 is almost always a house-circuit or power-cord issue outside the dryer itself. Check both breakers and measure outlet voltage before buying any parts.

## Common Causes

- **One tripped or blown breaker/fuse (~60%)** Amana electric dryers require two breakers or fuses on a 30-amp circuit, one for the motor and one for heat, so a single trip will cause low voltage and block heating.
- **Loose or improperly installed power cord (~20%)** Loose terminal screws at the dryer's connection block or a power cord installed backwards can prevent full 240-volt supply from reaching the controls.
- **Faulty wall receptacle or outlet wiring (~10%)** A worn receptacle, corroded outlet terminals, or a failed leg of the branch circuit can drop voltage below the required 240 V.
- **Low utility line voltage (~5%)** Utility brownouts or service-entrance issues can reduce incoming voltage to the home, and Amana directs you to a qualified electrician if this is the case.
- **Misread fault code (~5%)** If the display actually shows F1 E4 rather than F4 E4, the meaning may differ and you should consult your model's service sheet or owner's manual for the correct definition.

## Step-by-Step Fix {#fix}

1. **Clear the code** by pressing any button on the control panel, then watch to see if it reappears when you start a new cycle.
2. **Check both circuit breakers** at your home's electrical panel and confirm they are fully in the ON position. Reset any tripped breaker by switching it all the way off, then back on.
3. **Unplug the dryer** (or turn off both breakers) and remove the rear access panel or lower front toe panel to expose the terminal block where the power cord connects.
4. **Inspect terminal screws** on the dryer's connection block and tighten any that are loose. Verify the power cord is installed according to the wiring diagram on the dryer cabinet.
5. **Measure supply voltage** at the wall receptacle using a multimeter. You should read approximately 240 V between the two hot slots and about 120 V from each hot slot to neutral.
6. **Restore power** and run a timed dry heated cycle for at least five minutes. If the code does not return and the dryer heats normally, the repair is complete.
7. **Call a qualified electrician** if voltage is low at the outlet, if a breaker continues to trip, or if the code persists after confirming proper cord installation and full voltage supply.

## When to Call a Pro

Call a licensed electrician if you measure low voltage at the outlet, if one or both breakers trip repeatedly, or if you are uncomfortable working with 240-volt circuits. Call an appliance technician if the code persists after confirming full voltage supply and tight terminal connections, because the fault may then lie in the dryer's control board or internal wiring. Amana's service documentation directs you to a qualified electrician for persistent low-voltage faults, since the root cause is usually in the home's branch circuit rather than inside the dryer itself.

**Rough cost:** DIY runs about $0-50 in parts (if a power cord needs replacement), 15-30 min. A pro service call runs about $100-200 service call plus parts if wiring or outlet needs work.
