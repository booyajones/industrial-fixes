## Frigidaire Dryer AL-18 Error Code — What It Means

The AL-18 code is not a standard documented Frigidaire dryer fault code in manufacturer materials. It may be a misread of the E68 error, which indicates a stuck key or button on the console, or a keypad and user interface problem. E68 appears when the control board detects continuous input from a button that is stuck down, contaminated with moisture or residue, or failed electronically. In some field cases, technicians have found that what appears to be a console fault was actually caused by failed thermostats or heater circuit issues triggering a false keypad error.

If your display shows AL-18, verify the exact characters and consult your model's manual, because code formats vary across Frigidaire platforms. The repair steps below address the verified E68 console fault, which is the closest match in available documentation.

## Common Causes

- **Stuck or jammed button** A control panel button is physically stuck in the pressed position and not returning to neutral.
- **Moisture or residue on keypad** Spills, humidity, or detergent residue on the console surface interfere with button contact operation.
- **Failed touchpad or user interface board** The membrane switch or electronic interface board behind the buttons has worn out or shorted.
- **Loose ribbon cable or connector** The ribbon cable linking the console to the main control board is unseated or damaged.
- **Main control board misreading input** The control board falsely detects a key press due to internal fault or bad solder joints.
- **Failed thermostat or heater circuit fault** Field reports show burned thermostats or heater wiring issues can trigger console error codes on some models.

## Step-by-Step Fix {#fix}

1. **Disconnect power** at the breaker or unplug the dryer completely before opening any panels or touching internal components.
2. **Inspect all console buttons** for any that feel stuck, slow to pop back up, or crooked in their openings.
3. **Clean and dry the control panel** thoroughly with a soft cloth and mild cleaner to remove any moisture, detergent residue, or sticky buildup around the buttons.
4. **Run the dryer's key test mode** if your model supports it to identify which button the control board thinks is stuck, then retest after reassembly to confirm the fix.
5. **Check all ribbon cable and harness connections** at the console and main control board for loose plugs, bent pins, or damaged flat cable.
6. **Inspect thermostats and heater circuit wiring** for burns, open connections, or failed components if the console tests clean, because some field cases trace this symptom to the heater side.
7. **Replace only the confirmed failed part** after testing, whether that is the button mechanism, user interface board, ribbon cable, thermostat, or main control board.

## When to Call a Pro

Call a qualified appliance technician if you cannot identify which button is stuck using the key test, if the error returns immediately after cleaning and reseating connectors, or if you are uncomfortable working with the dryer's electrical components and control boards. Also call for help if the fault trace leads to the heater circuit and you do not have a multimeter and the skills to safely test thermostats and continuity. Professional diagnostics are worth the cost when multiple components may be involved or when the code does not match any published Frigidaire documentation for your specific model.
