## What this code means
The F6E3 error code on an Amana dryer indicates a voltage sensing or power supply error in the appliance's electronic control system. This code is tied to the dryer's power-sensing electronics and control board, not to mechanical components like the drum, belt, heating element, or airflow path. The fault means the control system has detected an interruption, instability, or anomaly in the power supply reaching the electronics.

Amana's official guidance for F6E3 starts with a simple power reset. Turn off the circuit breaker for five minutes, restore power, then run a Time Dry cycle and monitor for about five minutes to see if the code returns. If the error clears and stays off, the issue was likely a transient power glitch. If F6E3 comes back, the problem is persistent and points to an issue with the incoming power supply, wiring connections, or the control electronics themselves.

## Before You Replace Anything

Many homeowners assume F6E3 means a heating element or thermal fuse failure and replace those parts unnecessarily. This code is an electronics and power-supply fault, not a heat or airflow problem. Always start with the five-minute power reset and check the outlet and breaker before buying any parts.

## Common Causes

- **Intermittent or unstable incoming power (~40%)** Loose breaker, weak outlet, or voltage sags prevent the control from maintaining steady power sensing.
- **Faulty main control board (~30%)** Internal failure in the power-sensing circuitry of the appliance control unit triggers F6E3.
- **Loose or corroded wiring connections (~20%)** Damaged connectors or harness terminals between the power supply and control create intermittent contact.
- **Defective user interface or console assembly (~10%)** A fault in the operator control side of the electronics path can register as a voltage-sensing error.

## Step-by-Step Fix {#fix}

1. **Turn off the circuit breaker** that feeds the dryer and leave it off for a full five minutes to allow the control to reset completely.
2. **Restore power** at the breaker and press the dryer's power button to turn the unit on.
3. **Select a Time Dry cycle** and start the dryer. Watch the display for about five minutes to see if F6E3 reappears.
4. **If the code clears and stays off**, the issue was a transient power glitch and no further action is needed. If F6E3 returns, continue troubleshooting.
5. **Test the dryer outlet** with a multimeter to confirm both 120 V legs are present and stable (240 V total between the hot legs). If the outlet reads low or intermittent voltage, repair or replace the outlet or tighten the breaker.
6. **Unplug the dryer** and pull it away from the wall. Remove the top or rear panel to access the control board and wiring harness. Inspect all connectors between the power supply, main control, and console for looseness, corrosion, or burn marks. Reseat any loose connectors.
7. **If wiring and connectors look good**, replace the main control board. If F6E3 persists after board replacement, replace the user interface or console assembly. Reassemble the dryer, plug it in, and run a test cycle to confirm the code is gone.

## When to Call a Pro

Call a professional if you are not comfortable working with 240 V power, testing outlets with a multimeter, or removing and replacing electronic control boards. If the five-minute power reset does not clear F6E3 and you see no obvious damage at the connectors, a qualified appliance technician can trace the power-sensing circuit, verify stable incoming voltage at the terminal block, and replace the correct control component without trial and error. Also call a pro if you suspect the home's electrical panel or breaker is at fault, as that work requires a licensed electrician.

**Rough cost:** DIY runs about $80–180 in parts (control board or UI console), 45–90 min. A pro service call runs about $150–350.
