## Mitsubishi U4 Error Code — What It Means

The U4 error on Mitsubishi Electric heat pumps and mini-splits indicates an open or short circuit in one of the outdoor unit thermistors (temperature sensors). The outdoor control board cannot get a valid temperature reading from the sensor, so the system shuts down to protect itself. On some Mitsubishi product families the U4 code may also refer to indoor-outdoor communication faults, so always verify the exact code definition for your model family in the service literature before starting repairs.

## Common Causes

- **Failed outdoor thermistor** The sensor itself has failed internally, reading open circuit, short circuit, or out-of-range resistance.
- **Loose or corroded sensor wiring** Connector plugs at the outdoor board or sensor have backed out, corroded, or oxidized, breaking the signal path.
- **Damaged thermistor harness** Wiring between the sensor and outdoor control board is pinched, cut, or has deteriorated insulation causing a short.
- **Outdoor control board fault** The thermistor input circuit on the outdoor PCB has failed, even though the sensor itself tests normal.
- **Wrong code definition for your model** Some Mitsubishi product lines use U4 for communication or addressing faults instead of thermistor faults, so consult your service manual.

## Step-by-Step Fix {#fix}

1. **Verify the code definition** for your exact Mitsubishi model family in the service manual or tech sheet, because U4 is not defined identically across all product lines.
2. **Turn off power** at the outdoor disconnect and the indoor breaker, then wait two minutes for capacitors to discharge.
3. **Remove the outdoor unit cover** and locate the thermistor connectors on the control board, then trace each sensor wire to its mounting point on the heat exchanger or compressor.
4. **Inspect all thermistor harness connectors and wiring** for loose pins, corrosion, pinched insulation, or broken conductors, and repair or replace any damaged sections.
5. **Use a multimeter to check each thermistor** for open or short circuit at the sensor connector and at the board connector, comparing readings to the model's resistance table if available.
6. **Access the service diagnostic menu** on the Mitsubishi controller (if equipped) and request the fault detail code to identify which specific thermistor the board reports as faulty.
7. **Replace the identified thermistor** if it tests open, short, or out of range, or replace the outdoor control board if the sensor tests normal but the fault persists, then clear the error and run the system to verify the code does not return.

## When to Call a Pro

Call a licensed HVAC technician if you do not have a multimeter and refrigeration safety training, if the fault persists after replacing the sensor, or if you cannot safely access the outdoor unit electrical components. Mitsubishi heat pumps contain live voltage, pressurized refrigerant, and require model-specific diagnostic tools to identify which thermistor has failed. A qualified technician can use the service controller menu to pinpoint the exact sensor, verify the control board thermistor input circuit, and make sure refrigerant integrity during the repair.
