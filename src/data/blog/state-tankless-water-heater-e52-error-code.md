## State E52 Error Code — What It Means

The E52 error code on State tankless water heaters indicates a communications failure between the user interface (display panel) and the main control board. The two electronic components are not successfully exchanging data, so the unit locks out and stops heating until the communication issue is resolved.

This is not a sensor problem or water flow issue. It is strictly a failure in the internal electronic connection that allows the display to talk to the control board. The heater will typically remain in lockout mode until you restore the communication path or replace the failed component.

## Common Causes

- **Loose or improperly seated wiring harness** The communication cable between the user interface and control board has come loose, shifted, or was not fully inserted during installation or a prior repair.
- **Damaged communication wiring or connectors** The harness or plug pins between the display and board have physical damage, corrosion, or bent contacts that interrupt the signal.
- **Failed user interface module** The display panel itself has failed and can no longer send or receive data from the control board.
- **Failed main control board** The control board electronics have failed on the communication circuit, preventing it from linking to the user interface.
- **Intermittent power interruption** A power surge, brownout, or electrical glitch caused the board-to-display link to drop out and not re-establish automatically.

## Step-by-Step Fix {#fix}

1. **Turn off power** to the water heater at the circuit breaker or disconnect switch before touching any wiring or internal components.
2. **Remove the front cover** to access the user interface and control board, following your model's service instructions.
3. **Inspect the communication harness** between the user interface and control board for any loose connectors, visible damage, corrosion on pins, or wires that have pulled out of terminals.
4. **Disconnect and reconnect** the communication cable firmly at both the display and control board ends to make sure a solid seated connection.
5. **Restore power** and observe whether the E52 code clears and the heater resumes normal operation.
6. **If the fault returns immediately** or persists, contact State technical support or proceed with component-level diagnosis to determine whether the user interface or control board has failed.
7. **Replace the faulty component** (user interface or control board) based on diagnostic results or tech-support guidance, then verify that communication is restored and the code does not return.

## When to Call a Pro

Call a licensed technician or State technical support if you are uncomfortable working with live electrical components, if re-seating the wiring does not clear the code, or if you need to diagnose whether the user interface or control board is at fault. Component-level replacement requires matching exact part numbers to your model and verifying proper communication after installation. A qualified tech has the diagnostic tools and factory service literature to isolate the failing side of the communication link quickly and safely.
