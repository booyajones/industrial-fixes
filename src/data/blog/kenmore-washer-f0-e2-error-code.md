## Kenmore Washer F0 E2 Error — What It Means

The F0 E2 code on a Kenmore washer indicates excessive suds in the wash basket. The washer has detected too much foam and will automatically run a suds-reduction routine. During this routine the machine may slow the spin speed, extend the cycle time, or add extra rinses to clear the suds. This is not a drain fault or a motor problem. The code appears when the control board sees foam levels that could interfere with normal washing and rinsing.

The washer is designed to handle the problem on its own by adjusting the cycle. You should let the current cycle finish rather than stopping it mid-run. Once the load is complete, check whether suds remain in the tub. If they do, run an additional rinse and spin cycle to flush them out. The root cause is almost always detergent related rather than a hardware failure.

## Before You Replace Anything

Homeowners sometimes replace the pressure switch or control board thinking F0 E2 is a sensor fault. Before ordering any parts, confirm you are using HE detergent at the correct dose and run a rinse cycle to clear suds.

## Common Causes

- **Non-HE detergent or excessive dose (~70%)** Regular (non-HE) laundry soap or using more than the cap line recommends creates thick, persistent suds that trigger the code.
- **Bulk dispenser set incorrectly (~15%)** If your model has an automatic dispenser cartridge and you also pour detergent into the tray, the machine dispenses a double dose and oversuds.
- **Very soft water amplifying suds (~10%)** Soft water requires less detergent because it lathers more easily, so the normal dose can still cause excessive foam.
- **Underfilled or overfilled load size (~5%)** A tiny load with a full detergent dose or an overstuffed drum that traps suds can both lead to foam buildup the washer cannot rinse away.

## Step-by-Step Fix {#fix}

1. **Let the cycle finish** if the washer is currently running a suds-reduction routine and the code is displayed during the wash.
2. **Remove the load** once the door unlocks and check the tub for visible foam or suds sitting on top of the water or clinging to the basket.
3. **Run a Rinse & Spin cycle** with the tub empty (or with the sudsy load still inside) to flush any remaining detergent out of the system.
4. **Verify your detergent** is labeled HE and measure no more than the line on the cap that matches your load size (typically 1-2 tablespoons for a normal load).
5. **Check the bulk dispenser setting** in the control panel if your model has an automatic cartridge, and turn off auto-dispense if you also manually add detergent to the drawer.
6. **Reduce detergent by half** if you have very soft water or consistently see suds even when using HE soap at the recommended amount.
7. **Monitor the next few loads** to confirm the code does not return, and call for service only if F0 E2 reappears after correcting detergent type, dose, and dispenser settings.

## When to Call a Pro

Call a qualified appliance technician if the F0 E2 code continues to appear after you have switched to HE detergent, reduced the dose to the recommended amount, disabled any bulk dispenser conflict, and run extra rinse cycles to clear suds. Persistent codes may point to a control or sensing issue that mimics a suds condition, but the manufacturer guidance for F0 E2 does not list a specific part replacement as the primary fix. A technician will verify that the pressure system and control board are reading basket conditions correctly and will consult the service diagnostics for your exact Kenmore model number to rule out related faults.

**Rough cost:** DIY runs about $5-15 for HE detergent, 10-20 min. A pro service call runs about $100-180 service call if detergent changes do not resolve it.
