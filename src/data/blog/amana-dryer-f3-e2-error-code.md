## Amana Dryer F3 E2 Error Code — What It Means

The F3 E2 error code is not documented for Amana dryers in any manufacturer service manual or technical database. This code is exclusive to Amana and Whirlpool top-load washers, where it signals a water temperature sensor circuit failure. If you see F3 E2 on an Amana appliance, verify that the unit is actually a washer, not a dryer. The control board has detected that the water temperature sensor (NTC thermistor) is sending an invalid resistance signal, either because the sensor has failed, the wiring is broken or corroded, or the control board input circuit is damaged.

If you own an Amana dryer and are seeing an error code, consult your model's wiring diagram or owner's manual to confirm the exact code displayed. Dryers from sister brands (Maytag, Whirlpool) may use similar alphanumeric codes for different faults, such as moisture sensor failures, but these are distinct from the washer-specific F3 E2 definition.

## Before You Replace Anything

Homeowners sometimes replace the control board first when the actual fault is a broken wire or failed temperature sensor. Use a multimeter to test sensor resistance (typically 10-20 kΩ at room temperature for most models) and inspect the harness before ordering a board.

## Common Causes

- **Failed temperature sensor (NTC thermistor) (~65%)** The internal thermistor element degrades over time or breaks, sending an out-of-range resistance signal to the control board.
- **Broken or corroded wiring (~20%)** The wires connecting the sensor to the control board fracture, pull loose from crimp connectors, or corrode due to vibration and moisture exposure.
- **Heating element assembly failure (~10%)** The sensor is often mounted on or embedded in the heating element, and a burnt or corroded element can damage the sensor connection.
- **Control board input circuit damage (~5%)** The board's temperature sensor input channel is defective or miswired, misreading valid sensor signals as faults.

## Step-by-Step Fix {#fix}

1. **Verify appliance type and model.** Confirm the unit is an Amana or Whirlpool top-load washer, not a dryer. Locate the model number plate and cross-reference the error code in the owner's manual or wiring diagram.
2. **Disconnect power** for at least five minutes to reset the control board logic, then reconnect and observe if the code reappears immediately.
3. **Access the heating element assembly.** Unplug the washer, remove the front or rear access panel (consult your model's service manual), and locate the heating element at the bottom of the drum. The temperature sensor is typically a small thermistor with two wires attached to the element housing.
4. **Inspect wiring and connectors.** Check the sensor harness for cracks, loose crimp terminals, corrosion, or fraying near vibration points. Repair or replace damaged wiring segments before proceeding to sensor testing.
5. **Test sensor resistance.** Disconnect the sensor wires from the control board terminal, set a multimeter to ohms, and measure resistance across the sensor leads. Compare the reading to your model's specification table (typically 10-20 kΩ at room temperature). If the reading is infinite, near zero, or outside the valid range, replace the sensor.
6. **Replace the temperature sensor (if faulty).** Order the correct OEM sensor for your model, disconnect the old sensor from the heating element, install the new sensor, reconnect the wiring, and secure all fasteners.
7. **Test the repair.** Restore power, run a short wash cycle with a small load, and monitor for the F3 E2 code. If the code does not return and water heats normally, the repair is complete.

## When to Call a Pro

Call a professional if you are uncomfortable working with multimeters, disassembling the washer cabinet, or tracing wiring through the control board. Also call a technician if the sensor and wiring test correctly but the code persists, since the control board input circuit may require bench testing or replacement. If you own an Amana dryer and see an unfamiliar error code, a technician with access to the manufacturer's service database can confirm the exact fault definition and avoid incorrect part replacements.

**Rough cost:** DIY runs about $15-40 for sensor, 20-40 min. A pro service call runs about $120-220 for service call and sensor replacement.
