## Electrolux Dryer E13 Error — What It Means

The E13 error code on an Electrolux dryer signals a system fault, but the exact meaning varies by model and year. Some models use E13 to indicate a communication problem between the control board and other components, while others may link it to a temperature sensor issue or internal electronic fault. Because Electrolux uses different control systems across its dryer lineup, the same code can point to different underlying problems. Always consult your owner's manual or the wiring diagram on the dryer cabinet for the specific definition that applies to your unit.

In general, electronic error codes like E13 suggest a failure in the dryer's control circuit rather than a mechanical breakdown. The control board relies on signals from sensors and switches to manage the heating cycle and drum rotation. When one of those signals is missing or out of range, the board logs a fault and halts operation. Because the code is not universally defined across all Electrolux dryers, it is important to verify the meaning for your specific model before ordering parts.

## Before You Replace Anything

Many homeowners replace the main control board first, assuming any electronic error means the board is dead. In reality, a failed sensor or loose connector is the more common culprit. Test continuity on the temperature sensor and check all wiring harness connections before spending money on a new board.

## Common Causes

- **Faulty temperature sensor (~35%)** A thermistor or temperature sensor that has drifted out of range or failed open will send an invalid signal to the control board, triggering a fault code.
- **Loose or corroded wiring harness (~25%)** Vibration and heat can work connectors loose or corrode pins, breaking the communication path between the control board and sensors.
- **Control board glitch (~20%)** A temporary software fault or power surge can cause the board to log an error that clears after a full power reset.
- **Failed control board (~15%)** The main electronic control board may have a solder joint failure or damaged component that prevents normal operation.
- **Defective user interface board (~5%)** On models with a separate display panel, a communication failure between the user interface and main control board can generate an E13 code.

## Step-by-Step Fix {#fix}

1. **Unplug the dryer** from the wall outlet or switch off the circuit breaker to cut all power.
2. **Wait 3 minutes**, then restore power and press Start to see if the error clears. Many electronic faults are temporary and will reset.
3. **Locate the wiring diagram** on the back panel or inside the door frame of your dryer to confirm what E13 means for your specific model.
4. **Remove the top or rear panel** using a screwdriver or nut driver to access the control board and sensor locations.
5. **Inspect all wire harness connectors** on the control board, user interface, and sensors. Press each connector firmly to reseat and look for bent pins or melted plastic.
6. **Test the temperature sensor** (thermistor) with a multimeter set to resistance. Compare the reading at room temperature to the specifications in your service manual; if the reading is infinite or zero, the sensor has failed.
7. **Replace the faulty component**. If the sensor is bad, disconnect the wiring, unclip or unscrew the sensor from the blower housing or drum, and install the new one. If the control board is at fault, remove the mounting screws and transfer all connectors to the new board, taking a photo first to guide reassembly.
8. **Reassemble the panels**, restore power, and run a test cycle to confirm the error is gone.

## When to Call a Pro

Call a professional if you cannot locate the wiring diagram for your model or if the diagram identifies E13 as a sealed-system or high-voltage fault. Also call for help if you have already replaced the temperature sensor and reseated all connectors but the error persists, since tracing control-board signals requires specialized tools and schematics. If you are uncomfortable working inside the dryer cabinet or testing components with a multimeter, a qualified appliance technician can diagnose the exact cause in one visit and avoid the cost of trial-and-error part replacement.

**Rough cost:** DIY runs about $30–120 in parts, 45–90 min. A pro service call runs about $150–280.
