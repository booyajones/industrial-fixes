## State Water Heater E155 Error Code — What It Means

E155 indicates that communication between the control board and Sensor 2 has been lost or interrupted. This code is associated with integrated RDS controllers that manage refrigerant detection sensor systems, not standard State water heater combustion or ignition systems. If your State water heater displays E155, verify whether the unit uses an integrated controller or confirm your exact model family, since this code does not appear in the manufacturer's public residential tankless error-code documentation.

The code triggers when the control board stops receiving a signal from Sensor 2, either because the sensor has failed, the wiring harness is damaged, or the connector has come loose or corroded. Communication failures like this are typically caused by physical connection issues rather than internal sensor electronics, so checking the wiring and plug first will resolve most cases.

## Common Causes

- **Loose or disconnected sensor plug** The connector at Sensor 2 or at the control board has vibrated loose or was not fully seated during the last service.
- **Damaged or corroded wiring harness** The cable between Sensor 2 and the control board is pinched, cut, or has corroded terminals that interrupt the signal.
- **Failed Sensor 2** The sensor itself has failed internally and no longer transmits a signal to the control board.
- **Corroded or bent connector pins** Moisture or physical damage has corroded or deformed the pins in the sensor plug or board socket.
- **Control board input circuit failure** The board's receiver circuit for Sensor 2 has failed and cannot read even a healthy sensor signal.

## Step-by-Step Fix {#fix}

1. **Turn off power** to the water heater at the breaker or disconnect switch before inspecting any electrical connections.
2. **Locate Sensor 2** and trace its wiring harness from the sensor body to the control board, checking for visible damage, pinches, or cuts along the cable.
3. **Inspect the connector** at both the sensor and the control board end, looking for loose fit, corrosion, bent pins, or debris in the socket.
4. **Reseat the plug** at both ends by unplugging and firmly reconnecting, making sure the latch clicks or the connection is snug and fully engaged.
5. **Restore power** and press the reset or test button on the control board to retest communication and see if the code clears.
6. **Replace Sensor 2** if the code persists after verified clean and secure connections, then retest to confirm communication is restored.
7. **Test or replace the control board** if a new sensor still triggers E155 and all wiring and connectors have been confirmed intact, as the input circuit may have failed.

## When to Call a Pro

Call a qualified technician if you are not comfortable working with low-voltage control wiring or if the code persists after you have reseated connectors and replaced Sensor 2. Because E155 is tied to an integrated controller system rather than standard State tankless error codes, a technician familiar with RDS refrigerant detection modules or your specific model's control architecture will be able to confirm the sensor type, test communication signals with a multimeter, and determine whether the control board input circuit has failed. Professional diagnosis is also recommended if your unit's documentation does not list E155 or if you cannot positively identify Sensor 2 on your appliance.
