## Electrolux Dryer EA4 Error Code — What It Means

The EA4 code (also displayed as E 4) on an Electrolux dryer indicates a humidity sensor failure in the moisture-sensing system. Electrolux's official error-code guide identifies this as "Humidity Sensor Failed." The dryer may complete the current cycle and still run manual timed cycles, but if the error continues, service is required.

This is not a heating fault or a generic wiring issue. The code specifically points to a problem with the sensor assembly that detects moisture in your laundry, the wiring that connects it to the control board, or the control board itself. The sensor uses metal bars inside the drum to measure conductivity across wet fabric. When that circuit fails or gives inconsistent readings, the EA4 code appears.

## Before You Replace Anything

Many people replace the electronic control board first, assuming it is the brain of the problem. Start instead by cleaning the moisture sensor bars in the drum and inspecting the sensor harness and connectors for damage or corrosion, which solve most EA4 codes at no cost.

## Common Causes

- **Dirty or obstructed humidity sensors (~50%)** Lint film, fabric-softener residue, or hard-water deposits coat the metal sensor bars inside the drum and prevent accurate moisture readings.
- **Damaged sensor wire harness or connector issue (~25%)** The wiring between the humidity sensor and the control board becomes loose, corroded, or damaged, breaking the signal path.
- **Failed humidity sensor assembly (~15%)** The sensor bars or the embedded circuit inside the sensor assembly fail electrically and no longer report moisture data to the control board.
- **Electronic control board fault (~10%)** If the sensor and wiring test good, the control board itself may have a failed input circuit that cannot read the humidity sensor correctly.

## Step-by-Step Fix {#fix}

1. **Disconnect power** to the dryer by unplugging it or turning off the circuit breaker, and leave it off for at least five minutes to clear any transient faults in the control board.
2. **Locate the moisture sensor bars** inside the drum, typically two metal strips mounted on the back or front wall of the drum near the lint filter.
3. **Clean the sensor bars** thoroughly with a cloth dampened with rubbing alcohol or white vinegar to remove lint film, fabric-softener residue, and mineral deposits, then dry them completely.
4. **Inspect the sensor wire harness** by removing the rear or top panel (consult your model's service manual) and tracing the wires from the sensor to the control board, looking for loose connectors, broken wires, or corrosion.
5. **Restore power** and run the dryer on an automatic cycle to see if the EA4 code returns.
6. **Replace the humidity sensor assembly** if the code persists and the wiring is intact, following the manufacturer's instructions to disconnect the old sensor and install the new one.
7. **Replace the electronic control board** only if a known-good sensor and verified wiring still produce the EA4 code, as the control board's input circuit may have failed.

## When to Call a Pro

Call a technician if you are not comfortable removing panels to access the wiring harness, if you cannot locate the moisture sensor bars in your model, or if the code returns after you have cleaned the sensors and verified the wiring. A qualified appliance repair technician has the tools to test continuity in the sensor circuit and can confirm whether the sensor assembly or the control board is at fault. Also call a pro if your dryer is still under warranty, as DIY work may void coverage.

**Rough cost:** DIY runs about $30-80 in parts (sensor assembly or harness), 20-45 min. A pro service call runs about $150-280 service call and parts.
