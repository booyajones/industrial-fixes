## LG Oven F1 Error Code — What It Means

The F1 error code on an LG oven indicates an upper oven thermistor (temperature sensor) error. The control board has detected that the sensor circuit is open, shorted, or otherwise invalid and can no longer trust the oven temperature reading. On LG dual-oven ranges, this code specifically points to the upper oven thermistor rather than the lower cavity.

When the control sees an out-of-range signal from the sensor, it throws F1 and typically disables oven operation to prevent unsafe temperatures. The fault can stem from the sensor itself, the wiring harness that connects it to the control board, or less often the control board's input circuit.

## Before You Replace Anything

Many people replace the main control board first, only to find the code returns. Always measure the sensor resistance at room temperature (should be about 1080–1100 ohms on most LG ovens) and inspect the harness for damage before buying any board.

## Common Causes

- **Failed oven temperature sensor/thermistor (~60%)** The sensor element degrades over time, especially from repeated heating cycles, and reads open or out of specification.
- **Loose, damaged, or heat-melted wiring harness (~20%)** Wires or connectors near the sensor can burn, pinch, or pull loose, breaking the circuit to the control board.
- **Corroded or loose connector at the sensor or board (~10%)** Connector terminals oxidize or work free over time, causing intermittent or permanent opens in the sensor circuit.
- **Faulty main control board input circuit (~10%)** If the sensor and all wiring test correctly, the control board's thermistor input stage may have failed and misreads a good sensor as open or shorted.

## Step-by-Step Fix {#fix}

1. **Cycle power first.** Press CLEAR/OFF on the control panel, then turn off the circuit breaker for 60 seconds and restore power to see if the code clears and stays away.
2. **Disconnect power at the breaker.** Confirm zero voltage at the range terminal block with a multimeter before proceeding.
3. **Access the oven temperature sensor.** Remove oven racks and locate the sensor probe in the upper oven cavity, usually mounted through the rear wall with a bracket and two screws.
4. **Inspect the sensor and harness.** Look for burn marks, melted insulation, pinched wires, or corrosion on the connector. Pull the harness connector and examine the terminals.
5. **Measure sensor resistance.** Disconnect the sensor leads and measure across the two sensor terminals with a multimeter set to ohms. A healthy LG oven sensor reads about 1080 to 1100 ohms at room temperature.
6. **Replace the sensor if out of range.** If resistance is open, shorted, or significantly outside the expected range, install a new oven temperature sensor and reconnect the harness.
7. **Check wiring and connectors if the sensor tests good.** Trace the harness back to the control board, verify continuity in each wire, and repair any damaged connections or replace the harness if needed. If wiring is intact and the fault persists, replace the main control board.

## When to Call a Pro

Call a technician if you are uncomfortable working inside a 240-volt appliance, if you cannot safely access the sensor in the oven cavity, or if the sensor and wiring both test good but the error persists and you prefer not to replace the control board yourself. A qualified appliance technician will carry a multimeter and the correct replacement parts, can verify proper sensor resistance and harness continuity at the board, and will make sure the new part is installed safely. Professional service also makes sense if your range is still under warranty or if you need the repair completed quickly without trial and error.

**Rough cost:** DIY runs about $20–50 for sensor, 30–60 min. A pro service call runs about $150–250 including service call and sensor.
