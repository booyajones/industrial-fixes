## Maytag Oven F2 Error Code — What It Means

On a Maytag oven or range, F2 is the high-temperature or oven overtemperature fault. The control has detected that the oven temperature has exceeded its safe limit, or it is being told that by a bad temperature-sensing circuit. On some Maytag models the display may show F2 E1 or F2 E0, which Maytag's product help ties to the user interface or keypad, control, or wiring rather than a simple bad sensor only.

Plain F2 typically means oven too hot or runaway temperature condition. F2 E1 on certain ranges points toward an issue with the user interface, keypad, control, or associated wiring. Technician-facing descriptions commonly group F2 with temperature runaway, shorted relay, or faulty temperature sensor or probe.

## Before You Replace Anything

Many people replace the main control board first when the real problem is a faulty oven temperature sensor. Always test the sensor resistance and inspect its wiring before ordering a new control.

## Common Causes

- **Defective oven temperature sensor or probe (~45%)** The sensor gives an incorrect high reading to the control, triggering the overtemperature fault even when the cavity is not actually hot.
- **Shorted or stuck relay on the control board (~25%)** A relay keeps bake or broil heat on when it should be off, causing a real runaway temperature condition.
- **Wiring harness problems (~15%)** Shorts, breaks, or intermittent connections between the sensor, control, and user interface produce false high-temperature signals.
- **User interface, keypad, or main control failure (~10%)** On models that report F2 E1 or F2 E0, the fault often traces to the touchpad, control assembly, or their associated wiring rather than the sensor alone.
- **Actual oven overheating (~5%)** Less commonly, the oven is genuinely overheating due to a control issue that fails to cycle the heating element off at the correct temperature.

## Step-by-Step Fix {#fix}

1. **Kill power at the circuit breaker** before any inspection. Restore power only for testing when safe to do so.
2. **Read the exact code variant** on the display. Plain F2 is usually sensor or relay related. F2 E1 or F2 E0 on some Maytag models points toward the user interface, keypad, control, or wiring.
3. **Inspect the oven temperature sensor or probe** for visible damage, loose terminals, or heat damage. The sensor is typically mounted in the rear wall of the oven cavity with a metal sheath and two-wire plug.
4. **Measure the sensor resistance** with a multimeter and compare it to the manufacturer's specification for your exact model. If the reading is open, shorted, or clearly out of range, replace the sensor.
5. **Check wiring continuity and shorts** between the sensor, control, and user interface, especially if the fault is intermittent or if you see F2 E1 or F2 E0.
6. **Check the control board output and relay behavior** if the sensor tests normal and the cavity is not actually overheated. A stuck relay or failed control is a common root cause of real runaway temperature.
7. **Reset power** after correcting the issue and verify the code does not return during a test bake cycle.

## When to Call a Pro

Call a professional if you are not comfortable working inside the range cabinet, if the wiring inspection reveals extensive damage, or if you have replaced the sensor and checked all wiring but the F2 code returns. A technician will test relay operation on the control board, measure control output voltages, and determine whether the main control or user interface assembly has failed. High-voltage AC connections are present throughout the oven circuit, so if you are unsure about safe disassembly or multimeter use, a service call is the safer choice.

**Rough cost:** DIY runs about $20-60 in parts, 30-60 min. A pro service call runs about $150-300.
