## Electrolux Washer Won't Turn On — What's Happening

When an Electrolux washer won't turn on, the manufacturer separates the symptom into two categories. If the display is completely blank and the ON/OFF button does nothing, the machine is not receiving or using power correctly. If the washer powers up but refuses to start a cycle, Electrolux points to a door not fully closed, an active child lock, or a displayed error code as the most common blockers.

This is not a single fault code in Electrolux service literature. Instead, it is treated as a no-response or no-start condition that requires separate checks of the power supply, door latch, control lock status, and any error codes on the display.

## Most Likely Causes

- **No mains power or outlet problem** The wall outlet has no voltage due to a tripped breaker, failed GFCI, or wiring fault.
- **Loose or failed plug connection** The power cord is not fully seated in the outlet or the cord itself is damaged.
- **Control lock or child lock enabled** A padlock symbol is lit on the display, blocking all buttons until the lock is cleared.
- **Door not latched fully** An overloaded drum or item caught in the door prevents the latch from engaging, so the cycle will not start.
- **Stored fault or error condition** A previous error code or internal fault is preventing the control from initializing until it is cleared.

## How to Diagnose and Fix {#fix}

1. Unplug the washer and plug a known-good device such as a hair dryer into the same outlet to verify the outlet has power.
2. If the outlet is dead, reset the circuit breaker or GFCI and confirm voltage before reconnecting the washer.
3. Unplug the washer for 15 minutes, then reconnect it to allow the control board to reset.
4. Check the display for a padlock symbol and, if present, disable child lock by holding the highlighted button for 3 to 5 seconds.
5. Open the door and remove enough laundry so the drum is not overloaded, then close the door firmly until you hear it latch.
6. Look for any error code on the display and follow the code-specific diagnostic path rather than guessing at parts.
7. If the display remains blank after a confirmed good outlet and 15-minute reset, note the model number and prepare for component-level testing of the line filter, main control board, and door lock assembly.

## When to Call a Pro

If the outlet is good, the reset procedure does not restore the display, and there is no child lock or door obstruction, the fault is inside the machine. A technician will use the wiring diagram for your specific model to test the line filter, power-switch interface, main control board, and door lock circuit. Component-level diagnosis requires a multimeter and knowledge of the board's power-on sequence, so call a qualified service provider at that point.
