## Frigidaire Dishwasher LO Error Code — What It Means

The LO code (often misread as L0 with a zero) indicates low or empty rinse aid in the dispenser. This is not a drain, latch, or water-inlet fault. Frigidaire's consumer code guide confirms LO is the rinse-aid warning, and the usual fix is to refill the dispenser to the proper level.

If the code persists after refilling, the dispenser assembly or its level-sensing function may be faulty. A clogged dispenser cap or a control-board glitch can also prevent the code from clearing.

## Common Causes

- **Rinse-aid reservoir empty or low** The most common cause is simply running out of rinse aid during normal use.
- **Dispenser cap or outlet clogged** Hardened residue or detergent buildup can block the dispenser door or sensing mechanism.
- **Faulty dispenser assembly or sensor** A failed actuator or level-sensing component prevents the control from registering a full reservoir.
- **Temporary control-board glitch** The code may remain displayed after refill until the control is reset by cycling power.
- **Wiring or connector issue** An intermittent open or poor connection between the dispenser and the control board can trigger the warning.

## Step-by-Step Fix {#fix}

1. Verify the display shows LO (letter O) rather than a different code such as i20, i30, or a door-latch warning.
2. Refill the rinse-aid dispenser to the fill line using liquid rinse aid, then close the cap securely.
3. Inspect the dispenser cap and outlet for hardened residue or blockage and clean with warm water if needed.
4. Reset power by unplugging the dishwasher or switching off the circuit breaker for 60 seconds, then restore power.
5. Run a short cycle and observe whether the LO code clears after refill and reset.
6. Test the dispenser assembly for proper operation and inspect wiring connectors for continuity if the code persists with a full reservoir.
7. Replace the dispenser assembly if the component tests faulty or the code returns repeatedly even when full.

## When to Call a Pro

Call a technician if the LO code returns after refilling the dispenser and resetting power, or if you are not comfortable testing electrical continuity on the dispenser circuit. A qualified service provider can verify the dispenser assembly, check control-board inputs, and replace faulty components with the correct part for your model. If the dishwasher is still under warranty, contact Frigidaire or an authorized service center before attempting any electrical repairs.
