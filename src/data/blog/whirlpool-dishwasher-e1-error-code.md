## Whirlpool F1E1 Error Code — What It Means

The F1E1 (or 1-1) code on a Whirlpool dishwasher indicates a control or relay fault detected by the main electronic control board. When this code appears, the dishwasher will start a drain sequence and then stop operating. This is an internal electrical fault within the control system, meaning the control has detected a stuck relay or communication problem rather than a simple sensor or drain issue.

Whirlpool's own diagnostic information identifies F1E1 as a stuck relay indication on the main control. The machine is protecting itself by shutting down after it detects this abnormality. This is not a water-level sensor, drain pump, or inlet valve code, despite what some third-party sources may say.

## Before You Replace Anything

Many homeowners replace the drain pump or water inlet valve because third-party sites incorrectly describe F1E1 as a drain or water-level code. Always inspect the wiring harness and connectors first before replacing the main control board.

## Common Causes

- **Failed or stuck relay on the main control board (~60%)** The control board has detected an internal relay that will not open or close correctly, triggering the F1E1 fault and stopping the cycle.
- **Loose, corroded, or damaged wiring harness connections (~25%)** Poor connections at the control board or related modules can create intermittent faults that the control interprets as a stuck relay.
- **Control board communication or power supply issue (~10%)** A problem with the power supply to the control or internal communication between board components can register as a relay fault.
- **Frayed or shorted harness wiring (~5%)** Damaged wiring between the control and other circuits can cause abnormal resistance or shorts that trigger the relay-fault detection.

## Step-by-Step Fix {#fix}

1. **Turn off water and power.** Shut off the water supply to the dishwasher and disconnect power at the breaker or by unplugging the unit for safety.
2. **Record the exact code.** Confirm the display shows F1E1 or 1-1 and note the symptom: the drain sequence starts and then the machine stops.
3. **Perform a power reset.** Leave power disconnected for at least 30 seconds to clear temporary control faults, then restore power and test.
4. **Access the main control board.** Remove the outer door panel (usually by removing screws around the perimeter) to expose the control board mounted behind the front panel.
5. **Inspect all wiring harness connectors.** Check every connector at the control board and associated modules for looseness, corrosion, fraying, or burn marks. Reseat any suspect connectors firmly.
6. **Retrieve the tech sheet.** Locate the diagnostic sheet behind the toe-kick or inside the door panel and use it to identify harness circuits and perform point-to-point continuity checks with a multimeter.
7. **Replace the main control board if harness is good.** If all connections test sound and continuity is normal, the control board has a failed internal relay and must be replaced. Transfer any attached wiring to the new board one connector at a time, then test the dishwasher.

## When to Call a Pro

Call a professional if you are not comfortable working with electrical connections or if you do not have a multimeter and the model-specific tech sheet to trace circuits. A technician can quickly verify whether the harness or the control board is at fault and has access to diagnostic mode tests that may pinpoint the exact relay circuit involved. If the code returns after a control board replacement, a pro can check for underlying power-supply or grounding issues that may be damaging new boards.

**Rough cost:** DIY runs about $150-$300 for control board, 45-90 min. A pro service call runs about $250-$450.
