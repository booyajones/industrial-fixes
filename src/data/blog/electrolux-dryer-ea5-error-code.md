## Electrolux Dryer EA5 Error Code — What It Means

The EA5 error code is a fatal fault indicating that the Main Electronic Control Board (also called the IQ Touch Board) has self-diagnosed itself as defective or is no longer functioning correctly. According to Electrolux documentation, this is described as a main voltage sensing failure where the board cannot verify the incoming power line integrity. The board locks out all operation to prevent unsafe conditions. Unlike non-critical errors, EA5 typically prevents the dryer from starting or continuing any cycle, and the board will stop power to the heating element and motor.

This is a terminal fault in the control system. The board's internal microcontroller or voltage sensing circuitry has determined it cannot operate safely. The dryer will not resume normal function until the underlying problem is corrected, which usually means replacing the control board itself.

## Before You Replace Anything

Many homeowners replace the main control board without first checking incoming voltage and wiring connections. Use a multimeter to verify voltage is within 110-125V for 120V systems or 220-250V for 240V systems, and inspect all wire harness connections for damage before ordering a board.

## Common Causes

- **Defective main control board (~65%)** The internal microcontroller or voltage sensing circuitry on the board has failed due to age, heat stress, or component burnout.
- **Power supply voltage spikes or surges (~15%)** Significant voltage fluctuations from storms or grid instability can damage the board's voltage regulation components.
- **Low incoming voltage (~8%)** If the incoming voltage is below the board's operating threshold (typically below 105V for 120V systems), the board registers a sensing failure.
- **Loose or damaged wiring connections (~7%)** Frayed, burnt, or loose wires connecting the main board to the power supply or user interface cause intermittent signals the board interprets as a fault.
- **Moisture or humidity ingress (~3%)** Water or humidity entering the control panel corrodes board contacts, particularly common in bathrooms or poorly vented areas.
- **Excessive heat buildup (~2%)** Restricted vents or prolonged high-heat operation degrade board components over time.

## Step-by-Step Fix {#fix}

1. **Disconnect power completely.** Unplug the dryer from the wall outlet or shut off the circuit breaker. Wait at least 5 minutes to allow the board to reset and clear any temporary logic errors. Reconnect power and check if the EA5 code clears. If it does not, proceed to the next step.
2. **Verify incoming voltage.** Use a multimeter to measure voltage at the dryer's power inlet terminals. For 120V systems, voltage must be between 110V and 125V. For 240V systems, voltage must be between 220V and 250V. If voltage is out of range or unstable, the issue is your home power supply and must be corrected by the utility company or an electrician.
3. **Remove the top and back panels.** Access the main control board by removing screws securing the dryer top and back cover. Locate the main board, typically mounted behind the control panel at the top front of the dryer.
4. **Inspect all wire harnesses.** Look closely at every wire connected to the main board. Check for burnt insulation, discolored wire jackets, loose crimp terminals, broken wire strands, or signs of moisture damage. Pay special attention to the main power harness and the moisture sensor wire connections.
5. **Examine the control board for visible damage.** Look for burnt components, cracked capacitors, scorched solder pads, or any discoloration on the circuit board surface. Even if you see no obvious damage, the board's internal circuitry can fail without external signs.
6. **Order and install the replacement main control board.** If wiring is intact and voltage is correct, the board must be replaced. Use your dryer's model number to order the exact replacement board. Disconnect all wire harnesses from the old board (take a photo first), mount the new board in the same location, and reconnect all harnesses exactly as they were.
7. **Reassemble and test.** Replace the back and top panels, restore power, and run a test cycle. The EA5 code should not return if the board was the root cause and all connections are secure.

## When to Call a Pro

Call a qualified appliance technician if you are uncomfortable working with household electrical connections or if you lack a multimeter to verify incoming voltage. A pro should also be called if the EA5 code persists after you have replaced the main control board and verified all wiring, because the fault may involve the user interface board or a deeper electrical issue in the dryer cabinet. If your dryer is still under warranty, contact Electrolux service directly before attempting any repairs to avoid voiding coverage.

**Rough cost:** DIY runs about $150-300 in parts, 45-90 min. A pro service call runs about $250-450.
