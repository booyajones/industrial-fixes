## LG Dryer HE Error Code — What It Means

The HE code is documented by LG for washer-dryer combo units as a temporary heater error. LG's official dryer support pages do not list HE as a standard dryer error code. Instead, LG dryers use codes such as TE1/TE2 for temperature sensor failure, d80/d90/d95 for restricted exhaust, HS for humidity sensor issues, and PF for power interruption. If you see HE on your appliance, first verify whether you have a true dryer or a washer-dryer combo by checking the model label and owner's manual.

For LG combo units showing HE, the manufacturer directs you to power down the unit, unplug it, and then retry. If the code reappears, schedule service. For standalone LG dryers displaying any heat-related performance issue, follow the diagnostic path for the actual error code shown or consult the correct dryer troubleshooting guide for your model.

## Before You Replace Anything

Some owners assume HE means a failed heating element and order a new element. First confirm your appliance type and whether HE is even a valid code for your model by checking the LG manual, then perform the reset procedure before replacing any parts.

## Common Causes

- **Washer-dryer combo temporary heater fault (~40%)** On LG combo units, HE indicates a temporary heater error that LG directs you to clear by unplugging and power cycling the appliance.
- **Misidentified appliance or error code (~30%)** HE does not appear in LG's published dryer error lists, so the code may be from a combo unit or misread display.
- **Heater assembly or wiring fault (combo units) (~20%)** If HE repeats after reset on a combo, the heater assembly, wiring connectors, or related thermostats may be faulty and require service.
- **Control board misreading or display issue (~10%)** A stuck or corrupted display can show an incorrect code until the unit is fully power cycled.

## Step-by-Step Fix {#fix}

1. **Turn off and unplug the appliance.** Press the power button to off, then disconnect the power cord from the wall outlet.
2. **Wait 60 seconds.** Allow the control board to fully discharge and reset any temporary faults.
3. **Plug the unit back in and power on.** Restart the appliance and observe whether the HE code reappears on the display.
4. **Run a test cycle.** Select a short drying or heating cycle to verify that the code has cleared and the heater operates normally.
5. **Check your model documentation.** Locate the model and serial number label (usually inside the door or on the rear panel) and confirm whether your appliance is a combo unit and whether HE is listed in the owner's manual error table.
6. **If the code returns, schedule service.** LG's official guidance for a repeating HE code on combo units is to contact LG service or an authorized technician for heater circuit diagnosis.
7. **For standalone dryers, consult dryer-specific codes.** If you have a dryer (not a combo) and see a display that looks like HE, verify the exact characters shown and check for TE1, TE2, d80, d90, d95, HS, or PF codes instead.

## When to Call a Pro

Call a professional if the HE code returns after a full power reset, if you are unsure whether your appliance is a dryer or a combo unit, or if you need to test the heater circuit and related sensors. Heater assembly replacement on washer-dryer combos involves disassembly of the drum and rear panels, disconnecting high-voltage wiring, and verifying continuity and resistance values that require a multimeter and the service manual. LG's own support documentation directs combo owners with repeating HE codes to schedule service rather than attempt component-level repairs. If your appliance is a standalone dryer and you see an unfamiliar code, a technician can enter diagnostic mode, retrieve stored fault history, and identify the correct root cause using the manufacturer's test sequences.

**Rough cost:** A pro service call runs about $150-300.
