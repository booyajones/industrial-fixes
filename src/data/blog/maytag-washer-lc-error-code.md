## Maytag Washer LC Error Code — What It Means

The LC (or LoC / LOC) code on your Maytag washer indicates that the Control Lock feature has been activated. This is not a failure code. It simply means the user interface is locked so cycle settings cannot be changed accidentally during operation. The washer itself is functioning normally, but the control panel will not respond to button presses until you deactivate the lock.

## Common Causes

- **Control Lock button pressed** Someone pressed and held the Control Lock function, either intentionally or by accident.
- **Secondary function activated** On some models, a secondary button function or key combination enabled the lock without using a dedicated Control Lock button.
- **Touchpad membrane issue** A stuck or damaged key membrane can register a continuous Control Lock input even when you are not pressing the button.
- **Control panel harness fault** A loose or corroded harness connection between the control panel and main board can cause erratic lock signals.

## Step-by-Step Fix {#fix}

1. **Locate the Control Lock button** on your control panel or find the key with a lock/key symbol printed as a secondary function above or below another button.
2. **Press and hold the Control Lock button** for 3 to 5 seconds until the LC code or lock icon disappears from the display.
3. **Check your owner's manual** if the code does not clear, since some older models use a different button combination to disable the lock.
4. **Unplug the washer** or turn off the circuit breaker for about 5 minutes if the lock still does not release, then restore power and try the Control Lock button again.
5. **Inspect the control panel** for visible damage, stuck buttons, or moisture around the touchpad if the LC code returns immediately after clearing.
6. **Test the key response** by pressing each button gently to confirm that all keys release properly and none are physically stuck.
7. **Replace the user interface or touchpad assembly** if the LC code persists after a power reset and no mechanical button issues are found, as the input circuit is likely faulty.

## When to Call a Pro

Call a technician if the LC code does not clear after you hold the Control Lock button and perform a full 5-minute power reset. If the code reappears immediately every time you restore power, or if other buttons on the control panel are also unresponsive, the user interface board or its wiring harness likely needs diagnosis with a multimeter and possible replacement. A qualified service tech can verify the correct part number for your specific Maytag model and test the control board signals before ordering components.
