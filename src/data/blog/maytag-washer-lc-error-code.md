## Maytag Washer LC Error Code — What It Means

The LC or LOC code on a Maytag washer indicates that the Control Lock feature has been activated. This is not a hardware fault or error. The washer is simply preventing accidental changes to settings during operation. The control panel will not respond to button presses until you unlock it using the correct procedure for your model. This is a normal user-enabled function that can be toggled on or off at any time.

## Before You Replace Anything

Homeowners sometimes think the control board or user interface has failed and order expensive replacement parts when the panel is simply locked. Always verify you are using the correct unlock button and procedure from your owner's manual before replacing any electronics.

## Common Causes

- **Control Lock button pressed accidentally (~70%)** The Control Lock button was touched unintentionally while loading clothes or adjusting settings, and the panel locked itself.
- **Wrong unlock method used (~15%)** Some models require a specific button combination or a longer press than the user tried, so the lock appears stuck even though the correct procedure would clear it.
- **Temporary control glitch (~10%)** A brief electronic hiccup in the control board can make the lock indicator stay on even after pressing the unlock button, usually cleared by a power cycle.
- **Stuck or damaged Control Lock button (~3%)** The physical button or keypad contact for Control Lock is mechanically stuck or damaged, preventing the unlock signal from registering.
- **User interface board fault (~2%)** The UI board or control panel assembly has a hardware issue that keeps the lock state active regardless of button presses.

## Step-by-Step Fix {#fix}

1. **Identify the Control Lock button** on your console by checking the owner's manual or the label printed on the control panel itself. The button may be labeled "Control Lock," "CNTL Lock," or shown with a padlock icon.
2. **Press and hold the Control Lock button** for 3 to 5 seconds. Watch the display for the LC or LOC indicator light to turn off. Some models emit a beep or chime when the lock disengages.
3. **Verify the panel is unlocked** by pressing another button, such as a cycle selector or Start. If the washer responds normally, the lock has cleared and you can proceed with a load.
4. **If the code remains**, unplug the washer from the wall outlet or switch off the dedicated circuit breaker. Wait 2 to 3 minutes to allow the control board to reset completely.
5. **Restore power** and press the Control Lock button again using the same 3-5 second hold. Check whether the code clears after the power cycle.
6. **Inspect the Control Lock button** for physical damage, stickiness, or debris. Gently clean around the button with a damp cloth if you see residue that might cause a stuck input.
7. **Consult the model-specific wiring diagram or service manual** if the code persists after these steps. The user interface board or keypad assembly may need professional inspection or replacement.

## When to Call a Pro

Call a professional if you have followed the correct unlock procedure from your owner's manual, completed a full power cycle by unplugging the washer for several minutes, and the LC or LOC code still will not clear. A technician can test the user interface board, inspect the control panel wiring harness for shorts or damaged connectors, and determine whether the keypad itself has a stuck input or a failed button contact. Also call for help if you are uncomfortable working around the control console or if your model requires disassembly to access internal wiring. A qualified appliance repair technician will have the diagnostic tools and genuine Maytag parts to resolve persistent control lock issues safely.
