## Mitsubishi Fb Error Code — What It Means

The Fb error code on Mitsubishi Electric mini-splits indicates an indoor unit control system error, including memory error. Mitsubishi's official error-code tables identify this as a fault within the indoor unit's electronic control board or its stored data. Unlike filter or refrigerant issues, Fb points to a problem with the indoor controller PCB, its memory chip, or the wiring and connectors that link the indoor and outdoor units.

In the field, this code usually appears when the indoor control board has failed, when memory on the board has become corrupted, or when a loose connector or damaged wire disrupts communication between the indoor and outdoor units. Mitsubishi's service guidance directs technicians to check the indoor/outdoor interconnect wiring and the indoor controller board itself when Fb is present.

## Common Causes

- **Failed indoor control PCB** The most common cause is a faulty or unstable indoor controller board, especially when the code returns after a reset.
- **Memory corruption on the indoor board** Mitsubishi explicitly lists memory error as part of the Fb description, meaning data stored on the control board has become corrupted or lost.
- **Loose or disconnected connector** A poorly seated or corroded connector on the indoor PCB or at the indoor/outdoor wiring terminal can interrupt the control signal and trigger the fault.
- **Damaged indoor/outdoor interconnect wiring** Broken, pinched, or shorted conductors in the communication wire between the indoor and outdoor units prevent normal operation and set the Fb code.
- **Power or voltage irregularity affecting the board** Unstable input voltage or power surges can stress the indoor controller and cause control-system faults, though this is less common than direct board or wiring failure.

## Step-by-Step Fix {#fix}

1. **Power down the system completely** by switching off the unit and opening the breaker, wait two minutes, then restore power to clear the fault and see if the code reappears.
2. **Read and record the error code** from the handheld remote or the indoor unit display, and note whether the indoor indicator lamp is flashing, since Mitsubishi shows Fb on both the controller and the LED.
3. **Inspect the indoor/outdoor interconnect wiring** at both the indoor and outdoor terminal blocks for loose screws, damaged insulation, or broken conductors, and tighten or repair any faults you find.
4. **Check all connectors on the indoor controller board** by removing the indoor unit cover, gently reseating each plug on the PCB, and looking for corrosion or bent pins.
5. **Verify whether the Fb code returns** after the reset and wiring checks. If the fault does not reappear, the issue was likely a temporary loose connection. If it does return, the indoor PCB is the next target.
6. **Replace the indoor control PCB** if the code persists after all wiring and connector checks are confirmed normal. Mitsubishi's service tables point to board replacement when the fault recurs and external connections test good.
7. **Consult your model's service manual** for any model-specific voltage or connector pinout data before ordering the replacement board, since Mitsubishi does not publish universal resistance or voltage specs for the Fb code itself.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working inside the indoor unit or removing the controller board cover, or if the Fb code returns immediately after you restore power and you have confirmed all visible wiring is intact. Replacing the indoor PCB requires matching the exact board revision to your serial number, transferring DIP-switch settings or configuration jumpers, and sometimes re-pairing the indoor and outdoor units through a service menu. A technician will also verify that the outdoor unit is not sending a fault signal that mimics an indoor memory error, and will have the diagnostic tools to read detailed fault logs from the controller. If your system is still under warranty, contact Mitsubishi or your installing contractor before opening the unit, since self-service may void coverage on the control board.
