## Frigidaire Washer E46 Error Code — What It Means

The E46 error code on Frigidaire front-load washers indicates a board communications problem. This fault means the main electronic control board cannot communicate properly with related circuits or boards in the washer. The machine will stop mid-cycle or refuse to start because the control system cannot coordinate operations. This is an internal electronics fault rather than a user-level load or drain issue.

[Jump to Fix](#fix)

## Common Causes

- **Failed main control board** The electronic control board itself has failed and can no longer send or receive signals to other components.
- **Loose or corroded wiring harness connections** Connector plugs between the control board and other boards or sensors have worked loose, corroded, or developed poor contact over time.
- **Damaged wiring harness** Wires in the harness between boards have been pinched, chafed, or broken, interrupting the communication circuit.
- **Failed user interface board** The display and button control board at the top of the washer has failed and cannot communicate with the main board.

## Step-by-Step Fix {#fix}

1. **Unplug the washer** from the wall outlet and wait two minutes to allow the control boards to reset completely.
2. **Restore power and run a test cycle** to see if the E46 code returns immediately or if the reset cleared a temporary glitch.
3. **Remove the top and front panels** according to your model's service access points to expose the control boards and wiring harnesses.
4. **Inspect all wiring harness connectors** at the main control board and user interface board for loose plugs, corrosion, or pushed-back pins, then disconnect and firmly reseat each connector.
5. **Check the wiring harness visually** for any pinched, burned, or damaged sections between the control boards and replace the harness if you find damage.
6. **Test the washer** after reseating connections to see if communication is restored and the E46 code clears.
7. **Replace the main control board** if all connections are secure and the code persists, as this is the repair action supported by the fault guide for E46.

## When to Call a Pro

Call a qualified appliance technician if you are not comfortable working with live electrical components or removing panels to access control boards. A pro can use diagnostic software to pinpoint whether the fault is in the main board, the user interface board, or the wiring between them, saving you from replacing the wrong part. If your washer is still under warranty, contact Frigidaire or an authorized service center before replacing any boards yourself.
