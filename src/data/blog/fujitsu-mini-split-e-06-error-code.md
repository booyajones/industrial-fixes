## Fujitsu E:06 Error Code — What It Means

The E:06 code on a Fujitsu mini split indicates an outdoor unit pipe sensor open-circuit or sensor missing fault. This means the outdoor control board cannot detect the thermistor that monitors refrigerant pipe temperature, either because the sensor is disconnected, the wiring is broken, or the sensor itself has failed open. The system will not run normally until the sensor circuit is restored.

[Jump to Fix](#fix)

## Common Causes

- **Disconnected or loose sensor connector** The pipe thermistor connector has backed out of the outdoor PCB or sensor, breaking the circuit.
- **Broken or cut sensor wiring** The wiring harness between the pipe sensor and outdoor control board has been damaged, pinched, or severed.
- **Failed open thermistor** The pipe sensor itself has failed internally and reads open circuit instead of normal resistance.
- **Missing or unplugged sensor** The pipe sensor was never installed, fell off during service, or was left unplugged after maintenance.
- **Outdoor control PCB failure** The sensor input on the outdoor main board has failed and cannot read the sensor even when wiring and sensor are good.

## Step-by-Step Fix {#fix}

1. **Power down the system** completely at the breaker or disconnect and wait two minutes before touching any components.
2. **Open the outdoor unit** service panel and locate the pipe sensor mounted on the refrigerant line near the compressor or service valves.
3. **Inspect the sensor connector** at both the sensor and the outdoor control board, reseat any loose plugs, and check for corrosion or damaged pins.
4. **Trace the sensor wiring** from the thermistor back to the PCB, looking for cuts, pinches, rodent damage, or breaks in the wire insulation.
5. **Measure the sensor resistance** with a multimeter set to ohms, an open or infinite reading confirms the sensor has failed and needs replacement.
6. **Check the outdoor PCB sensor input** if the sensor and wiring test good, consult your model's service manual for board-level diagnostics or replace the outdoor main PCB.
7. **Restore power and clear the code** after reconnecting or replacing the sensor, then monitor the system for stable operation without the fault returning.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working with live electrical components or if you cannot locate the outdoor pipe sensor. A pro should also diagnose the fault if the sensor and wiring appear intact but the code will not clear, as this points to a control board issue that requires proper refrigerant handling and board-level troubleshooting. Any work involving the sealed refrigerant system or PCB replacement should be left to a qualified technician.
