## Maytag Dishwasher FAE5 Error Code — What It Means

The FAE5 (or F10E5) error code on Maytag dishwashers indicates that the cycle ended early, the machine drained itself, and the control board logged a fault. Maytag's official documentation does not provide a deeper explanation of the exact component or sensor that triggered the code. The manufacturer's only published instruction is to press Cancel twice and then attempt to start a new cycle.

If the error returns after clearing it, the dishwasher has detected a persistent problem. The exact cause is model-specific and requires the service diagnostic mode and technical sheet for your model number. Because Maytag and Whirlpool share platforms, this code family appears on both brands with identical behavior, but the fault path varies by model and year.

## Before You Replace Anything

Homeowners sometimes replace the main control board or user interface first, assuming an electronic glitch. Before ordering any parts, enter the machine's diagnostic mode (model-specific key sequence) to read the stored fault history and identify the actual failed input or sensor.

## Common Causes

- **Flood switch or base pan float triggered (~30%)** Water pooled in the base pan from a previous leak or splash can hold the float up and signal a flood condition, aborting the cycle.
- **Optical water indicator (OWI) or turbidity sensor fault (~25%)** On some Whirlpool-family platforms a dirty or failed turbidity sensor may cause the control to abort and drain mid-cycle.
- **Drain hose routing or air-gap blockage (~20%)** An improperly installed drain hose loop or blocked air gap can cause water to back-siphon or overfill, triggering safety shutdowns.
- **Main control board or UI communication glitch (~15%)** A one-time electronic fault or corrupted cycle data may latch the error without a physical component failure.
- **Wiring or connector corrosion at flood-switch or sensor (~10%)** Corroded terminals or pinched wires can send a false signal to the control board and abort the wash.

## Step-by-Step Fix {#fix}

1. **Press Cancel twice** as instructed by Maytag, wait two minutes, then start a new cycle to clear the latched fault code.
2. **Observe the cycle behavior.** If the machine runs to completion without re-displaying FAE5, the fault was transient and no further action is needed.
3. **If the code returns immediately or mid-cycle**, power off the dishwasher at the breaker and pull the unit forward to access the base pan and lower front panel.
4. **Check for water in the base pan.** Tip the machine back slightly over a towel. If water drains out, locate the leak source (tub gasket, hose connection, or pump seal) and repair it, then reset the float switch.
5. **Locate and download the tech sheet** for your exact Maytag model number. The sheet will list the diagnostic-mode key sequence and the fault-code definition table specific to your machine.
6. **Enter service diagnostic mode** using the key sequence from the tech sheet. Scroll through the stored fault log and note any sensor or switch codes logged alongside FAE5.
7. **Test the components identified in the fault log** using a multimeter. Common test points include the flood switch continuity, OWI sensor resistance (if present), and wiring harness continuity to the control board. Replace only the verified failed part.

## When to Call a Pro

Call a professional technician if the error returns after you have pressed Cancel twice and the model's tech sheet or diagnostic mode is not available to you. A trained tech has the service manual, fault-history tools, and multimeter skills to isolate whether the fault is a flood switch, sensor, wiring harness, or control-board issue. Because the manufacturer does not publish a component-level repair path for FAE5 on public pages, attempting part replacement without diagnostic confirmation wastes time and money. If you see water in the base pan but cannot locate the leak source, or if entering diagnostic mode shows fault codes you do not understand, professional help will save you from replacing the wrong part.

**Rough cost:** A pro service call runs about $150–350 depending on model and part.
