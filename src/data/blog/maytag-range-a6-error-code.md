## Maytag 5A6 Error Code — What It Means

The 5A6 code on a Maytag range indicates that the appliance is in Sabbath mode. This is not a fault code or a hardware failure. It is a mode state that changes the oven's behavior to comply with religious observances. The range will continue to operate in Sabbath-mode behavior until the mode is manually turned off.

Sabbath mode is typically entered intentionally by the user or installer using a specific control-panel button sequence. The display may also remain in this state after a power interruption if Sabbath mode was already enabled before the power loss. Maytag does not list any sensor, heating element, or electronic control failures as common causes of the 5A6 code.

## Before You Replace Anything

Homeowners sometimes assume 5A6 is a control board or temperature sensor fault and replace those parts unnecessarily. Always verify the code is not simply Sabbath mode by attempting the exit sequence in your owner's manual before ordering any components.

## Common Causes

- **Sabbath mode intentionally activated (~75%)** The user or installer pressed the control-panel sequence to enter Sabbath mode, either deliberately or by accident.
- **Sabbath mode retained after power interruption (~15%)** The appliance was in Sabbath mode when power was lost, and the setting persisted when power was restored.
- **Control panel button stuck or misread (~5%)** A stuck Temp/Time or control key caused the sequence to activate unintentionally, though this is uncommon.
- **Control board or user-interface defect (~5%)** The electronic control or touchpad is defective and will not exit Sabbath mode using the normal sequence, though no Maytag source confirms this as a typical cause of 5A6.

## Step-by-Step Fix {#fix}

1. **Locate your model number** on the label inside the oven door or on the back of the range, and download the Use & Care guide from Maytag's support site to verify the exact Sabbath-mode exit sequence for your unit.
2. **Attempt the exit sequence** described in your manual. A common method is to press and hold the lower oven Cancel button and the Temp/Time button simultaneously for a few seconds until the display shows Sabbath off, but this varies by model.
3. **Power-cycle the appliance** at the circuit breaker if the sequence does not work. Turn off the breaker, wait two minutes, then restore power and check whether 5A6 has cleared.
4. **Verify the display** after power is restored. If 5A6 is gone and the range operates normally, the mode has been exited successfully.
5. **Test basic oven functions** by selecting Bake and setting a temperature. If the oven heats and the display behaves normally, no further repair is needed.
6. **Consult Maytag support** or schedule a technician visit if the code persists or the control panel does not respond to button presses. The control board or user interface may require professional diagnosis.
7. **Document any error patterns** such as whether the code reappears after a power cycle or only after certain button presses, and share this information with the technician to speed diagnosis.

## When to Call a Pro

Call a professional if the 5A6 code does not clear after following the manual's exit sequence and a full power cycle at the breaker. If the control panel is unresponsive to all button presses or if the display shows additional error codes alongside 5A6, a technician should test the electronic control board, wiring harness, and user interface for faults. Although 5A6 itself is a mode indication and not a component failure, a control that cannot exit the mode may need replacement or reconfiguration that requires service-level diagnostics and access to Maytag's technical literature.

**Rough cost:** DIY runs about $0, 2-5 min. A pro service call runs about $100-200 for a service call if control diagnosis is needed.
