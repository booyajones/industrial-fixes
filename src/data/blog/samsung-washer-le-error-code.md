## Samsung Washer LE Error Code — What It Means

Samsung groups LE, 1E, 1C, LC, LC1, 1 1C, and 1 LC together as a water level or leakage error. The code means the control system has detected moisture somewhere it does not belong, or there is an issue with the sensor itself. This is not a motor fault. The washer thinks it is seeing an abnormal water condition and stops the cycle to prevent damage.

The error can be triggered by an actual leak (even a small one that is hard to see), kinked supply or drain hoses, too many suds from excess detergent or non-HE detergent, or a problem with the drain hose holder behind the washer. In some cases the water-level or leak sensor itself is faulty, sending a false signal to the control board.

## Before You Replace Anything

Homeowners often replace the control board first when the real problem is a small leak pooling in the base or a kinked drain hose. Always inspect for visible water and hose routing before ordering electronics.

## Common Causes

- **Actual water leak (~35%)** Small leaks around hose connections, the dispenser, pump, or tub seal allow moisture into the base and trigger the sensor.
- **Kinked or improperly routed drain hose (~25%)** A drain hose that is pinched, kinked, or not held correctly by the retainer can cause water backup or pooling that the sensor reads as a leak.
- **Excess suds from too much detergent (~20%)** Using non-HE detergent or too much HE detergent creates suds that overflow into areas with moisture sensors.
- **Faulty water-level or leak sensor (~12%)** The sensor itself can fail or its wiring can corrode, sending a false leak signal to the control board even when no water is present.
- **Missing or damaged drain hose holder (~8%)** Samsung warns that the drain hose holder screw must not be removed and if the holder is missing, service is required to restore correct hose position.

## Step-by-Step Fix {#fix}

1. **Unplug the washer** and pull it forward so you can access the back and underside.
2. **Inspect for visible leaks** around all hose connections (hot, cold, drain), the dispenser drawer, the door boot, the drain pump housing, and the floor under the washer.
3. **Check the drain hose** behind the washer for kinks or pinches, and confirm it is held in the drain hose holder with the screw in place (Samsung warns not to remove this screw).
4. **Run an empty hot cycle** with no detergent or additives and watch for suds in the drum. If suds appear, you are using too much or the wrong detergent. Switch to HE detergent and reduce the dose.
5. **Tilt the washer back** (with help) and inspect the base pan for standing water. If water is present, dry it out and trace the source of the leak (hose, seal, or pump).
6. **Replace any cracked or leaking hoses** and tighten loose connections. If the drain hose holder is missing or broken, order a replacement and install it per the service manual.
7. **Plug in and run a test cycle**. If the LE code clears, the repair is complete. If the code returns with no leak and no suds, the water-level or leak sensor or control board wiring is faulty and you should request service.

## When to Call a Pro

Call a professional if you have checked for leaks, straightened all hoses, verified the drain hose holder is in place, run an empty suds test, and the LE code still appears. At that point the sensor, its wiring harness, or the control board is likely at fault. A technician will use a multimeter to check sensor continuity and the wiring for shorts or corrosion, and may need to access internal components that require partial disassembly of the cabinet. Also call service immediately if you find water pooling inside the base pan but cannot locate the source, because internal tub or pump seal leaks require specialized tools and parts to repair safely.

**Rough cost:** DIY runs about $15-80 in parts (hoses or sensor), 30-90 min. A pro service call runs about $150-300.
