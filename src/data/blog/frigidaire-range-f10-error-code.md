## What this code means
F10 is a runaway temperature or over-temperature fault. The electronic oven control has detected that the oven is heating when it should not be, or that temperature is climbing beyond safe limits. This is not simply a sensor reading error. The control believes an unsafe heating condition exists.

The fault originates in the oven temperature sensing circuit or in the control's ability to cut power to the heating elements. In practice, the code ties back to how the control monitors and stops heat output. The control may be receiving incorrect temperature feedback from the sensor, or a relay may be stuck closed and continuing to power a bake or broil element even when the control tries to turn it off.

## Before You Replace Anything

Many people replace the electronic control board first. Always test the oven temperature sensor with a multimeter at room temperature and inspect the sensor harness for breaks or loose connectors before ordering a control board.

## Common Causes

- **Failed oven temperature sensor** The RTD or thermistor sends incorrect resistance readings to the control, making it believe the oven is overheating or not responding to commands.
- **Wiring or harness fault** Opens, shorts, damaged insulation, corrosion, or loose connectors between the sensor and control cause intermittent or false temperature signals.
- **Electronic oven control or relay failure** A relay sticks closed on the control board and continues sending power to a bake or broil element even when the control tries to shut it off.
- **Heat-related condition after self-clean** Extreme residual heat or sensor drift during or after a self-clean cycle can trigger the fault, though the underlying issue is usually still the sensor or control.

## Step-by-Step Fix {#fix}

1. **Cut power at the breaker** if the oven is actively heating or the code will not clear, because F10 indicates a real runaway condition.
2. **Reset the control** by disconnecting power for one minute, then restore power and observe whether the code returns immediately or only after starting a bake cycle.
3. **Access the oven temperature sensor** by removing the rear wall panel inside the oven cavity (unplug or lock out the breaker first).
4. **Test the sensor resistance** with a multimeter at room temperature. You should see roughly 1,080–1,100 ohms. Record the reading.
5. **Inspect the sensor harness and connector** from the sensor probe back to the control board for broken wires, burnt insulation, corrosion, or loose pins. Wiggle the harness while watching the ohm reading for jumps.
6. **Replace the failed component**. If the sensor is out of range or the harness is damaged, install a new sensor or repair the harness. If both test good and the code persists, replace the electronic oven control board.
7. **Run a controlled bake test** at 350 °F for 15 minutes and verify the oven heats normally, cycles on and off, and the F10 code does not return.

## When to Call a Pro

Call a professional if you are not comfortable working inside the oven cavity with the power off, if you cannot safely access the sensor or control board, or if you have replaced the sensor and inspected the harness but the F10 code still appears. A technician can test the control board's relay outputs, check for stuck relays, and confirm whether the board is falsely holding power to the heating elements. Also call a pro if the oven continues to heat even after the breaker is reset, because that indicates a serious control fault that requires immediate attention.
