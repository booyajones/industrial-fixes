## What this code means
The C-21 code on Samsung microwaves indicates an error with the temperature sensor circuit. Samsung's internal code tables map C-20, C-21, and C-22 to temperature sensor faults. This is distinct from the E-24 code, which Samsung uses on some microwave platforms to signal an over-temperature condition when cavity temperature rises above the safe limit during operation. In practice, C-21 can appear either because the sensor itself has failed (open or shorted circuit) or because the control board is receiving a fault signal from contamination, damaged wiring, or a stuck relay that mimics an overheat event.

Samsung's published service guidance instructs users to perform a power reset first. If the code returns after reset, the unit requires technician verification because the fault may be a true overheating condition, a failed sensor, or a control board issue. The manufacturer does not provide specific resistance or voltage specifications for field diagnosis in public documentation, so technicians must rely on continuity checks, visual inspection, and systematic component substitution.

## Before You Replace Anything

Homeowners sometimes replace the main control board first, assuming the code means a board failure. Always test the temperature sensor circuit for open or short conditions and inspect the sensor wiring and connectors for damage or corrosion before replacing the control PCB.

## Common Causes

- **Failed temperature sensor or thermistor** The sensor can develop an open or short circuit, sending a fault signal to the control board even when the cavity temperature is normal.
- **Damaged or corroded sensor wiring and connectors** Heat, moisture, or physical stress can damage the harness between the sensor and control board, creating an intermittent or permanent open circuit.
- **Actual overheating of the microwave cavity** Blocked vents, a failed cooling fan, or extended high-power operation can cause genuine over-temperature that triggers the sensor circuit.
- **Stuck relay on the main control board** A relay that remains closed can create a continuous heating condition or send a false overheat signal to the controller, even when the cavity is cool.
- **Moisture or contamination on the control PCB** Steam, grease, or cleaning solution can infiltrate the electronics enclosure and create leakage paths or corrosion that mimic a sensor fault.

## Step-by-Step Fix {#fix}

1. **Disconnect power** by unplugging the microwave from the wall outlet or switching off the circuit breaker that supplies it.
2. **Wait 30 to 60 seconds** to allow the control board capacitors to discharge and the system to fully reset.
3. **Restore power** and test the microwave with a short low-power cycle to see if the C-21 code reappears.
4. **If the code returns**, unplug the unit again and remove the outer cover to access the control compartment and sensor location (consult your service manual for fastener locations).
5. **Locate the temperature sensor** (usually a small thermistor mounted near the magnetron or cavity wall) and inspect the sensor body, terminals, and wiring harness for signs of heat damage, corrosion, or disconnection.
6. **Check continuity** across the sensor terminals with a multimeter (consult your model's wiring diagram for expected resistance values, as Samsung does not publish generic specs for all models).
7. **If the sensor tests open or shorted**, replace the temperature sensor assembly and reconnect the harness securely, then re-test the microwave.
8. **If the sensor circuit is intact**, inspect the main control PCB for visible relay damage, burn marks, or moisture contamination, and replace the control board if a fault is found or if the code persists after sensor replacement.

## When to Call a Pro

Call a qualified appliance technician if the C-21 code persists after a power reset, if you are not comfortable working with line-voltage wiring inside the microwave, or if you lack the tools to safely access and test the temperature sensor circuit. Microwaves contain high-voltage capacitors that retain charge even after unplugging, and the magnetron and control components require careful handling. A technician will verify whether the fault is a failed sensor, damaged wiring, or a control board issue, and will have access to the service manual with model-specific resistance and voltage values for accurate diagnosis. Professional service is also recommended if the microwave shows signs of actual overheating, as this may indicate a blocked vent, failed cooling fan, or other safety hazard that requires systematic inspection.

**Rough cost:** A pro service call runs about $150–$300.
