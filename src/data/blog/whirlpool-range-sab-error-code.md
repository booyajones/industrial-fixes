## What this code means
The SAB code (and its variants Sab, 5AB, and 5A6) indicates that Sabbath Mode is currently active on your Whirlpool range. This is not a fault or failure code. Sabbath Mode is a feature that restricts oven operation to bake-only cycles, disables tones and chimes, and limits display feedback to comply with religious observance requirements. When Sabbath Mode is enabled, all cooking and cleaning cycles except bake are disabled, and the mode can remain active for up to 72 hours on some models or until manually turned off.

Because SAB is a mode indicator rather than a hardware fault, Whirlpool does not link this code to any component failure or replacement part. The display appears when someone has intentionally enabled Sabbath Mode through the range's control panel or key sequence. To clear the code, you must exit Sabbath Mode using the procedure specific to your model, which is found in the owner's manual.

## Before You Replace Anything

Homeowners sometimes assume SAB is a control-board fault and replace the control panel. Before ordering parts, verify the code meaning in your owner's manual and try the Sabbath Mode exit sequence, which costs nothing.

## Common Causes

- **Sabbath Mode enabled through settings (~95%)** Someone pressed the key sequence or menu option to turn on Sabbath Mode, either intentionally or by accident.
- **Display glitch after power event (~4%)** A brief power interruption or surge caused the display to show SAB even though Sabbath Mode was not actively selected.
- **Control panel error persisting after mode exit (~1%)** The display continues to show SAB after you attempted to exit Sabbath Mode, usually due to incomplete key sequence or a stuck button.

## Step-by-Step Fix {#fix}

1. Locate your owner's manual. Find the section on Sabbath Mode or the error-code table to confirm the exact exit procedure for your Whirlpool model.
2. Enter the Sabbath Mode exit sequence. Most Whirlpool ranges use a specific button combination (often holding a cooking-mode button or pressing a settings key). Follow your manual's instructions exactly.
3. Verify the display clears. Once you complete the exit sequence, SAB should disappear and the display should return to normal standby or clock mode.
4. Perform a breaker reset if the code persists. Turn off the circuit breaker supplying the range for one minute, then restore power and wait one minute to see if the display resets.
5. Try the exit sequence again after the reset. If SAB reappears, repeat the Sabbath Mode exit steps from your manual.
6. Check for stuck buttons. Inspect the control panel for any buttons that feel sticky or do not spring back, as a stuck key can prevent the exit sequence from completing.
7. Consult Whirlpool support if SAB will not clear. If the code remains after multiple exit attempts and a breaker reset, contact Whirlpool or a qualified technician to verify the control board is registering key presses correctly.

## When to Call a Pro

Call a pro if the SAB code will not clear after you have followed the owner's manual exit sequence, performed a full breaker reset, and verified no control-panel buttons are stuck. A technician can test the control board's key-input circuits and check for a firmware issue. Because SAB is not a hardware fault code, component replacement is rarely needed. If the display behaves erratically in other ways (random characters, unresponsive touch, or codes cycling rapidly), the control board may have a separate electrical issue that requires professional diagnosis.
