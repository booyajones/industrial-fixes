## Whirlpool Range SAB Error Code — What It Means

The SAB (or Sab, 5AB, 5A6) display on a Whirlpool range is not a failure code. It indicates that Sabbath Mode is currently activated. Sabbath Mode is an intentional feature that sets the oven to remain on in a Bake setting until manually turned off, with all tones and most other cooking functions disabled to comply with religious observance requirements.

This display means the control is operating as programmed, not reporting a defective component. The mode may have been enabled through the settings menu, left active after a prior use, or mistakenly activated. The solution is to exit Sabbath Mode using your model-specific control sequence or perform a power reset.

## Common Causes

- **Sabbath Mode intentionally enabled** The user or installer turned on the feature from the oven's settings or menu system.
- **Mode left active from prior use** The appliance was not returned to normal operation after a previous Sabbath cycle and the feature remains on until manually disabled.
- **Mistaken interpretation of the display** The SAB indicator is read as an error code when it is actually a normal mode status message.
- **Accidental keypad activation** The Sabbath Mode sequence was pressed unintentionally during cleaning or other interaction with the control panel.

## Step-by-Step Fix {#fix}

1. **Confirm the display** shows SAB, Sab, 5AB, or 5A6 and verify your model has Sabbath Mode capability by checking the owner's manual.
2. **Locate the exit sequence** in your model's documentation, as steps vary by control platform (most require pressing Settings or Menu, navigating to Sabbath Mode, and selecting Off or Disable).
3. **Attempt to exit Sabbath Mode** using the prescribed key sequence for your specific model, watching for the display to return to normal time or temperature readout.
4. **Perform a power reset** if the mode will not clear normally by turning off the range circuit breaker or fuse for at least one minute, then restore power and check the display.
5. **Re-enter the menu** if SAB reappears and navigate to Sabbath Mode settings to manually disable the feature, then press Cancel or Off to confirm.
6. **Test normal oven operation** by selecting Bake at a standard temperature and verifying that all tones and display functions return to normal behavior.
7. **Inspect the control interface** if Sabbath Mode cannot be disabled and the keypad does not respond correctly to the cancel sequence, as this may indicate a user interface or control board issue rather than a mode setting.

## When to Call a Pro

Call a qualified appliance technician if you cannot locate the correct exit sequence in your manual, if the SAB display returns immediately after a proper disable attempt and power reset, or if the control panel does not respond to any keypad input. A professional can verify whether the user interface or control board is sending incorrect mode commands and perform board-level diagnostics. For most cases, SAB is simply a mode indicator and can be cleared by following your model's instructions without any repair or part replacement.
