## What this code means
Samsung publishes the E-05 code as **Cooking Time Setting Over Error (Combination)**. This is an input or programming fault, not a cooking fault. The microwave has detected that a combination-mode cook time entered exceeds the allowed range for that mode. Samsung advises a power reset first. If the code returns, the manufacturer directs you to contact service. Do not confuse E-05 with SE or 5E codes, which are unrelated.

## Before You Replace Anything

Many users assume the magnetron or high-voltage parts have failed. E-05 is a programming fault, not a cooking fault, so test the keypad and power-cycle first before ordering parts.

## Common Causes

- **Cook-time entry exceeds combination-mode limit** The user entered a time longer than the microwave allows for combination cooking, triggering the code.
- **Stuck or shorted keypad button** A stuck button can send repeated or incorrect digits, causing the control to see an out-of-range time.
- **Control-board logic error** The main control misinterprets valid input as over-limit, often after a power surge or firmware glitch.
- **Corrupted control memory** A memory fault in the control can store or recall incorrect time values for combination programs.
- **Keypad membrane failure** Worn or moisture-damaged membrane contacts can generate phantom presses or garbled data.
- **Wiring or connector fault between keypad and control** A loose ribbon cable or corroded connector can corrupt the time data stream to the control board.

## Step-by-Step Fix {#fix}

1. **Disconnect power.** Unplug the microwave or turn off the circuit breaker and wait 60 seconds to fully reset the control board.
2. **Restore power and retest.** Plug the unit back in, enter a short cook time (3 to 5 minutes) in combination mode, and press Start to see if the error clears.
3. **Inspect the keypad.** Remove the outer cover and check each button for sticking, moisture, or visible damage. Press each button and listen for a clean click.
4. **Check the ribbon cable.** Locate the flat ribbon cable running from the keypad to the main control board. Reseat both ends and look for corrosion or torn conductors.
5. **Test the keypad assembly.** If you have a multimeter, consult your model's service manual for keypad resistance values and test each button contact. Replace the keypad if readings are open or erratic.
6. **Replace the main control board.** If the keypad tests good and the code persists after reset, swap the control board. Match the model and serial number on the rating plate to order the correct part.
7. **Reassemble and verify.** Reinstall all covers, restore power, and run a short combination-mode program to confirm the error does not return.

## When to Call a Pro

Call a technician if the error returns after a power reset and you are uncomfortable working with the control board or keypad assembly. A qualified service tech can verify the control logic, test the keypad under load, and confirm correct firmware operation. Samsung's own guidance is to contact service when the code persists. If your microwave is under warranty, do not open the cabinet yourself or you will void coverage. For models with capacitive touch controls or integrated displays, keypad replacement requires precise alignment and connector work best done by a trained servicer.

**Rough cost:** DIY runs about $80-180 for a control board or keypad assembly, 30-60 min. A pro service call runs about $150-280 for diagnosis and control-board replacement.
