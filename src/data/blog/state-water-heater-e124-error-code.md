## State Water Heater E124 Error Code — What It Means

The E124 error code does not appear in any verified State Water Heaters documentation or official troubleshooting guides. State directs technicians to locate the exact model number from the rating plate or QR code on the unit, then reference that model's specific manual and fault code chart. Without the model-specific documentation, it is not possible to confirm what E124 means, which components it relates to, or what repair steps apply. Different State models use different control boards and sensors, so error codes are not universal across the product line.

## Common Causes

- **Model-specific code not documented** E124 does not appear in the supplied State manufacturer troubleshooting materials, so its meaning depends entirely on your model.
- **Control board firmware variation** Different State models use different electronic controls, and each assigns fault codes differently.
- **Missing or incorrect model manual** Technicians cannot decode the fault without the exact service bulletin or manual for your unit.
- **Display or communication error** The code may indicate a problem with the control board's internal diagnostics rather than a specific component failure.

## Step-by-Step Fix {#fix}

1. **Locate the rating plate** on your State water heater, usually on the front panel or inside the access door, and write down the complete model number and serial number.
2. **Scan the QR code** on the rating plate with your smartphone if present, or visit the State Water Heaters website and enter your model number to download the exact manual.
3. **Review the fault code table** in the model-specific troubleshooting section of your manual to find the definition and diagnostic tree for E124.
4. **Follow the manufacturer's diagnostic steps** exactly as written for that code, checking the components and parameters listed in your model's chart.
5. **Power cycle the unit** by turning off the circuit breaker for two minutes, then restoring power to see if the code clears after a temporary glitch.
6. **Document the conditions** when the code appeared, including water temperature, recent changes, and any other symptoms, then provide this to a technician if the code persists.
7. **Contact State technical support** or a licensed service technician with your model number and error code if the manual does not resolve the issue.
