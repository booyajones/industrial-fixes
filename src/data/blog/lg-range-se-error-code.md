## LG Range SE Error Code — What It Means

On LG ranges, SE stands for sensor error. This code indicates the control system has detected a fault in one of the range's sensors or in the wiring and communication circuits that connect those sensors to the main control board. The error is not a cooking fault you can clear by changing settings. It points to a hardware problem that prevents the control from reading sensor data correctly.

LG's published guidance treats SE as a service-level fault rather than a user-resolvable issue. The code can appear when a sensor has failed, when the connector or harness is loose or corroded, or when the control board cannot interpret the sensor signal. Because ranges rely on temperature sensors and other feedback devices to regulate heat safely, the appliance will not operate normally until the fault is repaired.

## Common Causes

- **Failed temperature sensor or thermistor** The sensor element itself has burned out or drifted out of range, so the control board cannot read a valid signal.
- **Loose or damaged sensor connector** The wiring harness plug at the sensor or at the control board has backed out, corroded, or lost contact due to heat or vibration.
- **Broken or shorted sensor wiring** The wire run between the sensor and the board has been pinched, cut, or melted, creating an open circuit or short that triggers the error.
- **Control board communication fault** The main control or user interface board has a defect in the sensor input circuit, preventing it from processing the signal even when the sensor is good.
- **Intermittent contact from thermal cycling** Repeated heating and cooling causes solder joints or terminals to crack, producing a fault that comes and goes with temperature changes.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker or unplug the range completely, then wait at least 60 seconds to allow the control boards to discharge and reset.
2. **Restore power** and check whether the SE code reappears immediately or after starting a heating cycle.
3. **If the code returns,** turn off power again and remove the rear access panel or control housing to expose the sensor connectors and wiring harnesses.
4. **Inspect each sensor connector** for loose contact, corrosion, or heat damage, then unplug and reseat every connector firmly to make sure a clean connection.
5. **Trace the sensor wiring** from the sensor body to the control board, looking for pinched insulation, melted sections, or any point where the wire may have rubbed against a sharp edge.
6. **Consult your model's service manual** for the sensor resistance or voltage specification, then use a multimeter to measure the sensor at the harness plug and compare the reading to the published range.
7. **Replace the failed component** (sensor, harness, or control board) based on your test results, then reassemble the range, restore power, and verify that the SE code does not return during a normal heating cycle.

## When to Call a Pro

LG directs customers to professional service when the SE code persists after a power cycle. If you are not comfortable working inside a live 240‑volt appliance, measuring sensor circuits with a multimeter, or interpreting model-specific resistance tables, call a qualified appliance technician. A pro will use the service manual to identify which sensor has failed, test each circuit methodically, and replace only the defective part. Because range sensors are critical to safe temperature regulation, incorrect diagnosis or improper reassembly can create a fire or shock hazard.
