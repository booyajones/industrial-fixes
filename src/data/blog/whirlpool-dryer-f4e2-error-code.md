## What this code means
On Whirlpool all-in-one washer-dryer combo units, the F4E2 code indicates a fault in the dryer heater circuit. The typical symptom is that the wash function still works normally, but the dry cycle either fails to start, stops partway through, or runs without producing heat. The machine has detected a problem in the electrical circuit that powers the dryer heater element.

This code does not appear on standalone Whirlpool dryers or washing machines. It is specific to combo models that combine both wash and dry functions in a single unit. The control board has flagged an issue on the dryer side while the wash side may continue to operate.

## Before You Replace Anything

Do not replace the main control board first. The fault is usually in the heater circuit wiring, connections, or the heater element itself. A technician should test the heater circuit continuity and wiring before replacing any control components.

## Common Causes

- **Heater circuit failure (~45%)** The dryer heater element or its wiring has failed open, preventing current flow and triggering the fault code.
- **Loose or corroded heater wiring connection (~30%)** A connector in the heater circuit has worked loose or corroded, breaking the electrical path to the heating element.
- **Control-side heater detection fault (~15%)** The main control board or a relay that monitors heater operation is failing to detect normal heater function even when the circuit is intact.
- **Damaged wiring harness (~10%)** Physical damage, wear, or chafing has created an open or short in the harness between the control and the heater element.

## Step-by-Step Fix {#fix}

1. **Unplug the combo unit** from the wall outlet or turn off the breaker to cut all power, then wait about 5 minutes.
2. **Restore power** and run a single test dry cycle with a small load to see if F4E2 reappears.
3. **If the code returns**, stop using the dry function and schedule service. Do not keep retrying the cycle.
4. **If you are comfortable with electrical diagnostics**, unplug the unit again, remove the rear or bottom access panel, and visually inspect all connectors and wires in the heater circuit for burns, corrosion, or loose terminals.
5. **Use a multimeter** to test continuity across the dryer heater element terminals (with power off and element disconnected). Consult your model's wiring diagram for the correct resistance range.
6. **Check each connector** in the heater circuit by unplugging and re-seating it to make sure a solid connection, then inspect for corrosion or melted pins.
7. **If the heater element tests open or a wiring fault is confirmed**, replace the failed component or repair the damaged harness. If all wiring and the element test good, the fault is likely on the control side and the main control or a relay may need replacement by a technician.

## When to Call a Pro

Call a professional technician if the F4E2 code returns after a single reset, if you are not comfortable working with live or de-energized electrical circuits, or if your visual inspection and continuity tests do not reveal an obvious heater-element or wiring fault. Diagnosing control-side faults requires a wiring diagram and experience tracing signals between the main control board and the heater circuit. Because combo units integrate wash and dry systems in one cabinet, parts access can be tight and misdiagnosis can lead to unnecessary control-board replacement. A qualified appliance tech will test the heater circuit end-to-end, verify all connectors, and replace only the component that has actually failed.

**Rough cost:** A pro service call runs about $200-400.
