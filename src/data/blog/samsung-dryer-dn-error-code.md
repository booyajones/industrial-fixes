## Samsung Dryer DN Error Code — What It Means

The DN code on Samsung smart dryers indicates that a firmware or software update is currently downloading to the dryer's control system. Samsung states that the dryer will restart itself automatically when the installation is complete. This is not a mechanical failure code. It appears on connected models that support over-the-air updates.

The code is normal during an active download and should clear within a few hours. Samsung recommends leaving the dryer powered on and waiting up to 24 hours. If DN persists beyond that window, the update may have stalled or a control-board communication fault has occurred.

## Before You Replace Anything

Homeowners sometimes replace the main control board immediately, assuming a fault. Wait the full 24-hour download window and perform a controlled reset before ordering any parts.

## Common Causes

- **Firmware download in progress (~70%)** The dryer is actively receiving a software update and will restart when complete.
- **Stalled or interrupted update (~15%)** A power interruption or weak network connection caused the download to hang.
- **Control-board communication glitch (~10%)** The main control or user-interface board lost communication during a setup or update cycle.
- **Main control-board fault (~5%)** The board cannot exit download mode due to a firmware corruption or hardware failure.

## Step-by-Step Fix {#fix}

1. **Confirm your model number** by checking the rating plate inside the door or on the back panel, and verify it is a Samsung smart or connected dryer that supports firmware updates.
2. **Leave the dryer powered on** if the DN code has appeared recently. Do not unplug the dryer during an active firmware download, as this can interrupt the update and cause further faults.
3. **Wait up to 24 hours** for the download to complete. Samsung states the dryer will restart automatically when the software is installed.
4. **Perform a controlled reset** if the code persists beyond 24 hours. Turn the dryer off and leave it off for 60 seconds, then turn it back on. Some service guides recommend waiting 2 to 3 minutes or unplugging briefly if a simple off cycle does not clear the code.
5. **Run a basic drying cycle** after the reset to verify the code clears and the dryer operates normally.
6. **Inspect wire harness connections** between the main control board and the user-interface board if the code returns immediately. Look for loose connectors, corrosion, or damaged wires that could interrupt communication.
7. **Contact Samsung service or a qualified technician** if DN remains after the 24-hour window and a reset. The main control board or user-interface board may need inspection, reflash, or replacement.

## When to Call a Pro

Call a professional if the DN code persists for more than 24 hours despite a controlled reset, or if you are uncomfortable working with electronic control boards and wire harnesses. A qualified technician can perform electronic diagnostics, verify board communication, reflash firmware if supported, and replace the main control or user-interface board with the correct part number for your model. Also call service if the dryer will not power on or displays additional error codes alongside DN, as this may indicate a more complex fault requiring manufacturer-level support or a factory service tool.

**Rough cost:** DIY runs about $150-250 for a control board if needed, 30-60 min. A pro service call runs about $200-350 for a service call and board replacement if needed.
