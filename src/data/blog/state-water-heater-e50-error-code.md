## State Water Heater E50 Error Code — What It Means

On State hybrid electric heat-pump water heaters, the E50 code signals an ambient temperature sensor failure or that the heat pump compressor is operating outside its normal temperature range. The control system uses this sensor to monitor the air temperature around the unit and determine whether the heat pump can safely run. When the sensor fails or reads out of range, the system locks out the heat pump to protect the compressor.

This code is specific to State hybrid electric models. If you have a gas or standard electric tank, your model uses a different fault code system. Always verify your exact model number from the rating plate before troubleshooting.

## Common Causes

- **Failed ambient temperature sensor** The sensor itself has failed internally and no longer reports valid readings to the control board.
- **Loose or corroded sensor connector** The plug at the control assembly has backed out or the pins have corroded, breaking the signal path.
- **Damaged sensor wiring** The wire harness between the sensor and control board is pinched, cut, or chafed through insulation.
- **Control assembly fault** The main control board has developed an internal failure in the sensor input circuit.
- **Ambient temperature outside operating range** The installation location is too hot or too cold for the heat pump to operate safely, triggering a legitimate out-of-range condition.
- **Intermittent connection after service** Recent work on the unit dislodged a connector or stressed a wire that now makes intermittent contact.

## Step-by-Step Fix {#fix}

1. **Turn off power at the circuit breaker** for at least 30 seconds, then restore power and watch the display to see if the fault clears on its own.
2. **Remove the upper access panel** on the unit to expose the control assembly and wiring harness connections.
3. **Inspect all sensor connectors** at the control board for looseness, corrosion, or backed-out pins, and reseat each connector firmly.
4. **Trace the sensor wiring** from the control board to the ambient sensor location and look for pinched, cut, or abraded insulation.
5. **Check the installation environment** to confirm the unit is not in an enclosed space that exceeds the maximum or falls below the minimum ambient operating temperature listed in your installation manual.
6. **Replace the ambient temperature sensor** if the fault persists after power cycling and connector inspection, following the replacement procedure in the service manual.
7. **Contact State technical support** if the new sensor does not clear the code, as the control assembly itself may require replacement or advanced diagnostics.

## When to Call a Pro

Call a licensed plumber or water heater technician if the fault returns after a power cycle, if you are uncomfortable working inside a 240-volt appliance, or if you cannot locate the sensor or control board connectors. The manufacturer recommends contacting State technical support for persistent sensor faults that do not clear with a simple reset. A technician can perform voltage and resistance tests at the control board, verify proper sensor operation, and replace the control assembly if the board input circuit has failed.
