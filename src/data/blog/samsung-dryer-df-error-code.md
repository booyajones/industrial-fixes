## What this code means
The dF error code on a Samsung dryer indicates a door-related fault. Samsung groups dF with codes like dC, dE, do, d0, 1 DC, and 1 dF, all of which point to problems with the door, its latch, or the sensors that confirm the door is secured correctly. In practical terms, the dryer believes the door is not secure or the door-switch circuit is not reporting the expected door status.

When you see dF, the machine has detected that the door-switch circuit is not reading a proper closed and latched condition. This can be a mechanical problem (the door isn't actually latching), an electrical problem (the switch or wiring has failed), or a control-board issue (the board isn't reading the door input correctly). The dryer will not start or will stop mid-cycle until it sees a valid door-closed signal.

## Before You Replace Anything

Many people replace the main control board when the dF code appears, but the real cause is usually a failed door switch or broken latch. Test the door switch for continuity and inspect the latch mechanism before buying a control board.

## Common Causes

- **Faulty door switch (~40%)** The door switch may fail internally so it no longer changes state when the door closes, or it may have a broken terminal or loose connector.
- **Broken or misaligned door latch or strike (~30%)** A cracked latch, bent strike plate, or loose door hinge prevents the door from closing far enough to actuate the switch.
- **Debris or laundry obstructing the door (~15%)** Lint buildup, a sock caught in the seal, or an item wedged in the door gap can prevent full closure.
- **Loose or damaged wiring in the door-switch circuit (~10%)** Broken wires, corroded terminals, or a loose harness connector between the door switch and the control board interrupt the signal.
- **Main control board misreading the door input (~5%)** When the switch, latch, and wiring all test good but the code persists, the control board itself may have a failed door-input circuit.

## Step-by-Step Fix {#fix}

1. **Unplug the dryer** and wait 60 seconds to make sure all capacitors discharge and the control resets.
2. **Open and close the door** firmly, listening for a positive click and checking that no clothing or lint obstructs the seal or latch area.
3. **Inspect the door latch and strike** on both the door and the cabinet frame for cracks, bends, or misalignment, and clean away any lint or debris.
4. **Test the door switch** by removing the top or front panel (consult your model's service manual), locating the door switch, and using a multimeter to verify it changes from open to closed continuity when the door shuts.
5. **Check the door-switch wiring harness** for loose connectors, broken wires, or corroded terminals between the switch and the main control board.
6. **Replace the failed component**: install a new door switch if the switch does not change state, or replace the latch assembly if it is cracked or misaligned.
7. **Restore power, close the door, and run a test cycle** to confirm the dF code is cleared and the dryer operates normally.

## When to Call a Pro

Call a professional if you are uncomfortable working with the dryer's panels, wiring, or electrical components. A technician has the meters and experience to quickly isolate whether the fault is in the door switch, the harness, or the control board. Also call a pro if you have replaced the door switch and latch, verified the wiring is intact, and the dF code still appears, since that points to a control-board repair or replacement that requires model-specific programming or calibration in some Samsung models.

**Rough cost:** DIY runs about $15-50 in parts, 20-45 min. A pro service call runs about $120-220.
