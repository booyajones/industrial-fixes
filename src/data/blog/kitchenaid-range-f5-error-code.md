## KitchenAid Range F5 Error Code — What It Means

The F5 error code on a KitchenAid range indicates a problem with the oven door latch assembly, the door switch, or the wiring connecting them. KitchenAid publishes specific guidance for F5 E0 and F5 E3, both of which point to the door latch mechanism and door switch circuit as the root cause. This is not a temperature sensor fault. The control board cannot verify the door latch position, either because the latch is misaligned, the switch has failed, or the wiring harness is damaged. The code will prevent normal oven operation until the latch circuit is restored.

## Common Causes

- **Mispositioned or bent latch arm** The door latch striker or arm has shifted out of alignment or bent, preventing proper engagement with the switch.
- **Failed door latch assembly** The mechanical latch mechanism has broken internally or no longer actuates the door switch correctly.
- **Defective door switch** The switch that signals latch position to the control board has failed open, closed, or intermittent.
- **Damaged wiring or connectors** Wires or terminals in the latch or switch circuit are loose, pinched, burned, or corroded.
- **Control board misreading latch state** If all mechanical and electrical components test normal, the control may have an internal fault reading the door switch signal.

## Step-by-Step Fix {#fix}

1. **Turn off power at the circuit breaker** for a full minute, then restore power and check whether the F5 code reappears on the display.
2. **Note the exact code variant** (F5 E0, F5 E3, or plain F5) shown on the control, as KitchenAid repair procedures differ by sub-code.
3. **Inspect the door latch assembly** for bent arms, binding, or misalignment by opening and closing the door and watching the latch engage the striker.
4. **Check the door switch and wiring harness** at the latch for loose connectors, pinched wires, burn marks, or broken terminals.
5. **Test the door switch electrically** using a multimeter to verify it opens and closes correctly as the latch moves, and replace the switch if readings are abnormal.
6. **Replace the oven door latch assembly** if the mechanical parts are damaged or the switch cannot be replaced separately, then cycle power.
7. **Verify normal operation** by running a short bake cycle and confirming the F5 code does not return and the door locks during self-clean if applicable.

## When to Call a Pro

Call a professional if you are uncomfortable working inside a live appliance or if the code returns after you have replaced both the latch assembly and door switch and verified all wiring. If the control board itself is misreading the latch circuit and all physical components test normal, diagnosis requires comparing signal voltages to factory specifications, which are not published in homeowner documentation. A qualified appliance technician has model-specific wiring diagrams, the correct OEM parts cross-references, and the test equipment to isolate a control board fault safely.
