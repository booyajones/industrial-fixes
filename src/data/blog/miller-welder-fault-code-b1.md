## Miller Welder Fault Code B1 — What It Means

Miller fault code B1 indicates an **output voltage fault**. The machine's control board detected output voltage outside the acceptable operating window during weld or idle monitoring. On Miller inverter welders, that usually points to a short on the output side, a failing output module, or unstable input power that keeps the machine from regulating arc voltage correctly. The machine shuts down to protect the IGBT section and output rectifier.

## Common Causes

- **Shorted weld leads or work clamp** — Damaged lead insulation or a clamp contacting grounded metal can drag output voltage out of range.
- **Loose output connections** — High resistance at the dinse connector, lug, or internal output stud creates unstable voltage under load.
- **Input voltage problem** — Low line voltage, a bad generator, or a weak extension cord can prevent the machine from maintaining proper output.
- **Failed output board or IGBT module** — Internal power section damage causes the machine to sense abnormal output voltage even with correct external connections.

## Step-by-Step Fix {#fix}

1. **Inspect weld leads and work clamp** — Check both leads end to end for cuts, burn marks, or exposed copper. Replace damaged leads or clamps.
2. **Tighten output terminals** — Power the machine off, remove the case if needed, and verify the output studs, dinse sockets, and internal lugs are tight and clean.
3. **Verify incoming power** — Measure input voltage at the receptacle while the machine is powered. Avoid long undersized extension cords and unstable generator power.
4. **Test with no weld leads attached** — Disconnect the output leads, power the welder on, and see if B1 returns immediately. If it does, the fault is likely internal.
5. **Reset the system** — Shut the welder off for 60 seconds, restore power, and strike a short test arc with known-good leads and material.

## When to Call a Pro

If B1 returns with the leads disconnected and input power confirmed good, the output board or inverter section needs bench diagnosis. Miller inverter repair involves live high-voltage DC bus circuits, so use an authorized Miller service center.
