## Bosch Washer E28 Error Code — What It Means

Bosch identifies E28 (or F28) as a flow sensor issue on its washing machines. The washer is not detecting the expected water flow signal from the flow sensor during the fill cycle. This can mean the sensor itself has failed, or that something is preventing normal water flow into the machine so the sensor reads abnormal conditions.

The code will prevent the washer from continuing the cycle until the flow sensor sees correct water movement. The underlying cause may be as simple as a kinked hose or blocked inlet screen, or it may require replacing the flow sensor or checking the wiring between the sensor and the main control board.

## Before You Replace Anything

Homeowners sometimes replace the main control board when the real fault is a failed flow sensor or a blocked inlet screen. Always test the flow sensor electrically and inspect the inlet path before swapping expensive boards.

## Common Causes

- **Failed flow sensor (~40%)** The flow sensor itself has worn out or broken internally and no longer sends a valid signal to the control board.
- **Blocked inlet screens or filters (~25%)** Debris in the inlet screens or filters restricts water flow enough that the sensor reading appears abnormal.
- **Kinked or blocked inlet hose (~15%)** The inlet hose is crushed, kinked, or blocked, reducing water supply to the machine and triggering the flow sensor fault.
- **Faulty wiring or connectors (~10%)** Loose, corroded, or damaged wiring between the flow sensor and the control board interrupts the signal path.
- **Insufficient water supply (~7%)** The shutoff valve is not fully open or household water pressure is too low, so the sensor never sees adequate flow.
- **Control board fault (~3%)** If the flow sensor and wiring test good but the code persists, the main control board may be misinterpreting the signal.

## Step-by-Step Fix {#fix}

1. **Turn off power and water.** Unplug the washer and close both hot and cold shutoff valves behind the machine.
2. **Check water supply.** Open the valves fully and verify normal household pressure by running a nearby faucet at full flow.
3. **Inspect the inlet hose.** Disconnect both ends, look inside for debris or blockage, and straighten any kinks or crushing.
4. **Clean inlet screens.** Remove the inlet hose from the back of the washer and use needle-nose pliers to pull out the small mesh screens in each inlet port, rinse them under running water, and reinstall.
5. **Test the flow sensor wiring.** With power still off, locate the flow sensor (usually mounted on the inlet valve assembly or nearby on the tub), unplug its connector, inspect pins for corrosion or damage, and reseat firmly.
6. **Test or replace the flow sensor.** Use a multimeter to check continuity or resistance across the sensor terminals (Bosch does not publish specific ohm values in consumer documentation, so consult your model's service manual). If the sensor is open, shorted, or mechanically damaged, replace it.
7. **Restore power and test.** Plug the washer back in, open the water valves, and run a rinse or drain-and-spin cycle to verify the E28 code is gone. If the code returns and all previous checks passed, suspect the main control board.

## When to Call a Pro

Call a technician if you are uncomfortable working with electrical connectors, if the flow sensor tests within spec but the code will not clear, or if you have already replaced the sensor and cleaned the inlet path but E28 returns. A pro can perform board-level diagnostics, verify the sensor signal with an oscilloscope, and determine whether the main control board is at fault. Also call if the washer shows signs of a water leak around the inlet valve or sensor area, since that may indicate a cracked housing or failed seal that requires disassembly and parts you cannot easily reach.

**Rough cost:** DIY runs about $50–120 in parts, 1–2 hours. A pro service call runs about $150–300.
