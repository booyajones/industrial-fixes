## Scotsman Prodigy Plus Error Codes — What They Mean

Scotsman Prodigy Plus ice machines (HC, HID, and Brilliance series) are the most widely installed modern Scotsman commercial ice machines. They use a SmartBoard controller that displays error codes when faults are detected. This guide covers the most common Prodigy Plus error codes.

## Prodigy Plus Error Code Summary

| Code | Meaning | Urgency |
|------|---------|---------|
| Code 1 | Long harvest cycle | Medium |
| Code 2 | Long harvest — repeat | High |
| Code 3 | Long freeze cycle | Medium |
| Code 4 | Long harvest assist | High |
| Code 5 | Harvest assist fault | High |
| Code 8 | Water inlet valve fault | Medium |
| Code P1 | Power interruption (informational) | Low |
| Code E1 | Evaporator temp sensor fault | Medium |

## Common Causes

- **Codes 1-5 (harvest/cycle faults)** — Low refrigerant charge, dirty condenser, high water temperature, or failed harvest assist solenoid. These are the most common Prodigy calls.
- **Code 8 (water inlet)** — Clogged inlet valve screen, low supply pressure, or failed solenoid coil.
- **Code E1 (sensor)** — Failed evaporator thermistor or damaged sensor cable.
- **Code P1** — Informational only; records power interruptions. Not a fault requiring repair.

## Step-by-Step Fix {#fix}

1. **For Codes 1-3 (cycle too long)** — Start with condenser cleaning (use a fin brush and compressed air). Check incoming water temperature. Verify refrigerant pressures with a gauge set against the Scotsman pressure chart.
2. **For Code 4-5 (harvest assist)** — Test the harvest assist hot gas solenoid valve during a harvest cycle — the suction line should warm up. If it stays cold, the solenoid coil has failed. Test coil resistance (typically 10–30Ω).
3. **For Code 8 (water inlet)** — Check supply water pressure (needs 20–80 PSI). Remove and clean the inlet valve screen. Test solenoid coil resistance.
4. **For Code E1 (sensor)** — Disconnect the sensor and measure resistance at room temperature (~32kΩ at 32°F, ~10kΩ at 77°F for standard NTC). Open circuit = replace sensor.
5. **Reset the machine** — Press Off, wait 3 seconds, press On. Monitor the next cycle to confirm the code doesn't return.

## When to Call a Pro

Refrigerant work (recharge for low-charge cycle faults) requires EPA 608 certification. Codes that persist after cleaning and sensor/valve replacement need a certified tech for refrigeration diagnosis.
