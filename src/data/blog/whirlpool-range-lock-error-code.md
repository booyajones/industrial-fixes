## Whirlpool Range LOC Error Code — What It Means

On Whirlpool ranges, LOC is not a fault code. It means the Control Lock feature is active and the keypad is intentionally disabled to prevent unintended use. The display shows LOC when you press any button while the controls are locked. This is a normal user-activated state, not a component failure. The oven door also will not lock if the oven is already in use.

The control lock is usually activated accidentally by holding the correct key combination too long or pressing the lock button during cleaning or setup. In most cases, it is a simple user setting that can be cleared with the proper unlock sequence, not a repair issue.

## Before You Replace Anything

Homeowners sometimes replace the control board or keypad thinking LOC is a fault, when it is simply a locked panel. Always try the unlock sequence and a power reset before ordering any parts.

## Common Causes

- **Accidental activation of Control Lock (~85%)** The lock key or START/ENTER was held too long, or the lock combination was pressed during cleaning or cooking, enabling the feature.
- **Stuck or damaged Control Lock button (~8%)** The lock key on the overlay or membrane is physically stuck down, continuously signaling the control to remain locked.
- **Failed user interface or touchpad assembly (~5%)** The keypad or ribbon cable to the control is damaged, causing erratic lock signals or preventing the unlock command from registering.
- **Main electronic control board fault (~2%)** The control board is not processing the unlock sequence correctly or is holding the lock status in memory after a brief power glitch.

## Step-by-Step Fix {#fix}

1. **Verify the oven and timer are off.** Make sure no cooking cycle or timer is running before you attempt to unlock the panel.
2. **Press and hold START/ENTER for 5 seconds.** On most Whirlpool range models, this is the unlock sequence. Some models use a dedicated Control Lock button held for about 3 seconds instead. Listen for a tone and watch for LOC to disappear from the display.
3. **If LOC does not clear, perform a power reset.** Turn off the range circuit breaker at the panel and wait 1 full minute. Restore power and check if the display is normal and the buttons respond.
4. **Inspect the keypad for stuck buttons.** Gently press each key, especially the Control Lock or START/ENTER button, to see if any feel stuck or do not spring back. Clean around the edges of the overlay if needed.
5. **Check the ribbon cable and user interface connections.** If the unlock and reset both fail, pull the range out and remove the rear access panel or lift the top. Look for a loose or damaged ribbon cable between the touchpad and the main control board. Reseat any visible connectors.
6. **Test the range after each step.** After reconnecting power or reseating a cable, press a button and confirm LOC is gone and the oven responds normally.
7. **Replace the user interface or control board only if physical damage is found.** If the ribbon is torn, the touchpad is cracked, or the control board shows burn marks, order the correct part for your model number and swap it. Otherwise, the lock is likely just a setting that can be cleared without parts.

## When to Call a Pro

Call a technician if the unlock sequence and breaker reset both fail to clear LOC, or if the code returns immediately after being cleared. A pro can verify whether the user interface, ribbon cable, or main control board is sending or receiving faulty lock signals. Also call if you are not comfortable accessing the rear panel, disconnecting power at the breaker, or handling the touchpad and control wiring. If the range is still under warranty, contact Whirlpool or an authorized service center before replacing any parts yourself.

**Rough cost:** DIY runs about $0, 1-5 minutes. A pro service call runs about $80-150 service call if a technician is called to unlock, or $150-350 if parts are actually needed for a stuck key or failed control.
