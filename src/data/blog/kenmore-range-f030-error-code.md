## What this code means
The F30 error code on a Kenmore range or dual-fuel oven indicates that the electronic control has detected a fault in the oven temperature sensor circuit. This circuit includes the RTD (resistance temperature detector) probe, its wiring harness, and the connection to the main control board. The control is not seeing the expected sensor resistance, or it is detecting an open, short, or ground fault somewhere in the purple-wire sensor circuit.

The code does not appear during normal operation. It triggers when the control cannot measure oven temperature reliably, so it halts the heating cycle to prevent runaway or unsafe temperatures. The fault may be intermittent if a connector is loose, or constant if the sensor probe has failed or wiring is shorted to the metal cabinet.

## Before You Replace Anything

Many people replace the main control board first when the actual fault is a loose connector, damaged purple-wire harness, or failed RTD sensor. Always check sensor resistance (should be about 1,080 ohms at room temperature) and inspect the harness for shorts to ground before ordering a new control.

## Common Causes

- **Loose or unplugged sensor connector (~35%)** The RTD sensor plug at the rear of the oven can vibrate loose or corrode, breaking the circuit and triggering F30.
- **Failed oven temperature sensor probe (RTD) (~30%)** The resistance temperature detector inside the oven cavity can drift out of spec or fail open, giving an incorrect or missing resistance reading.
- **Damaged sensor wiring harness (~20%)** The purple-wire sensor circuit can fray, burn, or break where it runs behind the control panel or near the oven cavity, creating an open or intermittent connection.
- **Short to cabinet ground (~10%)** A bare sensor wire touching the metal chassis creates a ground fault that the control interprets as a circuit failure.
- **Failed electronic control board (~5%)** If sensor resistance and wiring both check good, the input circuit on the main control board may have failed and cannot read the RTD correctly.

## Step-by-Step Fix {#fix}

1. **Restore power and note the code.** If F30 appears immediately and does not clear after unplugging the range for one minute, the fault is constant and requires further checks.
2. **Disconnect power** at the breaker or unplug the range completely before removing any access panels.
3. **Remove the rear access panel** to expose the main control board and the purple-wire sensor harness that runs to the oven cavity.
4. **Disconnect the sensor plug** from the control board and measure resistance across the two sensor leads with a multimeter. A healthy RTD circuit should read about 1,080 ohms at room temperature.
5. **Check each sensor lead to the metal cabinet** for a ground fault. The meter should read OL (open/infinite). If it reads 0 ohms, the circuit is shorted to chassis and you must inspect the harness for bare or pinched wires.
6. **Replace the sensor probe** if resistance is far from 1,080 ohms or if the probe shows visible damage. If resistance and ground-fault checks are both good, replace the main control board.
7. **Reassemble the range, restore power, and run a test bake cycle** to verify the code does not return and oven temperature climbs normally.

## When to Call a Pro

Call a technician if you are not comfortable working inside the range cabinet, measuring resistance with a multimeter, or identifying ground faults in low-voltage sensor circuits. A pro can quickly verify whether the RTD, harness, or control board has failed and will carry the correct replacement parts on the truck. Also call if the fault returns after you replace the sensor, since that points to a control-board input failure or a hidden wiring short that requires tracing the purple-wire harness through the entire range.

**Rough cost:** DIY runs about $25-80 in parts, 30-90 min. A pro service call runs about $150-300.
