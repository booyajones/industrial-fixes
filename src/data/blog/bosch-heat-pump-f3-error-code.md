## Bosch Heat Pump F3 Error Code — What It Means

The F3 error code on Bosch Industrial heat pump controls indicates a T6B temperature sensor error. This means the control board is receiving an abnormal signal from the T6B sensor circuit, which could be open, shorted, out of range, or disconnected. The system shuts down or limits operation to protect the compressor and refrigerant circuit when it cannot accurately read this temperature input.

Bosch uses different fault code sets across residential and industrial product lines, so always verify the code meaning in your specific unit's service manual. The F3 definition as a T6B sensor fault comes from Bosch Industrial documentation and may not apply to all Bosch heat pump families.

## Common Causes

- **Failed or damaged T6B temperature sensor** The thermistor itself has failed internally, reading open, shorted, or out of the correct resistance range for the measured temperature.
- **Loose or corroded sensor connector** The plug at the sensor or control board has backed out, corroded, or lost spring tension on the terminals, breaking electrical contact.
- **Damaged sensor wiring** The wire harness between the sensor and control board is cut, pinched, or has insulation damage that creates an open or short circuit.
- **Sensor installed incorrectly or unseated** The T6B sensor is not fully inserted into its mounting well or has shifted out of proper contact with the surface or refrigerant line it monitors.
- **Control board input circuit fault** The sensor and wiring test correctly, but the control board's input circuit or IO board has failed and cannot process the sensor signal.

## Step-by-Step Fix {#fix}

1. **Confirm the fault code definition** by checking your unit's model number and service manual, because Bosch code meanings vary across product families.
2. **Locate the T6B sensor** using the wiring diagram or service manual, then inspect it for physical damage, proper seating in its mounting well, and secure attachment to the refrigerant line or air path.
3. **Check the sensor connector and wiring** by unplugging the sensor at both ends, looking for bent pins, corrosion, moisture, or frayed wires, and cleaning or reseating the connectors as needed.
4. **Measure the sensor resistance** with the power isolated and a digital multimeter set to ohms, then compare the reading to the temperature/resistance chart in the manual (Bosch air-to-air systems often use 10 kΩ sensors reading about 10,000 Ω at 77 °F).
5. **Replace the T6B sensor** if the resistance is open (infinite), shorted (near zero), or does not match the chart for the ambient temperature, using the exact part number from your unit's parts list.
6. **Clear the fault code** and run the system through a full cycle, monitoring for the F3 to return.
7. **Test the control board** if the new sensor does not resolve the fault by checking for voltage or continuity at the board input terminals, and replace the control board only after confirming the sensor and harness are correct.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working with live electrical circuits, do not have a multimeter and the manufacturer's resistance chart, or if the sensor tests correctly but the F3 code returns after replacement. Misdiagnosing a sensor fault and replacing the wrong component wastes money, and improper sensor installation can lead to compressor damage or refrigerant system problems. A technician has the model-specific service manual, the correct Bosch part numbers, and the tools to test the control board input circuit when the sensor itself is not the root cause.
