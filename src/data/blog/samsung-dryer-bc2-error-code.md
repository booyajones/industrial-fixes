## Samsung Dryer bC2 Error Code — What It Means

The bC2 code on a Samsung dryer indicates the control is detecting a button that has been held down for more than 75 seconds or a key-circuit short that makes a button appear stuck. Samsung groups bC2 together with bE, bE2, 6E, 6E2, and 6C2 under the same stuck-button fault family. The control reads one of the front-panel buttons as continuously pressed, even though you may not be touching it.

This is usually caused by a physical problem at the user interface, not a functional dryer issue. A button may be mechanically stuck, moisture or detergent residue may be bridging contacts on the console, or the display PCB has developed a short in the key-input circuit. Less commonly, the main control board misreads the button-input path.

## Before You Replace Anything

Many people replace the main control board when the real fault is a stuck or contaminated button on the user interface assembly. Before ordering any parts, press each button individually and clean the console surface to see if the code clears after a power reset.

## Common Causes

- **Physically stuck button (~40%)** One of the front-panel buttons is mechanically jammed, binding, or not returning fully after being pressed.
- **Moisture or residue on the console (~30%)** Water, detergent, or fabric-softener residue has seeped around the buttons and is creating a conductive path that the control reads as a held button.
- **Faulty user interface or keypad assembly (~20%)** The keypad membrane or tactile switch inside the user interface has failed, causing a continuous closed-circuit signal.
- **Display PCB key-circuit short (~8%)** A solder joint, trace, or component on the display printed circuit board has developed a short in the button-input circuit.
- **Main control board misreading input (~2%)** The main control incorrectly interprets the signal from the user interface, though this is less common than a fault at the keypad itself.

## Step-by-Step Fix {#fix}

1. **Unplug the dryer** from the wall outlet or turn off the circuit breaker to remove all power before you begin any inspection.
2. **Leave the dryer powered off for 2–3 minutes** to allow the control to reset, then restore power and check whether the bC2 code returns.
3. **Press each button on the control panel individually** and note whether any stick, bind, or feel abnormal compared to the others.
4. **Inspect the console surface** around all buttons for moisture, detergent residue, fabric-softener film, or any other contamination, and wipe the area dry with a clean cloth.
5. **If a button is physically stuck**, try working it gently to free it, or remove the console cover (consult your model's service manual) and clean around the button posts with a light spray of contact cleaner.
6. **If the code persists after cleaning and reset**, the user interface assembly or display PCB has an internal fault and should be replaced.
7. **Test the dryer** by selecting a short cycle to confirm the code does not return and all buttons respond normally.

## When to Call a Pro

Call a qualified appliance technician if you are uncomfortable removing the console cover or if you have replaced the user interface assembly and the bC2 code still appears. A technician can test the signal path between the keypad and the main control, check for circuit-board shorts with a multimeter, and determine whether the main control board is misreading the input. Professional diagnosis is especially helpful if your model integrates the display PCB and user interface into a single expensive assembly, since a tech can confirm the fault before you invest in the part.

**Rough cost:** DIY runs about $50–150 in parts (user interface or display PCB), 20–40 min. A pro service call runs about $150–250 including service call and part.
