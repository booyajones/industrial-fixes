## Maytag Washer D5 Error Code — What It Means

On most Maytag household top-load and front-load washers, the code displayed as Sd, 5d, or Sud indicates excessive suds detected by the control. The washer will attempt a suds reduction routine to foam down the load before continuing the cycle. If your machine is a coin-operated or commercial Maytag and the display truly reads D5, that code points to a coin sensor or user-interface input fault rather than a suds problem. Because model families differ, verify your exact model number and tech sheet before diagnosing.

Maytag's own product help distinguishes Sd/5d (excess suds) from F9E1 (drain time fault), so the code alone does not mean the drain pump has failed. The control is monitoring basket movement and motor behavior during the cycle. If suds lock the load or if drainage is restricted, the control will throw the code and pause. Technicians should not replace the pump until confirming that the drain path is truly obstructed and the suds issue has been ruled out.

## Before You Replace Anything

Many owners replace the drain pump when they see D5/Sd/5d, but the code is usually triggered by too much detergent or a kinked drain hose. Check for suds and clear the drain path before ordering a pump.

## Common Causes

- **Excess detergent or non-HE formula (~50%)** Over-sudsing from too much soap or regular (non-HE) detergent causes the control to detect excessive foam and pause the cycle.
- **Kinked or clogged drain hose (~20%)** A bent, crushed, or debris-blocked drain hose restricts water flow and can contribute to suds lock behavior.
- **Blocked pump filter or catch (~15%)** Foreign objects or lint in the pump filter or catch prevent proper drainage and trigger the code.
- **Load imbalance or bunched laundry (~10%)** A tangled or unbalanced load restricts basket movement and can mimic a suds condition to the control.
- **Coin sensor or UI board fault (commercial/coin-op D5 only) (~5%)** On coin-operated Maytag models, D5 indicates a faulty coin sensor micro switch, corroded user-interface board, or harness issue.

## Step-by-Step Fix {#fix}

1. **Confirm the exact code and model family.** Look at the model tag and verify whether the display reads Sd, 5d, Sud, or D5. For household washers, treat Sd/5d as a suds code. For coin-operated models showing D5, consult the tech sheet for coin-sensor diagnostics.
2. **Let the suds reduction routine finish.** If the washer is actively running a cycle and the code appears, allow it to complete the foam-down process before intervening. Do not interrupt the cycle or you may restart the timer.
3. **Switch to HE detergent and reduce the dose.** Empty the drum and restart with a small load using only 1-2 tablespoons of high-efficiency detergent. Never use regular detergent in a front-load or HE top-load washer.
4. **Inspect and clear the drain hose.** Pull the machine forward, disconnect the drain hose from the standpipe or tub, and check for kinks, clogs, or foreign objects. make sure the hose is not routed higher than the washer's outlet and is not crushed behind the unit.
5. **Check the pump filter or catch.** If your model provides access to a cleanout filter (typically on front-load washers), open it and remove lint, coins, or debris. Have a shallow pan and towel ready to catch residual water.
6. **Run a diagnostic cycle.** Enter the service mode or motor test on your model to watch basket behavior and listen for unusual pump noise. If the pump runs but water does not flow, the pump may be mechanically obstructed or failed.
7. **Replace the drain pump only after ruling out external obstructions.** If the drain path is clear, detergent is correct, and the pump does not move water during the test, install a new drain pump. Use the model number to order the correct pump assembly and harness.

## When to Call a Pro

Call a technician if you have verified the drain hose is clear, switched to HE detergent, and the code returns after running a diagnostic cycle. If your washer is a coin-operated model and you see D5, a pro can test the coin sensor harness and UI board continuity with the tech sheet procedure. Also call for help if the pump is new or known-good but the code persists, because mechanical drag in the drive system or a control board fault may be mimicking a suds condition. A qualified appliance tech will run the full service diagnostic, measure motor current, and check for internal basket obstructions or failed sensors that a parts swap cannot fix.

**Rough cost:** DIY runs about $15-50 in parts, 20-45 min. A pro service call runs about $120-250.
