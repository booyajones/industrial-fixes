## Manitowoc Ice Machine E37 Error — What It Means

The E37 error code on Manitowoc ice machines indicates a fault detected by the control board, though the exact meaning can vary by model and control system version. This code typically points to a problem with sensor communication, a wiring issue, or a control board malfunction. Because Manitowoc uses different control platforms across its product line, always consult your specific model's service manual or wiring diagram to confirm what E37 represents for your machine.

The error may appear during startup, mid-cycle, or after a power interruption. In many cases it reflects a temporary glitch or a loose connection rather than a failed component. Before replacing parts, verify that all harness connections are seated properly and that the machine has stable power.

## Before You Replace Anything

Many technicians replace the control board first when the actual problem is a corroded or loose connector at a sensor. Inspect and clean all sensor plugs and pins before ordering a board.

## Common Causes

- **Loose or corroded sensor wiring (~40%)** Vibration, moisture, and mineral dust can loosen plugs or corrode pins at thermistor and probe connections, interrupting signal to the board.
- **Failed thermistor or temperature sensor (~25%)** A sensor that drifts out of range or opens internally will trigger a fault code when the control board cannot read a valid resistance.
- **Control board firmware glitch or memory error (~15%)** Power surges or age-related memory corruption can cause the board to log spurious errors that clear with a reboot or firmware update.
- **Defective main control board (~12%)** Internal component failure on the board itself can generate false error codes even when all sensors and wiring test normal.
- **Intermittent ground fault or voltage fluctuation (~8%)** Poor grounding or unstable mains voltage can cause erratic readings and trigger safety shutdowns with error codes.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the breaker and lock out the disconnect to prevent accidental startup during service.
2. **Record the error** by photographing the display and noting any additional fault codes or indicator lights for reference.
3. **Remove the front panel** or access cover to expose the control board and wiring harnesses, following your model's service manual.
4. **Inspect every connector** at the control board, thermistors, and probes for corrosion, moisture, or bent pins, and clean with electrical contact cleaner if needed.
5. **Test each sensor** with a multimeter set to resistance mode, comparing readings to the temperature-resistance table in the service manual.
6. **Check incoming voltage** at the power supply terminals to confirm stable line voltage and verify the ground connection is solid.
7. **Clear the error code** by following the reset procedure in the manual (typically a specific button sequence or power cycle), then monitor the machine through a full ice-making cycle to confirm the fault is gone.

## When to Call a Pro

Call a qualified commercial refrigeration technician if you are not comfortable working with electrical diagnostics or if the machine uses a refrigerant-circuit sensor that requires recovery and recharge. Professional service is also recommended when the fault persists after you have verified all connections and tested sensors, since control board replacement often requires firmware setup and may involve sealed-system work. Technicians have access to factory service bulletins, updated firmware, and specialized diagnostic tools that can pinpoint intermittent faults quickly.

**Rough cost:** A pro service call runs about $180-400.
