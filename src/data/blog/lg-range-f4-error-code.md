## What this code means
The F4 error code on an LG electric range indicates a lower oven thermistor or oven sensor fault. LG's official troubleshooting documentation describes this as a shorted oven sensor in the temperature-sensing circuit. The control board has detected that the resistance reading from the lower oven sensor is outside the expected range, typically because the sensor has failed short or the wiring has been damaged.

This code applies only to LG ranges. LG uses the same F4 code differently on microwave ovens (where it means a humidity sensor error), so always confirm you are looking at range-specific guidance. The fault points to the lower oven cavity on dual-oven models or the main oven sensor on single-oven ranges.

## Before You Replace Anything

Many people replace the main control board when they see F4, but a shorted or damaged oven sensor is usually the real culprit. Always test the sensor resistance and inspect the wiring harness before ordering a board.

## Common Causes

- **Shorted oven sensor (~60%)** The lower oven thermistor itself has failed short-circuit, causing the control to read an invalid resistance and throw the F4 code.
- **Damaged or loose sensor wiring (~25%)** Heat, pinching, or corrosion has damaged the wiring or connectors between the sensor and the control board, creating a short or intermittent connection.
- **Burned or corroded connector terminals (~10%)** High heat near the oven cavity can char or corrode the sensor plug terminals, producing a short that mimics a sensor failure.
- **Control board misreading the sensor circuit (~5%)** The control board's sensor input circuitry has failed and interprets a good sensor as shorted, though this is less common than a genuine sensor or wiring fault.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker and unplug the range to prevent shock before opening any panels or touching internal wiring.
2. **Locate the lower oven sensor** at the rear wall inside the oven cavity. It is a thin metal probe extending into the oven space, with a two-wire connector behind the wall.
3. **Inspect the sensor and harness** for cracks, burns, melted insulation, or loose connectors. Check both the sensor probe and the connector at the control board end of the harness.
4. **Disconnect the sensor plug** and use a multimeter set to resistance (ohms) to measure across the sensor terminals. Consult your model's service data for the expected resistance at room temperature. A reading near zero ohms indicates a short.
5. **Replace the shorted sensor** by removing the mounting bracket or clip inside the oven, pulling the old sensor and harness through the back wall, and installing the new sensor in reverse order. Reconnect the plug securely.
6. **Restore power** and run a test bake cycle. The F4 code should clear immediately if the sensor was the problem. If the code persists, recheck all connections and consider testing the control board input circuit.
7. **If the sensor and wiring test good**, the control board may be misinterpreting the signal. Replace the main control board only after confirming the sensor circuit is intact.

## When to Call a Pro

Call a professional if you are uncomfortable working inside a 240-volt electric range, if you cannot safely access the sensor connector behind the oven cavity, or if the sensor and wiring both test normal but the F4 code will not clear. A technician can verify the control board input circuit with specialized tools and has access to model-specific resistance tables and service data that are not published in owner manuals. If your range is still under warranty, contact LG or an authorized service center before attempting any repair yourself.

**Rough cost:** DIY runs about $25-$60 in parts, 30-60 min. A pro service call runs about $150-$300.
