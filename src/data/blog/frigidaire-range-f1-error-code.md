## Frigidaire Range F1 Error Code — What It Means

Frigidaire's published error-code guide defines F1 as a shorted keypad fault. The electronic oven control sees a keypad line stuck active, shorted, or otherwise invalid, so it cannot trust user input from the control panel. On some models and failure states, F1 can also signal a control-board or oven-control fault triggered by the keypad circuit or by an overheating or false-temperature condition during heating.

Electrically, the control detects a keypad signal that is continuously active or out of range. This can be caused by a physically stuck button, moisture or food residue on the touch panel, a damaged membrane or control console, a loose or corroded ribbon-cable connector between the console and the main board, or a failure in the user interface board or electronic oven control itself. If the fault appears during a bake or cleaning cycle and the oven is actually running too hot, the oven temperature sensor probe or control relay circuit may be the underlying problem.

## Before You Replace Anything

Many people replace the main electronic oven control board first. Before ordering that expensive part, disconnect power for five minutes and check every button for physical sticking, inspect the console for moisture or residue, and reseat the ribbon cable between the console and control.

## Common Causes

- **Shorted or stuck keypad (~50%)** A button stuck in the down position or a shorted touch-panel membrane creates a continuous input signal that the control reads as a fault.
- **Moisture, residue, or contamination on the console (~20%)** Food spills, grease, or cleaning spray on the control panel can bridge contacts and create a false key-press input.
- **Loose or corroded ribbon cable or connector (~15%)** The harness between the console and the main control can develop poor contact or pin corrosion that shorts the keypad signal path.
- **Failed user interface board or console assembly (~10%)** The keypad circuit board itself can fail even when buttons move freely and the panel appears clean.
- **Main electronic oven control (EOC) failure (~5%)** If the keypad and all connections are verified good, the main control board may be misreading the keypad lines or have an internal fault.

## Step-by-Step Fix {#fix}

1. **Disconnect all power** at the circuit breaker or by unplugging the range before opening any panels or touching internal components.
2. **Press each keypad button individually** and watch for any that do not return fully or feel sticky. If you find a stuck key, clean around it with a cotton swab and isopropyl alcohol. If the button remains stuck, plan to replace the console assembly.
3. **Inspect the control panel surface** for moisture, grease, or food residue. Wipe the entire console with a damp cloth and isopropyl alcohol. Let it dry completely before restoring power.
4. **Remove the range top or rear access panel** (consult your model's service manual for fastener locations) to reach the ribbon cable or wiring harness that connects the console to the main control board. Unplug the connector, check pins for corrosion or damage, and firmly reseat it.
5. **Restore power and test** the range. If the F1 code returns immediately or during the first heating cycle, replace the keypad or console assembly (some models integrate the two). If the code clears with a new console but returns later, replace the electronic oven control board.
6. **If the fault occurs only during heating and the oven runs hot**, verify actual cavity temperature with an external oven thermometer. Measure the oven temperature sensor probe resistance (consult your model's resistance table) and replace the sensor if it is out of spec.
7. **Reassemble all panels**, restore power, and run a test bake cycle to confirm the repair. Clear any stored error codes by holding the cancel or clear button, or by cycling power one more time.

## When to Call a Pro

Call a professional if you are uncomfortable working around 240-volt wiring, if your range uses a direct wire connection rather than a plug, if the fault returns after replacing both the console and the main control board, or if you need help reading wiring diagrams to verify sensor and relay circuits. A qualified appliance technician can bring the correct model-specific service sheet, measure keypad and sensor values with precision test equipment, and handle the high-voltage connections safely. Also call a pro if the range shares a junction box with other hardwired kitchen equipment or if local code requires a licensed electrician for any appliance repair work.

**Rough cost:** DIY runs about $60–180 in parts, 45–90 min. A pro service call runs about $150–350.
