## What this code means
F-29 on a Whirlpool dryer indicates a moisture sensor circuit fault. The control board is seeing the moisture-sensing circuit as invalid, shorted, or out of the expected range. This is not primarily a vent code. The moisture sensor bars (usually metal strips inside the drum or on the front bulkhead) monitor dampness in clothes, and when that circuit fails, the dryer cannot complete automatic cycles properly.

Whirlpool's published first step is a 5-minute power reset followed by a Time Dry test to see whether the code returns. If it does, the problem is most often dirty sensor bars, a loose or damaged wiring harness between the sensor and the main control, or a shorted sensor circuit. Less commonly, the main control board itself has failed.

## Before You Replace Anything

Many people replace the main control board first. Before that, clean the sensor bars with rubbing alcohol and check every connector in the sensor harness for looseness or corrosion.

## Common Causes

- **Dirty or residue-covered moisture sensor bars (~50%)** Fabric softener, lint, and mineral deposits coat the sensor strips and prevent the circuit from reading correctly.
- **Loose, damaged, or unplugged sensor harness connectors (~25%)** Vibration and heat can unseat connectors or break wires between the sensor and the control board.
- **Shorted or failed moisture sensor assembly (~15%)** The sensor bars themselves can corrode, short together, or break, sending an invalid signal to the control.
- **Failed main control board (~8%)** If the sensor and wiring test good but the code persists, the control board cannot read the circuit correctly.
- **Restricted vent system (~2%)** Heavy lint buildup or crushed ducting is not the direct F-29 cause but can worsen drying performance and mask other faults.

## Step-by-Step Fix {#fix}

1. **Disconnect power** at the circuit breaker and wait 5 minutes to allow the control board to reset.
2. **Restore power** and select a Time Dry cycle, then run the dryer for about 1 minute to see whether F-29 reappears.
3. **Locate the moisture sensor bars** inside the drum or on the front bulkhead (consult your model's service manual for the exact location).
4. **Clean the sensor bars** with a cloth dampened in rubbing alcohol to remove fabric softener film, lint, and mineral deposits, then dry them completely.
5. **Inspect the sensor wiring harness** from the sensor bars to the main control board for loose connectors, broken wires, or signs of heat damage.
6. **Check for a shorted sensor circuit** by measuring resistance across the sensor terminals (consult your model's wiring diagram for expected values) or replace the moisture sensor assembly if it tests out of range.
7. **Replace the main control board** only if the sensor, harness, and all connections test good but F-29 still returns after every reset and Time Dry test.

## When to Call a Pro

Call a technician if you are not comfortable working inside the dryer cabinet or if you lack a multimeter and service data to test the moisture sensor circuit. A pro can verify whether the sensor is shorted, check continuity and resistance values against factory specifications, and confirm that the main control board is processing the sensor signal correctly. Also call if you have already cleaned the sensor bars and reseated every connector but F-29 returns immediately, because that usually means either a failed sensor assembly or a control board fault that requires diagnostic tools and a wiring diagram.

**Rough cost:** DIY runs about $15–50 in parts, 30–60 min. A pro service call runs about $150–300.
