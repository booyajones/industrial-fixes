## Bosch Heat Pump E5 Error — What It Means

Bosch uses E5 differently across product lines, so first identify your exact model. For Bosch BOVA/BOVB/BOVC/BOVD air-to-air heat pump outdoor units, E5 means high-pressure protection in heating (PT). The system has detected a condition that could damage the compressor and has shut down to protect itself.

On some other Bosch commercial HVAC equipment, E5 instead indicates abnormal power supply voltage. This guide focuses on the air-to-air heat pump interpretation, which is the most common application for Bosch heat pump models.

## Common Causes

- **Faulty T5 outdoor coil temperature sensor** The T5 sensor is reading far outside normal range or showing a fixed value like 32 degrees, triggering false high-pressure protection.
- **Outdoor fan not operating** The fan that cools the outdoor coil has stopped or is running too slowly, causing actual high pressure in the refrigerant circuit.
- **Extreme ambient temperature** Outdoor air temperature above 125°F can cause legitimate high-pressure trips even when all components are working correctly.
- **T5 sensor reading does not match actual conditions** After the unit has been idle for at least five minutes, T5 still reads more than 50°F away from outdoor temperature.
- **Abnormal power supply voltage** On some Bosch commercial equipment, E5 indicates input voltage problems rather than a refrigerant or pressure issue.

## Step-by-Step Fix {#fix}

1. **Check if the display shows E4 plus a sensor name** instead of E5. If so, that named sensor has failed and should be replaced using the part number from the Bosch Aftermarket Resource Center.
2. **Access the parameters menu and compare T5 to T3 and T4 readings.** If T5 shows 32 or is far off from the other temperature sensors, replace the T5 sensor. If T5 is close to T3/T4, contact Bosch technical support before replacing parts.
3. **Measure T5 resistance with an ohmmeter** if you can access the sensor. If the ohm reading is outside the expected range by more than ±10%, replace the T5 sensor.
4. **Verify the outdoor fan is running** when the unit attempts to operate. If the fan does not start or runs very slowly, follow the Bosch E6 code procedure to diagnose the fan circuit.
5. **Check outdoor ambient air temperature.** If it is above 125°F, wait for the air to cool down and reset the unit. If ambient is below 125°F and the fan is working, continue.
6. **Let the unit sit idle for at least five minutes, then recheck T5** against actual outdoor temperature. If T5 is more than 50°F away from outdoor temperature, replace the T5 sensor. If T5 is within 50°F, contact Bosch technical support.
7. **Contact Bosch technical support** if T5 reads reasonably but E5 still appears, as this indicates a possible control board or system-level fault that requires factory-level diagnostics.

## When to Call a Pro

Call a licensed HVAC technician if you cannot access the parameters menu, if T5 reads normally but the code persists, or if the outdoor fan tests require electrical troubleshooting. Refrigerant system diagnostics and control board replacement require EPA certification and specialized gauges. Bosch directs technicians to contact factory support when sensor readings are reasonable but the fault continues, which usually means a board-level or system logic problem beyond field repair. If your unit is the commercial type and E5 means abnormal voltage, call an electrician to test and correct the incoming power.
