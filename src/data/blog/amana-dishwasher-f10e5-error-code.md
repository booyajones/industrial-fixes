## What this code means
F10E5 is Amana's error code for a cycle-end fault. When the code appears, the dishwasher finishes draining and then displays the error on the console. Amana groups F10E5 and FAE5 together in their consumer help pages and does not publish a detailed public fault definition beyond this symptom behavior.

Because Amana does not identify a single component in the public documentation, recurring F10E5 is typically treated as a service fault in the control, communication, or input path rather than a simple user-reset condition. The error usually points to a failure in the main control board, user interface, door latch or door-switch input, wiring harness, or a model-dependent sensor affecting cycle completion logic.

## Before You Replace Anything

Many homeowners replace the main control board first. Always inspect the door latch, door switch, and all wiring connectors for looseness or corrosion before ordering a new control.

## Common Causes

- **Main control board failure (~40%)** The main control board develops intermittent faults or loses communication with other components, triggering the cycle-end error after the drain completes.
- **User interface or console fault (~25%)** The user interface panel or console loses communication with the main control or develops internal circuit faults that prevent normal cycle completion.
- **Door latch or door-switch input problem (~20%)** The door latch assembly or door switch fails to register a proper closed and latched state, so the control sees an incomplete cycle condition.
- **Wiring harness or connector issue (~10%)** Loose, corroded, or damaged connectors between the control, latch, and user interface cause intermittent signal loss that the control interprets as a cycle fault.
- **Model-dependent sensor or input fault (~5%)** A sensor or input specific to your model (such as a water-level or temperature input) sends faulty data to the control during the final cycle phase.

## Step-by-Step Fix {#fix}

1. **Press Cancel twice** on the dishwasher control panel to clear the fault, then start a new cycle as instructed in Amana's consumer help documentation.
2. **Power off the dishwasher** at the circuit breaker for two minutes, then restore power and attempt another cycle to rule out a transient electronic glitch.
3. **Open the door and inspect the latch area** for broken springs, misalignment, or debris that would prevent the door from closing and latching cleanly.
4. **Pull the dishwasher forward** and remove the lower access panel or toe-kick to expose the wiring connections under the tub.
5. **Check all wiring connectors** at the main control board (usually under the door panel), the door latch, and the user interface for looseness, corrosion, or pin damage.
6. **Enter diagnostic or service mode** if your model supports it (consult your tech sheet) and check for stored fault codes that identify the specific failed input or component.
7. **Replace the main control board** if diagnostics confirm a board fault and all wiring and door components check out, or replace the user interface if button response is erratic or the display flickers.

## When to Call a Pro

Call a qualified appliance technician if the code returns after the Cancel-twice reset and you are not comfortable working with wiring or control boards. A technician can enter service mode, read stored fault codes, and use the model-specific tech sheet to isolate the exact failed component. Professional diagnosis is also warranted if you have already replaced the door latch and checked all visible connectors but the fault persists, because distinguishing between a bad control board and a bad user interface often requires voltage measurements and communication-bus testing that are beyond typical DIY tools.

**Rough cost:** DIY runs about $150–$350 for control board or interface, 45–90 min. A pro service call runs about $200–$450.
