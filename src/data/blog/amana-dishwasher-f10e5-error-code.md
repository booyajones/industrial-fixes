## Amana Dishwasher F10E5 Error Code — What It Means

The F10E5 (also shown as FAE5 on some models) code means your dishwasher stopped mid-cycle, drained the tub, and displayed the error. Amana's product help confirms this behavior but does not publish a single specific fault definition for all models on the public help page. The code appears across Whirlpool-family platforms and is commonly linked to door latch signal issues, control board communication faults, or wiring problems that interrupt the cycle-completion logic.

[Jump to Fix](#fix)

## Common Causes

- **Door latch or switch input fault** The door latch assembly or its switch may send an intermittent open signal, causing the control to halt the cycle.
- **User interface to control board communication issue** A corrupted signal or temporary glitch between the console and main control stops the cycle and triggers the code.
- **Main control board fault** The control board may fail to send or receive expected signals, ending the cycle prematurely.
- **Loose or corroded wiring connector** Poor contact at the latch, UI, or board harness can create an intermittent open circuit.
- **Sensor or input related to cycle logic** Depending on the model, a sensor tied to cycle-completion may send a fault signal.

## Step-by-Step Fix {#fix}

1. **Press Cancel twice** on the control panel and start a new cycle, following Amana's first troubleshooting step.
2. **Turn off the breaker** to the dishwasher for one to five minutes if the code returns, then restore power and retry the cycle.
3. **Inspect the door latch area** with power off for any obstruction, damage, or contamination, and verify that the door closes firmly without interference from racks or utensils.
4. **Check wiring connectors** at the door latch, user interface, and main control board for looseness, corrosion, or damaged pins.
5. **Run model-specific diagnostics** using the service tech sheet or diagnostic procedure for your exact model to identify which input is faulting.
6. **Test and replace the failed component** only after input/output testing confirms the fault, rather than replacing parts based on the code alone.
7. **Document the fault** and any test results if you plan to call service, since model-specific values and sequences are not published on the public help page.

## When to Call a Pro

Call a qualified appliance technician if the code persists after the Cancel reset and basic latch inspection, or if you are not comfortable working with live AC wiring and control boards. Technicians have access to model-specific diagnostic sequences, wiring diagrams, and test values that Amana does not publish on the public help page. Professional testing avoids unnecessary part replacement and confirms the exact fault before ordering components.
