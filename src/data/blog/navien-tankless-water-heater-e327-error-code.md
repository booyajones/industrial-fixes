## Navien E327 Error Code — What It Means

The E327 error code on a Navien tankless water heater indicates a communication failure between the main printed circuit board (PCB) and one or more internal components, such as sensors or secondary control modules. The exact component involved may vary by model, so consult your owner's manual or the unit's wiring diagram for precise details. This code typically appears when the control board cannot receive data from a sensor or when wiring connections become loose or corroded. Because Navien units rely on constant communication between the PCB and sensors to regulate temperature and flow, any interruption triggers a fault and shuts down operation to prevent unsafe conditions.

## Before You Replace Anything

Many homeowners replace the main PCB assuming it has failed, when the real issue is often a loose connector or a failed temperature sensor. Inspect all wiring harnesses and test sensor resistance with a multimeter before ordering a new board.

## Common Causes

- **Loose or corroded wiring connections (~40%)** Vibration, moisture, or age can cause connectors between the PCB and sensors to loosen or develop corrosion, interrupting communication.
- **Failed temperature sensor (~30%)** Inlet or outlet temperature sensors can fail internally or drift out of specification, preventing the board from reading accurate data.
- **Main PCB failure (~15%)** The control board itself can develop solder cracks, component failures, or memory corruption that prevents it from polling sensors correctly.
- **Damaged wiring harness (~10%)** Wires can be pinched, chewed by rodents, or damaged during prior service, creating open circuits or shorts that block communication.
- **Grounding or electrical noise issues (~5%)** Poor grounding or electrical interference from nearby devices can disrupt low-voltage communication signals between components.

## Step-by-Step Fix {#fix}

1. **Turn off power** to the water heater at the circuit breaker and close the gas shutoff valve to make sure safe working conditions.
2. **Remove the front cover** of the unit by unscrewing the retaining screws, then set the panel aside to access the internal components.
3. **Inspect all wiring connectors** on the main PCB and each sensor (inlet, outlet, flow, and any auxiliary sensors). Look for loose plugs, bent pins, or greenish corrosion.
4. **Reseat each connector** firmly by unplugging and reconnecting it. If corrosion is visible, spray the contacts with electrical contact cleaner and wipe dry.
5. **Test sensor resistance** using a multimeter set to ohms. Disconnect each sensor's wiring plug, measure across the sensor terminals, and compare readings to your model's specification table (typically found in the service manual or wiring diagram).
6. **Replace any sensor** that reads outside the acceptable range. Note the sensor's model number or consult the parts diagram to order the correct replacement.
7. **Reinstall the front cover**, restore power and gas, and run a test cycle. If the error clears and hot water flows normally, the repair is complete. If the code reappears, the main PCB or wiring harness may need professional diagnosis and replacement.

## When to Call a Pro

Call a qualified technician if you are uncomfortable working with gas appliances, if the error persists after reseating connectors and replacing out-of-spec sensors, or if you lack a multimeter and the knowledge to test component resistance safely. Tankless water heaters operate on both gas and line voltage, and misdiagnosis can lead to expensive part replacements or unsafe conditions. A trained technician can perform advanced diagnostics, including PCB signal testing and harness continuity checks, and will have access to factory service bulletins that address model-specific communication faults.

**Rough cost:** A pro service call runs about $150-350.
