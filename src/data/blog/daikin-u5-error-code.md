## Daikin U5 Error Code — What It Means

The U5 fault code on a Daikin system indicates a communication failure between the indoor unit and the wired remote controller. This is not a refrigerant issue or a compressor problem. It means the indoor unit's control board and the remote controller are unable to communicate properly over the wiring that connects them.

Daikin's official fault chart lists U5 as a malfunction of transmission between the indoor unit and the remote controller. The failure can originate on either end of the connection or in the wiring itself. In many cases, the error appears after a remote is connected or disconnected, and a simple power cycle will clear it.

## Common Causes

- **Two main remote controllers connected** Daikin systems allow multiple remotes, but only one can be configured as the main controller, and connecting two mains triggers a U5 communication conflict.
- **Defective indoor unit PCB** The control board inside the indoor unit can fail and lose its ability to send or receive signals to the remote controller.
- **Defective remote controller PCB** The circuit board inside the wired remote can fail and prevent proper communication with the indoor unit.
- **Transmission error caused by noise** Electrical interference from nearby equipment or damaged wiring can corrupt the signal between the indoor unit and the remote.

## Step-by-Step Fix {#fix}

1. **Power cycle the indoor unit** by turning off the breaker or disconnect for 30 seconds, then restoring power to see if the U5 clears on its own.
2. **Check for duplicate main remotes** if your system has multiple wired controllers, and verify that only one is set as the main controller in the configuration menu.
3. **Inspect the remote controller wiring** for damage, loose terminals, or routing near motors, transformers, or other electrical noise sources, and repair or reroute as needed.
4. **Swap the remote controller with a known-good unit** to isolate whether the fault follows the remote or stays with the indoor unit.
5. **Replace the remote controller PCB** if the U5 fault follows the remote to the new indoor unit during your swap test.
6. **Replace the indoor unit PCB** if the U5 fault remains with the original indoor unit when a known-good remote is connected.
7. **Re-test the system** after any part replacement and verify stable communication between the indoor unit and remote for at least 15 minutes of run time.

## When to Call a Pro

Call a licensed HVAC technician if the power cycle and wiring inspection do not clear the U5, or if you are not comfortable swapping control boards and remotes to isolate the fault. Communication faults require methodical substitution testing, and incorrect wiring or board installation can damage expensive components. A technician has the diagnostic tools and replacement parts to quickly identify whether the indoor PCB, the remote PCB, or a wiring issue is responsible.
