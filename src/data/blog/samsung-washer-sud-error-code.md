## Samsung SUD Error Code — What It Means

The Samsung SUD or SUDS error code indicates that your washer has detected an over-sudsing condition. Excessive foam has built up inside the drum, and the machine pauses the cycle to allow the suds to dissipate naturally. This is not a mechanical or electrical failure code. Samsung describes it as improper detergent use rather than a component breakdown.

The control system senses the foam level and stops temporarily until the bubbles break down. Once the suds reduce, the washer should resume the cycle automatically. If the code persists across multiple cycles, the root cause is usually detergent misuse or a drainage problem that traps sudsy water and prevents it from clearing.

## Before You Replace Anything

Homeowners sometimes suspect the control board or pressure sensor when SUD appears repeatedly. Before replacing any electronic component, verify detergent type and dosage, then clean the drain pump filter, because clogged filters and overdosing account for nearly all cases.

## Common Causes

- **Overdosing detergent (~50%)** Using more than the recommended amount for your load size creates excessive foam that triggers the code.
- **Using non-HE detergent (~25%)** Regular detergent in a high-efficiency front-load washer suds far more than HE formulas and overwhelms the machine.
- **Not accounting for detergent concentration (~10%)** Ultra-concentrated (2x or 3x) products require much smaller doses, and using a standard scoop causes over-sudsing.
- **Clogged drain pump filter (~10%)** Lint, debris, and foreign objects in the filter restrict drainage and trap sudsy water in the tub.
- **Kinked or blocked drain hose (~5%)** Poor hose routing or obstructions prevent suds from draining away, so the condition persists cycle after cycle.

## Step-by-Step Fix {#fix}

1. **Stop the cycle and unplug the washer.** Allow the machine to sit for 10 to 15 minutes so foam inside the drum can settle and break down naturally.
2. **Verify detergent type and dose.** Confirm you are using HE detergent and check the product label for the correct amount based on load size and concentration (1x, 2x, or 3x).
3. **Run a rinse or drain cycle with no detergent.** Start the washer empty or with just clean water to flush out residual suds and test whether the code clears.
4. **Access and clean the drain pump filter.** Open the service panel (usually lower front), place a shallow pan to catch water, unscrew the filter cap, remove lint and debris, rinse the filter under running water, and reinstall it securely.
5. **Inspect the drain hose routing.** Check that the hose is not kinked, crushed, or installed too deep in the standpipe, because restricted flow traps sudsy water.
6. **Reset the washer.** Unplug the machine for 60 seconds, plug it back in, and run a short test cycle with the correct HE detergent dose.
7. **Monitor the next few loads.** If SUD returns, reduce detergent further or check for hidden obstructions in the pump housing and drain path.

## When to Call a Pro

Call a technician if the SUD code persists after you have switched to HE detergent at the correct dose, cleaned the drain pump filter, verified the drain hose is clear and properly routed, and run multiple rinse cycles. A pro can inspect the pump housing for hidden obstructions, test the pressure or level sensor if applicable, and check the control board for faults. Also call if you see water backing up into the drum, hear loud grinding from the pump, or notice any unusual odors or leaks during drain cycles, because those symptoms point to mechanical blockages or pump failure rather than simple detergent misuse.

**Rough cost:** DIY runs about $0-15 in cleaning supplies, 20-45 min. A pro service call runs about $100-200 if a service call is needed to clean the drain system.
