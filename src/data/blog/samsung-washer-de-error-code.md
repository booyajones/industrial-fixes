## What this code means
The dE, dE1, Ed, dC, DC, or DC1 code on a Samsung front-load washer is a door-related fault. The machine believes the door is open, not fully latched, or not being sensed as closed. Samsung's support documentation describes this as a door or door switch fault. On some models the main PCB door-sensing circuit can also trigger this code. The washer will not start a cycle until it receives a valid closed-door signal.

## Before You Replace Anything

Homeowners often replace the main PCB thinking it is the door-sensing circuit, when the actual fault is a failed door interlock switch or debris in the gasket. Test the door switch for continuity and clean the gasket thoroughly before ordering a control board.

## Common Causes

- **Laundry caught in the door seal (~35%)** Clothing, a bra wire, or other items are trapped between the door gasket and cabinet, preventing the latch from fully engaging.
- **Door not fully closed or latched (~30%)** The door is resting against the frame but not pushed firmly enough to engage the latch mechanism and close the interlock switch.
- **Debris or residue on the door gasket (~15%)** Lint, detergent buildup, or mildew on the rubber door seal prevents a tight seal and proper latch closure.
- **Faulty door switch or interlock assembly (~15%)** The door interlock switch has failed internally or its contacts are corroded, so it no longer signals the control board that the door is closed.
- **Main PCB door-sensing circuit fault (~5%)** The circuit on the main control board that reads the door switch signal has failed, even though the door and switch are working correctly.

## Quick Diagnosis

Answer these to narrow it down fast.

<details class="dtree"><summary>Does the door close with a distinct click or firm resistance when you push it shut?</summary>

</details>

<details class="dtree"><summary>After cleaning the gasket and firmly closing the door, does the code still appear when you power-cycle the washer?</summary>
<div class="dtree-body"><strong>Yes:</strong> The door switch or main PCB door-sensing circuit is faulty. Test the door switch for continuity or call a technician.<br><strong>No:</strong> The fault was mechanical. The washer should now operate normally.</div>
</details>

## Step-by-Step Fix {#fix}

1. **Open the door fully** and inspect the entire rubber gasket for clothing, bra wires, coins, or other objects trapped in the seal. Remove any obstructions.
2. **Wipe the gasket and door frame** with a damp cloth to remove lint, detergent residue, and mildew. Pay special attention to the area where the latch striker meets the seal.
3. **Close the door firmly** until you hear or feel a distinct click. The door should resist being pulled open without pressing the release button.
4. **Power-cycle the washer** by unplugging it for 60 seconds, then plug it back in and start a test cycle to see if the code clears.
5. **Inspect the door switch wiring** if the code persists. Unplug the washer, remove the top or front panel per your model's service manual, locate the door interlock assembly, and check for loose or corroded connectors.
6. **Test the door switch for continuity** using a multimeter. With the door closed the switch should show continuity. Consult your model's wiring diagram for the correct terminals. Replace the door interlock assembly if it fails this test.
7. **Check the main PCB door-sensing circuit** if the door switch tests good and all wiring is intact. If the door signal is present at the board but the code remains, replace the main control board.

## When to Call a Pro

Call a professional if you have cleaned the gasket and verified the door closes firmly but the code persists and you are not comfortable testing electrical components with a multimeter. A technician can quickly test the door switch continuity, trace the wiring to the main board, and determine whether the interlock or the PCB door-sensing circuit is at fault. Also call a pro if you need to disassemble the front panel or top of the washer and are unfamiliar with your model's construction, or if the washer is still under warranty.

**Rough cost:** DIY runs about $30-80 in parts (door switch/interlock), 20-45 min. A pro service call runs about $120-250 including service call and part.
