## ABB ACS580 A4A2 — What It Means

The code A4A2 does not appear in ABB's official ACS580 fault code list and does not match ABB's standard numeric (e.g., 3381, 7122) or alphanumeric (F0001, STO) fault naming conventions. This strongly suggests the code is either misread from the drive display, generated by a third-party controller (PLC, BMS, or external motor control system), or confused with a real ABB fault.

Before troubleshooting further, power-cycle the drive and use the keypad or Drive Composer software to pull the actual event history. The real fault will appear as a documented ABB code with a timestamp. If A4A2 persists or appears on an external system display, verify wiring to any third-party controllers and consult that equipment's documentation. Common ABB faults that are sometimes misread include 3381 (output phase loss), 7122 (overload alarm), and STO (safe torque off triggered).

## Before You Replace Anything

Technicians sometimes replace the drive's control board or mainboard when seeing an unfamiliar code. Always retrieve the actual fault history via Drive Composer or the keypad event log before ordering parts.

## Common Causes

- **Misread or transient display error (~40%)** The drive display may show garbled text during a power glitch or startup sequence, creating a false code that clears after reboot.
- **Third-party PLC or BMS code (~30%)** External control systems (building management, programmable logic controllers) often generate custom alarm codes that appear on operator displays but are not native to the VFD.
- **Confusion with fault 3381 (output phase loss) (~15%)** If motor connections are loose or a phase is open, the drive reports 3381, which can be mistyped or misread as A4A2.
- **Confusion with fault 7122 (overload alarm) (~10%)** Excessive motor current or a bad mainboard connection triggers 7122, which may be confused during a hasty visual check.
- **STO (Safe Torque Off) jumper or 24 V supply fault (~5%)** If the STO circuit is open or control power is lost, the drive may stop with an STO alarm that is mistaken for an alphanumeric fault.

## Step-by-Step Fix {#fix}

1. **Power-cycle the drive** by switching off the main disconnect, waiting 30 seconds for capacitors to discharge, then switching back on and observing the display for a clear or different fault.
2. **Retrieve the event history** by pressing the menu button on the keypad, navigating to menu 4.1 (Fault Log) or 4.2 (Alarm Log), and recording the actual fault code, timestamp, and any active alarms.
3. **Cross-reference the real code** in the ACS580 user manual or fault table to identify the documented meaning, common causes, and recommended diagnostic steps for that specific fault.
4. **Inspect all power and motor connections** at the drive input terminals, motor output terminals, and control wiring blocks for loose, corroded, or broken wires that could trigger phase-loss or overload faults.
5. **Test motor insulation and continuity** using a megohmmeter set to 500 V DC (insulation resistance should be greater than 1 MΩ), and check winding resistance between phases (should be less than 0.5 Ω difference).
6. **Check third-party equipment** if the drive is networked to a PLC, BMS, or operator panel by reviewing that system's alarm documentation, Modbus or Ethernet/IP diagnostic registers, and wiring to confirm the code is not external.
7. **Contact ABB technical support** if the code remains unexplained, providing the drive nameplate data (model ACS580, frame size, firmware version) and event log screenshots for official guidance.

## When to Call a Pro

Call a qualified industrial electrician or ABB-certified technician if you cannot retrieve a documented fault code after power-cycling and checking the event log, if motor insulation tests fail (below 1 MΩ), or if the drive is part of a complex automation system with PLC or BMS integration. Professional diagnosis is also necessary when the real fault involves high-voltage DC bus components, internal board replacement, or parameter reprogramming that could affect safety circuits or networked equipment. ABB offers remote support and field service for drives under warranty or service contract.

**Rough cost:** A pro service call runs about $150-400 depending on the real fault and required parts.
