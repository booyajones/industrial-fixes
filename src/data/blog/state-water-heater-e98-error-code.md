## State Water Heater E98 Error Code — What It Means

The E98 error code is not defined in publicly available State Water Heaters documentation. Unlike common codes such as E01 (ignition failure) or E05 (sensor fault), E98 does not appear in standard troubleshooting guides for State models. This code may be model-specific, related to a software revision, or displayed due to a control board malfunction. Without the exact model number and corresponding service manual, it is not possible to determine the precise meaning or required repair procedure.

## Common Causes

- **Model-specific code** E98 may only exist on certain State models or firmware versions not covered in general documentation.
- **Control board misread** The electronic controller may display E98 due to internal memory corruption or a transient fault.
- **Undocumented sensor fault** A secondary sensor or safety switch not listed in standard manuals may trigger this code.
- **Display or wiring error** Loose wiring harness connections or a failing display can produce unfamiliar error codes.

## Step-by-Step Fix {#fix}

1. **Power cycle the unit** by switching off the circuit breaker for two minutes, then restoring power to clear transient faults.
2. **Locate the model and serial number** on the rating plate (usually on the side or front of the tank) and write down the full string.
3. **Download the model-specific manual** from the State Water Heaters support website using your model number to find the exact E98 definition.
4. **Inspect wiring connections** at the control board and all sensor plugs for corrosion, moisture, or loose terminals.
5. **Contact State technical support** at the number in your manual with the model number and E98 code for official guidance.
6. **Document the sequence** of events leading to the code (recent power outage, water temperature fluctuations, or other symptoms) to help the technician diagnose.
7. **Do not bypass safety interlocks** or attempt firmware changes without manufacturer authorization.

## When to Call a Pro

Call a licensed plumber or State-authorized service technician immediately if you cannot locate your model's manual or if the E98 code persists after a power cycle. Because this code is not documented in standard references, professional diagnostic equipment and direct manufacturer support are necessary to avoid misdiagnosis or unsafe repairs. A technician can also verify whether a control board replacement is covered under warranty and make sure any gas or high-voltage work meets local code.
