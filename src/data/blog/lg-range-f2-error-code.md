## LG Range F2 Error Code — What It Means

The F2 error code on LG ranges and ovens signals a thermistor error. The main control board has detected an abnormal signal from the oven temperature sensor circuit. This means the sensor is reading as open, shorted, out of acceptable range, or intermittently disconnected. LG officially lists Code 2 as a thermistor error in its support documentation, and technicians treat it as an oven temperature sensor circuit fault that prevents accurate oven temperature regulation.

## Common Causes

- **Failed oven temperature sensor** The thermistor itself has drifted out of spec or failed internally, sending an invalid resistance signal to the control board.
- **Loose or damaged wiring harness** Connector pins, crimps, or wire insulation between the sensor and main control have corroded, loosened, or suffered heat damage.
- **Intermittent connector issue** Poor termination or a loose plug at the sensor mounting location creates an on-and-off open circuit that triggers the code.
- **Main control board input fault** The sensor input circuit on the control board has failed even though the sensor and harness test within normal limits.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker or unplug the range completely before beginning any diagnostic work.
2. **Reset the control** by restoring power and observing whether the F2 code returns immediately or during the next preheat cycle.
3. **Access the oven temperature sensor** by removing the rear panel or the oven cavity cover, then disconnect the two-wire sensor connector.
4. **Measure sensor resistance** at room temperature with a multimeter set to ohms and compare the reading to the resistance table in your model's service manual.
5. **Inspect the harness and connectors** for corrosion, heat discoloration, loose pins, or physical damage along the entire run from sensor to control board.
6. **Replace the oven temperature sensor** if resistance is out of specification, reads open or shorted, or fluctuates when the leads are wiggled.
7. **Replace the main control board** if the sensor measures correctly, all wiring shows good continuity and secure connections, but the F2 code persists after reassembly.

## When to Call a Pro

Call a qualified appliance technician if you are uncomfortable working with live voltage or accessing internal oven components. Professional diagnosis is also recommended if you have replaced the oven temperature sensor and verified all wiring continuity but the F2 code continues to appear, since control board replacement requires correct part matching and often involves transferring overlay panels or recalibrating oven settings. If your range is still under warranty, contact LG or an authorized service center before purchasing parts.
