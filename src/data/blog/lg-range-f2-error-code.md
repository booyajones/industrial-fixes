## LG Range F2 Error Code — What It Means

On an LG range or oven, the F2 error code indicates a thermistor error. The control system is detecting an out-of-range or invalid signal from the oven temperature sensor, so it cannot trust the cavity temperature feedback. The range will typically shut down the oven function to prevent overheating or unsafe operation.

The code points to a problem in the temperature-sensing circuit: the sensor itself, the wiring harness or connector between the sensor and the main control board, or a fault in the control board's sensor-input circuitry. A simple power reset clears the code temporarily if it was a transient glitch, but if F2 returns immediately or during the next bake cycle, a component has failed.

## Before You Replace Anything

Many people replace the main control board first because the display shows the error, but a loose connector or a failed $20 sensor causes F2 far more often. Always test the sensor resistance and inspect the harness before ordering a control board.

## Common Causes

- **Failed oven temperature sensor (thermistor) (~60%)** The sensor probe has drifted out of calibration, developed an open circuit, or shorted internally so the control board sees an impossible resistance value.
- **Loose or damaged sensor connector (~20%)** The plug at the sensor or at the control board has backed out, corroded, or has a broken or heat-damaged pin.
- **Pinched or broken sensor harness wire (~10%)** The wire from the sensor to the control board is cut, pinched behind the oven cavity, or has cracked insulation causing an intermittent short.
- **Main control board sensor-circuit fault (~10%)** The board's analog-to-digital converter or pull-up resistor for the sensor input has failed, even though the sensor itself is good.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker and unplug the range if possible to make sure a safe work area.
2. **Press the range Power ON/OFF button** and wait a moment, then restore breaker power. If the F2 code clears and does not return, monitor the oven for a few uses.
3. **Access the oven temperature sensor** by removing the oven racks and the rear panel inside the oven cavity (typically two screws). The sensor is a metal probe that extends into the oven.
4. **Inspect the sensor connector and harness** at the back of the cavity. Look for loose plugs, corroded terminals, pinched wires, or heat damage. Reseat any loose connectors.
5. **Test the sensor resistance** with a multimeter set to ohms. Disconnect the sensor plug, measure across the sensor terminals, and compare the reading to your model's specification (consult the service manual or wiring diagram if available).
6. **Replace the oven temperature sensor** if it reads open (infinite resistance), shorted (near zero), or significantly out of range. Install the new sensor and reconnect the harness.
7. **Restore power and test** the oven. Run a bake cycle and verify that F2 does not return. If the code persists after sensor and wiring are confirmed good, replace the main control board.

## When to Call a Pro

Call a professional appliance technician if you are not comfortable working with multimeters, accessing the back of the oven cavity, or identifying wire harnesses. Also call if you have replaced the sensor and verified the wiring but the F2 code still appears, because the main control board will need to be diagnosed and swapped. A technician can confirm the exact sensor specification for your model, isolate intermittent wiring faults, and flash or replace the control board safely. If your range is still under warranty, contact LG service before opening the unit so you do not void coverage.

**Rough cost:** DIY runs about $15-40 for sensor, 20-40 min. A pro service call runs about $120-250 including service call and sensor.
