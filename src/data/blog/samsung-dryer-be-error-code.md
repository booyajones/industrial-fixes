## Samsung Dryer bE Error Code — What It Means

The bE error code on a Samsung dryer indicates the control panel is detecting a stuck, jammed, or continuously pressed button on the user interface. Samsung groups bE, bE2, bC2, 6E, 6E2, and 6C2 together as jammed button errors that appear when a console button is physically stuck or being read as held down. This is not a heating, airflow, door, thermistor, or vent fault. The code means a button on the control panel is being read as pressed all the time, usually because the button is physically stuck, moisture has infiltrated the keypad, the user interface is damaged, or the main control board is misreading the button input.

## Common Causes

- **Physically stuck button** A button on the console is jammed, mushy, or not springing back to its normal position after being pressed.
- **Moisture or residue on keypad** Water, detergent, or other liquid has seeped around the buttons and is causing false input signals.
- **Damaged user interface assembly** The keypad membrane or button contacts are cracked, worn, or physically damaged.
- **Control board misreading input** The main control board is registering a continuous button press even when the keypad hardware is intact.

## Step-by-Step Fix {#fix}

1. **Disconnect power** to the dryer by unplugging it or switching off the circuit breaker and wait at least 60 seconds before restoring power to reset the control board.
2. **Press and release each button** on the control panel individually, including the edges, to identify any button that feels stuck, slow to return, or different from the others.
3. **Inspect the console area** for visible moisture, spills, residue, cracks, or physical damage around the buttons and wipe the surface dry if needed.
4. **Power the dryer back on** and check if the bE code clears or returns immediately.
5. **Verify the dryer is on its own dedicated circuit** and confirm the power cord is installed properly with correct voltage supplied (especially for electric models).
6. **Replace the user interface or keypad assembly** if a button is visibly damaged, does not spring back normally, or the code returns after reset and cleaning.
7. **Contact Samsung service or a qualified technician** if the code persists after replacing the user interface, since the main control board may be misreading button input.

## When to Call a Pro

Call a professional if the bE code returns immediately after a power reset and you cannot identify a stuck or damaged button, if you are uncomfortable disassembling the console to access the user interface, or if replacing the keypad does not clear the fault. Technicians have the tools and model-specific diagrams to test the main control board and diagnose electrical faults between the keypad and board. Samsung also directs service through its authorized support channels when button damage is confirmed.
