## State Water Heater E143 Error Code — What It Means

The E143 error code is not confirmed in State's official troubleshooting documentation available across their product line. State water heaters use model-specific error code tables, and the meaning of E143 depends entirely on your unit's exact model and serial number. State directs technicians to scan the QR code on the rating plate to pull up the correct manual and fault code list for that specific heater. Without that model-specific manual, you cannot reliably diagnose what E143 means, which component has failed, or which repair procedure to follow.

[Jump to Fix](#fix)

## Common Causes

- **Model-specific fault definition** E143 may represent different faults on different State models, so the code table in your unit's manual is the only reliable source.
- **Missing or outdated documentation** If you are working from a generic guide or an older manual, the E143 code may not appear at all.
- **Control board or sensor mismatch** Some error codes only appear on specific control-board revisions or after software updates.
- **Incorrect model lookup** Using the wrong model number or a manual for a similar but different heater will give you the wrong fault list.

## Step-by-Step Fix {#fix}

1. **Locate the rating plate** on your State water heater and write down the complete model number and serial number.
2. **Scan the QR code** on the rating plate with your phone to open the State support page for that exact unit.
3. **Download the service manual** or view the error code table linked from the QR scan results.
4. **Look up E143** in the model-specific fault table to see the component, condition, or sensor involved.
5. **Run the diagnostic steps** listed in the manual for E143 before ordering or replacing any parts.
6. **Replace the component** named in the manual using the part number and installation instructions provided by State.
7. **Clear the error** using the reset procedure in your manual and verify normal operation through a full heating cycle.

## When to Call a Pro

Call a licensed plumber or water heater technician if you cannot find the model-specific manual through the QR code, if the E143 definition in your manual points to a gas valve or sealed combustion component, or if you are uncomfortable working with gas lines or electrical control boards. Because E143 is not documented in general State literature, a technician with access to State's service portal can pull the exact fault definition and parts list for your heater and complete the repair safely.
