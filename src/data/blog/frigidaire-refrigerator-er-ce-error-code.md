## Frigidaire Er CE Error Code — What It Means

The Er CE (or SY CE) error code indicates a communication failure between the refrigerator's main control board and the user interface or display board. The two boards exchange data over a wiring harness, and on many models that harness runs through the door hinge area where repeated opening and closing can stress the wires. This code does not point to a temperature, defrost, or sealed-system problem. It signals an electronics, wiring, or connector issue in the control loop.

Because the same communication path often feeds the ice maker and water dispenser controls, you may also lose those functions when Er CE appears. The code can be triggered by a physical problem like a loose plug or corroded pin, or by a failed board. On some models a temporary software lockup can set the code, and a full power reset will clear it if no hardware fault exists.

## Before You Replace Anything

Many people replace the main control board first when they see a control error code. Before ordering a board, unplug the refrigerator and inspect every connector at both the display panel and the main board for corrosion, moisture, or loose pins, and flex the door harness gently while checking for intermittent breaks.

## Common Causes

- **Loose, oxidized, or moisture-contaminated connector (~35%)** Humidity or minor leaks cause corrosion on the pins at the display board or main control board, breaking the data link.
- **Broken or intermittent wire in the door harness (~30%)** Repeated door movement fatigues the conductors inside the flex harness where it passes through the hinge or upper door area.
- **Failed user interface or display board (~20%)** The front control panel board stops communicating after a component failure or voltage spike.
- **Failed main control board (~10%)** The main board loses the ability to send or receive data on the communication circuit due to board-level component failure.
- **Software or firmware lockup (~5%)** A transient glitch or power event causes the control software to hang, setting the code until the unit is power-cycled.

## Step-by-Step Fix {#fix}

1. **Unplug the refrigerator** and wait five minutes to allow the control boards to reset completely and discharge any residual power.
2. **Plug the unit back in** and check whether the Er CE code reappears immediately. If it does not return, monitor the refrigerator for 24 hours to see if the fault was transient.
3. **Remove the screws** securing the user interface or display panel and carefully pull the panel forward to access the wiring connector on the back of the board.
4. **Inspect the connector pins and socket** for corrosion (green or white powder), moisture, or loose fit. Spray electronics contact cleaner on the pins, wipe dry, and reseat the connector firmly.
5. **Open the rear or top access panel** to reach the main control board. Inspect its harness connector for the same signs of damage, clean if needed, and reseat.
6. **Trace the wiring harness** from the main board through the cabinet and into the door hinge or upper door area. Gently flex the harness while watching the display or listening for relay clicks that indicate an intermittent open.
7. **Test continuity** on each wire in the harness using a multimeter if you can access both ends. An open or high-resistance reading on any communication wire confirms a break.
8. **Check supply voltages** at the main board connector if you have the model-specific pinout. For example, on model PRMC2285AF the main board should output 12 V DC and 5 V DC on specific pins. If those voltages are present but communication is absent, suspect the harness or the UI board.
9. **Replace the failed component** once isolated: the door harness if you found a break or intermittent connection, the user interface board if the harness and main board test good, or the main control board if supply voltages are missing or incorrect.

## When to Call a Pro

Call a professional if you are not comfortable working with control boards and wiring harnesses, or if you have tested connectors and continuity without finding an obvious fault. A technician has the model-specific wiring diagram, voltage specifications, and board-level diagnostic tools to isolate the failure quickly. Also call for service if the refrigerator is still under warranty, because opening panels or replacing boards yourself may void coverage. If you have already replaced one board and the code persists, a tech can verify that the harness and remaining board are functioning correctly before you spend more money.

**Rough cost:** DIY runs about $80–250 in parts, 1–2 hours. A pro service call runs about $200–400.
