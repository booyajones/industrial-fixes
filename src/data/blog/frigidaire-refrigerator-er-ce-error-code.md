## Frigidaire Refrigerator Er CE Error Code — What It Means

Er CE means Error Communication. The main control board and the user interface board cannot exchange data, so the display and controls may freeze or behave oddly.

Cooling can keep running, but settings and the dispenser may not respond. The cause is usually a loose harness between the boards, a damaged connector, or a failed board.

[Jump to Fix](#fix)

## Common Causes

- **Power up glitch** A surge or outage can leave the two boards unable to sync until reset.
- **Loose harness** The cable between the user interface and main board can vibrate loose.
- **Damaged connector** Bent pins or corrosion at the plug break the data link.
- **Failed user interface board** The door display board can stop talking to the main board.
- **Failed main control board** The main board can lose its side of the communication link.

## Step-by-Step Fix {#fix}

1. Unplug the refrigerator for a few minutes to power cycle the boards.
2. Plug it back in and check whether the controls respond normally.
3. If the code stays, pull the unit out and open the rear access panel.
4. Reseat the harness at both the main board and the user interface board.
5. Inspect the connectors for bent pins, corrosion, or loose fit.
6. Replace the user interface board if the wiring is sound and the fault stays.
7. Replace the main control board if a new interface board does not clear it.

## When to Call a Pro

If a power cycle and reseated wiring do not clear Er CE, the next step is finding which board failed. A technician can test the boards so you replace only the faulty one.
