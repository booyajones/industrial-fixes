## Senville EH C3 Error Code — What It Means

The EH C3 error code on Senville mini split systems indicates an indoor unit sensor out of range fault, specifically tied to the refrigerant sensor. According to Senville's support documentation for AURA-series units, this code triggers when the refrigerant sensor (TS05-N10) is reading values outside the normal operating range. The system halts normal operation to protect the compressor and other components from operating with faulty temperature data.

[Jump to Fix](#fix)

## Common Causes

- **Failed refrigerant sensor element** The TS05-N10 sensor itself has degraded or failed internally and no longer provides accurate readings to the control board.
- **Damaged sensor wiring or connector** Wiring between the sensor and the indoor board is cut, pinched, corroded, or the connector has worked loose during installation or service.
- **Moisture or corrosion at sensor terminals** Water infiltration or condensation has corroded the sensor pins or connector contacts, causing intermittent or out-of-range signals.
- **Control board reading fault** The indoor control board has a fault in the sensor input circuit, though this is less common than sensor failure.

## Step-by-Step Fix {#fix}

1. **Power off the system** at the breaker and wait two minutes to clear any transient faults, then restore power and check if the EH C3 code reappears.
2. **Locate the refrigerant sensor** (TS05-N10) on the indoor unit, typically clipped or secured to the refrigerant line near the evaporator coil.
3. **Inspect the sensor wiring and connector** for visible damage, corrosion, loose pins, or pinched wires, and reseat the connector firmly into the control board.
4. **Check for moisture** around the sensor and connector, and dry thoroughly if any condensation or water is present.
5. **Replace the refrigerant sensor** (TS05-N10) if the wiring and connector are intact but the fault persists, following manufacturer wire color codes and securing the new sensor to the same location.
6. **Clear the error code** by cycling power off and on, then run the system in cooling mode for 15 minutes to verify normal operation.
7. **Document the repair** and monitor the system for 24 hours to confirm the code does not return.

## When to Call a Pro

Call a licensed HVAC technician if you are uncomfortable working inside the indoor unit, if the error returns immediately after replacing the sensor, or if you do not have the tools to safely access the refrigerant line area. Technicians can also verify refrigerant charge and system operation with calibrated gauges after sensor replacement, which is important if the out-of-range reading was caused by an actual refrigerant issue rather than sensor failure. If the control board itself is suspected, a tech can test the sensor input circuit and replace the board under warranty if applicable.
