## State Water Heater E68 Error Code — What It Means

The E68 error code does not appear in available State water heater manufacturer documentation, so its exact meaning cannot be verified for your unit. State produces both tank-style and heat-pump hybrid electric models with built-in diagnostics, but E68 is not listed in the standard fault tables provided by the manufacturer. Some non-State appliances use E68 to indicate a shorted heating element, but that definition has not been confirmed for State water heaters and should not be assumed without checking your specific model's service literature.

Because State and A. O. Smith share platforms, the most common fault patterns on these units involve air-intake blockages, venting obstructions, clogged filters, and flame or ignition sensor issues. If your display shows E68, start by inspecting the air intake and exhaust path for debris, then consult your model number and rating plate to identify the correct diagnostic guide.

## Common Causes

- **Blocked air intake or exhaust vent** Lint, dust, nests, or other debris can obstruct airflow and trigger fault codes on State tankless and heat-pump models.
- **Clogged inlet water filter or flow sensor** Scale buildup or sediment can reduce water flow below the minimum threshold and cause the control board to fault.
- **Failed heating element or sensor (unconfirmed for E68)** A shorted element or high-limit sensor may generate error codes, but this has not been verified as the E68 definition for State.
- **Control board misread or corrupted memory** Power surges or voltage sags can cause the board to display codes that do not match the actual fault condition.
- **Incorrect model documentation lookup** State offers multiple product lines with different code sets, so the code may be valid only on a specific platform or vintage.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker and close the cold-water inlet valve to make the unit safe for inspection.
2. **Write down your complete model and serial number** from the rating plate so you can request the correct service manual or tech-support guidance.
3. **Inspect the air intake screens and exhaust vent termination** for any blockages, remove covers, and clear away lint, spider webs, or other debris.
4. **Check the inlet water filter** if your model has one, rinse it under running water, and look for scale or sediment in the filter housing.
5. **Restore power and water, then reset the unit** by cycling the breaker or pressing the reset button on the control panel and watch for the code to clear.
6. **Photograph the error display and any blinking LED patterns** because State's built-in diagnostics often use both alphanumeric codes and light sequences together.
7. **Contact State customer support or a licensed technician** with your model number and photos if the E68 persists, since the code is not defined in standard public literature.

## When to Call a Pro

Call a licensed plumber or water-heater technician if the E68 code reappears after you have cleared the air intake and inlet filter, or if you cannot locate an E68 definition in your owner's manual. Because this code is not documented in State's widely available service literature, a technician will need to consult factory diagnostic software or contact State technical support directly to identify the exact fault and the correct sensor or component involved. Do not replace the control board or any heating elements until a professional has verified the failure with meter readings and confirmed that E68 applies to your specific model platform.
