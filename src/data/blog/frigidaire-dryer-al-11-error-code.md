## Frigidaire Dryer AL-11 Error — What It Means

The AL-11 code is not clearly documented in official Frigidaire dryer materials, but it closely resembles the E11/E12 fault family, which indicates an electronic control board communication problem. This means the main control board has lost communication with another component or is experiencing an internal failure. The dryer will not run until the fault is cleared.

[Jump to Fix](#fix)

## Common Causes

- **Temporary control glitch after power interruption** A brief power surge or outage can cause the control board to lose synchronization and throw a communication fault code.
- **Failed electronic control board** The main control board itself may have failed internally, preventing proper communication with other dryer components.
- **Intermittent board failure** The control board may be failing intermittently due to heat stress or component degradation, causing the code to appear sporadically.
- **Loose or corroded wiring connector** A wire harness connection between the control board and another component may be loose, corroded, or damaged, disrupting communication signals.

## Step-by-Step Fix {#fix}

1. **Turn off the dryer** and unplug it from the wall outlet, or shut off the circuit breaker (for gas models, also close the gas shutoff valve before working).
2. **Wait three minutes**, then restore power to reset the electronic control board and clear any transient faults from memory.
3. **Run a test cycle** to see if the AL-11 code reappears during normal operation.
4. **If the code clears and does not return**, the issue was likely a temporary glitch and no further repair is needed.
5. **If the code returns immediately or during the cycle**, remove power again and inspect all wire harness connectors at the control board for looseness or corrosion, then reseat them firmly.
6. **Replace the electronic control board** if the code persists after connector inspection, following the instructions in your model's service manual.
7. **Check your model's tech sheet** (often found inside the console or drum) to confirm the exact meaning of AL-11 for your specific dryer model before ordering parts.

## When to Call a Pro

If you are uncomfortable working with live 240-volt circuits or removing the dryer console to access the control board, call a qualified appliance technician. Also contact a professional if the code persists after you have replaced the control board, as that may indicate a wiring fault elsewhere in the machine or a misdiagnosis of the original code. Because AL-11 is not documented in standard Frigidaire dryer code lists, a technician with access to your model's service sheet can verify the exact fault definition and rule out other failure modes before you invest in parts.
