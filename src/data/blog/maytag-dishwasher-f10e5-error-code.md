## Maytag Dishwasher F10E5 Error Code — What It Means

The F10E5 (also shown as FAE5) error code appears after your Maytag dishwasher completes a cycle, drains, and then stops. Maytag confirms the cycle ends normally in terms of draining, but the control detects a fault condition and displays this code. The manufacturer does not publicly document the specific internal sensor or input that triggers F10E5, so the exact root cause varies by model. In service practice on Whirlpool-family dishwashers (which include Maytag), recurring cycle-completion faults like this one are typically traced to door-latch signaling problems, control or user-interface communication issues, wiring connector faults, or intermittent sensor inputs. Because Maytag's published guidance is limited to the reset procedure, deeper diagnosis requires the model-specific tech sheet and diagnostic mode.

## Before You Replace Anything

Many people replace the main control board first without testing the door latch and harness connectors. Check the door-switch resistance and reseat all connectors before ordering the control.

## Common Causes

- **Door latch or door-switch fault (~35%)** The door-latch assembly includes a microswitch that signals the control when the door is securely closed, and intermittent contact or a worn latch can send a false open signal at the end of the cycle.
- **Loose or corroded wiring connector (~25%)** Harness connectors at the door, control board, or user interface can develop intermittent contact from vibration or moisture, triggering a communication or input fault code.
- **Main control board logic or memory fault (~20%)** The main control can log a cycle-completion error if its firmware detects an unexpected input state or fails to receive an expected end-of-cycle signal from a sensor.
- **User-interface or console communication error (~15%)** The touchpad console communicates with the main control over a ribbon cable or harness, and a corrupted message or loose connection can cause the control to abort and display an error.
- **Model-specific sensor fault (~5%)** Some models use additional sensors (turbidity, temperature, or float) that must report valid data at cycle end, and an out-of-range reading can trigger a non-specific fault code.

## Step-by-Step Fix {#fix}

1. **Press Cancel twice** on the dishwasher control panel to clear the F10E5 code and reset the control, as recommended by Maytag.
2. **Start a new wash cycle** and observe whether the error reappears at the end of the cycle or immediately upon start.
3. **Inspect the door-latch assembly** for broken plastic, a loose striker, or a visibly worn microswitch, and test that the door clicks firmly into the closed position.
4. **Unplug the dishwasher** (or turn off the breaker), remove the inner door panel, and reseat every harness connector at the door-latch assembly, the main control board, and the user interface.
5. **Check the door-switch contacts** with a multimeter (consult your model's wiring diagram for the correct terminals) to verify continuity when the door is latched and open circuit when unlatched.
6. **Enter diagnostic mode** if your model supports it (the key sequence is in the tech sheet) and run any door or UI communication tests to isolate the fault path.
7. **Replace the faulty component** (door latch, main control board, or user interface) based on your test results, reassemble the door panel, restore power, and run a full cycle to confirm the repair.

## When to Call a Pro

Call a professional if the F10E5 error returns after you have reset the dishwasher and reseated all connectors, or if you are not comfortable removing the door panel and testing door-switch continuity with a multimeter. A technician has the model-specific service sheet, diagnostic mode key sequences, and voltage or resistance tables needed to isolate intermittent faults in the control or sensor network. Also call if you have already replaced the door latch and the error persists, since that points to the main control board or a wiring fault that requires tracing harness continuity across multiple connectors. Professional diagnosis typically costs less than replacing the control board by guess, and the technician can confirm the exact part before you buy it.

**Rough cost:** DIY runs about $50–150 in parts, 30–90 min. A pro service call runs about $150–350.
