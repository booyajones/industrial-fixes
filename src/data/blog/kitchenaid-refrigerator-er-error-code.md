## KitchenAid ER Error Code — What It Means

The ER error code on your KitchenAid refrigerator indicates a communication failure between electronic control boards in the system. This means the user interface cannot correctly exchange data with the main control board or another connected module. It is not a sensor fault or component failure like thermistor codes (E3) or dispenser EEPROM faults (E6). Instead, the appliance has detected a loss of communication somewhere in the control network.

## Common Causes

- **Loose or damaged wiring connectors** The most common cause is poor contact, backed-out terminals, or corrosion in the harness between the UI and main control board.
- **Failed main control board** If the main control board cannot send or receive signals, the communication link fails and triggers ER.
- **Failed user interface (UI) board** A defective UI control or dispenser board on the communication side can prevent data exchange with the main board.
- **Moisture intrusion or harness oxidation** Water exposure or corrosion in connectors can create intermittent or permanent communication loss between boards.
- **Power interruption leaving boards in inconsistent state** Although KitchenAid codes power events separately as PO, an unstable power event can disrupt board communication and trigger ER.

## Step-by-Step Fix {#fix}

1. **Enter service diagnostics** by pressing SW1 and SW2 simultaneously for three seconds until you hear a chime (unit must not be in lockout mode).
2. **Read the error history** by pressing SW3 to toggle through stored error codes on the display and confirm that ER is active.
3. **Inspect all wiring harnesses and connectors** between the user interface and main control board for loose pins, backed-out terminals, corrosion, or physical damage, then reseat and secure any suspect connections.
4. **Clear the fault** by disconnecting power for one minute, then restore power and re-enter diagnostics to see if ER returns, which indicates whether the fault is intermittent or persistent.
5. **Replace the main control board** if wiring and connectors are intact and the error persists, as the main board may not be responding to communication requests.
6. **Replace the UI control board** if the main board tests good and communication still fails, since the display-side electronics may be defective.
7. **Exit diagnostics and restore normal operation** by pressing SW1 and SW2 for three seconds, disconnecting power briefly, or waiting twenty minutes for automatic exit.

## When to Call a Pro

Call a qualified appliance technician if you are uncomfortable working with live electronic controls or if you have inspected and reseated all wiring connectors but the ER code returns immediately after clearing. Board-level diagnosis requires entering service mode and isolating which side of the communication link has failed. A trained technician has the correct replacement boards for your model and can verify proper communication once repairs are complete.
