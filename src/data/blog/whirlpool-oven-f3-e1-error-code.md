## Whirlpool Oven F3 E1 Error Code — What It Means

The F3 E1 error code on a Whirlpool oven or range indicates the electronic control has detected a problem with the oven temperature sensor, its wiring, or the control board itself. The sensor is a probe mounted inside the oven cavity that monitors baking temperature. When the sensor resistance drifts out of range, the probe fails open or shorted, or the wiring connection is interrupted, the control can no longer regulate heat safely and throws this fault.

Whirlpool's product help directs you to reset power at the breaker and, if the code returns, investigate the sensor, wiring harness, and control board in that order. The error prevents normal baking operation until the fault is resolved.

## Before You Replace Anything

Many people replace the control board when the real culprit is a bad sensor or corroded connector. Always measure sensor resistance (should read about 1100 ohms at room temperature) and inspect the wiring before ordering a new board.

## Common Causes

- **Failed oven temperature sensor (~60%)** The sensor probe has drifted out of specification, failed open, or shorted internally, causing the control to detect an invalid resistance value.
- **Loose, damaged, or corroded sensor wiring or connectors (~25%)** The harness between the sensor and control board is pinched, burned, or has corroded terminals that create intermittent or open circuits.
- **Faulty electronic control board (~10%)** The control board's sensor input circuit has failed even though the sensor and wiring test normal.
- **Poor sensor grounding or mounting (~5%)** The sensor is not making proper contact with the oven cavity or has corroded mounting hardware that affects the reading.

## Step-by-Step Fix {#fix}

1. **Turn off power at the circuit breaker** to the oven and wait one minute, then restore power to reset the control and see if the code returns during idle operation.
2. **Unplug the range or kill power again**, then pull the oven away from the wall (for slide-in models) or remove the back panel (for wall ovens) to access the rear cavity where the sensor mounts.
3. **Locate the oven temperature sensor**, a metal probe extending into the oven cavity, and trace its wiring back to the connector on the control board or junction block.
4. **Inspect the sensor wiring and connector** for burns, pinched insulation, corrosion on the terminals, or loose pins, and clean or reseat the connector if needed.
5. **Disconnect the sensor leads and measure resistance with a multimeter** set to ohms. At room temperature the sensor should read about 1100 ohms. A reading near zero, infinite, or far outside that range means the sensor has failed.
6. **If the sensor tests bad, remove the mounting screw** (usually inside the oven cavity) and pull the old sensor out through the back wall, then slide the new sensor into place and reconnect the leads.
7. **Restore power and run a test bake cycle for about 10 minutes** at 350°F. If the F3 E1 code does not return and the oven heats normally, the repair is complete. If the code persists with a known-good sensor and wiring, replace the electronic control board.

## When to Call a Pro

Call a professional if you are uncomfortable working around 240-volt appliance wiring, if the oven is built into cabinetry that requires extensive disassembly to access the back, or if you have replaced both the sensor and control board and the F3 E1 code still returns. A technician can trace the wiring harness end to end, check for hidden shorts inside the oven cavity, and verify that the new parts were installed correctly. Also call a pro if your range uses gas and you need to move it away from the wall, since disconnecting and reconnecting the gas supply requires proper fittings and a leak test.

**Rough cost:** DIY runs about $20-50 for sensor, 30-60 minutes. A pro service call runs about $150-250 service call including sensor.
