## Kenmore Dryer F01 Error Code — What It Means

F01 on a Kenmore dryer signals that the electronic machine control board has failed. This code appears on Kenmore dryers built on Whirlpool-style platforms and indicates the board itself can no longer manage dryer operations. The fault can sometimes appear after a power surge or electrical glitch, but if the code returns after a reset, the control board is the failed component.

[Jump to Fix](#fix)

## Common Causes

- **Failed main control board** The electronic control board itself has experienced internal relay or solder-joint failure and can no longer regulate dryer functions.
- **Power surge or line glitch** A transient electrical event through the home's power lines can damage or disrupt the control board and trigger the fault.
- **Loose main power or neutral connection** Poor contact at the dryer's main power input or neutral terminal can cause intermittent control-board faults that register as F01.
- **Corroded or damaged harness connectors** Burned or loose wire terminals at the board's plug-in harnesses can interrupt communication and mimic a board failure.

## Step-by-Step Fix {#fix}

1. **Disconnect power** by unplugging the dryer or switching off the circuit breaker before accessing any internal parts.
2. **Reset the control** by leaving the dryer unplugged for at least five minutes, then restore power and check if the F01 code clears.
3. **Remove the dryer's top or rear access panel** (consult your model's service manual) to expose the main control board and wire harnesses.
4. **Inspect all harness connectors** at the control board for loose, burned, or corroded terminals and reseat each plug firmly.
5. **Check the main power connection and neutral wire** at the terminal block inside the dryer for tightness and signs of damage.
6. **Replace the main control board** if the F01 code returns after reset and all connectors and power connections are secure.
7. **Reassemble the dryer and run a short test cycle** to confirm the code is cleared and the machine operates normally.

## When to Call a Pro

Call a technician if you are not comfortable working with live electrical connections or removing cabinet panels. Main control board replacement requires transferring multiple wire harnesses and correctly identifying your model's board revision. If the code persists after board replacement, a pro can trace upstream power-supply issues or inspect for less common faults in the wiring harness that are difficult to diagnose without a schematic and multimeter.
