## What this code means
The E68 error code indicates the control believes one of the buttons on the panel is being held down continuously when it should not be. This can be a physically stuck or sticky button, moisture on the keypad, or a fault in the user interface assembly or main control board that causes a key input to read as closed even when the button is not pressed.

On some models the fault is mechanical (a button that does not return fully), while on others the keypad membrane or the control board itself interprets the circuit incorrectly. Technicians commonly use the dryer's built-in key-test diagnostic mode to identify which button circuit is reporting a stuck signal.

## Before You Replace Anything

Many people replace the main control board first when the actual problem is a stuck or dirty button on the keypad assembly. Clean and inspect every button for free play and run a diagnostic key test before ordering any boards.

## Common Causes

- **Sticky or stuck button (~40%)** Detergent, fabric-softener residue, spills, or debris cause a button to remain depressed or not return fully to the open position.
- **Failed keypad or user-interface assembly (~25%)** The membrane switch or tact switch inside the control panel no longer opens correctly, so the button circuit stays closed.
- **Moisture on the control panel (~15%)** Water or humidity bridges the membrane contacts and makes the control read a false key press even though the button moves freely.
- **Main control board fault (~15%)** The electronic control incorrectly interprets the key circuit as closed, and some technicians report this more often than an actually stuck button on certain models.
- **Damaged wiring or connector (~5%)** A pinched or shorted wire between the keypad and control board can hold a key input low and trigger the stuck-key detection.

## Step-by-Step Fix {#fix}

1. **Disconnect power** by unplugging the dryer or switching off the circuit breaker before any inspection or disassembly.
2. **Press each button on the control panel** to check for one that is stuck, sluggish, or does not return to its normal position.
3. **Clean the control panel** with a dry cloth or a lightly dampened cloth followed by thorough drying if you see residue, spills, or moisture on the keypad.
4. **Perform a power reset** by leaving the dryer unplugged for at least five minutes, then restoring power and checking whether the E68 code returns immediately.
5. **Enter the dryer's diagnostic key-test mode** (consult your model's service manual for the button sequence) to identify which button circuit the control sees as closed.
6. **Inspect the control-panel assembly from the rear** by removing the top or front panel as required for your model, and verify that each button actuates the membrane or tact switch cleanly.
7. **Replace the failed component** (user interface panel or main control board) based on which part the key test and inspection identify as faulty, then clear the code and run a test cycle.

## When to Call a Pro

Call a technician if you are not comfortable disassembling the dryer's control-panel area, if the diagnostic key test is not available or unclear for your model, or if you have already replaced the keypad assembly and the E68 code continues to appear. A pro can run full board-level diagnostics, verify wiring continuity between the interface and control, and confirm which board is truly at fault before ordering parts. Also call if the dryer shows multiple error codes at once or if you suspect water damage inside the control cavity that requires drying and inspection of all circuit boards.

**Rough cost:** DIY runs about $50–150 for control panel or board, 30–60 min. A pro service call runs about $150–300 for service call and part replacement.
