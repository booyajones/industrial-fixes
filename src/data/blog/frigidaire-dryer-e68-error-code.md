## Frigidaire Dryer E68 Error — What It Means

E68 on a Frigidaire dryer indicates a stuck key or button fault. The main control board is detecting one button as continuously pressed, which prevents normal operation. This code appears when a button is physically jammed, when moisture or sticky residue is bridging contacts on the keypad, or when the user interface board or main control board has failed. The dryer will not run until the stuck-key condition is resolved.

## Common Causes

- **Button physically stuck** A button is jammed from wear, mechanical binding, or physical damage and does not spring back freely.
- **Moisture or residue on the control panel** Spills, humidity, or sticky buildup around the keypad cause a switch to stay closed or register as closed.
- **Faulty user interface or keypad assembly** The control panel board itself has failed and continuously signals a key press even when no button is touched.
- **Main control board misreading key input** The main control board falsely interprets the keypad signals and throws E68 even when the panel is working correctly.

## Step-by-Step Fix {#fix}

1. **Unplug the dryer** from power and inspect every button on the control panel, pushing each one to verify it springs back freely and is not stuck down.
2. **Clean the control panel** with a dry cloth or very lightly dampened cloth if you see any moisture, spills, or sticky residue, then allow the area to dry completely.
3. **Reset the dryer** by unplugging it for at least one minute, then plug it back in and check whether the E68 code clears.
4. **Enter the dryer's function test mode** (consult your model's service manual for the key sequence) and run the key test to identify which button is being reported as stuck.
5. **Remove the console panel** to inspect the back of the control panel assembly for visible damage, corrosion, or moisture if a specific button is flagged or if buttons feel normal but the code persists.
6. **Replace the user interface or control panel assembly** if a button is defective or the key test confirms a panel fault (verify the correct part number for your model).
7. **Replace the main control board** if the control panel tests normal in key-test mode but E68 returns during operation, indicating the main board is falsely reading a stuck key.

## When to Call a Pro

Call a qualified appliance technician if you are not comfortable removing the console or working with control boards, if the fault persists after cleaning and resetting, or if you cannot access function-test mode to diagnose which component is at fault. A tech can run the key test, isolate whether the user interface or main control board is defective, and install the correct model-specific replacement without risking damage to live circuitry or voiding your warranty.
