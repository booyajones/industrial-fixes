## LG Dishwasher Won't Start — What's Happening

When an LG dishwasher won't start, it means the machine is failing a basic start condition and cannot begin a wash cycle. If no error code appears on the display, the unit is typically blocked by power supply issues, control or child lock activation, a door that isn't fully latched, a closed water supply valve, or a failed internal component like the door switch or control board. If the display shows an IE code, the dishwasher detected insufficient water during the fill window and points to a water supply restriction, kinked inlet hose, clogged inlet filter, or low household pressure below 20 PSI. If an OE code is present, the unit has a drain blockage that can also prevent the cycle from starting normally.

## Most Likely Causes

- **Control lock or child lock enabled** The control panel is locked or delayed start is active, blocking any immediate start command until the lock or delay is cleared.
- **Door not fully latched or failed door switch** The door is not closing completely or the door latch assembly or door switch has failed, so the control never sees a valid closed-door signal.
- **No power at the dishwasher** The circuit breaker is tripped, the under-sink switch is off, the outlet is dead, or the power cord connection inside the unit is loose or corroded.
- **Water supply valve closed or inlet filter clogged** The shutoff valve under the sink is closed, the inlet hose is kinked or pinched, or the inlet screen filter is blocked with sediment, preventing water from reaching the unit.
- **Faulty water inlet valve** The inlet valve solenoid is electrically open, shorted, or mechanically stuck closed and does not open when the control sends voltage.
- **Failed main control board or user interface** The main control board or user interface panel has failed and does not process the start button press or send power to the inlet valve and other loads.
- **Thermal fuse or noise filter failure** The thermal fuse on the control circuit or the noise filter assembly has opened, cutting all power to the control and leaving the dishwasher completely dead or nonresponsive.

## How to Diagnose and Fix {#fix}

1. Check the control panel for any lock icon or delay indicator and press and hold the lock button (often labeled Child Lock or marked with a padlock icon) for three to five seconds to disable control lock or cancel any delayed start.
2. Verify the circuit breaker serving the dishwasher is on, the under-sink switch (if present) is in the on position, and the outlet has live voltage using a non-contact tester or multimeter.
3. Open and close the door firmly to confirm it latches fully, then inspect the door latch mechanism and use a multimeter to test the door switch for continuity change when the latch engages, replacing the latch assembly if the switch remains open.
4. Locate the water shutoff valve under the sink and confirm it is fully open, then disconnect the inlet hose at the dishwasher and inspect the inlet screen filter for debris, flushing or replacing it if clogged.
5. Check household water pressure at a nearby faucet to confirm it is above 20 PSI and inspect the inlet hose for kinks or pinches along its entire run from valve to dishwasher.
6. If an IE code appears and water supply is confirmed good, test the water inlet valve for correct coil resistance (typically 500 to 1500 ohms per coil depending on model) and listen for a click or hum when the cycle starts, replacing the valve if it does not energize.
7. If an OE code is displayed, disconnect the drain hose and check for blockages in the hose, at the sink tailpiece connection, or in the garbage disposer knockout plug if the disposer was recently installed.
8. If power, door, and water are all confirmed correct and no error code is shown, access the control area and test the thermal fuse and noise filter for continuity, then inspect the main control board and user interface connectors for secure seating and signs of burn or corrosion before replacing the control board.

## When to Call a Pro

Call a professional if you are uncomfortable working with live 120-volt wiring, if the door latch and inlet valve both test good but the machine still will not start, or if you need to diagnose and replace the main control board or user interface. A qualified appliance technician has the model-specific wiring diagrams, signal-tracing tools, and replacement board inventory to isolate control failures quickly and restore operation safely.
