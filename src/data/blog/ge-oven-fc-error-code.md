## GE Oven FC Error Code — What It Means

The FC code on a GE range or wall oven indicates a failure somewhere in the door-lock circuit. GE's fault-code guide defines FC as a component failure in that circuit, which includes the lock motor or latch assembly, door-lock switch logic, wiring, or the electronic control that monitors the lock. The code typically appears after a self-clean cycle or when the latch becomes stuck or damaged.

In some cases the code is caused by a temporary control glitch rather than a hard failure. GE recommends cycling power at the circuit breaker first. If the code returns after a reset, service is required to replace the failed component.

## Before You Replace Anything

Homeowners sometimes replace the main control board when the door latch assembly is actually at fault. Inspect and test the latch mechanism for binding or damage before swapping the board.

## Common Causes

- **Failed or stuck door latch or lock assembly (~55%)** The latch motor jams, binds, or fails after a self-clean cycle or from mechanical wear, preventing the control from verifying lock status.
- **Wiring or connector fault in the lock circuit (~20%)** A loose, corroded, heat-damaged, or broken wire or connector interrupts the signal between the latch and the control.
- **Electronic control board fault (~15%)** The main oven control misreads lock feedback or cannot drive the latch circuit correctly, even when the latch hardware is sound.
- **Temporary control glitch (~10%)** A brief software or power anomaly sets the code without a hard failure, often cleared by a breaker reset.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker or fuse panel for at least one to two minutes to reset the electronic control.
2. **Restore power** and check whether the FC code reappears on the display.
3. **Let the oven cool completely** if it was recently in self-clean mode before attempting any inspection or manual latch release.
4. **Inspect the door latch assembly** for visible binding, misalignment, obstruction, or damage, and verify the door opens and closes smoothly.
5. **Check all wiring and connectors** in the lock circuit for looseness, heat discoloration, corrosion, or broken conductors.
6. **Test or replace the door latch assembly** if it does not actuate correctly or if its feedback is inconsistent when power is cycled.
7. **Replace the main control board** only if the latch assembly and wiring test good but the code persists, then reset power and verify operation.

## When to Call a Pro

Call a technician if you are uncomfortable working inside the oven cabinet or disconnecting high-voltage wiring. A pro should also diagnose the fault if both the latch assembly and wiring appear intact but the code persists, since isolating whether the control board or another component is at fault requires proper test equipment and experience with GE oven circuits. If the oven is still under warranty, contact GE or an authorized service center before opening the appliance.

**Rough cost:** DIY runs about $60-120 in parts, 45-90 min. A pro service call runs about $150-280.
