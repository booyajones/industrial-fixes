## GE Oven FC Error Code — What It Means

The FC error code on a GE range or wall oven indicates a fault in the door lock circuit. According to GE, this usually means that a component has failed somewhere in the door lock circuit. In practice, the control board is receiving conflicting or invalid signals from the door latch position switches. For example, the board may see both 'lock' and 'unlock' states at the same time, which triggers the FC fault.

The door lock circuit includes the door latch assembly (which houses one or more micro-switches), the wiring harness that connects the latch to the control board, and the control board itself. Any breakdown in this chain can produce the FC code. A power reset may clear the code temporarily, but if it returns, service is required to find and replace the defective component.

## Before You Replace Anything

Many people replace the control board first, assuming an electronics failure. Test the door latch switches with a multimeter and inspect the wiring harness for damage or loose connectors before ordering a new board.

## Common Causes

- **Defective latch or lock switches (~50%)** Micro-switches inside the latch assembly fail to report the correct lock or unlock state, sending conflicting signals to the control board.
- **Mechanical binding in the latch (~20%)** A stuck cam, bent hook, or debris in the latch slots prevents the switches from actuating correctly.
- **Loose, damaged, or corroded wiring (~15%)** Broken wires, damaged connector pins, or corrosion between the latch assembly and control board interrupt the signal.
- **Failed electronic control board (~15%)** If all mechanical parts and wiring test good, the board itself may have a fault in the door lock circuit logic.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker or fuse box and wait two minutes to attempt a control reset, then restore power and check if the FC code clears.
2. **Remove the oven door** (if necessary for access) and the inner door panels to expose the door latch assembly.
3. **Inspect the latch mechanism** for broken plastic, a bent or stuck latch hook, debris in the slots, or a mispositioned cam that would prevent normal switch actuation.
4. **Disconnect power again**, then use a multimeter set to continuity or resistance mode to test each latch switch. Manually move the latch through lock and unlock positions and verify that one switch closes in the lock position and the other closes in the unlock position.
5. **Check the wiring harness** between the latch assembly and the control board for broken wires, damaged or corroded connector pins, and loose connections. Repair or replace the harness if any damage is found.
6. **Replace the door latch assembly** if the switches fail the continuity test or if the mechanical parts are damaged. On some models the switches can be replaced separately if available as service parts.
7. **Replace the electronic control board** only if the latch assembly, switches, and wiring all test good but the FC code persists after reassembly and a final power reset.

## When to Call a Pro

Call a professional if you are not comfortable working with household electrical circuits, removing the oven door, or testing components with a multimeter. A qualified appliance technician has the wiring diagrams and test procedures to isolate the fault quickly and safely. Also call for service if you have replaced the latch assembly and checked all wiring but the FC code still appears, since that points to a control board fault that requires precise diagnosis to avoid wasting money on the wrong part.

**Rough cost:** DIY runs about $50–150 in parts, 45–90 min. A pro service call runs about $150–300.
