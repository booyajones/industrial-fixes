## LG Range F1 Error Code — What It Means

On LG ranges and ovens, the F1 error code indicates a thermistor-related fault. LG classifies numbered error codes 1, 2, and 3 as thermistor errors. The F1 fault specifically points to a problem with the oven temperature sensor (thermistor), which may be shorted, open, or reading out of range. LG's parts documentation describes one common scenario as the oven sensor being shorted for over one minute during cooking.

The thermistor is a temperature-sensing resistor that tells the control board the oven's current temperature. When the sensor fails, sends incorrect readings, or loses connection, the control board cannot regulate heat safely and throws the F1 code. The error can also result from damaged wiring between the sensor and the control board, or less commonly from a failed main control board itself.

## Before You Replace Anything

Many people replace the main control board first without testing the sensor. Always measure the sensor's resistance and check the harness for damage before ordering a new board, since a bad sensor or loose connector causes most F1 codes.

## Common Causes

- **Failed oven temperature sensor (thermistor) (~60%)** The sensor reads open, shorted, or drifts out of the expected resistance range, sending bad data to the control board.
- **Loose, damaged, or disconnected sensor wiring (~25%)** The harness or connector between the sensor and control board is broken, corroded, or unplugged, interrupting the signal.
- **Faulty main control board (PCB/ECM) (~10%)** When the sensor and wiring test good, the control board's sensor input circuit or relay section has failed.
- **Poor connector contact at sensor or board (~5%)** Corroded or loose pins at either end cause intermittent open or high-resistance readings that the board flags as a fault.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker or unplug the range completely before touching any internal components.
2. **Reset the range** by turning the breaker off for 30 seconds, then back on, or by unplugging the unit for a few minutes. Power back up and check if the F1 code clears.
3. **Access the oven sensor**, which is typically mounted inside the oven cavity at the back wall. Remove the oven racks and unscrew the sensor bracket if present.
4. **Inspect the sensor and harness** for loose connectors, broken wires, heat damage, or corrosion at the sensor end and at the control board plug.
5. **Measure the sensor resistance** using a multimeter set to ohms. Disconnect the sensor plug and measure across the sensor terminals. Compare the reading to your model's specification or use roughly 1.0-1.1 kΩ at room temperature as a sanity check. Replace the sensor if it reads open, shorted, or far out of range.
6. **Check harness continuity** from the sensor connector to the control board if the sensor tests good. Look for broken wires or poor pin contact in the connectors.
7. **Replace the main control board** if the sensor and wiring both test normal but the F1 code persists. After any repair, restore power, run a test bake cycle, and confirm the fault does not return.

## When to Call a Pro

Call a professional if you are uncomfortable working with 240-volt wiring, if the control board is difficult to access, or if you lack a multimeter and experience testing electrical components. A technician can quickly isolate whether the fault is in the sensor, harness, or board and has the tools to measure resistance and continuity safely. If the range is still under warranty or you need the repair documented for insurance or a landlord, a licensed service visit is the best path. For gas ranges, any work near the gas supply or burner systems should be handled by a qualified technician to avoid safety hazards.

**Rough cost:** DIY runs about $20-60 for sensor, 30-60 min; $100-250 for control board if needed. A pro service call runs about $150-300 depending on part and labor.
