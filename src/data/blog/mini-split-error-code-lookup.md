## Mini Split Error Code Lookup — Start Here

Mini split error codes vary wildly by brand, but the same themes repeat: communication loss between indoor and outdoor units, thermistor failures, drain faults, fan motor faults, and refrigerant-system protection trips. This page helps you narrow the category before you jump into the brand-specific guide.

[Jump to Fix](#fix)

## Common Mini Split Fault Patterns

| Fault Type | What It Usually Means |
|---|---|
| Communication fault | Indoor and outdoor boards not talking |
| Thermistor fault | Indoor coil, room, or outdoor sensor failed |
| Drain fault | Condensate pump or drain blocked |
| Fan fault | Indoor crossflow or outdoor fan issue |
| Compressor protection | Overcurrent, discharge temp, or pressure protection |
| Low refrigerant symptom | Sensor pattern suggesting leak or undercharge |

## Step-by-Step Fix {#fix}

1. **Read the exact code from the remote, board LED, or app**.
2. **Power cycle once only** — Repeated resets can hide intermittent faults.
3. **Check communication wiring and polarity on multi-split systems**.
4. **Inspect drains and pumps before chasing board faults**.
5. **If refrigerant work is suspected, stop and leak-check before adding charge**.

## Parts Often Needed

| Part | Notes |
|---|---|
| Thermistor | Common, relatively inexpensive failure |
| Indoor fan motor | For fan lock errors |

## When to Call a Pro

Most mini splits require manufacturer-specific service mode access to diagnose fully. If the code suggests inverter, compressor, or refrigerant faults, use a qualified ductless technician with the correct brand documentation.
