## What this code means
Maytag groups F72 through F78 as a dryer error family related to door-latch and door-switch communication faults. The manufacturer does not publish a more specific breakdown for F72 alone in its indexed product help, so the code points to a problem somewhere in the door-closure circuit for your model. The official first step is always a full power reset: kill the breaker for five minutes and restore power. If the code clears and stays gone, it was a stored glitch. If it returns after reset, the fault lies in the door switch, door latch, related wiring, or the control board that monitors that circuit.

## Before You Replace Anything

Many homeowners replace the main control board first. Test the door switch with a multimeter and inspect the latch and harness connectors before ordering any circuit board.

## Common Causes

- **Temporary control glitch or stored fault (~40%)** The control board logged an old door-circuit event that clears after a full power reset.
- **Faulty door switch (~30%)** The switch that tells the control board the door is closed has failed open or intermittent, preventing the start cycle.
- **Damaged door latch or strike (~15%)** A worn, cracked, or misaligned latch prevents the door from closing far enough to actuate the switch reliably.
- **Loose or corroded wiring harness or connector (~10%)** Backed-out terminals, heat damage, or corrosion at the door-switch or control-board connector interrupt the door-closure signal.
- **Failed main electronic control board (~5%)** The board no longer reads the door-switch circuit correctly even when the switch and wiring test good.

## Step-by-Step Fix {#fix}

1. **Kill power at the circuit breaker** and wait a full five minutes to clear any stored fault codes in the control-board memory.
2. **Restore power** and press Start to see if the dryer begins a normal cycle without the F72 code returning.
3. **Inspect the door latch and strike** for cracks, broken tabs, or wear. Close the door and listen for a firm click. Replace any damaged latch hardware.
4. **Unplug the dryer** and remove the top or front panel to access the door switch, following your model's service manual.
5. **Test the door switch** with a multimeter set to continuity. With the door closed the switch should show continuity. With the door open it should show no continuity. Replace the switch if it fails either test.
6. **Check all harness connectors** at the door switch and at the main control board for backed-out pins, heat marks, or corrosion. Clean and reseat each connector.
7. **Replace the main electronic control board** only if the door switch tests good, the wiring is intact, and the F72 code returns after reset. This is the least common failure path.

## When to Call a Pro

Call a technician if you are not comfortable working inside the dryer cabinet, if the wiring diagram for your model is unclear, or if the code returns after you have tested the door switch and inspected all connectors. A qualified service tech can measure the door-switch signal at the control board and isolate whether the fault is in the switch, harness, or board itself without replacing parts by trial and error.

**Rough cost:** DIY runs about $25–80 in parts, 30–90 min. A pro service call runs about $150–300.
