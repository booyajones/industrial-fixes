## LG Range E7 Error Code — What It Means

E7 does not appear in LG's official U.S. range and oven error code documentation. LG's published range fault codes cover thermistor failures, low voltage, keypad issues, and communication errors, but E7 is not listed among them. By contrast, E7 is a defined code for LG SideKick pedestal washers, where it means the unit is not properly installed under a compatible LG front-load washer or the stacking switch (top washer detection device) is damaged.

If you are seeing E7 on an LG range or oven display, the code is likely model-specific and not covered by the generic range code list. Verify your exact model number and consult the service literature or wiring diagram that shipped with that model. Do not assume the meaning from other LG product lines. If the display is dim or partially obscured, confirm you are reading the correct characters, as other codes (F7, E1, or E9) have defined meanings for ranges.

## Before You Replace Anything

Because E7 is not a documented LG range code, technicians sometimes replace the main control board or temperature sensor by guessing. Before ordering parts, locate the exact error code definition in your model's service manual or wiring diagram to confirm what the display is actually reporting.

## Common Causes

- **Code is model-specific or undocumented (~40%)** LG's generic range code list does not include E7, so the meaning depends on your specific model's firmware and documentation.
- **Display misread or partial fault (~25%)** A dim display, partial character, or viewing angle may make another code (F7, E1, E9) appear as E7.
- **Wrong appliance or label confusion (~20%)** The code may be from a nearby LG SideKick washer, where E7 means the stacking switch is not actuated or the unit is used alone.
- **Control board firmware anomaly (~10%)** A rare firmware glitch or memory error may display an undefined code that does not match published lists.
- **Service-mode or diagnostic code (~5%)** Some models use E7 during factory test modes or after a service reset, and it clears when the unit returns to normal operation.

## Step-by-Step Fix {#fix}

1. **Confirm the appliance type and model number.** Check the rating plate (usually inside the oven door or on the back panel) and write down the complete model and serial number.
2. **Verify you are reading the display correctly.** Clean the control panel glass, view the display straight-on in good light, and confirm each character. Compare the displayed code to the list in your owner's manual.
3. **Download or request the service manual** for your exact model from LG's support website or by calling LG customer service. Ask specifically for the error code table and diagnostic flowchart.
4. **Look up E7 in the model-specific documentation.** If the code is listed, note the component it references (sensor, relay, or board) and any resistance or voltage test points.
5. **Perform a power reset.** Turn off the circuit breaker for the range for 60 seconds, then restore power. If the code was a transient fault or memory error, it may clear.
6. **Inspect the control board and wiring harness** for obvious damage, burnt connectors, or loose plugs if the manual points to a board fault. Do not touch live circuits; turn off power first.
7. **Schedule service if the code persists** or if the manual confirms E7 requires a control board, relay, or sensor replacement that involves high-voltage connections or calibration.

## When to Call a Pro

Call a professional if the code persists after a power reset and you cannot locate model-specific documentation that defines E7. Because the code is not in LG's generic range list, diagnosis requires access to service literature and may involve high-voltage testing of the control board, relays, or wiring harness. A qualified technician will have the correct schematic, know which test points to measure, and can order the right part by referencing LG's internal service database. Do not replace the control board or any sensor without confirming the code's meaning for your exact model, as guessing can lead to unnecessary expense and may not resolve the fault.

**Rough cost:** A pro service call runs about $150-350 depending on model and final diagnosis.
