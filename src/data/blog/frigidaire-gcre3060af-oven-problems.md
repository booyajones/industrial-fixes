## Frigidaire GCRE3060AF Oven Problems & Error Codes — Overview

The Frigidaire GCRE3060AF is an electric range that shares the typical Frigidaire fault code set seen across the line. The most frequent service calls involve temperature sensor failures (F10, F30, F31) and communication errors between the user interface board and the oven relay board. Technicians report that probe drift, loose harness connectors, and failed relay boards account for the majority of repeat failures on this model family.

Frigidaire does not publish a unique code list for the GCRE3060AF specifically, so techs rely on the generic range code guide and the unit's service documentation. The F10 thermal runaway code is the most common fault in the field, followed by door lock issues (F90 series) and shorted keypad faults (F1). Most repairs involve the oven temperature probe, relay board, or user interface assembly.

## Most Common Problems on This Model {#fix}

- **F10 thermal runaway or excessive temperature detected** Usually caused by a failed or drifting oven temperature probe (RTD sensor) or a stuck relay on the oven relay board that keeps the heating element energized.
- **F30 open oven probe circuit** Triggered by an open or disconnected temperature sensor, a loose connector at the control, or a broken wire in the harness between the probe and relay board.
- **F31 shorted oven probe circuit** Caused by a shorted temperature sensor, pinched or damaged harness wiring, or moisture intrusion at the probe connector.
- **F3, F20, or F26 communication error between boards** Results from a loose ribbon cable or connector between the user interface board and the oven relay board, or a failed control board on either end.
- **F1 shorted keypad or touchpad** Caused by moisture ingress behind the control panel, a stuck key, or a damaged touch membrane on the user interface board.
- **F90 through F94 door lock fault** Indicates a failed door lock motor assembly, stuck or binding latch mechanism, or a wiring fault in the door lock circuit.
- **Oven not heating or heating unevenly** Often tied to a failing bake or broil element, a faulty relay on the relay board, or a drifting temperature probe that reads incorrectly.
- **Control panel unresponsive or random error codes** Typically caused by a failed user interface board, poor solder joints on the relay board, or loose power connections at the terminal block.

## When to Call a Pro

Call a tech for any error code that returns after a power reset, for any fault involving the relay board or high-voltage wiring, or if you are not comfortable working inside a live 240-volt appliance. Temperature probe replacement is straightforward for a confident DIYer, but relay board and control board diagnosis requires a meter and familiarity with the wiring harness. Door lock motor replacement involves removing the oven door and working around the latch mechanism. If the unit repeatedly throws F10 or communication errors after replacing the obvious parts, the problem is usually a failing relay board or a poor connection that needs professional tracing. For gas line, burner, or igniter work, or if you ever smell gas, stop and call a licensed technician.
