## State Water Heater E21 Error Code — What It Means

Error code E21 (sometimes shown as 021) on State tankless water heaters is a manufacturer-specific diagnostic code that varies by model family and platform revision. State publishes dedicated service bulletins for this code, including the RE3 - Error Code 021 document, but the exact fault description, component, and troubleshooting sequence depend on your unit's model number. Unlike universal fault codes, E21 does not have a single universal meaning across all State equipment, so matching the code to your rating-plate model number is the required first step before any repair work begins.

## Common Causes

- **Model-specific sensor or control fault** State assigns E21 to different components depending on platform, so the code can indicate a temperature sensor, flow sensor, ignition module, or board issue based on your exact model.
- **Wiring connection problem at the affected sensor** Loose or corroded connectors between the control board and the sensor named in your model's service bulletin will trigger the fault.
- **Failed component identified in your service manual** The part named in State's RE3 - Error Code 021 bulletin for your model may have exceeded its service life or suffered electrical failure.
- **Intermittent ground fault or voltage drop** Electrical noise or insufficient supply voltage can cause the control board to flag a sensor or ignition circuit as failed even when the part is functional.

## Step-by-Step Fix {#fix}

1. **Locate the model and serial number** on the rating plate of your State water heater and write down the full alphanumeric string.
2. **Download or request the service manual** for that exact model from State's technical support or dealer network to obtain the E21 fault definition and diagnostic tree.
3. **Power off the unit** at the circuit breaker or disconnect switch and wait two minutes for the control board to discharge before opening any access panels.
4. **Follow the model-specific diagnostic sequence** in the service manual, which will direct you to test voltage, resistance, or continuity at the component associated with code 021 for your platform.
5. **Inspect all wiring connectors** between the control board and the sensor or module named in the bulletin for corrosion, moisture, or loose pins and clean or reseat as needed.
6. **Replace the component identified** in the State service literature using the part number listed in the manual's exploded-view diagram or parts table.
7. **Restore power and run a test cycle** to verify the code clears and the unit completes a full heating sequence without retriggering the fault.

## When to Call a Pro

Call a licensed technician if you cannot locate the service manual for your specific State model number, if the diagnostic sequence requires voltage or continuity measurements you are not trained to perform safely, or if the code returns after replacing the component named in the bulletin. Because E21 is a model-dependent code without a universal definition, professional diagnosis ensures you replace the correct part and do not void warranty coverage by working outside State's published procedures for your platform.
