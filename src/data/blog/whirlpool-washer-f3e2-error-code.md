## What this code means
The F3E2 code on Whirlpool washers signals a water-temperature sensing fault. The control board expects a valid temperature reading from the thermistor (temperature sensor) in the heater or tub circuit and flags F3E2 when that signal is missing or out of range.

This is a washer-specific code. Do not confuse it with the F3E2 code on Whirlpool commercial dryers, which refers to a moisture sensor problem. On washers, F3E2 always points to the water-temperature sensor circuit.

## Before You Replace Anything

Many people replace the main control board first. Always test the thermistor resistance with a multimeter and inspect the harness for broken wires before replacing the control.

## Common Causes

- **Broken or loose wire in the sensor harness (~45%)** Vibration and movement can break conductors at the rear harness or connector points, cutting the signal to the control board.
- **Failed thermistor or temperature sensor (~35%)** The sensor itself can drift out of range or open, sending invalid resistance values to the control.
- **Loose connector at the sensor or control board (~12%)** Terminals can back out or corrode, creating intermittent or no contact.
- **Main control board input failure (~8%)** If the sensor and wiring test good, the board's thermistor input circuit may have failed.

## Step-by-Step Fix {#fix}

1. **Disconnect power** at the wall or breaker before any testing or repair work.
2. **Access the temperature sensor** by removing the rear panel or top cover, depending on your washer model.
3. **Unplug the sensor connector** and inspect both halves for bent pins, corrosion, or loose terminals.
4. **Measure sensor resistance** with a multimeter across the thermistor leads and compare to the expected range (consult your model's service manual or look for approximately 9.8 kΩ to 14.8 kΩ at typical operating temperature).
5. **Replace the thermistor** if it reads open, shorted, or significantly out of range.
6. **Trace the harness** from sensor to control board if the sensor tests good, checking for broken wires or poor continuity.
7. **Replace the main control board** only if both the sensor and wiring check out but the fault persists.

## When to Call a Pro

Call a technician if you are uncomfortable working with electrical connectors, if you cannot locate the temperature sensor on your model, or if you have replaced both the sensor and checked the wiring but the code returns. A pro can trace harness continuity with specialized tools and confirm whether the control board input circuit has failed. If the washer is still under warranty, professional service may be required to preserve coverage.

**Rough cost:** DIY runs about $15-50 in parts, 30-60 min. A pro service call runs about $120-250.
