## State Water Heater E137 Error Code — What It Means

The E137 error code does not appear in standard State Water Heaters documentation available from the manufacturer. State produces tankless, gas tank, and electric models across multiple generations, and error codes are model-specific. The same numeric code can indicate different faults depending on the control board platform, unit type, and year of manufacture. Without the exact model number from your rating plate, it is not possible to determine whether E137 refers to a sensor fault, control board communication error, or another condition. State directs users to locate the QR code or model and serial number on the unit's rating plate and reference the model-specific installation and operation manual for accurate troubleshooting.

## Common Causes

- **Model-specific control board logic** The code may be valid only on certain State control platforms and undefined on others.
- **Incorrect manual reference** Generic online error code lists do not reflect State's proprietary codes and should not be used for diagnosis.
- **Control board firmware variation** Different production runs or software versions may report unique codes not in older manuals.
- **Display or communication fault** The control may be showing a board-level diagnostic code rather than a user-serviceable error.

## Step-by-Step Fix {#fix}

1. Locate the rating plate on your State water heater and write down the complete model number and serial number.
2. Scan the QR code on the rating plate if present, or visit the State Water Heaters support site and enter your model number to download the correct manual.
3. Open the troubleshooting or error code section of your model-specific manual and search for E137 in the table.
4. Check whether the manual lists E137 and follow the diagnostic steps and component tests specified for that code.
5. If E137 does not appear in your manual, contact State technical support with your model and serial number to confirm whether the code is valid or if the control board requires evaluation.
6. Do not attempt repairs based on generic online code lists, as they do not correspond to State's proprietary error definitions.
7. If the control board displays codes not in the manual or behaves erratically, document the sequence and consult a licensed technician familiar with your model line.

## When to Call a Pro

Call a licensed plumber or water heater technician if your model manual does not list E137, if you cannot locate your model documentation, or if the control board shows multiple undefined codes. A professional can interface with State technical support, verify control board firmware versions, and determine whether the unit requires a board replacement or other model-specific repair. Do not guess at repairs or substitute parts without manufacturer confirmation of the fault definition.
