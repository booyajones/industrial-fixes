## What this code means
On Bosch washing machines, E32 is not a fault code in the usual sense. It indicates the unbalanced load detection system has interrupted the spin cycle because the laundry is unevenly distributed in the drum. The machine detected an imbalance during spin, so it stopped or limited spinning to protect the appliance and the load.

This is a built-in safety feature. The code does not point to a failed component. Instead, it signals that the wash needs to be rearranged before spinning can continue safely.

## Before You Replace Anything

Homeowners sometimes suspect bearings or suspension when E32 repeats. Before replacing anything, confirm the machine is level on the floor and that you are mixing small and large items evenly. Most E32 codes clear after proper load balancing.

## Common Causes

- **Uneven laundry distribution (~70%)** Heavy items clumped on one side of the drum cause the load to spin off-center and trigger the imbalance sensor.
- **Mixed small and large items (~15%)** Towels wrapped around smaller garments or a single heavy blanket can bunch together and create an unbalanced load.
- **Machine not level (~10%)** If the washer rocks or sits unevenly on the floor, even a properly distributed load may trip the imbalance protection.
- **Overloaded or underloaded drum (~5%)** Too much laundry prevents proper tumbling, and too little allows items to cluster on one side during spin.

## Step-by-Step Fix {#fix}

1. **Stop the cycle** by pressing the pause or stop button on the control panel.
2. **Open the door** and inspect the laundry inside the drum.
3. **Redistribute the items** so that heavy and light pieces are spread evenly around the entire drum, not clumped on one side.
4. **Close the door** firmly until it latches.
5. **Select the spin cycle** again (or press start to resume) and allow the machine to complete the spin.
6. **Check the washer is level** by pushing down on each corner of the top panel. If the machine rocks, adjust the leveling feet until it sits firmly on the floor.
7. **Contact Bosch service** if E32 returns repeatedly with properly balanced loads and a level machine, as further diagnosis is needed.

## When to Call a Pro

Call a professional if E32 appears on every cycle even after you redistribute the laundry and verify the machine is level. Bosch advises contacting service with the exact code when the symptom persists despite correct loading. A technician can inspect the suspension, drum bearings, and internal sensors to rule out deeper mechanical or installation issues that a homeowner cannot safely diagnose or repair.
