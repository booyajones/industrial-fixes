## What this code means
The F1 error code on a Maytag oven is a generic control or sensing circuit fault. Maytag states that F1 points to a possible problem with the oven temperature sensor, the electronic control board, or the wiring between them. The control is seeing an invalid sensor signal, losing the signal entirely, or detecting an impossible reading. The code does not pinpoint one guaranteed failed part, so diagnosis requires checking the entire sensor circuit.

The fault may appear constantly when the oven is in use, or it may be intermittent. Intermittent codes often mean a component tests fine when cold but fails once it heats up. In those cases technicians usually suspect the sensor first, then the board if the code returns after sensor replacement.

## Before You Replace Anything

Many people replace the control board first without testing the sensor or checking wiring. Always test the oven temperature sensor resistance and inspect connectors before swapping the board.

## Common Causes

- **Failed oven temperature sensor** The sensor probe or its internal thermistor drifts out of specification or opens entirely, especially after years of heat exposure.
- **Control board failure** Cracked solder joints or failed input circuitry on the electronic control board prevent the board from reading the sensor correctly.
- **Loose or damaged wiring and connectors** Heat-affected terminals, corrosion, or a loose plug between the sensor and control interrupt the signal.
- **Intermittent sensor or board fault** A component tests normal at room temperature but opens or shorts once the oven cavity heats up.

## Step-by-Step Fix {#fix}

1. **Switch off the circuit breaker** to the range for 1 minute, then restore power and check whether the F1 code returns.
2. **Pull the range away from the wall** and remove the rear access panel or oven-cavity back shield to expose the oven temperature sensor and its wiring harness.
3. **Inspect the sensor, its connector, and the harness** for heat damage, corrosion, cracks, or looseness. Reseat any loose plugs and repair or replace damaged wiring.
4. **Test the oven temperature sensor resistance** at room temperature using a multimeter. Consult your model's service data for the expected resistance value. An open circuit, short, or reading far outside specification means the sensor has failed.
5. **Replace the oven temperature sensor** if the resistance is out of spec or if the sensor looks heat-damaged. Reconnect the harness and reassemble the oven.
6. **Restore power and run a test bake cycle**. If the F1 code does not return, the repair is complete.
7. **Evaluate the electronic control board** if the code persists after sensor replacement. Look for cracked solder joints at the sensor input terminals or signs of overheating on the board. Replace the control if the sensor circuit has failed.

## When to Call a Pro

Call a professional if you are not comfortable working around 240-volt household wiring, if you cannot locate or remove the oven temperature sensor, or if the F1 code returns after you have replaced the sensor and inspected all wiring. A technician has the service manual, resistance tables, and diagnostic test modes to isolate a control board fault without guessing. If the appliance is still under warranty, contact Maytag or an authorized service center before opening the unit to preserve coverage.
