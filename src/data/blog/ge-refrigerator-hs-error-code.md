## GE Refrigerator HS Error Code — What It Means

The HS code on a GE refrigerator indicates a humidity sensor error in the fresh-food or crisper area. The control board has detected that the humidity sensor is not reading correctly or is sending an out-of-range signal. This is different from the HRS code, which signals a high-temperature refrigerator condition. Because GE code meanings can vary by model family, always verify the exact code against your unit's service literature or owner's manual before replacing any parts. If your display actually shows HRS rather than HS, the troubleshooting path is different and involves door seals, condenser coils, and compressor operation instead of the humidity sensor.

The humidity sensor monitors moisture levels in the crisper drawers to help keep produce fresh. When the sensor or its wiring fails, the control board cannot regulate humidity properly and displays the HS fault. In many cases the code can be cleared by a simple power reset, and no component replacement is needed if the code does not return.

## Before You Replace Anything

Homeowners sometimes replace the main control board when the real fault is a dirty or loose humidity sensor connector. Always inspect and clean the sensor area and check wiring connections before ordering a board.

## Common Causes

- **Failed humidity sensor (~45%)** The sensor itself has degraded or is reading out of range, causing the control board to log the HS fault.
- **Contaminated sensor area (~25%)** Moisture, debris, or residue around the sensor location interferes with accurate readings and triggers the error.
- **Loose or corroded wiring connector (~15%)** A poor connection or corroded pin in the sensor harness sends an intermittent or invalid signal to the control board.
- **Crisper drawer not seated properly (~10%)** A misaligned or improperly closed drawer shifts the sensor position or obstructs airflow, affecting the humidity reading.
- **Defective main control board (~5%)** The board misinterprets a valid sensor signal or has a failed input circuit, though this is less common than sensor or wiring faults.

## Step-by-Step Fix {#fix}

1. **Confirm the exact code** displayed on the control panel. Write down whether it reads HS or HRS, since these are different faults with different troubleshooting paths.
2. **Unplug the refrigerator** from the wall outlet for at least 60 seconds to reset the control board, then restore power and check whether the HS code reappears.
3. **Remove the crisper drawers** and inspect the humidity sensor location (usually mounted near the drawer compartment). Look for moisture, sticky residue, or debris on or around the sensor.
4. **Clean the sensor area** with a soft dry cloth or lightly dampened cloth. Make sure the sensor and its immediate surroundings are completely dry before reassembling.
5. **Check the sensor wiring harness** for loose connectors, bent pins, or corrosion. Disconnect and reconnect the sensor plug to make sure a solid electrical connection.
6. **Test the sensor circuit** if you have a multimeter. Consult your model's service guide for the correct resistance or voltage values at the sensor connector. If no factory spec is available, note that some field references cite roughly 16.3 kΩ at 32 °F for similar thermistors, but this is not a verified GE specification.
7. **Replace the humidity sensor** if cleaning and connector checks do not clear the code. Order the sensor by your refrigerator's full model number to make sure compatibility, then disconnect power, unplug the old sensor, plug in the new one, and reassemble the crisper drawer area.

## When to Call a Pro

Call a professional if you are uncomfortable working with electrical connectors inside the refrigerator, if the HS code persists after you have replaced the humidity sensor and verified all wiring, or if your refrigerator continues to show temperature problems in addition to the HS fault. A technician can test the control board's input circuits and verify whether the board itself has failed. Also call a pro if your display actually reads HRS instead of HS, because that code points to compressor, condenser, or sealed-system issues that require refrigerant handling and specialized tools.

**Rough cost:** DIY runs about $30–80 in parts, 30–60 min. A pro service call runs about $150–280 service call.
