## Samsung Oven E-28 Error Code — What It Means

E-28 is a short circuit fault on the Samsung oven temperature sensor. The board saw a resistance far below normal, which it treats as a shorted probe or harness.

A good sensor reads about 1080 ohms at room temperature. A reading near zero, or a probe sheath shorting against the cavity metal, drives the board to post E-28 and stop the cook.

## Common Causes

- **Shorted temperature sensor** The probe element has failed low and reads close to zero ohms.
- **Pinched harness lead** A wire crushed against the chassis shorts the two sensor leads together.
- **Melted sensor insulation** Heat near the cavity has melted the lead jacket and bridged the conductors.
- **Probe shorting to cavity** A cracked sheath lets the sensor element touch grounded metal.
- **Control board input fault** Less often the board sensing circuit misreads a good sensor as shorted.

## Step-by-Step Fix {#fix}

1. Cut power at the breaker for one minute, restore it, and watch for E-28 to return.
2. Pull the range and remove the back panel to reach the sensor harness.
3. Unplug the temperature sensor connector and inspect the leads for pinch or melt damage.
4. Set a multimeter to ohms and measure the sensor. Expect about 1080 ohms at room temperature.
5. Replace the sensor if it reads near zero or far below spec.
6. Check that the harness is not crushed against the chassis and reroute any pinched section.
7. If the sensor and wiring test good, have the control board input checked.

## When to Call a Pro

A short that returns after a new sensor often hides in the harness or the board. If you cannot find the pinched lead, a tech can trace the circuit and confirm whether the board sensing input has failed.
