## What this code means
F2 E0 on a Maytag range signals that the oven control thinks a key on the user interface or keypad is stuck, continuously pressed, or electrically shorted. The fault can also indicate a wiring problem or a communication failure between the touchpad and the electronic control board. The code appears when the control detects a key-press signal that never releases, even when no one is touching the panel.

Maytag product help lists the likely causes as the user interface or keypad, the electronic control, or the associated wiring harness and connectors. The fault is usually electronic, not mechanical, meaning you often will not see a button physically jammed down. Instead, a shorted trace on the touchpad membrane or a failed chip on the interface board sends a continuous press signal.

## Before You Replace Anything

Many people replace the main electronic control board first when the real culprit is the touchpad. Before buying a new control, power-cycle the range at the breaker and inspect the keypad connector for corrosion or looseness.

## Common Causes

- **Failed user interface or keypad assembly (~55%)** A shorted button membrane, liquid intrusion, or failed component on the touchpad board sends a constant key-press signal to the control.
- **Stuck key from residue or moisture (~20%)** Spills, cooking grease, or cleaning spray seep under the overlay and bridge contacts, causing the control to read a key as stuck.
- **Loose or corroded wiring connector (~15%)** The harness plug between the user interface and control board is partially unseated, corroded, or has bent pins that cause intermittent shorts.
- **Defective electronic control board (~10%)** The control misreads the keypad circuit or has a failed input chip that interprets normal signals as a stuck key.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker for at least one minute, then restore power and observe whether the F2 E0 code returns within about a minute.
2. **Inspect the keypad surface** for any button that appears stuck down, looks damaged, or has liquid or sticky residue around it.
3. **Unplug the range** or switch off the breaker again, then pull the range forward and remove the rear panel or control-console cover to access the back of the user interface.
4. **Check the wiring harness and connector** between the touchpad and the electronic control board for looseness, corrosion, bent pins, or pinched wires.
5. **Reseat the connector firmly** and inspect both the plug and socket for damage. If you find corrosion or bent pins, repair or replace the harness.
6. **Replace the user interface assembly** if the wiring is sound and the fault persists. Order the correct part for your model number and unplug the old interface, then snap or screw in the new one.
7. **Test the repair** by restoring power and running the oven through a short bake cycle. If F2 E0 still appears, replace the electronic control board.

## When to Call a Pro

Call a technician if you are not comfortable working with 240-volt appliances, if you cannot access the back of the control console, or if the fault persists after you have replaced both the user interface and the electronic control board. A pro can trace the circuit with a multimeter to confirm which component is shorted and can verify that no other wiring fault is present. If your range is still under warranty, contact Maytag or an authorized service center before replacing any parts yourself.

**Rough cost:** DIY runs about $80–180 for a touchpad or control board, 30–60 min. A pro service call runs about $150–300 including labor and part.
