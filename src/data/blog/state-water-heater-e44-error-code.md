## State Water Heater E44 Error Code — What It Means

The E44 error code on State tankless water heaters is most commonly associated with a gas valve malfunction, based on manufacturer documentation for similar platforms. This fault indicates the control board has detected an issue with the gas valve circuit or the valve itself is not responding correctly. While E44 is not universally published across all State product lines, the published repair procedure for this code follows a specific diagnostic sequence starting with a controller parameter check before replacing hardware.

## Common Causes

- **Incorrect controller parameter setting** The unit's P50 parameter may not be set to the required value of 2, which is the first published corrective action for E44.
- **Defective gas valve** The gas valve itself has failed internally or is not opening and closing on command from the control board.
- **Faulty wiring to the gas valve** Damaged or loose wiring between the control board and gas valve prevents proper signal transmission.
- **Control board failure** The main control board is sending incorrect signals or has failed in the gas valve control circuit.
- **Gas supply issue triggering valve fault** Insufficient gas pressure or supply interruption can cause the valve to register as faulty even when mechanically sound.
- **Valve coil burnout** The gas valve's solenoid coil has burned out due to electrical overstress or age.

## When to Call a Pro

Gas appliance repair carries serious safety risks including fire, explosion, and carbon monoxide hazards. If you are not trained and certified to work on gas-fired equipment, call a licensed plumber or gas technician immediately. Professional help is also necessary if you do not have the tools to safely measure gas pressure, test electrical circuits under load, or perform mandatory leak testing after any gas valve work. Many jurisdictions require permitted work and inspection for any gas appliance repair.
