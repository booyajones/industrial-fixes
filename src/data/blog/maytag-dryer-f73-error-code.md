## Maytag Dryer F73 Error Code — What It Means

F73 does not appear in Maytag's published dryer error code documentation. The manufacturer's dryer help page lists codes such as AF/F4E3, L2, and PF, and states that other F# E# codes indicate a service-requiring problem, but F73 is not identified as a dryer code. F73 is documented as a Maytag washer error code, where it signals a communication breakdown between the front interface control unit and the main control board.

If your Maytag dryer is displaying F73, first verify the model number and confirm whether the appliance is actually a washer or if the code has been misread. For Maytag washers showing F73, the issue is a control communication fault. For dryers displaying an unrecognized F# E# pattern, Maytag's guidance is to perform a power reset and contact service if the code persists.

## Common Causes

- **Appliance misidentification** F73 is a washer code, not a dryer code, so the first step is confirming the model type and verifying the displayed error.
- **Faulty wiring harness (washers)** Damaged or loose connectors between the front interface control unit and main control board disrupt communication on washers.
- **Defective front interface control board (washers)** A failed front control board on a washer cannot send signals to the main control board, triggering F73.
- **Main control board failure (washers)** The main control board on a washer may fail to receive or process signals from the front interface unit.
- **Power interruption or surge** A brief power loss or electrical surge can cause temporary communication faults on washers.
- **Unrecognized service code (dryers)** If a dryer displays an unlisted F# E# code, Maytag documentation indicates a condition requiring professional service.

## Step-by-Step Fix {#fix}

1. **Confirm the appliance model** by checking the rating plate inside the door or on the back panel to verify whether you have a washer or a dryer.
2. **Verify the error code** on the display to make sure it reads F73 and not a similar code like F7E3 or another dryer-specific F# E# pattern.
3. **Disconnect power** by unplugging the unit or switching off the breaker for at least two minutes, then restore power and check if the code clears.
4. **Access the control area** (washers only) by removing the front or top panel per your model's service manual to reach the interface control board and main control board.
5. **Inspect wiring and connectors** (washers only) between the front interface control unit and the main control board for loose, corroded, or damaged terminals and reseat all harness plugs firmly.
6. **Test the front interface control board** (washers only) by checking for obvious burn marks or swelling, and replace it if wiring is sound and the code persists after reconnection.
7. **Contact Maytag service** if the code remains after a power reset on a dryer, or if replacing the interface board on a washer does not resolve F73.

## When to Call a Pro

Call a professional if you have confirmed your appliance model and the error code persists after a full power reset. For washers, if you are uncomfortable removing panels, working with live control boards, or diagnosing multi-point wiring harnesses, a qualified technician can trace the communication path with a multimeter and replace boards safely. For dryers displaying an unlisted F# E# code, Maytag's published guidance directs you to service because the code is not part of the standard dryer diagnostic set. Always call for help if you see any sign of arcing, burning, or if multiple error codes appear in sequence.
