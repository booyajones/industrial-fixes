## Whirlpool Dishwasher FAE5 Error Code — What It Means

Whirlpool's public product help states that FAE5 (also shown as F10E5 on some models) means the dishwasher ended the cycle, drained, and displayed an error. The manufacturer does not publish a component-level explanation on the public page beyond the reset instruction. Whirlpool directs owners to press Cancel twice and then start a new cycle. For technicians, this is a service-level fault that often clears only after diagnosis if it repeats, not a simple user setting issue.

Because Whirlpool's public documentation does not decode the exact internal cause, treat FAE5 as "cycle ended with an error, reset and re-test" unless your model-specific service literature provides further detail. The exact meaning varies by model, so consult the tech sheet for your dishwasher's serial number if the code returns after reset.

## Before You Replace Anything

Many people replace the main control board without first checking door latch closure, inspecting connectors for corrosion, or running model-specific diagnostics. Always verify the door closes fully and inspect harness pins before ordering a control.

## Common Causes

- **Control or UI communication fault (~35%)** A signal error between the main control board and the user interface can trigger FAE5 when the cycle ends, especially if connectors are loose or corroded.
- **Door latch or switch input issue (~30%)** If the control does not see a consistent closed-door signal, it may log a fault at the end of the cycle and display FAE5.
- **Sensor or wiring fault in the control path (~20%)** An intermittent sensor input or a damaged wire in the harness can cause the control to flag an error and drain.
- **Main control board internal fault (~15%)** If the board's memory or processor encounters an error during the cycle, it may end with a drain and display FAE5.

## Step-by-Step Fix {#fix}

1. **Press Cancel twice** on the control panel to clear the code, per Whirlpool's instructions, then try to start a new cycle.
2. **Observe whether the code returns immediately or after a full cycle**. A one-time event may not need repair, but a recurring fault requires diagnosis.
3. **Turn off power at the breaker** for 60 seconds and restore it. This power reset is a common service check when the code repeats immediately.
4. **Inspect the door latch area** for obstructions, damage, or misalignment. Push the door firmly and listen for a solid click.
5. **Check all harness connectors** at the main control board, user interface, and door latch switch for loose pins, corrosion, or signs of arcing.
6. **Run the model-specific diagnostic mode** using the tech sheet for your serial number to identify which input or communication path triggered the fault.
7. **Replace the confirmed failed component** only after diagnostics. Common replacements include the main control board, user interface console, door latch assembly, or a related harness or sensor depending on the model.

## When to Call a Pro

Call a technician if the code returns after the reset steps, if you are not comfortable removing the lower access panel and toe kick to inspect connectors and wiring, or if you do not have access to the model-specific service tech sheet and diagnostic mode instructions. Dishwasher control diagnostics require a multimeter and familiarity with reading component-level fault logs. A qualified service technician can run the built-in diagnostic cycle, measure signal voltages at each input, and replace only the component that has failed rather than guessing at expensive boards.

**Rough cost:** A pro service call runs about $150–350 depending on part and labor.
