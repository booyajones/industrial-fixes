## Fujitsu E:29 Error Code — What It Means

E:29 on a Fujitsu mini split indicates a connection unit number error. The controller is detecting the wrong number or wrong combination of indoor units connected to the system. This fault is also described as a combination unit number error or indoor unit wired remote control error. The problem is usually in the system configuration, addressing, or control board logic rather than refrigeration hardware.

[Jump to Fix](#fix)

## Common Causes

- **Wrong number of connected indoor units** The number of indoor units connected does not match the system's permitted combination.
- **Miswiring or loose connector** Open cables, loose plugs, or incorrect wiring in the control or interconnect circuits prevent proper communication.
- **Incorrect indoor unit type** An incompatible or wrong indoor unit model is connected or configured for the system.
- **Defective indoor unit controller PCB** The controller board in the indoor unit has failed and cannot correctly report the unit configuration.
- **Main PCB fault** The main system control board has a defect that causes incorrect unit addressing or communication errors.
- **Incorrect remote control address setting** On systems with addressable controls, the remote or controller address does not match the actual unit configuration.

## Step-by-Step Fix {#fix}

1. **Verify the system configuration** by confirming the number and type of connected indoor units match Fujitsu's permitted combination for your outdoor unit model (consult the installation manual or nameplate data).
2. **Inspect all control wiring and connectors** at both the indoor and outdoor units, checking the external I/O PCB, controller PCB, and interconnect wiring for loose plugs, open cables, or miswiring.
3. **Check indoor unit type and addressing** to confirm each connected unit is the correct model for the system, and if your system uses addressable controls, verify or reset the remote control address setting.
4. **Power cycle the system** by shutting off the breaker or disconnect for three minutes, then restoring power and checking whether the E:29 code returns.
5. **Test or replace the indoor unit controller PCB** if inspection and configuration checks show no issues, as a defective board is a common cause of this fault.
6. **Inspect or replace the main PCB** if all previous checks pass and the error persists, following the troubleshooting flow in the service manual.
7. **Re-seat all connectors** on the controller and main boards after any repair and confirm the system operates without the fault code before finishing the job.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working with low-voltage control wiring or if you lack the service manual for your specific Fujitsu model. Configuration errors on multi-zone systems can cause compressor lockouts or damage if corrected incorrectly. Replacing control boards requires matching exact part numbers and sometimes updating firmware or resetting system parameters. If the fault returns after a power cycle and you have confirmed the correct number and type of indoor units, a technician with Fujitsu diagnostic tools and wiring diagrams is the safest next step.
