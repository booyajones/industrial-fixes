## What this code means
The F5 E3 code on Whirlpool top-load washers is a lid lock or door switch wiring error. The control board expects to receive a signal confirming the lid is locked for the cycle, but the lock feedback circuit is not providing that confirmation. This fault is tied specifically to the lid lock and door switch wiring system in Whirlpool top-load machines.

The washer will not start or continue its cycle until it sees a reliable locked-lid signal. The code can appear if the lid is not fully closed, if clothing or debris blocks the latch, if the lock assembly itself has failed, or if the wiring harness or connectors between the lock and the control have become loose, corroded, or damaged. A temporary control glitch can also trigger the code, which is why a power reset is the first troubleshooting step.

## Before You Replace Anything

Homeowners sometimes replace the control board when the F5E3 code persists. Check the lid lock assembly and its wiring harness first, both are far more often the root cause and cost much less to replace.

## Common Causes

- **Faulty lid lock assembly (~50%)** Internal switch contacts or the locking solenoid inside the assembly wear out, corrode, or stick so the control never receives the locked signal.
- **Loose or corroded wiring and connectors (~25%)** The harness plug at the lid lock or along the path to the control can work loose, corrode, or develop intermittent contact that interrupts the lock feedback circuit.
- **Lid not fully closed or latch misaligned (~15%)** Clothing caught in the lid, a worn striker, or mechanical misalignment prevents the lock from engaging cleanly and signaling the control.
- **Door switch failure (~8%)** The separate door or lid position switch (if present on the model) can fail and prevent the lock circuit from completing.
- **Temporary control glitch (~2%)** Electrical noise or a power surge can cause the control to lose communication with the lock circuit until the machine is fully power-cycled.

## Step-by-Step Fix {#fix}

1. **Unplug the washer** from the wall outlet and wait five minutes to clear any temporary control fault and discharge residual power.
2. **Open the lid and inspect the latch area** for clothing, detergent residue, or any debris that might prevent full closure or prevent the lock from engaging cleanly.
3. **Close the lid firmly** and make sure the striker aligns with the lock mechanism. Plug the washer back in and try to start a cycle to see if the F5E3 code clears.
4. **Access the lid lock assembly** by removing the top panel or control console according to your model's service manual. The lock is typically mounted under the lid near the front or center.
5. **Inspect the wiring harness and connector** at the lid lock. Look for loose pins, corrosion on the terminals, or any visible wire damage. Clean corroded contacts with electrical contact cleaner and reseat the connector firmly.
6. **Test or replace the lid lock assembly** if the wiring is intact and the code persists. Disconnect the lock connector, remove the mounting screws, and install a new lock assembly that matches your washer model number.
7. **Reassemble the washer**, plug it in, and run a short test cycle to confirm the control now detects the locked lid and the F5E3 code does not return.

## When to Call a Pro

Call a technician if you are uncomfortable working inside the washer cabinet or removing the top panel. Also call if you have replaced the lid lock assembly and checked all wiring but the F5E3 code still appears, which suggests a less common control board issue. A qualified service tech can perform continuity tests on the lock circuit, verify control board outputs, and determine whether the main control needs replacement. Most homeowners with basic hand tools can safely swap a lid lock assembly, but if you are unsure about disconnecting electrical connectors or reassembling sheet-metal panels, professional help will save time and prevent accidental damage to other components.

**Rough cost:** DIY runs about $30–80 in parts, 30–60 min. A pro service call runs about $150–250.
