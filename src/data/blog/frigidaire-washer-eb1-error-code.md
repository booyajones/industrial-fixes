## Frigidaire Washer EB1 Error Code — What It Means

EB1 on a Frigidaire washer means the control board is detecting incoming power frequency out of limits. The supply frequency is not within the washer's allowed range. This is primarily an incoming power problem, not a normal internal wash-system fault like fill, drain, or lock errors. The code points to the electrical supply side rather than water or mechanical components.

[Jump to Fix](#fix)

## Common Causes

- **Utility power frequency instability** The electrical service or branch circuit is producing unstable line frequency that falls outside the control's acceptable range.
- **Generator or inverter supply** The washer is plugged into a portable generator, modified sine-wave inverter, or other nonstandard supply that distorts frequency.
- **Improper power source** The washer is connected to an extension cord, shared circuit, or other arrangement that creates an abnormal input condition.
- **Intermittent supply issues** Loose connections at the receptacle, cord, or branch circuit cause the control to see an abnormal frequency input.
- **Control board misread or failure** The power-sensing section of the main control board is failing or misinterpreting a good supply, though the code description points to incoming power first.

## Step-by-Step Fix {#fix}

1. **Verify the power source.** Confirm the washer is plugged into a dedicated household utility outlet and not connected to a generator, inverter, or extension cord.
2. **Measure line frequency.** Use a multimeter capable of checking frequency and confirm the supply is stable and within the washer's required range.
3. **Inspect the cord, plug, and receptacle.** Check for loose connections, overheating, arcing marks, or intermittent opens that affect power quality to the board.
4. **Check the branch circuit.** Inspect breaker connections and wiring at the panel for loose neutrals or hot conductors that can cause supply instability.
5. **Cycle power to the washer.** Unplug the machine for two minutes, then reconnect and attempt a new cycle to see if the code clears on stable utility power.
6. **Test on a different known-good outlet.** If possible, connect the washer to another verified utility receptacle to rule out a local wiring issue.
7. **Replace the main control board if supply is verified good.** If EB1 returns on confirmed stable utility power with no cord or receptacle defects, the power-sensing circuitry on the control board is at fault.

## When to Call a Pro

Call a licensed electrician if you measure unstable line frequency at the outlet or find evidence of loose connections, overheating, or arcing at the receptacle or panel. If the supply tests good and stable but the EB1 code returns, call an appliance technician to test and replace the main control board. Because this code is supply-related rather than a typical washer fault, start with an electrical inspection before ordering appliance parts.
