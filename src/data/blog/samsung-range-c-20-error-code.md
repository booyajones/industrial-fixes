## What this code means
The C-20 error code on a Samsung range indicates an oven temperature sensor fault. The control board has detected that the oven sensor is either open (broken circuit) or shorted (resistance too low). Samsung groups C-20, C-21, and C-22 as sensor malfunctions and recommends turning the oven off and restarting, or removing power for 30 seconds or more if the code returns.

In practical terms, the control expects the oven sensor to read between roughly 950 and 2950 ohms. When the sensor drifts outside this range (shorted under 950 ohms or open over 2950 ohms), the C-20 code appears. A working sensor typically measures around 1080 ohms at room temperature. The fault can be the sensor itself, damaged wiring in the sensor harness, or a loose connector.

## Before You Replace Anything

Many people replace the main control board when they see a persistent sensor code. Always measure the sensor resistance and inspect the wiring harness for damage or rodent chewing before replacing any control.

## Common Causes

- **Failed oven temperature sensor (~60%)** The sensor probe has drifted out of spec, gone open, or developed an internal short so it no longer reads in the expected 950–2950 ohm range.
- **Damaged sensor wiring or connector (~25%)** Broken, burned, chewed, or loose wiring between the sensor and the control board causes an open or short condition that triggers the code.
- **Intermittent sensor connection (~10%)** Corrosion or vibration at the connector terminals creates an intermittent open circuit that appears as a sensor fault when the connection breaks.
- **Control board sensor-input failure (~5%)** If the sensor and wiring both test correctly, a fault in the control board's sensor-input circuit can cause a false C-20 code.

## Step-by-Step Fix {#fix}

1. **Disconnect power** by unplugging the range or switching off the circuit breaker before any diagnostic or repair work.
2. **Access the oven sensor** by removing the back panel inside the oven cavity or the rear access panel (consult your model's service manual for exact location).
3. **Disconnect the sensor connector** and use a multimeter set to ohms to measure resistance across the two sensor terminals at room temperature.
4. **Compare the reading** to the expected range of 950 to 2950 ohms (a typical good sensor reads around 1080 ohms at room temperature). If out of range, replace the sensor.
5. **Inspect the sensor wiring harness** from the sensor to the control board for breaks, burns, pinches, or rodent damage. Repair or replace any damaged wiring.
6. **Reconnect or install the new sensor**, secure all connectors, and restore power. Clear the code by unplugging for 30 seconds if needed.
7. **Test the oven** by running a bake cycle and verifying that the code does not return and the temperature climbs normally.

## When to Call a Pro

Call a professional if you are uncomfortable working with electrical connections or if the sensor and wiring both test correctly but the code persists. A technician can enter Samsung's diagnostic mode to verify stored fault codes, perform heat-soak testing of the sensor under load, and test the control board's sensor-input circuit. Also call a pro if you discover signs of rodent damage inside the range, since animals may have caused additional hidden wiring or insulation faults that require a full harness inspection.

**Rough cost:** DIY runs about $20–60 in parts, 30–60 min. A pro service call runs about $150–300.
