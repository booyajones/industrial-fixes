## Maytag Range F4 Error Code — What It Means

The F4 error on a Maytag range or oven indicates the control has detected a problem with the oven temperature sensor circuit. The sensor resistance is either out of range (open or shorted) or the control cannot reliably read it. Maytag's product help also describes F4 as a fault in the oven cavity control or associated wiring.

The control relies on a thermistor probe mounted inside the oven cavity to monitor baking temperature. When that probe fails, reads infinite resistance (open), reads near zero (shorted), or the wiring harness between the probe and control is damaged, the control throws F4 and stops oven operation to prevent unsafe heating.

## Before You Replace Anything

Many people replace the oven control board first because the error sounds electronic. Test the oven sensor resistance with a multimeter (should read around 1100 ohms at room temperature) and inspect the harness for damage before buying a board.

## Common Causes

- **Failed oven temperature sensor (~60%)** The thermistor probe inside the oven cavity has drifted out of tolerance, shorted internally, or opened, so the control sees an impossible resistance value.
- **Damaged or loose wiring harness (~25%)** The connector between the sensor and control has corroded pins, or the harness wires are pinched, burned, or broken, creating an open or intermittent short.
- **Defective oven control board (~10%)** The electronic range control (ERC) or oven cavity control has a failed input circuit that cannot read the sensor even when the sensor itself tests good.
- **Temporary power glitch (~5%)** A brief voltage spike or brownout can lock the control into an error state that a power reset will clear.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker and wait one full minute, then restore power and see if F4 reappears.
2. **Pull the range away from the wall** and remove the rear access panel or lower kick-panel to reach the oven temperature sensor, typically a metal probe mounted through the back wall of the oven cavity.
3. **Disconnect the sensor wire connector** from the wiring harness and set your multimeter to resistance (ohms).
4. **Measure the sensor resistance** across the two terminals at room temperature (around 70°F). A good sensor reads approximately 1100 ohms.
5. **Inspect the harness and connector** for burned pins, corrosion, pinched wires, or breaks between the sensor and the control board.
6. **Replace the oven temperature sensor** if it reads open (infinite ohms), shorted (near zero ohms), or is outside the expected range.
7. **Replace the oven control board** only if the sensor and harness both test good but the F4 code persists after reassembly and power-on.

## When to Call a Pro

Call a technician if you are uncomfortable working with the range pulled out, if you cannot locate the sensor or its connector, or if both the sensor and harness test good but the error remains. A pro can verify the control-board input circuit with a load test and replace the board safely. Also call if the oven shares a gas valve or high-voltage bake element circuit you are not confident isolating. The sensor replacement itself is straightforward for a DIYer with a multimeter and basic hand tools, but diagnosing a faulty control board is faster with service documentation and a known-good test sensor.

**Rough cost:** DIY runs about $20–50 in parts (sensor), 30–60 min. A pro service call runs about $150–250 including service call and sensor replacement.
