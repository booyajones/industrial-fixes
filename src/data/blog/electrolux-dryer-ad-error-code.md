## Electrolux Dryer AD Code — What It Means

The AD code on an Electrolux or Frigidaire dryer is not a fault code. It stands for Auto Dry Setting and appears when you have selected an automatic cycle that uses the moisture sensor to estimate dryness and adjust the drying time. The dryer is operating as designed when AD shows on the display.

If the dryer seems to stop too soon, run too long, or otherwise behave abnormally on Auto Dry cycles, the problem is usually not the code itself but dirty moisture sensor bars in the drum or a failed humidity sensor circuit. A separate error code (such as E4 on many Electrolux models) would typically appear if the sensor circuit has actually failed.

## Before You Replace Anything

Many people replace the electronic control board when Auto Dry cycles behave poorly, but the real cause is almost always dirty moisture sensor bars or damaged sensor wiring. Clean the bars with rubbing alcohol and check continuity on the sensor wires before ordering any board.

## Common Causes

- **Lint or fabric-softener film on moisture sensor bars (~70%)** Residue on the two metal sensor strips inside the drum prevents accurate moisture reading and makes Auto Dry cycles end too early or run too long.
- **Normal Auto Dry display (~15%)** The dryer was intentionally set to an Auto Dry cycle and the AD display is the correct indication of that mode, not a fault.
- **Damaged or corroded moisture sensor bars (~8%)** Physical damage, corrosion, or broken mounting of the sensor electrodes in the drum prevents the control from reading moisture levels.
- **Faulty sensor wiring or connections (~5%)** Broken wires or poor connections between the moisture sensor bars and the control board cause erratic or failed Auto Dry operation.
- **Failed electronic control board (~2%)** If the sensor bars are clean and the wiring tests good, the control board may no longer be processing the sensor signal correctly.

## Step-by-Step Fix {#fix}

1. **Verify the cycle setting.** Confirm that AD is appearing because you selected an Auto Dry cycle and that the dryer is not showing a separate error code such as E4.
2. **Unplug the dryer.** Disconnect power at the outlet or circuit breaker before working inside the drum.
3. **Locate the moisture sensor bars.** Look for two thin metal strips mounted on the inside of the drum, usually near the lint filter housing or on the rear drum wall.
4. **Clean the sensor bars thoroughly.** Dampen a soft cloth or cotton pad with rubbing alcohol and wipe both sensor strips to remove lint, fabric-softener residue, and detergent film.
5. **Inspect the sensor bars for damage.** Check for corrosion, cracks, or loose mounting. If the bars are broken or corroded, they will need replacement.
6. **Check sensor wiring.** Remove the dryer cabinet (consult your service manual) and trace the wires from the sensor bars to the control board, looking for breaks, pinches, or poor connections.
7. **Test the sensor circuit.** With the dryer unplugged, use a multimeter to check continuity between the sensor bars and the control board connector. Consult your model's tech data sheet for expected resistance values, if available.
8. **Reassemble and test.** Restore power, select an Auto Dry cycle with a small damp load, and verify that the dryer estimates time correctly and stops when clothes are dry.

## When to Call a Pro

Call a technician if you have cleaned the moisture sensor bars and checked the wiring but Auto Dry cycles still behave erratically, or if the dryer displays a true fault code (such as E4) along with AD. A pro can access the tech data sheet, run onboard diagnostics, and test the sensor circuit with precision instruments. Also call for help if you are uncomfortable removing the cabinet panels or tracing wiring inside the dryer.

**Rough cost:** DIY runs about $0-15 for rubbing alcohol and cloth; moisture sensor bars $20-50 if damaged; 15-30 min. A pro service call runs about $100-200 service call if sensor cleaning or wiring repair is needed.
