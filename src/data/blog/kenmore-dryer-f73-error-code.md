## What this code means
The F73 error code is not verified in Kenmore dryer manufacturer documentation. The closest documented fault for Kenmore dryers is F70, which indicates a communication failure between the main electronic control board and the user interface control panel. In plain language, the two control boards cannot talk to each other. This communication fault prevents the dryer from starting or continuing a cycle.

If your display shows F73 specifically, consult your model's wiring diagram or service manual to confirm the exact meaning for your machine. Different Kenmore model families sometimes use different fault codes. The repair steps below address the common F70 communication fault, which shares similar troubleshooting logic for control and interface problems.

## Before You Replace Anything

Many people replace the main control board first, spending $150 or more, when a loose or corroded harness connector is the real problem. Unplug the dryer and inspect every connector between the console and main board for looseness, corrosion, or damaged pins before ordering any boards.

## Common Causes

- **Loose or damaged wire harness (~40%)** The multi-pin connector between the main control board and user interface can work loose from vibration or heat, or individual pins can corrode and lose contact.
- **Failed user interface control assembly (~30%)** The control panel board that houses the buttons and display can fail, losing its ability to send or receive signals to the main board.
- **Failed main electronic control board (~20%)** The main control board (ECB) can suffer component or trace failures that prevent it from communicating with the user interface.
- **Power surge or unstable incoming voltage (~10%)** A voltage spike or brownout can corrupt control firmware or damage communication circuits, triggering a persistent fault code.

## Step-by-Step Fix {#fix}

1. **Unplug the dryer** from the wall outlet and wait five minutes to allow capacitors to discharge and to attempt a power reset.
2. **Restore power** and check if the code has cleared; if so, monitor the dryer for recurrence and consider installing a surge protector.
3. **Unplug again** and remove the top or front console panel to access the user interface control board and wiring harness, following your model's service manual.
4. **Inspect every harness connector** between the user interface and the main control board for looseness, corrosion, bent pins, or heat damage, and firmly reseat each connector.
5. **Check for damaged wires** along the harness run, especially where the harness passes through the cabinet or around hinges, and repair or replace any damaged sections.
6. **If wiring is intact**, test or replace the user interface control assembly first, as it fails more often than the main board and is usually easier to access.
7. **If a new interface does not resolve the code**, replace the main electronic control board and re-test the dryer through a complete cycle.

## When to Call a Pro

Call a qualified appliance technician if you are uncomfortable working with electrical panels or disassembling the console, if the wiring diagram for your specific Kenmore model is unclear, or if you have already replaced the harness and user interface without resolving the code. A technician can use diagnostic software and multimeter tests to pinpoint whether the main control board or another component is at fault. Professional service is also recommended if your dryer is still under warranty, as self-repair may void coverage.

**Rough cost:** DIY runs about $50-200 in parts, 45-90 min. A pro service call runs about $150-350.
