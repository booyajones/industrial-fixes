## Mitsubishi P9 Error Code — What It Means

The P9 error code on a Mitsubishi heat pump or mini-split indicates a pipe temperature thermistor fault in the indoor unit. Specifically, the system has detected an abnormality in the TH5 sensor circuit, which monitors the temperature of the refrigerant pipe or coil inside your indoor air handler. When this sensor reads out of range, is open, shorted, or cannot communicate with the control board, the unit throws P9 and may shut down to protect itself. This is a sensor and wiring issue, not a refrigerant or compressor problem.

## Common Causes

- **Failed TH5 thermistor** The pipe temperature sensor itself has failed open or shorted, causing the control board to see an impossible resistance value.
- **Loose or corroded connector** The plug connecting the TH5 sensor to the indoor control board has backed out, corroded, or developed a poor connection.
- **Damaged sensor wiring** The wire harness running from the thermistor to the PCB has been pinched, cut, or abraded during installation or service.
- **Indoor control board fault** If the sensor and wiring test good, the indoor PCB may have a failed input circuit that cannot read the TH5 signal correctly.

## Step-by-Step Fix {#fix}

1. **Confirm the P9 code** by entering diagnostic mode on the indoor unit or remote, and write down any other active codes.
2. **Turn off power at the breaker** serving the indoor unit and wait two minutes before removing the front cover and filter to access the control board area.
3. **Locate the TH5 thermistor** (a small bead sensor clipped or strapped to the refrigerant pipe near the indoor coil) and inspect its connector and wiring for damage, corrosion, or looseness.
4. **Disconnect the TH5 sensor plug** from the indoor PCB and use a multimeter in resistance mode to measure across the sensor leads, then compare the reading to the resistance chart in your model's service manual.
5. **If the thermistor reads open, shorted, or out of range**, order and install a replacement TH5 sensor, making sure the new sensor is securely clipped to the pipe in the original location.
6. **If the sensor tests good**, check continuity through the harness from sensor to board, inspect the board connector for bent pins or burn marks, and replace the indoor control board if the wiring is intact.
7. **Restore power and run a test cycle**, clearing the code from the system menu and verifying that the unit operates normally without re-triggering P9.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working with live electrical components or if you do not own a multimeter and cannot safely measure thermistor resistance. A pro will have the service manual resistance tables for your exact model, the correct replacement TH5 sensor in stock or on order, and the tools to verify whether the indoor board is at fault. If you replace the sensor yourself and the P9 code returns immediately, the problem is likely the control board or a hidden wiring fault that requires professional diagnosis.
