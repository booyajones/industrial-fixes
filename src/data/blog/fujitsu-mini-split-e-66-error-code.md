## Fujitsu E:66 Error Code — What It Means

The E:66 code (or E6 on some Fujitsu models) typically indicates a fault in the outdoor coil thermistor circuit. This sensor monitors the temperature of the outdoor heat exchanger and reports back to the control board. When the outdoor unit cannot read a valid temperature signal, the system shuts down and displays this error. The most common reason is an open sensor circuit, meaning the thermistor itself has failed, its wiring harness is damaged, or a connector has come loose or corroded. Less often, the outdoor PCB input that reads the sensor has failed.

## Common Causes

- **Failed outdoor coil thermistor** The sensor attached to the outdoor heat exchanger develops an open circuit or internal break, preventing the board from reading coil temperature.
- **Damaged sensor harness or wiring** The wiring between the outdoor coil sensor and the PCB is cut, abraded, pinched, or chewed by pests, causing an open circuit.
- **Loose or corroded connector** The sensor plug at the outdoor unit PCB or at the thermistor itself has backed out, corroded pins, or water intrusion breaking the electrical connection.
- **Outdoor PCB input failure** The main control board in the outdoor unit has a failed sensor input circuit, even though the thermistor and wiring are intact.

## Step-by-Step Fix {#fix}

1. Power off the system at the breaker and confirm the error code by checking the display or remote after power is restored, noting the exact model number from the outdoor and indoor unit labels.
2. Remove the outdoor unit service panel and visually inspect the thermistor, harness, and connectors for physical damage, rodent chewing, water marks, or loose plugs.
3. Locate the outdoor coil thermistor (a small bead sensor clipped or strapped to the outdoor coil) and disconnect it at the PCB connector, then measure resistance across the sensor leads with a multimeter to check for an open circuit or out-of-range reading.
4. Inspect the sensor connector pins and socket at the outdoor PCB for corrosion, bent terminals, or backed-out pins, clean or reseat the connector, and check harness continuity from sensor to board plug.
5. If the sensor and harness test good, consult your model's service manual to verify the PCB input circuit, checking for reference voltage (often 5 V on some Fujitsu models) and input signal integrity at the board.
6. Replace the failed component (thermistor, harness, or outdoor PCB), restore power, and run the unit through a full cooling and heating cycle to confirm the error does not return.
7. Clear the fault from the system memory by power-cycling or using the service mode if your model requires it, and monitor operation for at least 30 minutes.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working with live electrical components, if you cannot locate the outdoor coil thermistor, or if the code returns after you have replaced the sensor and verified harness continuity. Professional diagnostic tools and model-specific service manuals are often required to test PCB inputs and interpret Fujitsu fault codes accurately, especially since code formatting varies by model family. Refrigerant-side work or board-level repairs should always be performed by a qualified technician.
