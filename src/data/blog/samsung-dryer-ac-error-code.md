## Samsung Dryer AC Error Code — What It Means

The AC error code on a Samsung dryer indicates a failure in internal component communication between the electronic control boards. Samsung groups AC together with codes like Et, AE, EEE, AE4, AE3, AE5, E3, and 1 AC under the same communication-fault category. This is not a single-part failure but rather a breakdown in the signal path between the main control board and the user interface or other electronic components.

Samsung's official guidance is to restart the dryer first, as many AC codes clear after a power cycle. If the code persists after restart, the unit requires service to diagnose and repair the underlying communication fault, which typically involves control boards, wiring harnesses, or connector issues.

## Common Causes

- **Failing main control board (PCB)** The main control board is the most common component responsible for persistent AC codes when communication between boards breaks down.
- **Loose or corroded connector between control boards** Connectors linking the main PCB to the user interface board can work loose, corrode, or suffer pin-fit issues that interrupt signal paths.
- **Damaged wire harness** The interconnecting harness between the main board and UI board can sustain heat damage, fraying, or broken conductors that block communication.
- **Faulty display or user interface board** The UI board itself may fail and stop responding to or sending signals to the main control board.
- **Power supply disturbance or voltage irregularity** Transient voltage events, power outages, or incorrect supply voltage can disrupt board communication and trigger the AC code.

## Step-by-Step Fix {#fix}

1. **Power-cycle the dryer** by unplugging it (or switching off the breaker) for 60 seconds, then restore power and check if the AC code clears, as Samsung recommends a restart for this fault.
2. **Verify supply power and installation** if the code is intermittent or followed a power outage: confirm the outlet is correct for your model, no extension cord is in use, the power cord is seated fully, and supply voltage matches the dryer's rating.
3. **Unplug the dryer and remove the top or rear panel** to access the main control board and user interface board, following your model's disassembly sequence.
4. **Inspect all connectors and harnesses** between the main PCB and the UI board for looseness, corrosion, heat discoloration, or bent pins, and reseat each connector firmly.
5. **Test continuity and voltage** along the communication path between boards using a multimeter, consulting your model's service manual for pin assignments and expected values, to isolate whether the fault lies in wiring or a board.
6. **Replace the failed component** once isolated: most often the main control board, sometimes the UI board, or a damaged harness or connector, using the correct part number for your dryer model.
7. **Reassemble the dryer, restore power, and run a test cycle** to confirm the AC code is resolved and normal operation is restored.

## When to Call a Pro

Call a professional if the AC code returns after a power cycle and you are not comfortable opening the dryer cabinet, working with live voltage testing, or interpreting service-manual diagnostic charts. Communication faults require methodical isolation of boards, connectors, and harnesses, and misdiagnosis can lead to unnecessary part replacement. A qualified appliance technician has the service documentation, test equipment, and experience to pinpoint whether the main PCB, UI board, or wiring is at fault and can supply and install the correct OEM part for your exact model.
