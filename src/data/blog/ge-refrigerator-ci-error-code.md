## What this code means
The CI error code on GE refrigerators stands for "Check the icemaker for proper operation." In practice, this means the refrigerator has detected an ice maker communication error between the icemaker module and the main control board. When the icemaker circuit or module cannot communicate normally, ice production will stop until the fault is cleared or the failed component is replaced.

The code indicates that the control board is not receiving proper signals from the icemaker assembly. This can be caused by loose wiring, a failed icemaker module, a control board communication fault, or a mechanical jam in the icemaker mechanism. Some GE models may clear the code after a power reset if the fault was temporary, but a persistent CI code usually requires inspection of the icemaker harness and module.

## Before You Replace Anything

Homeowners often replace the entire icemaker assembly when the problem is just a loose connector or corroded pin. Before ordering parts, unplug the refrigerator and inspect the icemaker harness plug for full seating and clean metal contacts.

## Common Causes

- **Loose or disconnected icemaker wiring harness (~40%)** The plug between the icemaker module and the main board has worked loose, corroded, or lost contact due to vibration or ice buildup.
- **Failed icemaker module or assembly (~30%)** The icemaker's internal control circuit has failed and can no longer send or receive communication signals to the main board.
- **Ice jam or mechanical bind in the icemaker (~15%)** Ice has built up around the icemaker mechanism or ejector arm, preventing normal operation and triggering a communication fault.
- **Main control board communication fault (~10%)** The main control board has a failed communication circuit or memory glitch that prevents it from recognizing the icemaker module.
- **Temporary control glitch (~5%)** A brief power surge or software hiccup has set the code, and a power reset will clear it without further repair.

## Step-by-Step Fix {#fix}

1. **Verify your exact model number** from the serial tag inside the refrigerator, because GE error-code behavior and parts vary by platform.
2. **Cycle power** by unplugging the refrigerator for one to two minutes, then plug it back in and observe whether the CI code reappears on the display.
3. **Check icemaker operation** by confirming the icemaker is turned on (wire arm down or switch on) and that the ejector mechanism is not jammed by ice.
4. **Inspect the icemaker harness and connectors** for full seating, corrosion, damaged pins, or frayed wires where the module plugs into the refrigerator wiring.
5. **Clear any ice obstruction** in the icemaker mechanism if present, then allow the unit to cycle and recheck the code after one hour.
6. **Replace the icemaker module or assembly** if the code persists after reset and harness inspection, following your model's installation instructions.
7. **Replace the main control board** only if a known-good icemaker module still triggers the CI code, indicating a board-side communication failure.

## When to Call a Pro

Call a professional if you are not comfortable unplugging the refrigerator and removing the icemaker assembly, or if the code persists after you have replaced the icemaker module and you suspect the main control board. A technician has the service software and wiring diagrams to run platform-specific diagnostics, test communication signals between the icemaker and board, and determine whether the board itself has failed. Pros also carry multiple icemaker and board variants on the truck, so they can swap and test on the spot rather than ordering parts by trial. If your refrigerator is under warranty, call GE or an authorized servicer before replacing any parts yourself.

**Rough cost:** DIY runs about $80–180 for icemaker module, 30–60 min. A pro service call runs about $180–350 service call and module replacement.
