## Manitowoc Ice Machine E28 Error Code — What It Means

The E28 error code on a Manitowoc ice machine indicates an issue with the evaporator temperature sensor circuit. This sensor monitors the temperature of the evaporator plate during ice production and harvest cycles. When the control board cannot read the sensor properly, it throws the E28 fault and stops the machine to prevent unsafe operation.

The fault typically stems from a failed thermistor, loose or corroded wiring connections, or damage to the sensor cable. Because commercial ice machines rely on precise temperature readings to control refrigeration cycles, the system will not resume normal operation until the sensor circuit is restored. Consult your machine's service manual or wiring diagram for the exact sensor location and resistance values specific to your model, as these vary across Manitowoc's product line.

## Before You Replace Anything

Many operators replace the control board when the actual problem is a corroded connector or a failed thermistor. Test the sensor resistance with a multimeter against the model's specification table before ordering any parts.

## Common Causes

- **Failed evaporator thermistor (~50%)** The sensor itself has failed open or short, delivering no signal or an out-of-range reading to the control board.
- **Corroded or loose sensor connector (~25%)** Moisture in the machine environment causes corrosion at the plug, breaking electrical continuity.
- **Damaged sensor wiring (~15%)** The sensor cable has been pinched, cut, or abraded, interrupting the signal path.
- **Control board input failure (~8%)** The board's thermistor input circuit has failed and cannot read a good sensor.
- **Incorrect sensor installed (~2%)** A previous repair used the wrong thermistor type, leading to out-of-spec resistance readings.

## Step-by-Step Fix {#fix}

1. **Turn off power** to the ice machine at the breaker or disconnect switch and unplug the unit if accessible.
2. **Remove the front and side panels** as needed to access the evaporator compartment and locate the evaporator sensor, which is typically mounted on or near the evaporator plate.
3. **Disconnect the sensor connector** and inspect both the plug and socket for corrosion, moisture, or bent pins. Clean with electrical contact cleaner if needed.
4. **Measure sensor resistance** using a multimeter set to ohms. Consult your model's service manual for the correct resistance range at the current evaporator temperature.
5. **Replace the thermistor** if the reading is open, shorted, or out of spec. Use the exact OEM replacement part to match the control board's calibration.
6. **Inspect the sensor wiring** from the evaporator to the control board for cuts, abrasions, or pinch points, and repair or replace damaged sections.
7. **Reassemble the panels**, restore power, and observe the control display to confirm the E28 code has cleared and the machine enters a normal ice-making cycle.

## When to Call a Pro

Call a certified ice-machine technician if you are unfamiliar with refrigeration equipment, lack a multimeter and service manual, or if the error persists after replacing the sensor and inspecting wiring. Refrigeration circuits operate under pressure and require specialized tools and EPA certification for refrigerant work. A technician can also diagnose control-board faults that are not apparent from simple resistance checks and can verify that the machine returns to safe, compliant operation.

**Rough cost:** A pro service call runs about $150-350.
