## What this code means
The C-22 code on a Samsung oven indicates a sensor malfunction. Samsung groups C-20, C-21, and C-22 together as sensor-related faults in their official support documentation. This code typically points to an issue in the temperature sensor circuit, which may involve the sensor itself, its wiring and connectors, or the main control board's sensor input.

Samsung's first response is to turn the oven off and restart it. If the code remains, disconnect power for 30 seconds or more and then reconnect. If the code returns after these resets, the problem requires inspection of the sensor circuit and replacement of the failed component.

## Before You Replace Anything

Many people replace the main control board first when the actual fault is a failed temperature sensor or corroded connector. Test the sensor resistance and inspect all connectors before ordering a new board.

## Common Causes

- **Failed temperature sensor** The oven thermistor or temperature probe can fail open or short, sending incorrect readings to the control board.
- **Loose or corroded wiring** Connectors between the sensor and control board can work loose from heat cycling or develop corrosion that breaks the circuit.
- **Damaged sensor harness** Wires running to the sensor can fray, melt, or break where they pass through hot areas or sharp metal edges.
- **Control board sensor input failure** The main PCB's sensor circuit can fail even when the sensor itself tests good, though this is less common than sensor failure.

## Step-by-Step Fix {#fix}

1. **Turn off the oven** using the control panel, wait 10 seconds, then turn it back on to see if the code clears.
2. **Disconnect power** at the circuit breaker or by unplugging the oven for at least 30 seconds, then restore power and check if the code returns.
3. **Remove the back panel or lower access cover** (consult your model's service manual for location) to expose the temperature sensor and its wiring harness.
4. **Inspect the sensor connector** where it plugs into the control board or junction. Look for corrosion, burned pins, or a loose fit. Unplug it, clean contacts with electronics cleaner if needed, and reconnect firmly.
5. **Test the temperature sensor** with a multimeter set to resistance mode. Disconnect power first, unplug the sensor, and measure across its terminals. Consult your model's wiring diagram for the expected resistance range at room temperature.
6. **Replace the temperature sensor** if resistance is out of range, open, or shorted. Route the new harness away from sharp edges and high-heat zones, reconnect the plug, and reassemble panels.
7. **Test the repair** by restoring power, running the oven through a short bake cycle, and verifying that the C-22 code does not return. If it does, the control board's sensor input may be faulty and require professional replacement.

## When to Call a Pro

Call a qualified appliance technician if the code persists after you've checked connectors and the sensor tests within spec, because the fault likely lies in the main control board's sensor circuit. Also call a pro if you're not comfortable working around high-voltage wiring, removing oven panels, or using a multimeter. Ovens operate at 240 volts in most homes, and incorrect work can create shock or fire hazards. A technician has the service manual, correct replacement parts, and tools to safely diagnose whether the sensor, harness, or control board needs replacement.

**Rough cost:** DIY runs about $30-80 in parts, 45-90 min. A pro service call runs about $150-300.
