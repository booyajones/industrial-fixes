## GE Range F20 Error Code — What It Means

The F20 error on a GE range signals an over-temperature condition. GE states that F2 or F20 means the oven temperature has exceeded a preset threshold for an unknown reason. This fault can appear during normal baking or during a self-clean cycle. On many GE ovens the threshold is thought to be around 615°F in normal mode or 915°F during self-clean, though these figures come from repair technicians rather than official manufacturer specifications and will vary by model.

When the control board detects this over-temperature event it throws the F20 code and stops the heating cycle to prevent damage or fire. The fault indicates either that the temperature sensor is misreading, that the oven is actually overheating due to a stuck heating circuit, or that the control board logic has failed. A simple power reset can sometimes clear a temporary electronic glitch, but if the code returns the underlying cause must be found and repaired.

## Before You Replace Anything

Many homeowners replace the control board first. Always test the oven temperature sensor resistance with a multimeter before ordering any board. A bad sensor is cheaper and more common.

## Common Causes

- **Failed oven temperature sensor (~50%)** The sensor probe or its internal circuitry drifts out of specification and reports incorrect resistance values, causing the control to see a false over-temperature reading.
- **Stuck relay or shorted control board (~30%)** A broil or bake relay on the control board welds closed or shorts, keeping the heating element energized after the setpoint is reached and driving actual oven temperature too high.
- **Loose or corroded sensor wiring (~10%)** The harness connector at the sensor or control end develops a poor connection that causes erratic resistance readings and intermittent F20 faults.
- **Control board logic fault (~8%)** The oven control's microprocessor or firmware misinterprets correct sensor data or fails to respond to temperature feedback, triggering a false over-temperature alarm.
- **Temporary electronic glitch (~2%)** A voltage spike or static discharge corrupts the control's memory or registers, causing a one-time F20 code that clears after a power reset.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker or unplug the range. Wait at least five minutes to allow the control to reset and capacitors to discharge.
2. **Restore power** and observe whether the F20 code clears. If it does not return during a short test bake, monitor the oven for several cycles. If the code persists immediately, proceed to diagnostics.
3. **Locate the oven temperature sensor** inside the oven cavity, usually at the upper rear wall. The sensor is a metal probe about 1/4 inch in diameter with a wire harness running through the back panel.
4. **Disconnect the sensor harness** at the rear of the range. Use a multimeter set to ohms and measure the resistance across the sensor terminals at room temperature. Consult your model's service data for the correct resistance value. One repair source reports roughly 1,080 to 1,090 ohms on tested GE models, but this is not a universal GE specification.
5. **Replace the sensor** if the resistance reading is far outside the expected range or if the sensor shows an open or short. If the reading is correct, inspect the wiring harness and connectors for burns, corrosion, or loose pins.
6. **Check the control board and relays** if the sensor and wiring test good. Look for signs of a stuck broil or bake relay. Some models use a plug-in relay board section that can be replaced separately. If you lack the tools or wiring diagram, call a technician at this point.
7. **Reassemble and test** the oven with a controlled bake cycle at 350°F. Monitor the actual oven temperature with an independent oven thermometer. If the oven cycles normally and does not overheat or throw F20, the repair is complete.

## When to Call a Pro

Call a professional if you are uncomfortable working inside an electric range with 240-volt circuits, if the sensor tests good but the code persists, or if you do not have a wiring diagram to trace the relay outputs on the control board. A technician can isolate a stuck relay or control logic fault safely and will have access to factory service data and replacement relay assemblies that are not sold separately to consumers. Also call a pro if the oven has other symptoms such as not heating at all, repeated tripping of the breaker, or visible arcing inside the control cavity. These indicate more complex electrical faults that require professional diagnosis.

**Rough cost:** DIY runs about $30-80 in parts, 30-60 min. A pro service call runs about $150-300.
