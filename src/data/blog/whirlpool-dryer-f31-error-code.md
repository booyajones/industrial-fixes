## Whirlpool Dryer F31 Error Code — What It Means

The F31 error code on a Whirlpool dryer indicates a communication failure between the main electronic control board and the user interface control board. These two boards exchange signals constantly during operation, and when that data stream is interrupted or corrupted, the dryer halts and displays F31. The fault can stem from loose or corroded connectors, damaged wiring, or a failed board on either end of the circuit.

Because the code points to a communication breakdown rather than a specific sensor or mechanical failure, diagnosis requires inspecting the wiring harness and connectors that link the two boards. In many cases the problem is not a dead component but a poor electrical connection that can be corrected without replacing parts.

## Before You Replace Anything

Many owners replace the main control board or user interface board first when the real fault is a loose connector or pinched wire. Inspect and reseat every harness plug between the boards before ordering any board.

## Common Causes

- **Loose or corroded wiring harness connector (~50%)** Vibration over time can back connectors partway out of their sockets, and moisture or detergent residue can corrode pins and interrupt the signal path.
- **Pinched or damaged wire in the harness (~20%)** The ribbon cable or wire bundle between the boards can be cut, crushed, or worn through where it bends sharply or rubs against sheet metal.
- **Failed user interface control board (~15%)** The interface board that carries the display and buttons can suffer solder cracks or component failures that prevent it from answering the main control.
- **Failed main electronic control board (~10%)** The main board can lose the ability to send or receive messages due to relay failure, processor lockup, or power-supply sag.
- **Intermittent ground fault or voltage dip (~5%)** A poor cabinet ground or loose incoming power connection can cause brief voltage drops that scramble the communication bus and trigger the code.

## Step-by-Step Fix {#fix}

1. **Disconnect power** at the wall outlet or circuit breaker and leave the dryer unplugged throughout the repair.
2. **Remove the top panel** by sliding it back or lifting it after releasing clips or screws, depending on your model, to expose the control boards and wiring.
3. **Locate the wiring harness** that connects the user interface control (usually mounted on the console) to the main control board (typically on the blower housing or rear panel).
4. **Unplug every connector** in that harness, inspect each socket and pin for corrosion, burn marks, or pushed-back terminals, and spray with electronics contact cleaner if needed.
5. **Trace the entire length** of the harness and look for pinched insulation, cuts, or wires rubbing against sharp edges; repair any damage with electrical tape or replace the harness if multiple wires are compromised.
6. **Reseat all connectors firmly** until you hear or feel them click, then reassemble the cabinet and restore power to test.
7. **Run a short test cycle** and watch for the F31 code; if it returns, swap the user interface board first since it is usually easier to access and less expensive than the main control.

## When to Call a Pro

Call a technician if you are uncomfortable working with the dryer cabinet open or if you have already reseated connectors and inspected wiring without success. A pro can use a multimeter to measure continuity in each wire and can test voltage at the boards to isolate whether the fault is in the harness or in one of the boards. Also call if you discover evidence of arcing, melted plastic, or repeated fuse failures, since those symptoms suggest a deeper electrical problem that requires tracing circuits and possibly replacing the cabinet ground strap.

**Rough cost:** DIY runs about $80-180 in parts if a board is needed, 45-90 min. A pro service call runs about $150-300.
