## LG Refrigerator dH Error Code — What It Means

The dH code (shown as F dH or r dH) is a defrost failure. The board ran a defrost cycle but the defrost sensor never reached the expected temperature in the allotted time, so frost on the evaporator did not clear.

When defrost fails, frost piles up on the coil, airflow drops, and cooling suffers. The main parts behind dH are the defrost heater, the defrost sensor or thermal fuse, and sometimes a blocked drain or the main board.

## Common Causes

- **Failed defrost heater** A heater with an open element cannot melt the frost off the evaporator coil during the defrost cycle.
- **Bad defrost sensor or fuse** A defrost sensor or thermal fuse that opens up stops the cycle from completing and reaching temperature.
- **Heavy frost buildup** Frost packed on the coil from repeated failures takes longer to clear than the cycle allows.
- **Blocked defrost drain** A clogged drain line lets melt water refreeze and build ice that defrost cannot keep up with.
- **Loose wiring to the heater** A loose or corroded heater connector breaks the circuit so the heater never energizes.
- **Main control board fault** A board that does not drive the defrost cycle correctly can post dH even with good parts.

## Step-by-Step Fix {#fix}

1. Unplug the refrigerator for 2 minutes, then restore power and let it run a cycle to see if dH returns.
2. If frost is heavy, leave the doors open and thaw the unit fully (8 hours or more) with towels down for melt.
3. Pull the rear evaporator panel and inspect the coil and heater for frost and damage.
4. Test the defrost heater for continuity with a multimeter and replace it if the element reads open.
5. Test the defrost sensor and thermal fuse, and replace any part that does not read within spec.
6. Check the defrost drain for ice or debris and clear it so melt water can flow out.
7. If all parts test good and dH still returns, replace the main control board.

## When to Call a Pro

Call a technician if dH returns after you test or replace the heater and sensor, or if frost keeps building fast. Defrost diagnosis needs meter testing of several parts, and a misread can lead to replacing the wrong component.
