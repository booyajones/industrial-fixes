## Samsung Dryer Et Error Code — What It Means

The Et code on a Samsung dryer signals a communication error between internal components. Samsung groups this code with AC, AE3, AE4, AE5, E3, 1 AC, and EEE as internal component communication failures. The control board, user interface board, or wiring harness has lost the ability to talk to each other properly.

This is not a venting problem or a heating sensor fault. It is an electronic control issue. Most of the time the code appears after a power glitch or interrupted startup cycle. When it keeps coming back after a reset, one of the boards or the harness between them has failed.

## Common Causes

- **Temporary control glitch** A power interruption or incomplete startup can leave the control boards in a confused state that shows as Et.
- **Failed main control board** The main PCB can lose the ability to communicate with the display or other modules and trigger the code.
- **Faulty user interface board** The display and button panel may fail internally and stop responding to the main control.
- **Loose or damaged wiring harness** Corroded pins, loose plugs, or heat damage in the harness between boards can break the communication link.
- **Unstable power supply** Incorrect voltage, shared circuits, or use of an extension cord can cause electronic faults on Samsung dryers.

## Step-by-Step Fix {#fix}

1. **Power-cycle the dryer.** Unplug the unit or flip the breaker off for two minutes, then restore power and try a test cycle. Samsung recommends this as the first step to clear communication errors.
2. **Check the power supply.** Confirm the dryer is plugged directly into its own dedicated circuit with no extension cord and that the outlet delivers the correct voltage for your model.
3. **Run the built-in diagnostic.** Access the service mode per your model's manual to read stored fault codes and confirm the Et code is active, not a one-time glitch.
4. **Inspect wiring harness connections.** Open the cabinet and check every plug between the main control board and the user interface board for corrosion, loose fit, or burned pins.
5. **Test for intermittent faults.** Wiggle each harness connector gently while the dryer is in standby to see if the code reappears, which points to a bad connection rather than a failed board.
6. **Replace the main control board or UI board.** If the code returns after reset and all connections are clean and tight, replace the board most likely at fault based on your model's architecture and any additional codes in the diagnostic log.
7. **Call a Samsung-certified technician** if the code persists after power-cycle and you are not comfortable opening the cabinet or replacing boards yourself.

## When to Call a Pro

Call a professional if the Et code returns after a full power-cycle, if you see the code intermittently during every load, or if you are uncomfortable working inside the dryer cabinet with live electrical components. Samsung classifies persistent communication errors as faults that require service. A qualified technician will have the service manual, the correct replacement boards for your model, and the tools to run the full diagnostic suite without guessing which board has failed.
