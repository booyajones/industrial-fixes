## Goodman A3 Error Code — What It Means

The A3 code on a Goodman heat pump indicates a temperature sensor circuit problem. The control board is seeing an input that is electrically open, shorted, disconnected, or reading out of range. Because Goodman uses model-specific fault charts, the exact sensor (indoor coil, outdoor coil, or another location) depends on your unit. Always verify the code definition in your model's manual before ordering parts.

## Common Causes

- **Loose or disconnected sensor plug** The wiring connector at the thermistor or control board has backed out or corroded, breaking the circuit.
- **Open or shorted thermistor** The temperature sensor itself has failed internally, showing infinite resistance or near-zero resistance.
- **Damaged sensor harness** Wires have been cut, pinched, rubbed through by a fan blade, or damaged by water intrusion.
- **Sensor out of range** The thermistor has drifted due to age or heat damage and now reads outside the expected resistance window.
- **Control board input circuit failure** The sensor and wiring test good but the board's input path is bad, causing a false fault.

## Step-by-Step Fix {#fix}

1. **Identify the specific sensor** by looking up the A3 code in your unit's fault chart (on the control-board cover or in the installation manual).
2. **Power down the system** at the breaker and the outdoor disconnect, then remove the control-board cover or sensor access panel.
3. **Inspect the sensor connector and harness** for loose pins, corrosion, water damage, or wire breaks along the entire run from sensor to board.
4. **Measure the sensor resistance** using an ohmmeter across the sensor terminals, then compare the reading to the thermistor chart for your model (if the reading is open, shorted, or far out of range, replace the sensor).
5. **Check board-side continuity** by measuring from the board input terminals back to the sensor location to confirm the harness is intact.
6. **Replace the faulty component** (sensor, harness, or control board) as indicated by your testing, then restore power and run a full cycle to verify the code clears.
7. **Document the repair** by noting the measured resistance and the part replaced, so future service calls have a baseline.

## When to Call a Pro

Call a licensed HVAC technician if you do not have a multimeter or are uncomfortable working inside live electrical panels. If the sensor and wiring both test in range but the code returns after replacement, the control board likely needs diagnosis under power, which requires refrigerant and electrical expertise. Professionals also carry model-specific fault charts and thermistor resistance tables that are not always published online.
