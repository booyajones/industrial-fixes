## Whirlpool Microwave E11 Error Code — What It Means

The E11 error code on a Whirlpool over-the-range microwave indicates that the gas sensor has reported a problem to the main control board. According to Whirlpool, the issue may lie in the gas sensor itself or in the wiring and connectors that link the sensor to the control board. This fault can appear immediately when you power up the unit, during a cooking cycle, or after the microwave has been exposed to steam or heat.

[Jump to Fix](#fix)

## Common Causes

- **Failed gas sensor** The gas sensor has degraded or failed and is sending incorrect signals to the control board.
- **Loose or damaged wiring** The wiring harness or connectors between the gas sensor and control board are corroded, loose, or broken.
- **Control board circuit fault** The control board circuit that reads the gas sensor signal is defective and misinterpreting the sensor input.
- **Connector corrosion** Heat, moisture, or age has corroded the sensor connector terminals, creating an intermittent open circuit.

## Step-by-Step Fix {#fix}

1. **Turn off power at the circuit breaker** for a full minute, then restore power and monitor the display for one minute to see if the E11 code returns.
2. **Unplug the microwave** or switch off the breaker again, then remove the outer cabinet to access the gas sensor and wiring harness.
3. **Inspect the gas sensor connector** and wiring for signs of heat damage, corrosion, loose terminals, or breaks in the harness.
4. **Test the gas sensor** electrically using a multimeter and compare the reading to your model's service data (consult the technical sheet for the correct resistance specification).
5. **Check harness continuity** from the sensor connector all the way to the control board connector to rule out open or high-resistance paths.
6. **Test the control board circuit** if the sensor and wiring both check good, as the board may be misreading the sensor signal.
7. **Replace the failed component** (gas sensor, wiring harness, or control board) and reassemble, then run a test cycle to confirm the code is cleared.

## When to Call a Pro

Whirlpool recommends calling a qualified technician if the power reset does not clear the fault. Diagnosing E11 requires safe access to live and line-voltage circuits inside the cabinet, proper use of a multimeter, and comparison to model-specific sensor specifications that are not published in public documentation. If you are uncomfortable working around 120 V wiring, do not have the service manual for your model, or the code returns after a reset, schedule a service call rather than guessing at part replacement.
