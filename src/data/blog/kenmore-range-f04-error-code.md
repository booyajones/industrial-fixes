## Kenmore Range F04 Error Code — What It Means

The F04 code on Kenmore ranges (many of which are rebadged Whirlpool-family units) indicates a fault with the Electronic Oven Control board or the wiring connected to it. The control has detected a communication or circuit problem that prevents normal operation. On some models the code may also involve the touch panel or user interface board, particularly when F04 and F05 appear together.

This is not a heating-element fault. The control system itself has lost proper function, either because of a momentary electronic glitch, damaged wiring, or a failed board. The exact behavior varies by model, so always check your owner's manual or the wiring diagram inside the service panel for your specific unit.

## Before You Replace Anything

Homeowners often replace the entire Electronic Oven Control board before checking for loose or damaged wire harness connectors. Inspect and reseat every plug between the control and the touch panel first; many F04 codes clear after reconnecting a single loose connector.

## Common Causes

- **Glitched control logic (~45%)** A power surge, brownout, or internal electronic fault causes the control to lock into F04 and stop responding until power is cycled.
- **Loose or corroded wiring harness (~30%)** Vibration, heat, or age causes connectors between the Electronic Oven Control and the user interface or touch panel to work loose or corrode.
- **Failed Electronic Oven Control board (~20%)** The main control board itself has failed due to component wear, overheating, or voltage spike damage.
- **Faulty touch panel or user interface board (~5%)** On models with a separate UI assembly, the touch panel can develop a circuit fault that manifests as F04 or F05.

## Step-by-Step Fix {#fix}

1. **Turn off power at the circuit breaker** for the range and wait one full minute to allow the control to discharge and reset.
2. **Restore power** and observe the display for one minute; if F04 does not reappear, the reset was successful and no further work is needed at this time.
3. **If F04 returns immediately**, disconnect power again, remove the control-panel trim or back panel, and locate the Electronic Oven Control board and all associated wiring harnesses.
4. **Inspect every connector** between the control board and the touch panel or user interface for loose pins, heat discoloration, corrosion, or physical damage; reseat any suspect plugs firmly.
5. **Restore power** and test; if the code clears, secure the wiring and reassemble the panel.
6. **If F04 persists**, verify that your model uses a separate touch panel assembly; if so, disconnect and inspect the ribbon cable or interface plug, clean contacts if needed, and test again.
7. **Replace the Electronic Oven Control** if all wiring is intact and the code remains; order the board by your full Kenmore model number (usually inside the oven door or on the frame), disconnect power, photograph existing wire positions, transfer connectors to the new board, and test before reassembling the console.

## When to Call a Pro

Call a technician if you are uncomfortable working inside a 240-volt appliance, if you cannot confidently identify which connectors belong to the control circuit, or if you have replaced both the wiring and the control board and F04 still appears. A qualified service technician has the model-specific wiring diagram, can measure signal voltages at the control, and can determine whether a less common fault (such as a shorted relay or a problem in the clock circuit) is causing the code. Also call if your range is still under warranty, because self-repair may void coverage.

**Rough cost:** DIY runs about $150–350 for a control board, 30–60 min labor if you can power down safely. A pro service call runs about $200–450 including service call and board installation.
