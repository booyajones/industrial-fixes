## Frigidaire Dryer AL-22 Error Code — What It Means

AL-22 does not appear in published Frigidaire dryer error code documentation. The display may be showing a different code that has been misread, or the control board is displaying a non-standard fault. Frigidaire dryers commonly display codes like dr (door error) or E-series codes for sensor and control faults. Before assuming a major failure, verify the exact characters on the display and check that the door is fully closed and latched.

If the code persists after basic checks, the dryer may have a door-switch fault, a control-board communication error, or a wiring issue. Frigidaire recommends a hard power reset for persistent alarm codes. If the reset clears the code and normal operation resumes, no further action is needed. If the code returns, component testing is required.

## Common Causes

- **Misread or non-standard display** The code may actually be dr, E66, or another Frigidaire fault that looks like AL-22 on the panel.
- **Door not fully closed or obstructed** Clothing, lint, or a misaligned strike can prevent the door from latching and trigger a door-related error.
- **Faulty door switch** The switch may not signal the control board when the door is closed, causing a persistent fault.
- **Control board glitch or memory fault** A temporary software error can display unusual codes that clear after a power reset.
- **Wiring harness or connector fault** Loose or corroded connectors between the door switch and control can produce intermittent or invalid codes.
- **Failed main control board** If the board cannot correctly read or display standard codes, it may show alphanumeric strings not found in the manual.

## Step-by-Step Fix {#fix}

1. Write down the exact code as it appears on the display, including all letters, numbers, and spacing, and locate your model number on the dryer's data plate.
2. Check the door and strike for obstructions, lint buildup, or clothing caught in the seal, and confirm the door closes completely with an audible click.
3. Unplug the dryer or turn off the breaker for at least five minutes to perform a hard reset, then restore power and start a new cycle.
4. If the code returns, unplug the dryer and access the door-switch assembly (usually behind the front panel or near the door strike), disconnect the switch harness, and test continuity across the switch terminals with the door closed.
5. Inspect all wire connectors between the door switch and the main control board for corrosion, loose pins, or damage, and reseat each connection firmly.
6. If the door switch tests good and connections are clean, consult Frigidaire's service manual for your model number to confirm whether the displayed code is valid and to retrieve diagnostic steps for that specific fault.
7. Replace the control board only after confirming all switches, sensors, and wiring are functioning correctly, as non-standard codes often indicate board failure rather than a field device.

## When to Call a Pro

Call a qualified appliance technician if the code persists after a power reset and door inspection, if you cannot locate AL-22 in your model's service manual, or if you are uncomfortable testing electrical components with a multimeter. Technicians have access to Frigidaire's full fault-code database and can enter diagnostic mode to retrieve the true fault history. Control-board replacement requires careful handling of static-sensitive components and correct reassembly of the console, so professional service is recommended if wiring and switch tests do not resolve the issue.
