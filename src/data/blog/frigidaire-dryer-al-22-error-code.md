## Frigidaire Dryer AL-22 Error Code — What It Means

AL-22 does not appear in documented Frigidaire dryer error code lists or manufacturer support materials. Frigidaire dryers typically display codes such as E68 (stuck button), AD (Auto Dry mode indicator), or airflow warnings, but AL-22 is not among them. The display may have been misread (common candidates include AE, AF, or E codes), the model may use a proprietary code set not widely published, or a control board fault is generating an invalid code. Frigidaire recommends consulting the owner's manual for your specific model number to decode any unfamiliar display, since code definitions vary across product lines.

If the code appeared during a cycle interruption or after a power event, it may be a transient control glitch rather than a true fault. Frigidaire's standard troubleshooting for persistent unknown codes is to perform a hard reset by disconnecting power for several minutes, then restore power and observe whether the code returns. If the dryer will not run or the code reappears, the issue may be in the main control board, a stuck button on the control panel, or a sensor reporting invalid data.

## Before You Replace Anything

Do not replace the main control board before verifying the exact code and running the dryer's built-in diagnostics. Many Frigidaire dryers have a function test mode (entered by pressing specific button combinations) that will identify stuck keys, sensor faults, and wiring issues at no cost.

## Common Causes

- **Misread display or transposed digits (~40%)** The code shown may actually be a different alphanumeric sequence such as AE, AF, E22, or E68, all of which have documented meanings for Frigidaire dryers.
- **Control board generating invalid code (~25%)** A failing main electronic control can display garbage characters or codes not in the official list, often resolved by a power reset or board replacement.
- **Stuck or shorted button on control panel (~15%)** A button held down by debris or a failed membrane can cause the control to display an error and refuse to start, similar to the documented E68 code.
- **Corrupted firmware or temporary glitch (~10%)** Power surges or brownouts can cause the control to latch an undefined code until the dryer is fully power-cycled.
- **Non-standard or regional code variant (~10%)** Some Frigidaire models sold outside North America or private-label versions may use codes not published in widely available service literature.

## Step-by-Step Fix {#fix}

1. **Photograph the display** exactly as shown, including any flashing lights or additional symbols, so you have a reference for service lookup or phone support.
2. **Locate the model and serial number** on the dryer's rating plate (usually inside the door opening or on the rear panel) and write them down.
3. **Unplug the dryer** from the wall outlet or switch off the circuit breaker, then wait five full minutes to allow the control board capacitors to discharge completely.
4. **Restore power** and observe the display. If the code clears and the dryer operates normally, monitor it through several cycles to confirm the issue does not return.
5. **Enter the function test mode** if your owner's manual provides the button sequence (often a combination such as holding two buttons while powering on), then step through each test to identify stuck buttons or sensor faults.
6. **Inspect the control panel** for debris, moisture, or physical damage around each button. Press every button to confirm normal travel and audible clicks.
7. **Check the owner's manual or Frigidaire support** (Frigidaire.com/support) using your exact model number to see if AL-22 or a similar code is listed, or contact Frigidaire customer service with the model number and code for clarification.

## When to Call a Pro

Call a professional if the code persists after a power reset and you cannot find AL-22 in your model's documentation. A qualified appliance technician can access Frigidaire's full service manual and wiring diagrams for your specific model, run factory diagnostics, and determine whether the code indicates a control board fault, a mis-wired sensor, or a display error. Professional diagnosis is especially important if the dryer will not start at all, if you smell burning plastic, or if the code appeared after a recent move or installation, since wiring errors and voltage issues require safe, methodical testing. Expect to pay for a service call and diagnostic fee, which will be applied toward repair if you proceed.

**Rough cost:** DIY runs about $0-150 in parts if control panel or board is faulty, 30-60 min. A pro service call runs about $150-350 for diagnosis and control board replacement.
