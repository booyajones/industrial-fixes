## Frigidaire Range F19 Error Code — What It Means

F19 is not a Frigidaire factory error code found in published Frigidaire owner guidance. It is an LG range code that indicates an oven heating error, specifically that the oven user interface board cannot configure the oven relay board. If your range displays F19, verify the exact model number and brand on the unit label, because Frigidaire ranges use different fault codes like F9 for door-lock circuits. The code most often points to a communication failure between control boards or a faulty relay board.

## Common Causes

- **Failed board-to-board communication** The oven user interface board cannot configure or communicate with the oven relay board, triggering the heating error.
- **Loose or damaged wiring harness** The connector or harness between the UI board and relay board is mis-seated, corroded, or has broken terminals.
- **Faulty oven relay board** The relay board itself has failed and no longer responds to configuration commands from the UI board.
- **Faulty user interface board or touch panel** The control assembly or UIB has internal failures that prevent it from sending proper signals to the relay board.
- **Model identification error** The appliance may actually be an LG or rebranded unit displaying its native LG error code, not a true Frigidaire range.

## Step-by-Step Fix {#fix}

1. **Disconnect power** at the breaker, wait 30 seconds, then restore power to reset the control boards and clear transient faults.
2. **Verify the model number** on the rating plate inside the oven door or on the back panel to confirm whether the unit is Frigidaire, LG, or a rebranded model.
3. **Access the control boards** by removing the back panel or control housing, then unplug power again before touching any wiring.
4. **Inspect and reseat** the connector between the oven user interface board (look for MACS1 or MACS2) and the oven relay board (J3 or J4 connector), checking for corrosion or loose pins.
5. **Test the wiring harness** between those two boards for continuity and inspect for pinched, burned, or damaged wires.
6. **Replace the oven relay board** if the harness is intact and connections are clean, as this is the most common hardware failure for F19.
7. **Replace the user interface board and touch panel** if the fault persists after relay board replacement, then test the oven through a full preheat cycle.

## When to Call a Pro

Call a technician if you cannot positively identify your range brand and model, if the fault returns immediately after a breaker reset, or if you are uncomfortable working inside the control housing with live voltage nearby. Board-level diagnostics require a multimeter and familiarity with control-board connectors. If you replace the relay board and the code persists, the UI board is likely the culprit, and a professional can verify board voltages and configuration signals before you buy a second part. Because F19 is not a documented Frigidaire code, professional diagnosis is especially valuable to confirm whether you have the correct service literature and parts source for your actual appliance brand.
