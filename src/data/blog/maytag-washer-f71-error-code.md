## Maytag Washer F71 Error Code — What It Means

F71 is a model-dependent fault code that indicates a problem in the drive or motor control system. On some Maytag and Whirlpool-family platforms, F71 is described as a heartbeat failure, meaning the main control board is not receiving expected communication or input from the user interface board. On other models, F71 points to a motor control unit (MCU) or drive-system fault where the washer cannot properly regulate or confirm motor and basket operation. Because the exact meaning varies by platform, always verify against your model-specific tech sheet or service manual.

Common triggers include loose or damaged wiring between control boards, a defective user interface board, a failed main control board, or a faulty motor control unit. In at least one documented repair, F71 appeared when the basket would not engage in spin due to worn drive-hub splines, preventing the mechanical drive train from transmitting motion correctly. A transient software glitch can also cause F71, though a simple power reset will clear that scenario.

## Before You Replace Anything

Homeowners often replace the main control board or user interface board first. Check and reseat every harness connector between the control, user interface, and motor control sections before ordering any board.

## Common Causes

- **Loose or corroded wiring harness connector (~35%)** Plugs between the main control board, user interface, and motor control unit work loose or corrode, breaking the communication path.
- **Defective user interface board (~25%)** On heartbeat-failure platforms, the user interface board stops sending the expected signal to the main control.
- **Failed main control board (~20%)** The main control board itself loses the ability to process or generate the drive-system heartbeat signal.
- **Faulty motor control unit (MCU) (~15%)** The MCU or drive electronics fail to regulate the motor or report feedback to the main control.
- **Worn or broken drive hub or drive train (~5%)** Mechanical failure in the basket drive prevents the expected motor feedback, triggering the fault even though the electronics are intact.

## Step-by-Step Fix {#fix}

1. **Unplug the washer** at the outlet or flip the breaker off for at least two minutes to clear any transient fault in memory.
2. **Record your exact model number** from the label inside the door or on the back panel, then download the tech sheet or service manual to confirm the F71 definition for your platform.
3. **Remove the front or top panel** as required by your model to access the main control board, user interface board, and motor control unit.
4. **Inspect every wiring harness and connector** between the control boards and the motor control unit for loose plugs, broken wires, corrosion, or bent pins, and reseat each connector firmly.
5. **Run a manual diagnostic cycle** if your model supports one, observing whether F71 reappears immediately or only under load conditions.
6. **Test or replace the user interface board** first if the platform shows a heartbeat-failure fault and all harnesses are secure.
7. **Replace the main control board or motor control unit** only after confirming the wiring and user interface are intact, consulting the service manual for the correct part number and any calibration steps.

## When to Call a Pro

Call a qualified appliance technician if you are uncomfortable working inside the washer cabinet, if the diagnostic cycle or wiring inspection does not isolate the fault, or if you need to test live voltages on the control boards. A pro can use manufacturer diagnostic software and a multimeter to pinpoint whether the user interface, main control, or motor control unit has failed, saving you from replacing the wrong board. If the fault turns out to be a worn drive hub or other mechanical drive component, a technician has the tools to disassemble the basket and drive train safely.

**Rough cost:** DIY runs about $80–250 in parts, 45–90 min. A pro service call runs about $150–350.
