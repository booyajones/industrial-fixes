## LG Dishwasher Buttons Not Working — What's Happening

When buttons on your LG dishwasher stop responding, it means the control panel is not accepting input. This is a symptom, not a fault code. If the display shows "CL," the Control Lock (Child Lock) feature is active and is blocking all button presses until you unlock it. If you recently held the Start button for about three seconds, the dishwasher may be in a cancel or drain cycle, during which the panel shows dashes and ignores input until the drain finishes.

If the panel lights up but buttons still do nothing, and no lock indicator or cycle is running, the problem is usually in the user interface assembly, the main control board, or the power supply. LG guidance treats unresponsive buttons as a troubleshooting condition that requires checking lock status, cycle state, and power before moving to component-level diagnosis.

## Most Likely Causes

- **Control Lock enabled** LG documents this as the top cause when buttons are blocked and the display shows CL.
- **Dishwasher in cancel or drain state** Holding Start for three seconds triggers a cancel cycle that shows dashes and ignores input until draining completes.
- **Cycle already started or option incompatible** Once a wash cycle begins, some settings cannot be changed, and certain options are not available with every cycle.
- **No power or breaker tripped** If the panel is dark or flickers, the unit may have lost supply voltage or the breaker is off.
- **Failed user interface or touchpad assembly** The button membrane, console, or touchpad can fail from wear, moisture intrusion, or physical damage.
- **Main control board failure** The control board may fail to send voltage to the touchpad or stop interpreting button presses, though this is less common than panel failures.
- **Loose or corroded wiring harness** Connectors between the console and main board can work loose, corrode, or suffer damage, breaking the signal path.

## How to Diagnose and Fix {#fix}

1. Check the display for CL and disable Control Lock by holding Half Load + Energy Saver for three seconds (consult your model's manual for the exact combination if different).
2. Wait for any active cancel or drain cycle to finish if you recently held Start for three seconds and the panel shows dashes.
3. Verify the dishwasher has power by checking that the breaker is on, the plug is secure, and the display lights up when you press Power.
4. Test whether all buttons are dead or only specific keys fail, since partial failures point to the touchpad while total failures suggest power or board issues.
5. Unplug the unit and remove the door panel to inspect the console assembly and wiring harness for loose connectors, corrosion, moisture, or visible damage.
6. Check continuity and seating of the ribbon cable or harness between the user interface and the main control board, reseating any loose connections.
7. If the panel has power, no lock is active, and connections are clean, use model-specific diagnostics if available or replace the console assembly first, since it fails more often than the main board.
8. If a new console does not restore function and power is confirmed, test or replace the main control board as a last step.

## When to Call a Pro

Call a technician if you have confirmed power, cleared Control Lock, and reseated all connectors but buttons still do not respond. Diagnosing whether the console or the main board has failed requires multimeter testing and familiarity with your model's wiring diagram. If you are not comfortable removing the door panel, tracing harness connections, or handling live voltage during testing, professional service will save time and avoid misdiagnosis. LG-adjacent repair sources warn that control boards are frequently replaced unnecessarily, so an experienced tech can pinpoint the actual failed component and avoid wasting money on the wrong part.
