## Cooper&Hunter E4 Error Code — What It Means

The E4 error code on Cooper&Hunter mini splits typically indicates a problem with one of the unit's temperature sensors or the signal path between the sensor and the control board. The exact definition can vary across Cooper&Hunter model families, so always cross-check with your unit's manual. In most cases, E4 points to a faulty indoor or outdoor thermistor, a loose connector, or damaged wiring between the sensor and the main board. Less commonly, the control board itself may be failing to read an otherwise healthy sensor circuit.

## Common Causes

- **Loose or corroded sensor connector** The plug connecting the temperature sensor to the control board has worked loose, collected moisture, or developed corrosion that interrupts the signal.
- **Failed thermistor** The NTC temperature sensor itself has drifted out of specification or failed open or shorted.
- **Damaged sensor wiring harness** The wire run between the sensor and the board has been pinched, cut, or melted, breaking continuity or causing a short.
- **Dirty air filter or blocked coil restricting airflow** Severely restricted airflow can cause abnormal temperature readings that the board interprets as a sensor fault.
- **Control board input failure** The indoor PCB sensor input circuit has failed even though the sensor and wiring are within specification.

## Step-by-Step Fix {#fix}

1. **Power off the mini split** at the disconnect switch or breaker and wait two minutes for capacitors to discharge.
2. **Remove the indoor unit cover and filters** and inspect for heavy dust or blockage on the evaporator coil and blower wheel that could cause abnormal temperature behavior.
3. **Locate the temperature sensor** (a small black thermistor with two wires) clipped to the evaporator coil or mounted near the control board, and check that the connector is fully seated and free of corrosion.
4. **Measure the sensor resistance** with a multimeter set to ohms by unplugging the connector and probing the sensor leads. Consult your model's service manual for the correct resistance range at room temperature.
5. **Inspect the sensor harness** for visible damage, pinches, or melted insulation along the entire wire run between the sensor and the indoor board.
6. **Replace the temperature sensor** if the resistance is open, shorted, or significantly out of range. If the sensor tests good, reconnect it and power on the unit to see if reseating the connector clears the code.
7. **Replace the indoor control board** if the sensor and harness both test within specification but the E4 code persists after reconnecting and cycling power.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working inside live equipment, if you do not own a multimeter or cannot interpret resistance readings, or if you have replaced the sensor but the E4 code returns immediately. Also call a pro if your unit is still under warranty, since DIY repairs can void coverage. A technician will have model-specific resistance charts, the correct replacement sensors on the truck, and the tools to verify refrigerant charge and airflow if the root cause is more complex.
