## Electrolux Washer E60 Error Code — What It Means

The E60 error code on an Electrolux washing machine indicates a heating fault. The washer has detected that water is not heating properly during the wash cycle. Electrolux groups E60 with related codes E61 and E62, all pointing to problems in the heating system. The machine will usually stop mid-cycle or fail to complete a hot wash program when this code appears.

[Jump to Fix](#fix)

## Common Causes

- **Defective heating element** The electric heater that warms wash water has burned out or developed an internal break.
- **Faulty temperature sensor (NTC)** The thermistor that monitors water temperature has drifted out of range or failed open or short.
- **Blocked drain or dirty pump filter** Poor drainage can prevent the machine from completing the cycle correctly and trigger heating faults in Electrolux's diagnostic logic.
- **Water inlet valve or pressure sensor issue** If the tub does not fill to the correct level, the heating step cannot proceed and the machine may log E60.
- **Wiring or connector damage in the heating circuit** Corrosion, heat damage, or loose connections between the heater, sensor, and control board can interrupt heating signals.

## When to Call a Pro

Call a qualified appliance technician if you are uncomfortable working with live electrical components or if the heating element and temperature sensor both test within normal ranges but the E60 code persists. A technician can run factory diagnostic modes, test the pressure switch and inlet valve under load, and evaluate the main control board for relay or triac faults that prevent the heating circuit from energizing. Professional service is also recommended if you find burned wiring or corrosion inside the machine that suggests a deeper electrical fault.
