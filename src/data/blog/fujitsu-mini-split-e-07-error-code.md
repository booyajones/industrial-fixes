## Fujitsu E:07 Error Code — What It Means

The E:07 error code on a Fujitsu mini-split indicates an outdoor unit pipe sensor short circuit. The outdoor control board is reading an impossible low-resistance value from the outdoor coil or pipe thermistor, which means the system cannot trust the temperature input it needs to regulate refrigerant flow and compressor operation. Because the sensor circuit appears shorted, the unit shuts down to protect itself. This is a sensor-circuit fault, not a refrigerant or communication problem.

## Common Causes

- **Failed outdoor pipe thermistor** The outdoor coil temperature sensor itself has shorted internally, which is the most common cause of E:07.
- **Damaged or pinched sensor harness** Wiring to the outdoor sensor has been rubbed, pinched, or partially shorted by installation damage or rodent activity.
- **Corroded or loose sensor connector** The plug at the sensor or board input has become contaminated, corroded, or backed out, creating an intermittent short.
- **Water intrusion into the sensor circuit** Moisture from rain, condensation, or a drain issue has entered the sensor housing or connector and shorted the circuit.
- **Outdoor control board input failure** The sensor input circuitry on the outdoor PCB has failed, though this is less common than sensor or wiring faults.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working with line voltage, if you do not have a multimeter and the experience to measure thermistor resistance accurately, or if the fault returns after you replace the sensor and repair the wiring. Board-level diagnosis and refrigerant-side work require EPA certification and specialized tools. If the unit is under warranty, contact Fujitsu or your installer before opening any panels to avoid voiding coverage.
