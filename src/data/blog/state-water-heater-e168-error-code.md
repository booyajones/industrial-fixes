## State Water Heater E168 Error Code — What It Means

The E168 error code is not widely documented in official State Water Heaters literature, but in similar control systems it signals an electronic control board lockout or a generic fault condition. This means the control board has detected a problem but cannot identify the exact cause through its diagnostics. The code may appear after a power interruption, after a related fault has occurred, or when a component such as the igniter, gas valve, wiring, or the PCB itself has failed. The control locks out operation as a safety measure until the underlying issue is resolved.

## Common Causes

- **Interrupted or unstable power supply** A voltage spike, brownout, or loss of power can trigger a control lockout and generate the E168 code.
- **Preceding fault history stored in memory** The control board may display E168 after another fault has occurred and been logged, masking the original problem.
- **Failed igniter or electrode assembly** A worn spark igniter or fouled electrode prevents ignition and can cause the board to lock out with a generic fault code.
- **Faulty gas valve or wiring connections** A defective gas valve or loose wiring harness can prevent normal operation and trigger a control fault.
- **Defective control board (PCB)** Internal component failure on the PCB itself will produce an unidentified fault code and require board replacement.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker or disconnect, wait 60 seconds, then restore power to reset the control board and clear temporary faults.
2. **Check the display** for any additional or preceding error codes that may indicate the root cause, and record them before proceeding.
3. **Verify incoming voltage** at the unit with a multimeter, confirming supply is within the acceptable range (typically around 230 V ± 10% for electronic controls).
4. **Inspect all wiring and connectors** at the control board, gas valve, igniter, and other components for corrosion, looseness, or visible damage.
5. **Test the igniter and electrode** for proper spark and resistance according to your model's specifications, replacing if fouled or damaged.
6. **Examine the gas valve** for proper operation and listen for the click when the board calls for heat, testing coil resistance if your model provides values.
7. **Replace the control board (PCB)** if all other components test normal, the fault persists after reset, and no other error code points to a specific part.

## When to Call a Pro

Call a licensed technician if you are uncomfortable working with live voltage, gas connections, or electronic diagnostics. Professional help is also recommended if the fault returns after reset, if you find multiple error codes stored in memory, or if component testing requires equipment or specifications you do not have. A qualified service provider can retrieve detailed fault logs, perform voltage and resistance measurements safely, and make sure any replacement control board or gas valve is installed and configured correctly for your exact State water heater model.
