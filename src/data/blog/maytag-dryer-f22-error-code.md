## Maytag Dryer F22 Error Code — What It Means

The F22 code on a Maytag dryer indicates a problem with the exhaust or outlet thermistor circuit. The dryer has detected that the temperature sensor on the exhaust path is returning faulty data or has lost electrical continuity. When this happens, the control board cannot safely manage heat, so the dryer will often run for about a minute and then stop. The code may also appear after a power interruption, but if it returns after a reset, the thermistor circuit needs inspection.

Maytag's official troubleshooting procedure starts with a power reset: turn off the breaker for five minutes, restore power, and run a timed dry cycle to see if the code returns. If F22 reappears, the problem is real and typically points to a failed thermistor, a loose or corroded connector, damaged wiring between the sensor and control board, or in rare cases a faulty electronic control board.

## Before You Replace Anything

Many people replace the main electronic control board first. Always test the thermistor resistance with a multimeter and inspect the harness connectors before replacing the board, since a loose plug or bad sensor is far more common.

## Common Causes

- **Failed exhaust thermistor (~55%)** The outlet temperature sensor itself has drifted out of spec or opened internally, returning no reading or an incorrect resistance to the control.
- **Loose or corroded wiring harness connections (~25%)** The plug at the thermistor or at the control board has worked loose, become corroded, or lost pin contact, breaking the signal path.
- **Damaged or shorted thermistor wiring (~10%)** The harness between the thermistor and control has pinched insulation, broken wires, or a short to ground.
- **Electronic control board fault (~8%)** The control itself has failed in the thermistor input circuit, even though the sensor and wiring test good.
- **Temporary power interruption or reset issue (~2%)** A brief outage or voltage sag caused the control to log a false fault that clears with a breaker reset.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker for at least five minutes, then restore power and start a timed dry cycle to see if F22 returns.
2. **Unplug the dryer** and pull it away from the wall so you can access the rear panel or lower front access area, depending on your model.
3. **Locate the exhaust thermistor**, typically mounted on the blower housing or exhaust duct near the outlet, and inspect its wiring harness and connectors for looseness, corrosion, or damage.
4. **Disconnect the thermistor plug** and use a multimeter set to ohms to measure resistance across the sensor terminals at room temperature (repair sources cite roughly 10 kΩ, but consult your model's service sheet for exact values).
5. **Replace the thermistor** if the reading is open, shorted, or far from spec, or **replace the harness** if you find broken or shorted wires.
6. **Reassemble the dryer**, restore power, and run a timed dry cycle to verify that F22 does not return.
7. **Replace the main electronic control board** only if the thermistor and harness both test good but the code persists.

## When to Call a Pro

Call a technician if you are not comfortable using a multimeter to measure resistance, if you cannot access the thermistor location on your dryer model, or if the thermistor and harness both test good but the code returns. A professional can trace the circuit end-to-end, verify control-board input voltage, and order the correct board by serial number. Also call if the dryer uses gas and you smell gas or suspect a related valve issue, even though F22 itself is an electrical sensor fault.

**Rough cost:** DIY runs about $15–40 in parts, 30–60 min. A pro service call runs about $150–250.
