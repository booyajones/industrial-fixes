## Maytag F73 Error Code — What It Means

The F73 error code on Maytag front-load washers indicates a communication breakdown between the front user interface (console) and the main control board. Field reports and service technicians describe this as a signal fault along the wiring harness or a failure in one of the two control boards. Maytag does not list F73 explicitly in its published front-load error table, so the exact meaning can vary by model, but the pattern points consistently to a UI-to-CCU communication issue.

The fault often appears after a power interruption or can develop gradually from corroded connectors or a failing interface board. Because the two boards must exchange data constantly to run cycles, any break in that path will lock the machine and display F73.

## Common Causes

- **Loose or corroded wiring harness connections** Terminals between the user interface and main control board can back out, corrode, or develop poor contact over time.
- **Failed user interface board** The front console control board may lose its ability to send or receive communication signals to the CCU.
- **Failed main control board (CCU)** If the wiring is intact and the UI board is good, the main control board itself may no longer process communication from the console.
- **Power glitch or control lockup** A brief outage or voltage spike can freeze one or both boards and trigger a false communication fault that clears with a reset.
- **Damaged wiring harness** Physical wear, pinching, or chafing can break internal conductors in the ribbon or multi-pin cable between the boards.

## Step-by-Step Fix {#fix}

1. {'text': '**Unplug the washer** and wait at least 5 minutes to allow both control boards to fully discharge and reset, then restore power and test for the code.'}
2. {'text': '**Remove the top or front panel** to access the user interface board and the wiring harness that runs to the main control board near the bottom or rear of the cabinet.'}
3. {'text': '**Inspect the harness connectors** at both the UI board and the main control board for signs of corrosion, burned pins, melted plastic, or loose terminals.'}
4. {'text': '**Disconnect and reseat every connector** along the communication path, pressing firmly until you feel each lock click, then restore power and retest.'}
5. {'text': '**Check both control boards** for visible burn marks, swollen capacitors, or cracked solder joints that would indicate electrical damage.'}
6. {'text': '**Replace the user interface board** if the harness and connectors are sound but the F73 persists, since field experience shows the UI side fails more often in communication faults.'}
7. {'text': '**Replace the main control board (CCU)** if a new UI board does not clear the code, then run a test cycle to confirm communication is restored.'}

## When to Call a Pro

Call a qualified appliance technician if you are uncomfortable working inside a live-voltage cabinet, if the 5-minute power reset and connector reseating do not clear the code, or if you lack a multimeter and the experience to safely trace communication signals between boards. Because F73 is not formally documented in Maytag's published front-load error list, a technician with access to model-specific service software can confirm the exact fault path and avoid unnecessary part swaps. Professional diagnosis is also recommended if your washer is still under warranty, since self-repair may void coverage on control boards.
