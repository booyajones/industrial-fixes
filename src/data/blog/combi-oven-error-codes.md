## Commercial Combi Oven Error Codes — What They Mean

Commercial combi ovens from Rational (SelfCookingCenter, iCombi) and Alto-Shaam (Vector, Combitherm) are standard equipment in high-volume commercial kitchens. They display diagnostic codes or error messages when faults are detected.

## Rational SelfCookingCenter / iCombi Error Codes

| Code | Meaning |
|------|---------|
| E01 | Temperature sensor fault |
| E02 | Humidity sensor fault |
| E03 | Core temperature probe fault |
| E10 | Steam generator fault |
| E20 | Fan motor fault |
| E30 | Drain blocked |
| E40 | Water supply fault |

### Most Common Rational Fixes

**E10 — Steam Generator:** The steam generator has a scale buildup problem or heating element failure. Run a descaling cycle with Rational descaler. If E10 persists, the heating element may have failed.

**E20 — Fan Motor:** Fan motor overload or failure. Check for foreign objects in the oven chamber blocking the fan, or bearing failure on the motor.

**E30 — Drain Blocked:** The oven drain is blocked with food debris or scale. Clean the drain filter and flush the drain path with hot water.

**E40 — Water Supply:** Check water supply pressure (40–80 PSI required), inlet valve, and water filter saturation.

## Alto-Shaam Combi Error Codes

| Code | Meaning |
|------|---------|
| E-01 | Cabinet temperature sensor fault |
| E-02 | Steam temperature sensor fault |
| E-10 | Heating element fault |
| E-20 | Fan fault |
| E-30 | Water supply fault |

### Most Common Alto-Shaam Fixes

**E-10 — Heating Element:** Check element continuity (should read 10–50Ω depending on wattage). Open circuit = replace. Verify contactor operation.

**E-20 — Fan Fault:** Inspect fan for obstruction. Check motor continuity and capacitor.

**E-30 — Water Supply:** Verify supply pressure and inlet valve operation.

Combi oven electrical repairs involve high-voltage heating elements and control boards. Rational and Alto-Shaam authorized service should handle component-level repairs.
