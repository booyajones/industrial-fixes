## Manitowoc Ice Machine E25 Error — What It Means

The E25 error code on a Manitowoc ice machine typically indicates a problem with one of the temperature or level sensors, or their associated wiring. The exact sensor involved can vary by model, so consult your owner's manual or the wiring diagram inside the service panel to identify which probe the control board is flagging. Common candidates include the bin temperature probe, evaporator probe, or water level sensor.

When the control board cannot read a valid signal from the sensor (whether due to an open circuit, short, or out-of-range reading), it halts ice production and displays E25. The machine will not resume normal operation until the fault is corrected and the code is cleared.

## Before You Replace Anything

Many owners replace the sensor or control board immediately. First check every wire connection at both ends of the suspect sensor; a loose or corroded pin often mimics a failed sensor and costs nothing to fix.

## Common Causes

- **Loose or corroded sensor connector (~40%)** Vibration or moisture can loosen multi-pin connectors or cause corrosion on the terminals, breaking the circuit.
- **Failed temperature or level probe (~35%)** Probes fail over time from mineral buildup, freezing damage, or internal thermistor drift that puts resistance out of spec.
- **Damaged sensor wiring (~15%)** Wires can be pinched by panels, chafed against sheet metal edges, or nicked during previous service.
- **Control board misreading or fault (~10%)** Less often, the board itself develops a bad input channel or memory corruption that reports a false sensor error.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the breaker or unplug the ice machine to make sure safe access to internal components.
2. **Remove the front panel or service cover** to expose the control board and sensor wiring; consult your model's service manual for fastener locations.
3. **Locate the sensor connectors** by following the harness from the control board; note which sensors are flagged in your manual's E25 troubleshooting section.
4. **Inspect each connector** for corrosion, moisture, or loose pins; disconnect and spray with electrical contact cleaner if needed, then reseat firmly.
5. **Trace the sensor wiring** along its entire run, checking for pinch points, chafing, or breaks; repair or replace any damaged sections with the same gauge wire.
6. **Test sensor resistance** with a multimeter set to ohms; disconnect the sensor, measure across its terminals, and compare the reading to the specification table in your manual.
7. **Replace the faulty sensor** if resistance is out of range or the probe shows physical damage; secure the new sensor in the same location and reconnect the harness.
8. **Clear the error code** by powering the machine off for 60 seconds, then restore power; the display should reset and begin a normal ice-making cycle if the fault is resolved.

## When to Call a Pro

Call a refrigeration technician if you are uncomfortable working with 120V wiring or if the error persists after replacing the sensor and inspecting all connections. A pro can use diagnostic software to read board inputs directly, verify the control board is functioning correctly, and check refrigerant system parameters that may affect sensor readings. Also call if you suspect a sealed-system issue, such as low refrigerant or compressor faults, which require EPA-certified handling.

**Rough cost:** DIY runs about $50-150 in parts, 30-60 min. A pro service call runs about $200-400.
