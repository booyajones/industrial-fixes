## What this code means
Frigidaire labels F40 (and F41) as Cooktop Lock Out on electric ranges and cooktops. The code tells you that the cooktop is locked and normal burner operation is disabled. This is a lock-state or lockout communication fault, not a temperature or burner-performance problem.

Frigidaire's owner support instructs you to cancel the oven lock feature by holding the OFF button for 6 seconds on applicable models. If the code persists after that, Frigidaire recommends a power reset. When the fault continues after reset, the problem is usually a stuck key, a wiring issue between the console and control board, or a failed electronic component in the lockout path.

## Before You Replace Anything

Many owners replace the main control board first, but a stuck or contaminated touchpad key often causes a false lock signal. Clean the console surface and inspect for stuck buttons before ordering any board.

## Common Causes

- **Lock feature active (~40%)** The control lock or cooktop lock was turned on intentionally or by accident and was not cleared using the correct button sequence.
- **Stuck or dirty keypad (~30%)** A stuck button, spill residue, or moisture on the console is falsely sending or holding the lock command to the control.
- **Loose wiring or connector (~15%)** The ribbon cable or harness between the user interface and the main control board is loose, corroded, or damaged, causing the lockout state to persist or be misreported.
- **Failed user interface board (~10%)** The touchpad or console board has an internal fault that continuously signals a lock condition even when no button is pressed.
- **Defective main control board (~5%)** The main electronic control has a failed lock-control circuit that keeps the cooktop in lockout mode or cannot clear the fault after a reset.

## Step-by-Step Fix {#fix}

1. **Hold the OFF button for 6 seconds** to cancel the lock feature on models that use this sequence. Check your owner's manual for any model-specific unlock procedure.
2. **Perform a power reset** by unplugging the range or flipping the circuit breaker off for at least 30 seconds, then restore power and check whether the code clears.
3. **Inspect the console for stuck keys or contamination**. Wipe the touchpad surface with a slightly damp cloth to remove spills, grease, or moisture that might be bridging contacts.
4. **Check the ribbon cable and harness connections** between the user interface and the main control board. Reseat any loose connectors and look for corrosion, bent pins, or heat damage.
5. **Test with the console disconnected** (if you are comfortable working with unpowered electronics). Unplug the range, disconnect the user-interface ribbon from the control board, and restore power briefly. If the code vanishes, the console is faulty.
6. **Replace the user interface or touchpad assembly** if cleaning and reseating do not resolve the fault and testing points to the console.
7. **Replace the main control board** only if the console and all wiring test good, the code persists after reset, and you have ruled out every external cause. For new installations within 30 days, contact your installer before replacing parts.

## When to Call a Pro

Call a technician if you are not comfortable disconnecting the console or control-board connectors, if the code returns immediately after every reset, or if you have already replaced the user interface and the fault persists. A pro can test communication between the console and control, verify lock-circuit voltage on the board, and trace wiring faults. For ranges installed within the past 30 days, Frigidaire directs you to contact the installer first. After 30 days, schedule service through Frigidaire or an authorized repair shop to avoid guesswork and unnecessary part replacement.

**Rough cost:** DIY runs about $50–$200 in parts (console or board), 30–90 min. A pro service call runs about $150–$350 including service call and part.
