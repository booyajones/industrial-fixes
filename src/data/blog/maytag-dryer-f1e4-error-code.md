## Maytag Dryer F1E4 Error Code — What It Means

F1E4 does not appear in Maytag dryer documentation as a recognized fault code. This code is documented for Maytag and Whirlpool over-the-range microwaves, where it signals an appliance control board (ACU) failure or associated wiring problem. It also appears on Whirlpool all-in-one washer/dryer combination units as a main relay error. If you see F1E4 on a conventional Maytag dryer display, the code may have been misread (common look-alikes include F01, F1E1, or other control codes), or your unit may be a washer/dryer combo rather than a standalone dryer. Verify your exact model number on the data plate inside the door or on the frame. If your appliance is actually a microwave or a combo unit, the manufacturer directs you to power-cycle the unit and replace the control board if the fault returns.

## Common Causes

- **Misread error code** F1E4 is not a dryer code, so the display may show F01, F1E1, or another similar fault that was misidentified.
- **Wrong appliance type** Your unit may be a washer/dryer combination or a microwave, both of which use F1E4 to flag control board or relay problems.
- **Control board failure (microwave/combo units)** The appliance control board has failed or lost communication with critical circuits.
- **Wiring or connector problem** Damaged wiring or loose connectors between the control board and other components trigger the fault.
- **Main relay fault (washer/dryer combo)** The main relay on the control board has stuck or failed, preventing normal operation.

## Step-by-Step Fix {#fix}

1. **Confirm your appliance type and model number.** Check the data plate inside the door or on the cabinet frame to verify whether you have a standalone dryer, a washer/dryer combo, or a microwave.
2. **Double-check the displayed code.** Look closely at the display to confirm it reads F1E4 and not F01, F1E1, or another similar code, which are actual dryer faults.
3. **Unplug the appliance or switch off the dedicated circuit breaker.** Leave power disconnected for at least five minutes to allow the control board to reset.
4. **Restore power and run a test cycle.** If the code clears and does not return, the reset was successful.
5. **Inspect wiring and connectors at the control board** (for microwave or combo units). Look for burned, loose, or corroded terminals and repair or replace damaged wiring.
6. **Replace the appliance control board** if the code returns after a power reset and wiring is intact. This is the factory-recommended repair for persistent F1E4 faults on microwaves and combo units.
7. **Contact Maytag or consult the tech sheet** for your exact model if you have confirmed a standalone dryer and the code persists. The tech sheet is usually located behind the lower front panel or inside the control console.

## When to Call a Pro

Call a qualified appliance technician if you have confirmed your model number and the F1E4 code appears on a standalone dryer, since this code is not documented for dryers and may indicate a deeper electronic fault or a display error. Also call for service if you own a washer/dryer combo or microwave and the code returns after a power reset, as control board replacement requires disassembly and live-voltage work. If you are uncomfortable working with 120- or 240-volt circuits or removing cabinet panels, professional diagnosis will save time and prevent safety hazards.
