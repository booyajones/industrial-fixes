## Maytag Range F3 Error Code — What It Means

The F3 error code on a Maytag range or oven indicates the electronic control has detected a fault in the oven temperature sensing circuit. This is not a generic overheat alarm. Instead, the control board cannot read the oven temperature sensor probe correctly, either because the sensor has failed, the wiring between the sensor and control is damaged, or the control board's input circuitry has a problem.

Maytag's product help for the related F3 E1 code directs you to check the lower oven temperature sensor, control, or associated wiring. The fault may be intermittent or constant depending on whether a solder joint is cracked or a wire is loose. In some cases resetting power will clear the code temporarily, but the underlying hardware issue will cause it to return.

## Before You Replace Anything

Many people replace the electronic control board first when the real fault is a bad sensor or loose connector. Measure the sensor resistance and inspect the harness before buying a board.

## Common Causes

- **Failed oven temperature sensor probe (~50%)** The sensor element inside the oven has drifted out of specification or failed open, so the control cannot read temperature correctly.
- **Loose, corroded, or damaged wiring and connectors (~25%)** The harness between the sensor and the control board has a broken wire, loose plug pin, or corrosion that interrupts the signal.
- **Defective control board or poor solder joints (~20%)** Cracked solder at the probe connector on the control board or failed components (such as aged electrolytic capacitors) prevent the board from reading the sensor.
- **Heat-damaged connector pins on the board (~5%)** High-stress solder joints at the connector or nearby components have separated due to thermal cycling over time.

## Quick Diagnosis

Answer these to narrow it down fast.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker for at least one minute, then restore power and see if the fault clears and normal operation returns.
2. **Remove power again** and pull the range away from the wall so you can access the rear panel or lower access cover.
3. **Locate the oven temperature sensor probe** inside the oven cavity (a metal tube about the diameter of a pencil protruding through the rear wall) and trace its wire to the connector on the control board.
4. **Inspect the harness and connectors** for burns, loose pins, corrosion, or pinched wiring, and wiggle each connector to check for intermittent contact.
5. **Disconnect one lead of the sensor** from the circuit and use a multimeter set to resistance (ohms) to measure the sensor probe at room temperature (it should read around 1,100 Ω).
6. **If the sensor reads open or far outside 1,100 Ω**, replace the oven temperature sensor probe with a new one and reconnect the harness.
7. **If the sensor tests good**, check continuity from the sensor plug all the way to the control board connector, then inspect the board for cracked solder joints at the connector pins and consider control board repair or replacement.

## When to Call a Pro

Call a professional if you are not comfortable working with the range disconnected from power, if you cannot access the back of the unit safely, or if both the sensor and wiring test good but the fault persists (control board repair or replacement requires soldering skills and board-level diagnosis). A technician can reflow solder joints on the control board, replace failed capacitors, or swap the board efficiently. Also call for help if the range uses a high-voltage (240 V) hardwired connection and you are unsure how to verify the circuit is de-energized before working.

**Rough cost:** DIY runs about $20–60 in parts, 30–60 min. A pro service call runs about $150–300.
