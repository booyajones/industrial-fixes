## Fujitsu E:82 Error Code — What It Means

Code E:82 on a Fujitsu mini split is listed in the manufacturer's fault table as an "information error." This means the problem is with the control system itself rather than a refrigerant or mechanical failure. The indoor unit is reporting a fault in how it handles or exchanges information, typically involving communication between the indoor and outdoor units, wiring integrity, address settings, or the indoor controller board.

Because this is a control and communication fault, the repair focuses on electrical connections, configuration settings, and circuit boards rather than pressures, sensors, or mechanical parts. The code appears on the indoor unit display and usually points to an issue that prevents proper data exchange within the system.

## Common Causes

- **Lost communication between indoor and outdoor units** Damaged, loose, or disconnected interconnect wiring prevents the evaporator and condenser from exchanging control data.
- **Incorrect or duplicate address settings** Manual or auto address conflicts, mismatched remote controller addresses, or duplicated unit addresses in multi-zone systems cause information errors.
- **Faulty indoor controller PCB** A damaged or failed main control board on the indoor unit cannot process or relay information correctly.
- **Wiring faults at connectors or terminals** Reversed conductors, open pins, or corroded connector contacts interrupt control signals between units.
- **Power quality or grounding issues** Voltage drop, poor ground connection, or electrical noise disturbs the control logic and triggers intermittent information errors.

## Step-by-Step Fix {#fix}

1. **Power-cycle the system** by turning off the breaker for at least one minute, then restore power and check if the error returns after restart.
2. **Inspect all interconnect wiring** between the indoor and outdoor units, looking for loose connectors, damaged insulation, reversed wires, or corroded pins at both ends.
3. **Verify unit addressing and group settings** by checking that indoor and outdoor address numbers are valid for your system configuration, that no duplicate addresses exist, and that the remote controller address matches the indoor unit or group.
4. **Test the indoor controller PCB** by examining the board for visible burn marks, swollen capacitors, or damaged traces, and replace the controller board if wiring and addressing are correct but the fault persists.
5. **Check supply voltage and grounding** at the indoor unit to confirm stable line voltage with no significant drop during compressor startup and that the ground connection is secure and low-resistance.
6. **Re-commission the system** after any board replacement or address change by running a test cycle and confirming stable communication with no recurring error codes.
7. **Document the fault history** by noting when the error appears (startup, continuous, intermittent) to help identify whether the root cause is wiring, power quality, or a failing component.

## When to Call a Pro

Call a licensed HVAC technician if the error returns after a power reset, if you are not comfortable working inside live control panels, or if you cannot identify which wire or setting is causing the fault. Communication and address troubleshooting requires familiarity with Fujitsu's group configuration logic and safe work on low-voltage control circuits. A technician has the diagnostic tools to measure control signals, verify board function, and access the service menu to clear fault history and re-commission multi-zone systems correctly. If the indoor controller PCB needs replacement, professional installation confirms correct board pairing and system re-commissioning to prevent repeat faults.
