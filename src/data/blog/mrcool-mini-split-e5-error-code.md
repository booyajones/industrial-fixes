## MRCOOL E5 Error Code — What It Means

The E5 error code (sometimes displayed as EH61) on a MRCOOL mini-split indicates the indoor air handler has detected a fault in the evaporator coil temperature sensor circuit, often identified as the T2 sensor. This is not a refrigerant pressure code. The system has lost a reliable temperature reading from the sensor mounted on or near the indoor coil, so it cannot regulate cooling or heating properly and triggers the fault to protect the equipment.

## Common Causes

- **Loose or poor sensor connection** The connector at the control board or at the sensor itself has backed out or corroded, breaking the temperature signal.
- **Damaged sensor wiring** Frayed, pinched, or corroded wiring between the sensor and the indoor board can cause an open or intermittent circuit.
- **Failed evaporator coil temperature sensor** The sensor itself has gone open-circuit or drifted out of spec and no longer reports accurate resistance.
- **Dirty evaporator coil or restricted airflow** Heavy dust or debris on the indoor coil can cause abnormal temperature readings that confuse the sensor circuit.
- **Indoor control board fault** If wiring and sensor test good, the PCB input circuit for the sensor may have failed.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the breaker and wait at least 15 minutes, then restore power to see if the code clears on its own.
2. **Remove the indoor unit cover** to access the evaporator coil and the control board inside the air handler.
3. **Inspect the sensor wiring and connections** for fraying, corrosion, or loose plugs, then reseat the sensor connector firmly at the board.
4. **Disconnect the sensor from the board** and measure its resistance with a multimeter set to ohms. An open reading indicates a failed sensor.
5. **Check the evaporator coil** for dirt or debris and clean it if needed to rule out airflow-related temperature anomalies.
6. **Inspect the indoor control board** for burn marks, corrosion, or other visible damage around the sensor input terminals.
7. **Replace the sensor** if it tests open or out of range, or replace the indoor PCB if the sensor and wiring are sound but the fault persists.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working with live electrical components or if you do not own a multimeter to test the sensor. A tech can quickly isolate whether the fault is in the sensor, wiring, or control board and has access to OEM replacement parts and refrigerant-handling tools if further system diagnosis is needed. If the code returns after you replace the sensor, professional board-level diagnosis is the next step.
