## Whirlpool E62 Error Code — What It Means

The E62 error code on Whirlpool over-the-range microwaves indicates a problem with the gas sensor or its associated wiring. This sensor monitors for gas leaks and communicates with the control board through a wiring harness. When the sensor signal is interrupted, weak, or incorrect, the microwave displays E62 and may stop normal operation.

Whirlpool treats this as a sensor circuit fault, not a simple glitch. The code points to a failure in the sensor itself, a damaged or loose connector, or broken wiring between the sensor and the control board. Occasionally a control board input fault can also trigger E62, but the sensor and wiring are the primary suspects according to Whirlpool documentation.

## Common Causes

- **Failed gas sensor** The sensor element can fail internally and stop sending a valid signal to the control board.
- **Loose or corroded connector** The plug between the sensor harness and control board can work loose or develop corrosion, breaking the circuit.
- **Damaged wiring** Wires in the sensor harness can be pinched, cut, or burned, creating an open or short circuit.
- **Intermittent contact** Vibration or heat cycling can cause a marginal connection to fail temporarily and trigger the code.
- **Control board sensor input failure** If the sensor and wiring test good, the control board's sensor input circuit may be faulty.

## Step-by-Step Fix {#fix}

1. **Disconnect power** at the circuit breaker for at least one minute to allow the microwave to fully reset.
2. **Restore power** and monitor the display for one minute to see if the E62 code returns immediately.
3. **If the code clears and stays clear**, the fault may have been transient and normal operation can resume.
4. **If the code returns**, unplug the unit and remove the outer cabinet panels to access the gas sensor and wiring harness.
5. **Inspect the gas sensor connector** for looseness, corrosion, or damage, and check the wiring from the sensor to the control board for cuts or pinches.
6. **Test the gas sensor continuity** and resistance according to your model's service manual, and replace the sensor if readings are out of specification or the sensor is visibly damaged.
7. **If the sensor and wiring are intact**, replace the control board, as the sensor input circuit may be faulty.

## When to Call a Pro

Whirlpool recommends calling a qualified technician if the E62 code returns after a power reset. Working inside a microwave requires discharging the high-voltage capacitor and navigating live circuits, both of which carry serious shock and burn hazards. If you are not trained in microwave service or do not have the tools to safely discharge the capacitor and test sensor circuits, schedule a service call. Technicians have the meters, schematics, and safety procedures to diagnose sensor and control board faults without risk.
