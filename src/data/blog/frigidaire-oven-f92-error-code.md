## Frigidaire Oven F92 Error Code — What It Means

F92 is part of the F90 through F94 error family on Frigidaire ovens and ranges. Frigidaire groups all five codes together as door lock issues. The control board is detecting a problem with the oven door lock circuit or mechanism, not a cooking-temperature fault. The manufacturer's official guidance is to reset power by disconnecting for 30 seconds, then call service if the code comes back.

## Common Causes

- **Stuck or failed door lock assembly** The latch motor or lock mechanism binds, does not complete travel, or has broken linkage.
- **Door lock switch or micro-switch fault** The switch inside the lock assembly does not change state correctly when the latch moves.
- **Loose or damaged wiring** Connections between the electronic oven control and the lock assembly are open, corroded, or have loose pins.
- **Power or reset glitch** A temporary electronic hiccup triggers the code and clears after disconnecting power briefly.
- **Failed electronic oven control board** If the lock hardware and wiring test good, the EOC itself may be at fault.

## Step-by-Step Fix {#fix}

1. **Kill power** at the breaker or unplug the range before touching any components.
2. **Disconnect power for 30 seconds** to reset the control, then restore power and check if the code clears.
3. **Inspect the door lock assembly** for mechanical binding, broken parts, or a motor that does not move through full travel.
4. **Test the lock switch or micro-switch** for proper continuity when you manually actuate the latch.
5. **Check the wiring harness and connectors** from the EOC to the lock assembly for loose pins, corrosion, or open circuits.
6. **Replace the door lock assembly** if it binds, does not complete travel, or the switch does not toggle correctly.
7. **Replace the electronic oven control board** if the lock assembly and all wiring test good but the code persists.

## When to Call a Pro

Call a technician if the code returns after a power reset and you are not comfortable working inside the range cabinet. The repair requires disconnecting power, removing panels, and testing live circuits if you want to verify the control board. If your oven is stuck in a locked state after a self-clean cycle and will not open, a pro can safely disassemble the door lock mechanism without damaging the door or control. Most Frigidaire service centers stock the door lock assembly and can complete the repair in one visit.
