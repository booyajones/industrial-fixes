## Amana Dryer ERR Error Code — What It Means

The ERR code on an Amana dryer is a general control-detected error. The electronic control board has found a fault that requires service rather than a normal user reset. Unlike more specific codes like PF or L2, ERR is a broad indication tied to the control system and does not point to one exact failed part across all Amana models. The code can appear when the board detects a problem it cannot resolve on its own, such as a sensor circuit fault, a wiring issue, or an internal board failure.

Before starting any diagnostic work, confirm that the display is showing ERR and not a more specific code like F#E# or L2, because those have separate meanings and remedies in Amana's documentation. The actual cause will depend on your dryer model and may require entering service diagnostics to retrieve stored fault history.

## Before You Replace Anything

Many people replace the electronic control board immediately without checking the harness connectors or testing the sensor circuits first. A loose, pinched, or corroded connector at the board can trigger ERR and costs nothing to reseat.

## Common Causes

- **Control board internal fault (~40%)** The electronic control board itself has failed and cannot process sensor inputs or operate relays correctly.
- **Loose or miswired harness connector (~25%)** A connector at the control board is loose, pinched, or incorrectly seated, interrupting communication or power to a circuit.
- **Sensor circuit open or shorted (~20%)** The thermistor or another sensor circuit has an open wire, short, or out-of-range resistance that the board flags as an error.
- **Stuck membrane key or console fault (~10%)** A button on the control panel is stuck, shorted, or the membrane pad has failed, causing the board to detect a constant input signal.
- **Power-quality issue misread as ERR (~5%)** Low line voltage, a tripped breaker, or startup electrical noise creates a transient fault that the board logs as ERR.

## Step-by-Step Fix {#fix}

1. **Verify the exact code** displayed and write it down. Confirm it reads ERR and not a more specific fault code like F#E# or L2.
2. **Disconnect power** at the breaker or by unplugging the dryer. Wait one full minute, then restore power to clear any transient fault.
3. **Inspect all harness connectors** at the electronic control board. Remove and reseat each connector, checking for bent pins, corrosion, or pinched wires.
4. **Enter service diagnostics** for your specific Amana model using the button sequence in your technical sheet, and retrieve any stored fault history to identify the circuit involved.
5. **Test sensor circuits** associated with the fault log. Use a multimeter to measure the thermistor or other sensor resistance and compare to the model's specification table.
6. **Check the membrane console** for stuck buttons. Press each key firmly and listen for proper clicks. If a key is stuck or unresponsive, replace the console assembly.
7. **Replace the electronic control board** if connector and sensor tests pass and the board does not operate relays correctly during the prescribed diagnostic test, or if the fault log points to an internal board error.

## When to Call a Pro

Call a qualified appliance technician if you are not comfortable working with line-voltage connections, if you cannot identify which harness or sensor circuit is causing the fault, or if the dryer still shows ERR after you have reseated connectors and cycled power. Diagnosing ERR typically requires entering service mode, retrieving logged fault codes, and using a multimeter to test sensor circuits and board outputs. A technician has the model-specific wiring diagram and fault-code table needed to isolate the failed component quickly. If the control board must be replaced, a pro will also verify that the new board communicates correctly with all connected circuits before closing up the cabinet.

**Rough cost:** A pro service call runs about $150-350.
