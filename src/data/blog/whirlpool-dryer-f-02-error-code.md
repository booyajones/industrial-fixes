## Whirlpool Dryer F-02 Error — What It Means

The F-02 error code on a Whirlpool dryer indicates a keypad or stuck-button fault on the user interface. The control board is registering a continuous key press, either from a physically stuck button or an electrical problem in the control panel assembly. This is not a drain fault, venting issue, or motor problem. (Note that F02 on a Whirlpool washer is a completely different fault related to drain time and should not be confused with the dryer code.) Whirlpool's official dryer product help recommends powering the unit down for five minutes, restoring power, then running a timed dry cycle and watching to see if the code returns.

## Before You Replace Anything

Many owners replace the main control board when the real problem is a stuck button or failed user interface assembly. Before ordering any board, power-cycle the dryer and inspect every button on the console for physical sticking or contamination.

## Common Causes

- **Physically stuck button or key (~45%)** A button on the touchpad is jammed, held down by debris, or stuck in the pressed position and the control sees a continuous input.
- **Moisture or residue on the control panel (~25%)** Laundry-room humidity, spills, or detergent overspray can seep behind the keypad membrane and cause a false continuous-press signal.
- **Failed user interface or control-panel assembly (~20%)** The touchpad membrane or the printed circuit behind it has failed and sends a constant key-press signal even when no button is touched.
- **Loose or corroded ribbon connector (~6%)** The ribbon cable or plug between the user interface and the main control board is not seated fully or has corrosion that mimics a stuck key.
- **Main control board misinterpreting input (~4%)** The control board itself is faulty and incorrectly reads the keypad signals, although this is less common than a panel fault.

## Step-by-Step Fix {#fix}

1. **Turn off the dryer circuit breaker** (or unplug the unit) and leave power disconnected for five full minutes to allow the control to reset.
2. **Restore power** at the breaker or plug, then press the power button on the console.
3. **Select and start a Time Dry cycle** with no load in the drum, and observe the display for one full minute.
4. **Check every button** on the control panel for physical sticking by pressing each one and confirming it returns fully. Wipe around the buttons with a cotton swab dampened with isopropyl alcohol if you see residue.
5. **Unplug the dryer and pull it forward** to access the rear panel or top console screws (consult your model's service manual for disassembly).
6. **Remove the console cover** and locate the ribbon cable or wire harness that connects the user interface to the main control board. Unplug it, inspect both the plug and socket for corrosion or bent pins, and reseat it firmly.
7. **Reassemble and retest** the dryer with another timed cycle. If F-02 returns immediately, replace the user interface assembly. If the code still appears after a new interface, replace the main control board.

## When to Call a Pro

Call a technician if you are not comfortable removing the dryer console or working near control-board connectors. Also call for service if the fault persists after you have replaced the user interface assembly and reseated all connectors, since the main control board or wiring harness may need diagnosis with a multimeter and the service manual. If your dryer is still under warranty, contact Whirlpool or an authorized service center before opening the cabinet, because owner disassembly can void coverage.

**Rough cost:** DIY runs about $80–180 for a user interface assembly, 20–45 min. A pro service call runs about $150–300 including the part and service call.
