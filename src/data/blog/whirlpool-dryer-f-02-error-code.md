## Whirlpool Dryer F-02 Error Code — What It Means

On a Whirlpool dryer, F-02 is a user-interface or keypad fault. It is not a drainage or venting problem. Whirlpool's official troubleshooting requires a power reset and retest with a timed dry cycle. If the code clears, the dryer is ready to use. If it returns after the reset, the fault is in the control system and requires service.

Note that Whirlpool washers use F02 or F21 to indicate a drain time problem, so always confirm whether your appliance is a dryer or a washer before diagnosing.

## Common Causes

- **Stuck or faulty key on the control panel** A button that remains depressed or a damaged keypad sends a continuous signal and triggers the fault.
- **User interface board failure** The UI board that reads button presses and displays the cycle can fail internally and report F-02 to the main control.
- **Loose or corroded harness connector** The cable between the user interface and the main control board can work loose or develop oxidation that interrupts communication.
- **Main control board communication fault** The central control may fail to read the UI properly, either from a board-level defect or a firmware glitch.
- **Temporary power surge or static discharge** A voltage spike or electrostatic event can lock the control processor until power is fully cycled.

## Step-by-Step Fix {#fix}

1. **Turn off the circuit breaker** that feeds the dryer and leave it off for a full 5 minutes to drain residual power from the control boards.
2. **Restore power** at the breaker and return to the dryer.
3. **Select a timed dry cycle** on the control panel and press start.
4. **Observe the dryer for about 1 minute** to confirm the F-02 code does not return and the drum begins to tumble normally.
5. **If the code reappears**, inspect the keypad for any stuck buttons by pressing each key firmly and listening for a distinct click.
6. **Check the wiring harness** between the user interface and the main control board for loose connectors or visible corrosion on the pins.
7. **If the fault persists after reconnecting all harnesses**, the user interface board or main control board will need professional diagnosis or replacement.

## When to Call a Pro

Call a qualified appliance technician if the F-02 code returns after the 5-minute power reset and you cannot identify a stuck key or loose connector. Diagnosing communication faults between the user interface and main control often requires a multimeter, signal tracing, and access to service-mode diagnostics that are not published in homeowner literature. If you are uncomfortable working inside the dryer cabinet or around live 240-volt connections, professional service is the safer choice.
