## Gree EE Error Code — What It Means

The EE error code on Gree mini split systems indicates an EEPROM malfunction or driving board chip error on the outdoor or main control board. This is an electronics-level fault, not a refrigerant or airflow problem. Gree's own troubleshooting documentation for U-Match systems defines EE as a driving board chip error that typically requires a mainboard inspection and replacement if the fault persists. The code appears on the wired controller when the control board's memory or logic chip cannot function properly.

## Common Causes

- **Loose or incorrect jumper on the control board** A jumper that is not seated correctly can prevent the board from initializing the EEPROM chip and trigger the EE code.
- **Mainboard or driving board failure** The outdoor main control board may have a failed or damaged chip that stores system configuration and operating parameters.
- **EEPROM chip data corruption or damage** The memory chip itself can become corrupted or physically damaged, preventing the board from reading or writing critical data.
- **Power supply issue to the control electronics** Unstable or insufficient voltage to the logic circuits can cause the EEPROM to fail to operate, though this is less common than board-level faults.

## Step-by-Step Fix {#fix}

1. **Verify your exact model number** and pull the matching Gree service manual or fault guide, because code definitions can vary by platform.
2. **Power off the system completely** at the disconnect or breaker and wait two minutes before opening any panels.
3. **Remove the outdoor unit cover** and locate the main control board, typically mounted near the electrical connections.
4. **Inspect the jumper** on the control board for loose connections or incorrect placement, reseat or tighten it if needed, then power the system back on to see if the code clears.
5. **If the EE code remains**, power off again and check that the board connectors are fully seated and that no visible damage exists on the board surface or EEPROM chip.
6. **Replace the mainboard** if the jumper and connections are correct but the error persists, following Gree's documented remedy for this fault.
7. **Re-energize the system** and monitor the display to confirm the error has cleared and normal operation resumes.

## When to Call a Pro

Call a qualified HVAC technician if you are not comfortable working with live electrical panels or if you cannot locate the jumper or mainboard. Board-level diagnostics sometimes require a multimeter to verify power supply rails, and replacing the mainboard involves handling refrigerant lines and electrical connections that must remain sealed and secure. If your unit is under warranty, contact Gree or your installer before opening any panels, since self-service may void coverage.
