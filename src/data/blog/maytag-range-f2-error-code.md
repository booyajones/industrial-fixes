## Maytag Range F2 E1 Error Code — What It Means

The F2 E1 code on a Maytag range indicates a suspected problem with the user interface or keypad, the main control board, or the wiring that connects them. Maytag also notes that on some range models, incorrectly installed or uneven grates can trigger this code. The code means the control system has detected a communication or circuit fault in the user-interface path, not a temperature sensor issue as sometimes claimed online.

## Common Causes

- **Failed or stuck keypad or user interface** The touch panel or control interface has developed an internal fault or a button is mechanically stuck.
- **Defective control board** The main electronic control has failed and can no longer communicate properly with the user interface.
- **Loose or damaged wiring between UI and control** Harness connectors are loose, corroded, or wires are damaged along the path between the keypad and the control board.
- **Incorrectly installed or wobbling grates** On applicable rangetop models, grates that are not seated level or are in the wrong orientation can trigger the F2 E1 code.

## Step-by-Step Fix {#fix}

1. **Verify the exact code** displayed on your range and confirm it reads F2 E1, not another F2-family fault code.
2. **Check the grates** on your rangetop and confirm they are installed correctly, seated level, and not wobbling or reversed.
3. **Turn off power at the circuit breaker** for a full one minute, then restore power and monitor the display for one minute to see if the code clears.
4. **Inspect the wiring harness** between the user interface and the control board for any loose connectors, damaged insulation, or signs of moisture or contamination.
5. **Test or swap the user interface** if you have access to a known-good spare, because the keypad assembly is a common failure point for this code.
6. **Test or replace the control board** if the user interface and wiring both check out, since the control itself may have an internal fault.
7. **Reassemble and perform a final power reset** after any component replacement, then run the range through a normal heating cycle to verify the fault is cleared.

## When to Call a Pro

Call a qualified appliance technician if the code returns after a power reset and you have verified the grates are installed correctly. Diagnosing this code often requires component-level testing and substitution of the user interface or control board, and working inside the range cabinet involves line-voltage wiring. A technician has the tools to safely isolate whether the keypad, control, or wiring is at fault and can source the correct model-specific replacement parts.
