## What this code means
The F2 E1 code on a Maytag range signals a problem with the user interface or keypad, the main control, or the wiring between them. The control board is seeing an invalid signal from the touchpad, which can mean a stuck button, a shorted contact, a disconnected connector, or moisture in the panel. Maytag's official guidance also directs you to check whether the cooktop grates are installed correctly and level, because a wobbling grate can trigger this error on some range models.

In practice, the fault is usually electrical rather than mechanical. A shorted or stuck key on the control panel sends a constant signal that the control interprets as a fault. Steam or liquid spills around the touchpad are common triggers. Less often, the problem lies in a loose harness plug or a failing main control board that cannot properly read the keypad signals.

## Before You Replace Anything

Many people replace the main control board first, only to find the fault returns because the real problem is a shorted touchpad or a loose connector. Always inspect the keypad assembly and connectors before replacing the control.

## Common Causes

- **Failed or stuck keypad/touchpad (~50%)** A shorted contact, stuck button, or moisture intrusion in the touchpad sends a continuous invalid signal to the control board.
- **Loose or damaged wiring harness (~25%)** The connector between the user interface and the main control can work loose, corrode, or suffer bent pins that interrupt communication.
- **Moisture or steam intrusion (~15%)** Liquid spills or steam condensing inside the control panel create shorts across the touchpad circuit.
- **Main control board fault (~8%)** The control may fail to read the keypad correctly due to internal component failure or a bad microprocessor.
- **Incorrectly installed or wobbly grates (~2%)** On some Maytag range models, a grate that wobbles or sits unevenly can trigger this error code.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker for the range and wait at least one minute to allow the control to reset.
2. **Check the cooktop grates** to verify each grate is installed on the correct burner and sits level without wobbling. If a grate wobbles, try swapping grates between burners.
3. **Restore power** and monitor the display. If the F2 E1 code does not return, the issue was a mispositioned grate or a temporary glitch.
4. **Inspect the touchpad area** for stuck buttons, spills, or visible moisture. Gently press each key to feel for any that stick or do not spring back.
5. **Access the back or bottom of the range** (consult your model's service manual for panel-removal steps) and locate the wiring harness between the user interface and the main control board. Disconnect each connector, check for corrosion or bent pins, and reconnect firmly.
6. **Dry the control area** if you find any sign of moisture. Leave the breaker off for up to 24 hours to make sure complete evaporation, then test again.
7. **Replace the user-interface assembly** if the code returns immediately when you touch the panel. If the touchpad tests good and connectors are secure, replace the main control board.
8. **Restore power and run a full functional test** of all burners and the oven to confirm the error does not reappear.

## When to Call a Pro

Call a professional if you are uncomfortable working inside the range cabinet or removing the control panels, or if the fault persists after you have replaced both the touchpad and the main control board. A technician has the model-specific wiring diagram and can trace signal voltages between the user interface and control to isolate intermittent shorts or grounding faults that are hard to find without test equipment. Also call for help if you see signs of arcing, burnt wiring, or repeated failures that suggest a deeper electrical problem in the range.

**Rough cost:** DIY runs about $80–200 in parts (keypad assembly), 30–60 min. A pro service call runs about $150–350.
