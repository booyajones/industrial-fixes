## What this code means
The F03 (or F3) error code on a Kenmore range indicates an oven temperature sensor circuit fault. The electronic control board has detected that the oven temperature probe, its wiring, or the control board itself is reading out of range, open, or shorted. This is not a heating element failure but a sensor circuit problem that prevents the control from accurately monitoring oven temperature.

The fault path typically involves one of three components: the oven temperature sensor (probe), the wiring harness and connectors between the sensor and control board, or the electronic control board. The control will not allow the oven to operate normally until the sensor circuit is restored to the proper range.

## Before You Replace Anything

Many homeowners replace the electronic control board first when the actual problem is a $20 sensor or a loose connector. Always test the sensor resistance with a multimeter and inspect the wiring before ordering a control board.

## Common Causes

- **Failed oven temperature sensor (~60%)** The oven temperature probe has drifted out of specification, developed an open circuit, or shorted internally so the control reads an invalid resistance.
- **Loose or corroded sensor connector (~20%)** The two-wire plug at the control board or sensor has oxidized contacts, backed-out pins, or has vibrated loose during use.
- **Damaged sensor wiring harness (~10%)** The wires between the sensor and control board are pinched, burned, broken, or shorted together due to heat or mechanical damage.
- **Defective electronic control board (~8%)** The oven control board has a failed sensor input circuit even though the sensor and wiring test within specification.
- **Intermittent connection under heat (~2%)** A connector or crimp terminal opens or shorts only when the range heats up and components expand, then passes when cool.

## Step-by-Step Fix {#fix}

1. **Disconnect power** to the range by unplugging it or switching off the circuit breaker, and wait one minute for the control to reset.
2. **Remove the rear panel or top control cover** to access the oven temperature sensor wiring at the back of the control board.
3. **Locate and unplug the two-wire oven temperature sensor connector** from the control board or harness junction.
4. **Measure the sensor resistance** with a multimeter set to ohms. A good sensor typically reads about 1.0 kΩ to 1.1 kΩ at room temperature.
5. **Inspect the sensor wiring and connector pins** for burns, breaks, corrosion, or loose terminals. Wiggle the harness to check for intermittent opens.
6. **Replace the oven temperature sensor** if it reads out of range, open, or shorted. If the sensor tests good, check harness continuity and replace damaged wiring or the control board if the circuit is intact but the code persists.
7. **Reassemble the range, restore power, and run a preheat test** to verify the oven reaches temperature without triggering the F03 code.

## When to Call a Pro

Call a qualified appliance technician if you are uncomfortable working inside the range with the power off, if the wiring harness is extensively damaged and requires re-routing through the cabinet, or if the electronic control board needs replacement and you lack experience with multi-pin connectors and control calibration. A technician can also diagnose intermittent faults that only appear under heat by using a temperature simulator on the sensor circuit. If the range uses gas and you smell gas or suspect a valve problem alongside the sensor fault, shut off the gas supply and call for service immediately.

**Rough cost:** DIY runs about $15-40 in parts, 30-60 min. A pro service call runs about $120-250.
