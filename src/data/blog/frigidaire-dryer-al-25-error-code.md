## Frigidaire Dryer AL-25 Error Code — What It Means

Frigidaire does not document an AL-25 dryer code in verified manufacturer support material. Based on available evidence, AL-25 is very likely a misread or alternate display for code E68, which Frigidaire troubleshooting identifies as a stuck button or keypad input fault. The dryer's control board detects an input signal that remains active when it should not be, preventing normal operation.

If your display shows AL-25 exactly, confirm the code and verify your model number before proceeding. Frigidaire's general guidance for unrecognized codes is to perform a hard reset and consult the use-and-care guide for your specific model. The diagnostic and repair steps below address the E68 stuck-button fault, which is the most likely match for this symptom.

## Common Causes

- **Physically stuck control-panel button** A button on the user interface remains depressed due to debris, spill residue, or mechanical obstruction, causing the control to read a continuous input.
- **Contaminated keypad contact** Liquid, detergent, or lint buildup on the keypad membrane or contact surface prevents a button from releasing electrically even when it moves freely.
- **Damaged or worn keypad assembly** The keypad membrane or tactile switch has failed internally, sending a stuck-on signal to the main control board.
- **Failed user-interface control board** The control board itself registers a false stuck-input signal even when all buttons test mechanically free and clean.
- **Transient fault after power event** A momentary glitch or power interruption has caused the control to latch an error that will clear with a hard reset.
- **Misread display or different code** The actual code is not AL-25 but another Frigidaire dryer alarm that requires model-specific troubleshooting.

## Step-by-Step Fix {#fix}

1. **Confirm the exact code and model number.** Write down the code as shown on the display and locate your dryer's model number on the rating plate inside the door or on the frame.
2. **Perform a hard reset.** Disconnect power to the dryer at the breaker or unplug the cord, wait three to five minutes, then restore power and check whether the code returns.
3. **Enter the dryer's diagnostic or key-test mode** (consult your use-and-care guide for the button sequence). Run the key test to identify which button the control sees as active or stuck.
4. **Remove the control-panel cover.** Unthread the screws securing the top or front control panel, lift it away from the cabinet, and visually inspect each button for debris, damage, or a key that does not spring back.
5. **Clean and test each button.** Press each key manually to verify free travel and a distinct click. If a button is sticky, clean the area with isopropyl alcohol and a lint-free cloth, then allow it to dry completely.
6. **Reassemble and retest in key-test mode.** Reinstall the control panel, restore power, and run the key test again. If the fault clears, run a normal cycle to confirm the repair.
7. **Replace the user-interface assembly or main control board** if the key test still shows a stuck input after all buttons are verified clean and free-moving. If the code is not E68, contact Frigidaire service or a qualified technician with your model number for the correct diagnostic path.

## When to Call a Pro

Call a qualified appliance technician if the code does not match E68 or if the hard reset and visual button inspection do not resolve the fault. If you are not comfortable removing the control panel, working near live electrical connections, or interpreting diagnostic test modes, professional service is the safer choice. A technician can verify the exact code against Frigidaire's service documentation for your model, run the full key test, and replace the correct board assembly without risking damage to the dryer's wiring or control components.
