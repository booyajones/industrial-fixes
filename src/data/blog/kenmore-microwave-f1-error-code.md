## Kenmore Microwave F1 Error — What It Means

On most Kenmore microwave models, F1 indicates a thermistor open or thermistor sensing error. The control board cannot detect proper temperature feedback from the thermistor, so it flags a no-heat or sensor fault. Kenmore sourced microwaves from multiple manufacturers, so the exact meaning can vary by model prefix. Always cross-reference your full model number against the service manual to confirm the fault definition before ordering parts.

## Common Causes

- **Open or failed thermistor** The thermistor probe has burned out, fractured internally, or aged out of its resistance range so the control reads infinite or out-of-spec resistance.
- **Loose or corroded thermistor connector** The plug between the thermistor wire and the control board has backed out, oxidized, or lost pin contact, creating an open circuit.
- **Broken or damaged thermistor harness** The wiring to the thermistor has been cut, pinched, burned, or pulled apart inside the cabinet.
- **Failed control board sensing circuit** The input stage on the main control board that reads the thermistor signal has failed, even though the thermistor itself tests normal.

## Step-by-Step Fix {#fix}

1. **Unplug the microwave** and discharge the high-voltage capacitor using an insulated screwdriver across its terminals before opening any panels.
2. **Identify the manufacturer** by checking the first three digits of your Kenmore model number to confirm which fault chart applies to your unit.
3. **Locate and unplug the thermistor connector** from the main control board, then inspect both the plug and socket for corrosion, bent pins, or burn marks.
4. **Measure the thermistor resistance** with a digital multimeter set to ohms. Compare the reading to your model's service data. An open reading or value far outside the spec confirms a bad thermistor.
5. **Replace the thermistor** if it reads open or out of range. Route the new sensor along the original path and press the connector fully onto the control board pins.
6. **Inspect the wiring harness** between the thermistor and control for cuts, pinch points, or heat damage if the thermistor tests good but the fault persists.
7. **Swap the main control board** if the thermistor, harness, and connectors all test normal, because the input circuit on the board is misreading the sensor signal.

## When to Call a Pro

Call a technician if you are not comfortable discharging the high-voltage capacitor or working inside the microwave cabinet. If you have replaced the thermistor and verified all wiring but the F1 code returns immediately on power-up, the control board input circuit has likely failed and a professional can confirm the diagnosis and source the correct board for your specific Kenmore manufacturer variant.
