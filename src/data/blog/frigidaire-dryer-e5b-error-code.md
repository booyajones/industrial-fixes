## Frigidaire Dryer E5B Error Code — What It Means

The E5B error code on Frigidaire dryers typically indicates a communication fault between the main control board and another component, often the user interface or a sensor module. The exact meaning can vary by model, so consult your owner's manual or the wiring diagram inside the control panel for your specific dryer.

This code usually appears when the control board cannot receive or send signals properly. It may be caused by a loose wire harness, a corroded connector, or a failed control board. The dryer will not run while the error is displayed.

## Before You Replace Anything

Many people replace the main control board immediately, but a loose or dirty harness connector accounts for most E5B faults. Reseat and inspect all connectors between the control board and the user interface before ordering a new board.

## Common Causes

- **Loose or dirty wire harness connector (~50%)** Vibration and heat can work connectors loose over time, breaking the signal path between boards.
- **Corroded or damaged connector pins (~20%)** Moisture or age can corrode the pins inside the harness plugs, preventing reliable contact.
- **Failed main control board (~15%)** The control board itself can develop a fault in its communication circuitry, though this is less common.
- **Failed user interface board (~10%)** The keypad or display module may lose the ability to communicate with the main board.
- **Damaged wiring harness (~5%)** A wire inside the harness can break or short, usually at a flex point or where it passes through a sharp edge.

## Step-by-Step Fix {#fix}

1. **Unplug the dryer** from the wall outlet and wait one minute to discharge residual power.
2. **Remove the top panel or control-panel cover** by taking out the screws along the back edge or sides, depending on your model.
3. **Locate the wire harness** running between the main control board (usually in the console or top panel) and the user interface or other modules.
4. **Disconnect each connector** in the harness one at a time and inspect the pins and sockets for corrosion, moisture, or damage.
5. **Clean the contacts** with electrical contact cleaner and a small brush, then straighten any bent pins with needle-nose pliers.
6. **Reconnect all harness plugs** firmly until they click or seat fully, then plug the dryer back in and run a test cycle.
7. **If the error persists**, replace the main control board or user interface board, depending on which component shows no signs of life or communication.

## When to Call a Pro

Call a technician if you are uncomfortable working with electrical connectors or removing the control-panel cover. A pro can quickly trace the communication fault with a multimeter and has access to factory wiring diagrams. Also call if you have reseated all connectors and the error returns immediately, since the fault may require board-level diagnostics or a hidden wiring short that is difficult to locate without experience.

**Rough cost:** DIY runs about $80-180 in parts, 30-60 min. A pro service call runs about $150-280.
