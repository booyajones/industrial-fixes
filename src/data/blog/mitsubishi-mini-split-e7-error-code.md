## Mitsubishi E7 Error Code — What It Means

The E7 error code on Mitsubishi Electric Mr. Slim and mini-split systems is an indoor/outdoor unit communication error detected by the indoor unit. It means the indoor unit is not receiving the expected communication signal from the outdoor unit, or the communication path between the two units is abnormal. This is not a sensor fault. It is specifically a problem with the data connection that lets the indoor and outdoor units coordinate operation.

[Jump to Fix](#fix)

## Common Causes

- **Disconnected or miswired connecting cable** The communication wire between indoor and outdoor units is loose, damaged, or connected to the wrong terminals.
- **Electrical noise interference** External electrical noise is entering the communication wiring or power supply and disrupting the signal.
- **Incorrect system configuration** More indoor units are connected than the outdoor unit supports in the current installation setup.
- **Faulty indoor control board** The indoor unit's printed circuit board has failed and cannot process or receive communication signals.
- **Faulty outdoor control board** The outdoor unit's printed circuit board has failed and is not sending the required communication signals.

## Step-by-Step Fix {#fix}

1. **Power off the system** at the breaker and wait two minutes to allow the boards to fully reset before beginning inspection.
2. **Inspect the indoor/outdoor connecting wire** at both the indoor and outdoor terminal blocks for loose screws, corroded connections, or physical damage to the wire insulation.
3. **Verify correct wiring** by comparing terminal connections to the wiring diagram on the indoor and outdoor unit covers, checking that each wire lands on the correct terminal number.
4. **Check for electrical noise sources** such as VFDs, motors, or high-voltage lines running near the communication wiring, and confirm that communication and power wiring are routed separately.
5. **Confirm system configuration** by counting the number of indoor units connected and verifying against the outdoor unit's nameplate and installation manual that the configuration is supported.
6. **Replace the indoor P.C. board** if all wiring and configuration checks pass but the error persists, following Mitsubishi's board replacement procedure for your model.
7. **Replace the outdoor P.C. board** if a new indoor board does not resolve the error, then restore power and run a full system test cycle to confirm communication is restored.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working inside 240V equipment or if the error returns after you have verified all wiring connections. Communication errors can also indicate refrigerant circuit problems or system configuration issues that require leak detection, pressure testing, and software setup tools. Mitsubishi advises stopping use and contacting service if the error remains after basic troubleshooting. A qualified technician has the diagnostic tools to test board voltages, measure communication signals, and access service menus to pinpoint whether the fault is in the indoor unit, outdoor unit, or the connecting circuit.
