## Navien E615 Error Code — What It Means

The E615 code on a Navien tankless water heater indicates an abnormal operation related to input and memory circuits inside the unit's control system. Unlike codes that point to water flow, gas pressure, or ignition problems, E615 is an internal electronics fault. The control board or related low-voltage circuitry has detected a problem with how it reads or stores data, which usually means the main PCB is malfunctioning or experiencing a temporary glitch.

## Common Causes

- **Main control board failure** The PCB has developed an internal fault in its input or memory logic circuits, the most common cause for this code.
- **Temporary electronic glitch** A one-time software or power anomaly can trigger the code, which may clear after a full power reset.
- **Loose or corroded control-board connections** Wiring harnesses or connectors to the PCB may have poor contact, causing intermittent input faults.
- **Moisture or heat damage to electronics** Water intrusion or overheating near the control board can corrupt memory or input circuits.
- **Power supply irregularities** Voltage spikes, brownouts, or grounding issues can confuse or damage the board's logic components.

## Step-by-Step Fix {#fix}

1. **Record the exact error code** and note whether the heater is completely shut down or still providing intermittent hot water.
2. **Power-cycle the unit** by switching off the dedicated circuit breaker, waiting three to five minutes, then turning power back on to see if the fault clears.
3. **Inspect the control-board compartment** for obvious signs of moisture, burn marks, corrosion on connectors, or loose wiring harnesses to the PCB.
4. **Check incoming power** at the unit's service disconnect to confirm you have the correct voltage and a solid ground connection, ruling out external electrical issues.
5. **Test all low-voltage harness connections** to the main board by gently reseating each plug and looking for bent pins or oxidation on the contacts.
6. **Replace the main PCB** if the E615 code returns after the power reset and all connections are secure, following the manufacturer's replacement procedure for your model.
7. **Clear the fault and test operation** by running a hot-water tap for several minutes to verify normal ignition, flame modulation, and temperature stability without the code reappearing.

## When to Call a Pro

Call a licensed technician if the error persists after a power reset or if you are not comfortable working inside the unit's electrical compartment. Replacing the main control board requires familiarity with low-voltage connections, proper grounding, and manufacturer-specific calibration steps that vary by model. A qualified Navien service provider can also run factory diagnostics to confirm the board is the root cause and check for collateral damage to sensors or relays that might have been affected by the same fault.
