## Bosch Oven E04 Error Code — What It Means

The E04 error code on a Bosch oven typically indicates a problem with the oven temperature sensing system or the control board's ability to read temperature data. The exact meaning can vary by model, so consult your owner's manual or wiring diagram for your specific unit. In most cases, the oven detects that the temperature sensor is reading out of range, has an open or short circuit, or that the sensor's wiring harness has a fault. The oven will not heat or may stop mid-cycle when this code appears.

This fault usually involves either the temperature sensor itself, the wiring between the sensor and the control board, or less commonly the control board's sensor input circuit. The sensor is a resistive temperature device that changes resistance as temperature changes, and the control uses this signal to regulate heating elements. When the signal is lost or implausible, the E04 code protects the oven from uncontrolled heating or inaccurate temperature.

## Before You Replace Anything

Many owners replace the control board first, but a loose connector or failed sensor is far more common. Test the sensor's resistance with a multimeter and inspect all connectors before ordering a board.

## Common Causes

- **Failed temperature sensor (~50%)** The oven temperature sensor develops an open circuit, short, or drift in resistance outside the expected range.
- **Loose or corroded sensor connector (~25%)** The plug connecting the sensor to the control harness has corroded pins or is not fully seated, breaking the signal path.
- **Damaged sensor wiring (~15%)** The wire from the sensor to the control board is pinched, cut, or has insulation damage that causes intermittent shorts or opens.
- **Control board sensor input failure (~8%)** The control board's temperature input circuit has failed and can no longer read the sensor correctly.
- **Transient electronic glitch (~2%)** A power surge or static discharge temporarily locks the control into an error state that clears with a full power cycle.

## Step-by-Step Fix {#fix}

1. **Disconnect power** by unplugging the oven or switching off the circuit breaker at your panel.
2. **Remove the rear access panel** by unscrewing the sheet-metal screws around the back of the oven to expose the control board and sensor wiring.
3. **Locate the temperature sensor**, a metal probe extending into the oven cavity with two wires running to a connector or directly to the control board.
4. **Disconnect the sensor connector** and inspect both halves for corrosion, bent pins, or moisture, then clean with electrical contact cleaner if needed.
5. **Test the sensor resistance** using a digital multimeter set to ohms, placing one probe on each sensor terminal; consult your model's table for the expected resistance at room temperature, typically between 1,000 and 1,200 ohms.
6. **Inspect the sensor wiring** along its full length for any cuts, pinch points, or insulation damage that could cause shorts or opens.
7. **Replace the temperature sensor** if it reads open (infinite resistance), shorted (near zero ohms), or out of the expected range, by unscrewing the mounting bracket and pulling the probe from the oven cavity.
8. **Reassemble and test** by reconnecting the sensor, replacing the access panel, restoring power, and running a bake cycle to verify the E04 code does not return.

## When to Call a Pro

Call a professional if you are uncomfortable working with electrical connections, if you cannot access the rear panel or sensor safely, or if you have replaced the sensor and verified all wiring but the E04 code still appears. A technician can perform advanced diagnostics on the control board's sensor input circuit and has access to proprietary Bosch service software. Also call a pro if the oven shares a junction box with other high-voltage appliances or if local codes require a licensed electrician for any appliance wiring work.

**Rough cost:** DIY runs about $30-80 in parts, 30-60 min. A pro service call runs about $150-280.
