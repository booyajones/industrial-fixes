## Frigidaire Oven F41 Error Code — What It Means

The F41 code on a Frigidaire range signals a cooktop lockout fault. The control board believes the cooktop or oven lock feature is active or not clearing properly. Frigidaire groups F40 and F41 together under the same cooktop lockout issue, so the exact behavior depends on your model. When this code appears, the cooktop keys are usually unresponsive and the lock indicator may be lit on the display.

This code does not point to an electrical component failure in most cases. Instead, the lock function was enabled and failed to turn off normally, or the control is misreading input from the user interface. A simple power reset or manual unlock procedure clears the fault in the majority of cases.

## Before You Replace Anything

Homeowners often replace the main control board first, but a stuck or dirty lock button or loose ribbon cable between the keypad and control causes most F41 faults. Always try the manufacturer reset and inspect the console connections before ordering a new board.

## Common Causes

- **Lock feature was enabled and did not clear (~50%)** The cooktop lockout was activated by the user or accidentally, and the control did not register the unlock command when you tried to cancel it.
- **Stuck or misread lock button on the control panel (~25%)** A stuck, dirty, or intermittently responding OFF or lock key sends a continuous lock signal to the control board.
- **Loose or damaged ribbon cable between user interface and control board (~15%)** The wiring harness or ribbon connector that carries keypad signals to the main control is loose, corroded, or has damaged pins.
- **Touchpad or user interface console failure (~7%)** The console assembly is sending an incorrect lock command or failing to communicate unlock status to the control board.
- **Main control board misreading lockout status (~3%)** The electronic control board itself is misinterpreting input signals or has a firmware glitch that falsely reports cooktop lockout.

## Step-by-Step Fix {#fix}

1. **Disconnect power** by unplugging the range or switching off the circuit breaker for a full 30 seconds, then restore power to reset the control board.
2. **Attempt the manual unlock** by pressing and holding the OFF button on the control panel for 6 seconds if your model supports this feature.
3. **Check the lock indicator** on the display and test the cooktop keys to confirm whether the lockout has cleared and the range responds normally.
4. **Inspect the control panel** for any stuck, dirty, or visibly damaged buttons, especially the OFF or lock key, and clean the console surface with a damp cloth without spraying cleaner directly on it.
5. **Remove the control panel** by unscrewing the mounting fasteners and inspect the ribbon cable or wiring harness that connects the user interface to the main control board for looseness, corrosion, or damaged pins.
6. **Reseat or replace the ribbon cable** if you find any connector damage, then reassemble the console and test the range again.
7. **Replace the user interface console** if the fault persists after verifying all connections, and replace the main control board only if a new console does not solve the problem.

## When to Call a Pro

Call a qualified appliance technician if the power reset and manual unlock procedure do not clear the F41 code, if you are uncomfortable removing the control panel to inspect the ribbon cable, or if you have already replaced the user interface and the lockout fault returns. A technician can test signal continuity between the console and control board and confirm whether the main control board needs replacement. Professional diagnosis prevents ordering the wrong part and ensures any wiring issues are correctly identified and repaired.

**Rough cost:** DIY runs about $50–150 in parts, 20–45 minutes. A pro service call runs about $150–300 service call and parts.
