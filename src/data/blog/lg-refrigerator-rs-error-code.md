## LG Refrigerator rS Error Code — What It Means

The rS code (shown as Er rS) means the refrigerator section temperature sensor, also called the fresh food thermistor, is reading as a short or an open circuit. The main board uses this sensor to control fresh food cooling, so a bad reading throws rS and the fridge side may run too warm or too cold.

The usual causes are a failed thermistor, a loose or corroded connector, or moisture in the sensor circuit. The control board is the last thing to check.

[Jump to Fix](#fix)

## Common Causes

- **Failed refrigerator thermistor** A sensor that has shorted or opened gives the board a reading outside the valid range.
- **Loose sensor connector** A connector that worked loose or corroded breaks the link between the sensor and the board.
- **Moisture damage** Water reaching the sensor or wiring corrodes the pins and causes a false short or open.
- **Pinched wiring** A wire crimped during a past repair can break the sensor circuit over time.
- **Main control board fault** A board that misreads the sensor input can post rS even with a healthy thermistor.

## Step-by-Step Fix {#fix}

1. Unplug the refrigerator or trip the breaker for about 30 seconds, then restore power to check if rS clears.
2. Find the fresh food thermistor and inspect its connector for looseness, corrosion, or moisture.
3. Reseat the connector firmly and clean any corrosion on the pins.
4. Trace the wiring for pinch points or chafing and repair any damage you find.
5. Measure the thermistor resistance with a multimeter and compare it against the value for the fridge temperature.
6. Replace the refrigerator thermistor if the resistance is out of range or reads open or shorted.
7. If a new sensor and clean wiring still show rS, replace the main control board.

## When to Call a Pro

Call a technician if rS returns after a new thermistor and verified wiring. A code that survives a good sensor usually points to a board or harness fault that needs meter testing to pin down.
