## LG Refrigerator rT Error Code — What It Means

The rT error code on your LG refrigerator indicates an open or shorted room temperature sensor in the fresh-food compartment. The control board is not receiving a valid signal from the refrigerator compartment thermistor. This is an electrical sensor circuit fault, not a general cooling issue. LG's own documentation confirms rT points specifically to a shortened or open room temperature sensor circuit and states there are no DIY troubleshooting steps beyond service inspection.

[Jump to Fix](#fix)

## Common Causes

- **Failed refrigerator compartment thermistor** The room temperature sensor itself has either failed open circuit or shorted, the most common cause of this code.
- **Loose or corroded sensor connector** The wiring connector at the thermistor has worked loose, corroded, or developed damaged terminals that break the circuit.
- **Damaged sensor wiring harness** The wire run between the sensor and the control board has been cut, pinched, or abraded, creating an open or intermittent short.
- **Main control board input failure** The control board itself is unable to read the sensor circuit correctly, though this is less common than a bad sensor or wiring issue.

## When to Call a Pro

LG's official support documentation states there are no DIY troubleshooting steps for the rT code beyond requesting service inspection. If you are not comfortable working with live electrical circuits, testing thermistor resistance, or accessing components inside a sealed refrigerator compartment, call a qualified appliance technician. A professional has the model-specific service data, OEM thermistor resistance tables, and tools to safely diagnose the sensor circuit and control board inputs. If the code reappears immediately after a power reset or you see other fault codes along with rT, professional diagnosis is the best path.
