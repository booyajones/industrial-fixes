## Goodman Heat Pump d4 Error Code — What It Means

The d4 code on Goodman heat pumps indicates that shared data on the memory card has been rejected by the control system. This is a communication or data-compatibility fault within the unit's electronics, not a refrigerant pressure or sensor problem. The code is not universally documented across all Goodman models, so you must verify the exact code displayed on your indoor or outdoor unit and consult your model's service manual before troubleshooting. Some sources confuse d4 with E4, which are different codes with different causes.

[Jump to Fix](#fix)

## Common Causes

- **Corrupted or incompatible memory card data** The control board rejects stored or shared data that does not match the expected format or version for your model.
- **Control board communication failure** The main board or interface module cannot read or validate the memory card or shared data line between indoor and outdoor units.
- **Loose or damaged wiring harness** Frayed, corroded, or disconnected wires between the control board and memory card interface interrupt data transfer.
- **Failed or aging control board** Internal board faults, burnt components, or heat damage prevent the board from processing shared data correctly.
- **Incorrect memory card or module installed** A replacement card or data module that is not the correct part number for your model family will be rejected by the board.
- **Transient electronic glitch** A momentary power surge or interference can cause the board to misread or reject valid data until reset.

## Step-by-Step Fix {#fix}

1. **Confirm the exact code and model number** by checking the unit display, the serial tag on the indoor air handler, and the outdoor condenser tag to verify you are troubleshooting the correct fault.
2. **Power-cycle the system** by turning off the circuit breaker or disconnect switch for at least two minutes, then restore power to clear any transient control faults.
3. **Inspect all wiring harnesses and connectors** between the indoor and outdoor units and between the control board and any memory card or data module for loose, corroded, or damaged connections.
4. **Check the control board for visible damage** such as burnt or discolored components, swollen capacitors, or signs of overheating on the board surface.
5. **Verify the memory card or shared-data module** is fully seated in its slot and is the correct part number for your model by comparing it to the service manual or replacement-parts diagram.
6. **Consult your model's service manual** for any board diagnostic LEDs, jumper settings, or dip-switch configurations that may indicate a data-rejection fault or communication error.
7. **Replace the failed component** only after confirming which part is causing the rejection through step-by-step isolation and model-specific diagnostics, then clear the fault and test operation.

## When to Call a Pro

Call a licensed HVAC technician if you cannot verify the exact code or model number, if the fault persists after a power cycle and wiring inspection, or if you are not comfortable working with low-voltage control boards and data interfaces. A technician has the model-specific service manual, diagnostic tools, and correct replacement parts to isolate whether the fault is in the memory card, control board, or communication wiring. Because d4 is not a widely published code and meanings vary by model family, professional diagnosis is the safest path to avoid replacing the wrong part.
