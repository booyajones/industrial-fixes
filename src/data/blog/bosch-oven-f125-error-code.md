## Bosch Oven F125 Error Code — What It Means

The F125 error code on a Bosch oven indicates that the cancel key is stuck or that the keypad is registering a continuous cancel button press. This is not a heating element, temperature sensor, or ignition fault. The control board detects that the cancel key input remains closed when it should be open, which prevents normal operation and triggers the fault code.

The stuck key condition is most often caused by physical debris, grease buildup, a failed membrane keypad, or a wiring issue between the user interface and the electronic control board. Bosch diagnostics point to the keypad assembly as the primary suspect when F125 appears.

## Common Causes

- **Stuck or contaminated cancel key** Grease, food residue, or cleaning product buildup can prevent the cancel key from releasing, keeping the input circuit closed.
- **Failed membrane keypad** The touch panel or membrane switch can deteriorate over time, causing the cancel key contact to remain closed even when not pressed.
- **Loose or damaged wiring connector** The harness between the keypad and control board can become unseated or corroded, creating a false stuck-key signal.
- **Electronic control board malfunction** If the board incorrectly reads the cancel key input as closed, the fault will persist even after keypad replacement.

## Step-by-Step Fix {#fix}

1. **Power off the oven** at the circuit breaker for 60 seconds to reset the control board and clear any transient glitches.
2. **Restore power** and check whether the F125 code reappears immediately or during the next use cycle.
3. **Inspect the cancel key and surrounding keypad area** for visible sticking, food debris, grease, or damage to the membrane surface.
4. **Clean the keypad** gently with a damp cloth and mild detergent, avoiding excess moisture that could seep behind the panel, then dry thoroughly.
5. **Remove the outer door or control panel cover** (consult your model's service manual for fastener locations) and verify that the ribbon cable or wire harness connector between the keypad and control board is fully seated and free of corrosion.
6. **Replace the membrane keypad or user interface assembly** if cleaning and reseating connectors do not clear the fault, as a stuck cancel key contact is the most common hardware cause.
7. **Test the oven** after reassembly by running a bake cycle to confirm the F125 code does not return, and if it does, replace or further diagnose the electronic control board.

## When to Call a Pro

Call a qualified appliance technician if the F125 code returns immediately after a power reset and you cannot identify visible debris or sticking on the cancel key, or if you are uncomfortable removing the control panel cover and working with ribbon cable connectors. A technician can perform continuity tests on the keypad circuit, verify proper voltage at the control board input, and determine whether the fault lies in the user interface or the board itself. If your oven is still under warranty, contact Bosch support before attempting repairs to avoid voiding coverage.
