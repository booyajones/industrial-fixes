## Samsung Microwave C-22 Error — What It Means

The C-22 error code on a Samsung microwave indicates a temperature sensor fault in the oven cavity temperature sensing circuit. Samsung groups C-20, C-21, and C-22 together as temperature sensor errors. The UK support documentation specifies that the sensor is either open (broken connection) or shorted (electrical short circuit). The code is generated when the microwave's control electronics detect an out-of-range signal from the thermistor that monitors cavity temperature.

This fault prevents the microwave from operating because the control board cannot safely monitor cooking temperature. Samsung instructs users to unplug the unit and contact service when this code appears. The error can be triggered by a failed sensor, damaged wiring, moisture intrusion from spills or steam, or less commonly a fault in the control board's sensor input circuit.

## Before You Replace Anything

Many people replace the main control board first when the actual fault is a failed $15 temperature sensor or a loose connector. Always test the sensor with a multimeter and inspect the harness before ordering a control board.

## Common Causes

- **Open or shorted temperature sensor (~55%)** The cavity thermistor fails electrically (broken element or internal short), triggering the open or short fault condition Samsung describes.
- **Loose or corroded sensor connector (~20%)** The plug at the sensor or control board works loose, corrodes, or develops damaged pins, creating an intermittent or permanent open circuit.
- **Moisture intrusion in electronics (~15%)** Steam, spills, or condensation reach the sensor circuit or control board, creating temporary short or open conditions until the unit dries.
- **Damaged sensor wiring harness (~7%)** The wire between the sensor and control board is pinched, cut, or has broken strands, causing an open circuit in the temperature sensing loop.
- **Control board sensor input fault (~3%)** The main control board's MICOM sensing input circuit fails even though the sensor and wiring test normal, requiring board-level service.

## Step-by-Step Fix {#fix}

1. **Unplug the microwave** from the wall outlet or switch off the dedicated circuit breaker to eliminate all power before any inspection or repair work.
2. **Wait 60 seconds** and restore power to attempt a simple reset, then test the microwave. If the C-22 code clears and does not return, the fault may have been transient.
3. **Check for moisture exposure**. If the microwave was recently used for steaming or suffered a spill, unplug it and allow at least 24 hours for all internal electronics to dry completely before retesting.
4. **Access the temperature sensor circuit**. Remove the outer cabinet panels (consult your model's service manual for fastener locations). The temperature sensor is typically a small thermistor mounted on or near the oven cavity wall with a two-wire plug.
5. **Inspect the sensor connector and harness**. Look for loose plugs, bent or corroded pins, pinched wires, or physical damage along the harness run between the sensor and the main control board.
6. **Test the temperature sensor** with a multimeter set to resistance (ohms). Disconnect the sensor plug and measure across the thermistor terminals. Samsung's published guidance identifies open or short conditions but does not specify a resistance value, so consult your model's wiring diagram or service manual for the expected range.
7. **Replace the temperature sensor** if it reads open (infinite resistance) or shorted (zero or near-zero resistance), or if the connector is damaged. Install the new sensor, reconnect the harness securely, reassemble the cabinet, and test.
8. **If the sensor and wiring test normal** but the C-22 code persists, the fault lies in the main control board's sensor input circuit. Contact Samsung service or an authorized technician for board-level diagnosis and replacement.

## When to Call a Pro

Call a professional if you are not comfortable working inside the microwave cabinet or do not have a multimeter and the skills to test electrical circuits safely. Microwaves contain high-voltage components (magnetron, capacitor, transformer) that can store lethal charge even when unplugged. A qualified technician has the tools and training to discharge capacitors, test the sensor circuit accurately, and replace the sensor or control board without risk. Also call service if the sensor and wiring test normal but the code persists, because that points to a control-board fault requiring board-level diagnosis. Samsung recommends contacting an authorized service center for all C-22 faults to make sure safe and correct repair.

**Rough cost:** A pro service call runs about $120-250.
