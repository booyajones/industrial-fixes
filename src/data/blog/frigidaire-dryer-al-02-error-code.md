## Frigidaire Dryer AL-02 Error Code — What It Means

AL-02 does not appear in the manufacturer-published Frigidaire dryer fault code lists that include codes like E10, E11, E12, E24, E66, and AD. The display may be showing a different code that is being misread, or your model may use a control platform with a different diagnostic family. Before replacing any parts, confirm the exact characters on the display and locate your model's tech sheet (often taped inside the cabinet or door frame) to verify the correct code meanings for your specific series.

Because the code cannot be confirmed in Frigidaire documentation, the safest first step is a hard power reset. Frigidaire's own support guidance recommends disconnecting power for several minutes to clear transient electronic faults. If the code returns, identify your model number from the rating label and consult the service literature or a technician familiar with that control board generation.

## Before You Replace Anything

Do not order a control board or thermistor until you have confirmed the exact code on your model's tech sheet. A misread code or simple power glitch often clears with a hard reset, saving the cost of unnecessary electronic parts.

## Common Causes

- **Misread or model-specific code (~40%)** The display may show a code from a different control family, or characters are being read incorrectly (for example, AD or A0 mistaken for AL).
- **Control board transient fault (~30%)** A temporary electronic glitch can trigger an unfamiliar code that clears with a hard reset.
- **Moisture-sensor contamination (if code is actually AD) (~15%)** Lint or fabric-softener residue on the drum sensor bars can cause auto-dry errors that are sometimes mistaken for other codes.
- **Thermistor failure (if code is actually E24) (~10%)** A bad thermistor reading out of the nominal 50,000-ohm range can register as a temperature-sensing error.
- **Main control board failure (~5%)** If the reset does not clear the code and the tech sheet confirms no match, the electronic control may need replacement.

## Step-by-Step Fix {#fix}

1. **Photograph the display** while the code is visible so you have an exact record of the characters.
2. **Unplug the dryer** from the wall outlet and wait at least five minutes to perform a hard reset.
3. **Plug the dryer back in** and run a short timed-dry cycle to see if the code returns.
4. **Locate your model and serial number** on the rating label (usually inside the door frame or on the back panel).
5. **Find the tech sheet** taped inside the control-panel housing, the lower kick panel, or the rear access panel, and verify the code list for your series.
6. **If the code is confirmed as AD**, clean the moisture-sensor bars inside the drum with rubbing alcohol and a lint-free cloth.
7. **If the code does not match any published Frigidaire code**, contact Frigidaire support or a technician with your model number and photo to identify the correct diagnostic path.

## When to Call a Pro

Call a technician if the code persists after a hard reset and you cannot locate or interpret the tech sheet for your model. A qualified service provider can cross-reference the control board generation, perform voltage and resistance checks on sensors and wiring, and confirm the exact fault before ordering parts. Professional diagnosis is especially important when the code does not appear in standard Frigidaire documentation, because ordering the wrong electronic component based on a guess can waste both time and money.

**Rough cost:** DIY runs about $0-10, 5-10 min for reset; sensor or board parts $50-150 if confirmed faulty, 30-60 min. A pro service call runs about $100-250 depending on diagnosis and part.
