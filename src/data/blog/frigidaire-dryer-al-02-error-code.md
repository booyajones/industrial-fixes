## Frigidaire Dryer AL-02 Error Code — What It Means

AL-02 does not appear in Frigidaire's documented error code library for dryers. The closest verified code is AD, which indicates an auto-dry or moisture sensor fault. This code appears when the electronic control cannot read the moisture sensor bars inside the drum, often due to residue buildup, a broken wire, or a failed control board. If your display shows something that looks like AL-02, confirm the exact characters and your model number, because it may be a misread AD, EA, or another similar fault code. Restricted airflow from a clogged vent can also contribute to drying problems that trigger sensor-related alarms.

## Common Causes

- **Dirty moisture sensor bars** Fabric softener residue or mineral deposits coat the two metal strips inside the drum and prevent accurate moisture detection.
- **Failed moisture sensor assembly** The sensor bars or their wiring harness can crack, corrode, or lose continuity over time.
- **Defective electronic control board** The main control may fail to process the sensor signal correctly even when the sensor itself is intact.
- **Blocked exhaust vent or lint screen** Poor airflow prevents clothes from drying properly and can cause the control to flag a sensor fault.
- **Loose or corroded wire connections** Vibration or moisture can loosen the spade terminals or corrode the contacts at the sensor or control board.
- **Misread display or incorrect model lookup** Some display styles can make AD look like AL-02, or the code may belong to a different appliance brand entirely.

## Step-by-Step Fix {#fix}

1. Unplug the dryer from the wall outlet or shut off the circuit breaker to kill all power before opening any panel.
2. Open the dryer door and locate the two narrow metal sensor bars mounted on the inside of the drum near the lint screen, then scrub them with a cloth dipped in rubbing alcohol to remove any film.
3. Pull out the lint screen and vacuum the slot, then disconnect the exhaust duct at the back of the dryer and inspect it for lint clogs or crushed sections that restrict airflow.
4. Restore power and run a short auto-dry cycle with damp towels to see if the code clears after cleaning the sensors and vent.
5. If the code returns, unplug again and remove the top or front panel to access the moisture sensor wiring harness, check each spade terminal for tightness and corrosion, and verify continuity across the sensor bars with a multimeter.
6. Test the electronic control board by consulting your model's service sheet for sensor-circuit resistance values, or swap the board if the sensor tests good but the fault persists.
7. Record your exact model number and the characters shown on the display, then search Frigidaire's official code list or call support if AL-02 still does not match any published definition.

## When to Call a Pro

Call a technician if you cannot locate two metal sensor bars inside your drum, if the code displayed does not match any Frigidaire documentation you find online, or if you have already cleaned the sensors and vent but the fault returns immediately. A qualified appliance repair tech can use factory diagnostic software to read internal fault logs, measure sensor resistance against the exact specification for your control board revision, and confirm whether AL-02 is a valid code for your model or a display error that points to a different underlying problem.
