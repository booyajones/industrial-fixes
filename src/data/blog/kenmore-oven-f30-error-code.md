## Kenmore Oven F30 Error Code — What It Means

On most Kenmore ovens and ranges built on Electrolux or Frigidaire controls, the F30 error code indicates that the main control board is not receiving a valid temperature signal from the oven temperature sensor circuit. The control interprets this as an open circuit or a sensor reading that falls outside the expected range, so it flags F30 and typically disables oven operation to prevent unsafe heating.

In practice, the fault is usually in the sensor probe itself, the wiring harness that connects it to the electronic control board, or the control board's input circuit. The temperature sensor is a resistive temperature device (RTD) that changes resistance with temperature. When the circuit is open, shorted to ground, or reads far out of specification, the control throws the F30 code.

## Before You Replace Anything

Many people replace the main electronic control board first when the real problem is a failed sensor or a loose connector. Always test the sensor resistance and inspect the wiring before ordering a new control.

## Common Causes

- **Failed oven temperature sensor (~60%)** The RTD probe itself has failed open or is reading out of range, so the control cannot see a valid temperature signal.
- **Loose or corroded sensor connector (~20%)** The spade terminals or plug at the sensor or control board are loose, oxidized, or making intermittent contact.
- **Damaged sensor wiring harness (~10%)** Wires between the sensor and control board are broken, pinched, or shorted to the metal cabinet.
- **Faulty electronic control board input (~10%)** The sensor and wiring test normal but the control board's temperature input circuit has failed and cannot read the sensor.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker or unplug the range completely before beginning any repair work.
2. **Access the sensor probe** by pulling the range away from the wall and removing the rear access panel or lower rear kick panel to reach the back of the oven cavity.
3. **Locate the temperature sensor probe** mounted in the rear wall of the oven chamber, usually near the top. It is a metal tube about one-quarter inch in diameter with a wire harness leading to the control area.
4. **Disconnect the sensor connector** at the rear of the range and use a multimeter set to ohms to measure resistance across the two sensor terminals. At room temperature the sensor should read approximately 1,080 ohms. An open reading (infinite resistance) or a very low reading indicates a failed sensor.
5. **Inspect the wiring harness and connector** for loose spade terminals, broken wires, heat damage, or corrosion. Check that no wire is shorted to the metal frame of the range.
6. **Replace the oven temperature sensor** if the resistance is out of range or open. Remove the mounting screw or bracket inside the oven cavity, pull the probe out, disconnect the old sensor, install the new probe, and reconnect the harness.
7. **Restore power and test** by running the oven through a bake cycle. If the F30 code returns and the new sensor tests correctly, inspect or replace the wiring harness and then the electronic control board if necessary.

## When to Call a Pro

Call a professional if you are not comfortable working with 240-volt appliances, if you cannot safely access the back of the range, or if you have tested the sensor and wiring and both are in specification but the code persists. A technician can isolate whether the control board input circuit has failed and can source the correct model-specific parts. Also call a pro if the range is still under warranty or if you need the repair documented for a service plan.

**Rough cost:** DIY runs about $20–50 in parts, 30–60 minutes. A pro service call runs about $150–250 including part and labor.
