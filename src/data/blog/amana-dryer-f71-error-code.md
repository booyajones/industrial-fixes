## What this code means
F71 on an Amana dryer is a control communication fault. The code indicates a problem in the internal communication between the main control board and the user interface board, not a venting or airflow issue. The control system cannot exchange data properly, which prevents the dryer from running normally.

Amana's manufacturer guidance for F71 is to power the unit down at the breaker for 5 minutes, restore power, and run a Time Dry cycle to see whether the error returns. If the fault clears, the dryer can return to service. If F71 comes back immediately, the next step is to inspect the control system wiring and boards rather than checking ducts or sensors.

## Before You Replace Anything

Many owners replace the user interface board first, assuming the display is at fault. Before ordering any board, pull the power for 5 minutes and inspect every wire connector at both the main control and the user interface for loose pins or corrosion, since a bad connection is more common than a failed board.

## Common Causes

- **Loose or damaged wire connection (~40%)** A connector between the main control board and the user interface board has worked loose, corroded, or burned, breaking the communication path and triggering F71.
- **Failed main control board (~35%)** The main electronic control board has lost its ability to send or receive signals, usually because of a power surge, moisture intrusion, or component failure on the board itself.
- **Failed user interface board (~20%)** The user interface board (the sub-board behind the console) has failed and can no longer communicate with the main control, often due to heat damage or moisture.
- **Temporary software glitch (~5%)** A transient fault in the control software causes F71 once but clears after a full power reset, with no physical damage present.

## Step-by-Step Fix {#fix}

1. **Turn off power at the breaker.** Flip the circuit breaker for the dryer to OFF and wait a full 5 minutes to allow all capacitors to discharge and the control software to reset.
2. **Restore power and run Time Dry.** Turn the breaker back on, select Time Dry on the console, and start the cycle. Watch for about one minute to see if F71 returns.
3. **If F71 clears, monitor the dryer.** Run a full load and check that the dryer completes the cycle without displaying the error again. If F71 does not come back, no further repair is needed.
4. **If F71 returns, shut off power and open the console.** Remove screws securing the control console (typically along the top or back edge) and carefully tilt or lift the console to expose the control boards and wiring harnesses.
5. **Inspect all wire connectors.** Check every plug between the main control board and the user interface board for loose pins, corrosion, melted plastic, or burn marks. Unplug and reseat each connector firmly. If a connector is damaged, replace the harness.
6. **Test the dryer again.** Restore power and run Time Dry. If F71 is gone, the loose connection was the cause. If the error returns immediately, one of the boards has failed.
7. **Replace the failed board.** If wiring is intact and F71 persists, replace the main control board first (it is the most common board failure for communication faults). If that does not resolve the fault, replace the user interface board. Retest after each replacement.

## When to Call a Pro

Call a technician if you are not comfortable working with 240-volt wiring or removing the dryer console. A pro can quickly test the communication circuit with a multimeter, isolate the failed board, and replace it in one visit. Also call for help if the console shows signs of a short circuit (burn marks, melted plastic, or a burning smell), since that condition can point to a more complex wiring fault that requires tracing the entire harness. If you have already replaced one board and F71 still appears, a technician can verify that the replacement part is correct and that no secondary damage exists elsewhere in the control system.

**Rough cost:** DIY runs about $80–200 in parts (control board), 30–60 min. A pro service call runs about $150–300.
