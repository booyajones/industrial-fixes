## Noritz Error Code 90 — What It Means

Noritz **error code 90** indicates a **combustion abnormality**, usually tied to the combustion fan, air intake, exhaust restriction, or poor burner combustion conditions. On many Noritz tankless units, code 90 shows up when the fan cannot maintain the expected air-to-gas ratio or the unit detects incomplete combustion risk. The heater shuts down to prevent unsafe operation. In practice, this code often points to venting issues, dirty combustion components, or a failing fan motor.

## Common Causes

- **Blocked intake or exhaust vent** — Debris, insect nests, snow, or crushed vent pipe restricts airflow and prevents the combustion fan from moving the designed amount of air.
- **Dirty burner or heat exchanger** — Soot and scale disrupt combustion and make the control board interpret the burn as abnormal.
- **Failing combustion fan motor** — A weak fan motor or dirty blower wheel cannot sustain the RPM needed for stable combustion.
- **Incorrect gas pressure** — Low or fluctuating gas pressure changes the air-fuel ratio enough to trigger code 90.

## Step-by-Step Fix {#fix}

1. **Inspect the venting path** — Check both intake and exhaust terminations outside. Remove leaves, nests, screens clogged with lint, or any sign of sagging vent pipe collecting condensate.
2. **Clean the air intake filter and combustion area** — If your model has an intake filter, wash it. Remove the front cover and inspect the combustion fan and burner area for dust or soot buildup.
3. **Check the combustion fan** — With the unit calling for hot water, listen for the fan ramping smoothly. Grinding noise, weak startup, or surging fan speed points to a failing motor.
4. **Flush or descale the heat exchanger** — Heavy scale can create overheating and unstable combustion conditions. Isolate the unit and descale with a pump kit and approved descaling solution.
5. **Reset the system** — Turn the unit off, wait 30 seconds, and restart. If code 90 returns during the next demand cycle, combustion analysis and gas pressure testing are needed.

## When to Call a Pro

Code 90 involves combustion safety. If venting is clear and the unit still trips, have a licensed tankless water heater technician check gas pressure and run a combustion analysis before further operation.
