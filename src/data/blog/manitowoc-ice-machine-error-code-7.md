## Manitowoc Ice Machine Error Code 7 — What It Means

Manitowoc error code 7 on Indigo and older electromechanical models indicates a **bin thermostat fault** — the machine's bin full sensor or bin thermostat has detected a condition that prevents normal ice making, or the bin control is not cycling correctly. The bin thermostat (or its modern equivalent, a bin sensor switch) stops ice production when the bin is full and restarts it when ice is dispensed. Code 7 appears when this sensor is stuck, failed, or sees an unexpected condition. On Indigo series machines, code 7 can also indicate a bin temperature sensor out of range.

## Common Causes

- **Bin sensor probe covered with ice or frost** — Ice bridging or frost buildup on the bin sensor probe causes it to read as "full" even when the bin is empty.
- **Failed bin thermostat or sensor** — The sensor or thermostat fails, sending a constant "full" or "fault" signal to the controller.
- **Ice stuck in the bin (bridging)** — A large ice bridge above the bin level sensor can prevent the sensor from detecting the actual ice level correctly.
- **Wiring fault to the bin sensor** — Loose or corroded wiring to the bin thermostat causes an intermittent or out-of-range signal.

## Step-by-Step Fix {#fix}

1. **Inspect the bin** — Open the ice bin lid and look at the ice level. If the bin is clearly not full but the machine is stopped, the sensor may be iced over or the ice may have bridged.
2. **Break up any ice bridge** — Use a clean plastic scoop (never a metal tool) to break up any ice bridging over or around the bin sensor probe. Remove excess ice if the bin is overfull.
3. **Defrost the bin sensor probe** — If the probe has frost buildup, allow it to warm up with the bin lid open for a few minutes, or use a towel soaked in warm water to clear frost from the probe.
4. **Inspect the bin sensor wiring** — Locate the bin thermostat or sensor (typically a metal probe hanging into the ice bin compartment). Check the wiring connector for corrosion or looseness.
5. **Test the bin thermostat** — With the probe at room temperature (not in ice), test continuity across the thermostat. On a normally-open thermostat, it should be open at room temperature and close in ice. Reversed behavior = replace the thermostat.
6. **Reset the machine** — Power the machine off for 30 seconds and back on. The Indigo display will restart the fault evaluation cycle.

## When to Call a Pro

If code 7 persists after clearing ice and confirming the sensor is unobstructed, the Indigo controller board may have a failed input or the sensor may require calibration. Contact a Manitowoc-authorized service technician for Indigo controller diagnostics.
