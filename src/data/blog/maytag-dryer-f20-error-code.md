## What this code means
The F20 error code on a Maytag dryer indicates a moisture-sensing or no-dry-detected type fault. Maytag's official guidance is to power-cycle the unit for five minutes and then run a Timed Dry cycle to see whether the code returns. The exact underlying fault is model-dependent, and Maytag's published dryer help page does not define the specific component failure. This code is being raised by the dryer's internal diagnostic system rather than a simple user setting issue.

Do not confuse this dryer code with F20 on Maytag washers, which indicates a water-inlet problem. For dryers, the most credible causes are a temporary control glitch, sensor or airflow-related detection issues, or an electronic control problem. Without access to your exact model's service manual, more specific diagnosis cannot be confirmed.

## Before You Replace Anything

Homeowners sometimes replace the main control board before checking for loose wiring or performing a simple five-minute power reset, which clears most temporary faults at no cost.

## Common Causes

- **Temporary control glitch (~50%)** A transient software fault in the control board can trigger F20, and a five-minute power reset clears it in most cases.
- **Moisture sensor failure or contamination (~25%)** Lint or residue on the moisture sensor bars or a failed sensor can prevent the dryer from detecting dryness correctly.
- **Faulty main control board (~15%)** A defective electronic control board may incorrectly report a sensing fault even when all sensors are working.
- **Loose or corroded wiring harness (~10%)** Poor connections between the control board and sensors can cause intermittent F20 codes.

## Step-by-Step Fix {#fix}

1. **Turn off the circuit breaker(s)** supplying power to the dryer and leave them off for a full five minutes to allow the control board to reset.
2. **Restore power** by switching the breaker(s) back on.
3. **Start a Timed Dry cycle** on the dryer and let it run for at least one minute.
4. **Watch for the F20 code** to see if it reappears during the test cycle.
5. **If the code returns**, write down your exact model number from the data plate inside the door or on the rear panel and consult the matching service manual for component-level diagnostics.
6. **Inspect the moisture sensor bars** inside the drum for lint or residue. Clean them with rubbing alcohol and a soft cloth if necessary.
7. **Check wiring harness connections** between the control board and the moisture sensor. Reseat any loose connectors and look for corrosion or damage.
8. **Replace the main control board** only after confirming all sensors and wiring are intact and the fault still persists on every Timed Dry test.

## When to Call a Pro

Call a professional if the F20 code persists after a power reset and you are not comfortable removing the dryer cabinet to inspect wiring or test the control board with a multimeter. A technician has the service manual and test equipment to diagnose model-specific sensing circuits and can confirm whether the control board, sensor assembly, or wiring harness is at fault. Also call a pro if you need the dryer back in service quickly and do not want to risk ordering the wrong part, since Maytag does not publish part-level diagnostics for F20 on its public help page.

**Rough cost:** DIY runs about $80-200 in parts, 1-2 hours. A pro service call runs about $150-350.
