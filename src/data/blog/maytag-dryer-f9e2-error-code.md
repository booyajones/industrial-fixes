## What this code means
The F9E2 code does not appear in Maytag's dryer fault code documentation. Maytag dryers use F3E2 for a moisture sensor issue, which appears after five consecutive loads dry without the sensor registering moisture. If you saw F9E2 on your dryer display, double-check the code on the screen. You may have misread F3E2, or your model uses a non-standard code path. On Maytag dishwashers, F9E2 indicates a drain fault, but that meaning does not transfer to dryers.

If the code is actually F3E2, it means the moisture sensor bars inside the drum are not detecting wet laundry. Common triggers include very small loads or a single item that never touches the sensors, a dryer that is not level, or a failed sensor connection. Maytag recommends clearing the code by pressing Power, then turning the circuit breaker off for five minutes if the code persists, and running a Timed Dry cycle to check if the fault returns.

## Before You Replace Anything

Homeowners often replace the main control board when the fault is actually a loose or corroded connector at the moisture sensor bars inside the drum. Clean the sensor bars with a Scotch-Brite pad and check the connector first.

## Common Causes

- **Misread fault code (~40%)** The display shows F3E2 (moisture sensor) but was read as F9E2, or the model uses a non-standard code variant.
- **Very small load or single item (~25%)** Maytag documents that a single towel or very small load may never contact the moisture sensor bars, causing the F3E2 fault.
- **Dryer not level (~15%)** An unlevel dryer prevents laundry from tumbling into contact with the moisture sensors during the cycle.
- **Dirty or corroded moisture sensor bars (~10%)** Fabric softener residue or mineral buildup on the sensor strips inside the drum blocks conductivity readings.
- **Loose or damaged sensor wiring (~7%)** A corroded connector or broken wire between the sensor bars and the control prevents moisture data from reaching the board.
- **Failed control board moisture input (~3%)** The circuit that reads the moisture sensor signal on the main control has failed, even though the sensors and wiring are good.

## Step-by-Step Fix {#fix}

1. Press Power to turn off the dryer and clear the displayed code from the control.
2. Check the display carefully to confirm whether the code reads F9E2 or F3E2, since Maytag's dryer documentation lists F3E2 as the moisture sensor fault.
3. Locate the circuit breaker(s) that supply the dryer and turn them off, wait five minutes, then turn them back on to reset the control logic.
4. Open the dryer door and find the two vertical moisture sensor bars on the inside wall of the drum, usually near the lint filter or on the front drum rim.
5. Clean both sensor bars with a Scotch-Brite pad or fine sandpaper to remove fabric softener residue, mineral deposits, and any corrosion, then wipe them dry.
6. Place a level on top of the dryer and adjust the leveling feet front-to-back and side-to-side so the machine sits flat on the floor.
7. Run a Timed Dry cycle with a normal-sized load and watch the display to see if the code reappears during or after the cycle.
8. If the code returns, unplug the dryer, pull it forward, and remove the lower front or rear access panel to inspect the sensor wiring connector for corrosion or loose pins.
9. If the sensor connector is clean and secure and the code still appears, call for service to test the moisture sensor circuit and the main control board.

## When to Call a Pro

Call a technician if the code reappears after you have cleared it with a breaker reset, cleaned the moisture sensor bars, verified the dryer is level, and confirmed a normal-sized load. A pro will measure continuity and resistance through the sensor circuit, inspect the connector for hidden corrosion, and test the control board's moisture-sensor input with a multimeter. If your dryer displays F9E2 and you cannot find that exact code in your owner's manual or on the wiring diagram, a tech can cross-reference the model number against service bulletins to determine whether it is a non-standard code or a display fault.

**Rough cost:** DIY runs about $15-50 in parts, 20-40 min. A pro service call runs about $120-250.
