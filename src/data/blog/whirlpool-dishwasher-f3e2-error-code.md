## Whirlpool F3E2 Error Code — What It Means

F3E2 is not a standard Whirlpool dishwasher error code according to manufacturer documentation. This code appears on Whirlpool commercial-grade residential dryers, where it indicates the unit has completed five consecutive drying cycles without registering any moisture sensor data. The dryer's control board expects to see changing resistance values from the moisture sensor as wet fabric dries. When that signal is absent for five loads in a row, the board logs F3E2.

If you are seeing F3E2 on a dishwasher display, verify the exact model number and check the service manual for that specific platform. The code may be model-specific or the display may be showing a different code. For dryers, F3E2 points to a broken wire in the sensor circuit, a failed moisture sensor, or occasionally a main control board issue.

## Common Causes

- **Broken sensor wiring** A cut, pinched, or corroded wire in the harness between the moisture sensor and control board will prevent the signal from reaching the controller.
- **Failed moisture sensor** The temperature and moisture sensor can drift out of its normal resistance range or fail open, sending no usable data to the board.
- **Dryer not level** An unlevel dryer can cause uneven tumbling and prevent the moisture sensor bars from making consistent contact with the load.
- **Load too small** Very small loads may not make reliable contact with the sensor strips inside the drum, causing the board to miss moisture readings.
- **Faulty control board** In rare cases the main control board itself loses the ability to read or process the sensor signal even when the sensor circuit is intact.

## Step-by-Step Fix {#fix}

1. **Verify the appliance type** by checking the model number on the rating plate. Confirm whether you have a dishwasher or a dryer, since F3E2 is documented only for Whirlpool dryers.
2. **Power down the unit** by unplugging the appliance or switching off the circuit breaker at the panel and waiting two minutes to clear fault memory.
3. **Access the moisture sensor** by opening the dryer door and locating the two metal sensor strips mounted on the inside rear wall or lint filter housing of the drum.
4. **Inspect the wiring harness** that connects the sensor to the main control board for loose connectors, broken insulation, or corroded terminals.
5. **Test the sensor resistance** using a multimeter set to ohms. Place one probe on each sensor bar and verify the reading falls within the expected range, typically around 9.8 kΩ to 14.8 kΩ at room temperature.
6. **Check that the dryer is level** front to back and side to side using a bubble level on top of the cabinet. Adjust the leveling legs as needed.
7. **Reassemble and restore power**, then run a small test load of damp towels to verify the sensor registers moisture and the code clears.

## When to Call a Pro

Call a technician if you have confirmed the appliance is a dishwasher and cannot locate F3E2 in your service manual, since the code may indicate a control board fault specific to that platform. For dryers, if the sensor tests within range and all wiring is intact but the code persists, the main control board is the likely culprit and requires diagnostic equipment to confirm. Any work involving the control board or internal high-voltage wiring should be handled by a qualified appliance repair technician.
