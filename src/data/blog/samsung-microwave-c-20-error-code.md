## Samsung C-20 Error Code — What It Means

C-20 on a Samsung range or oven signals a temperature sensor malfunction. The control board sees the oven sensor signal outside the expected resistance range, either shorted below 950 Ω or open above 2950 Ω. Samsung groups C-20, C-21, and C-22 together as sensor faults, with C-20 specifically indicating the oven temperature probe is reading incorrectly or not at all.

In practical terms, the oven cannot regulate temperature because the control has lost reliable feedback from the sensor. The most common cause is a failed oven temperature sensor itself, though damaged wiring, loose connectors, or a control-board circuit problem can also trigger the code. A power reset may clear a transient fault, but if the code returns the sensor circuit needs testing.

## Before You Replace Anything

Many people replace the main control board first. Test the sensor resistance with a multimeter and inspect the harness and connectors before ordering any board.

## Common Causes

- **Failed oven temperature sensor (~65%)** The sensor probe itself shorts or opens, reading outside the 950–2950 Ω window and triggering the fault.
- **Damaged, rubbed, or burned sensor wiring (~20%)** Wires between the sensor and control become frayed, pinched, or burned, breaking the circuit or causing intermittent contact.
- **Loose or corroded sensor connector (~10%)** The plug at the sensor or at the control board works loose, corrodes, or develops poor pin contact.
- **Control board input circuit fault (~5%)** The main PCB's sensor input path or connector pins fail, even when the sensor and harness test correctly.

## Step-by-Step Fix {#fix}

1. **Turn off power at the circuit breaker.** Wait at least 30 seconds, then restore power to reset the control and clear transient faults.
2. **Enter diagnostics mode** (if your model supports it) to confirm the stored fault code is C-20 and check for additional codes.
3. **Locate the oven temperature sensor.** It is a metal probe mounted through the rear wall of the oven cavity, typically secured by one or two screws and connected to a two-pin harness plug.
4. **Disconnect the sensor plug** and measure resistance across the sensor terminals with a multimeter set to ohms. A reading below 950 Ω or above 2950 Ω confirms a failed sensor.
5. **Inspect the sensor wiring and connectors** for rubbed insulation, burned spots, loose pins, or corrosion at both the sensor end and the control-board end.
6. **Replace the oven temperature sensor** if it tests out of range or shows physical damage. Remove the mounting screws, pull the probe from the oven, transfer the harness connector, and install the new sensor in reverse order.
7. **Restore power and test.** Run a preheat cycle and verify the code does not return and the oven reaches the set temperature normally.

## When to Call a Pro

Call a technician if you are uncomfortable working near high-voltage wiring at the rear of the range, if the sensor and harness both test correctly but the code persists (indicating a control-board fault), or if diagnostic mode reveals multiple stored codes suggesting a broader electrical problem. Also call if the sensor is difficult to reach (for example in a wall oven requiring cabinet removal) or if you lack a multimeter and cannot verify resistance before ordering parts.

**Rough cost:** DIY runs about $20–50 in parts, 30–45 min. A pro service call runs about $150–250.
