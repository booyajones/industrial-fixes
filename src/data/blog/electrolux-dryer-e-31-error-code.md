## Electrolux Dryer E31 Error Code — What It Means

On Electrolux and Frigidaire dryers, E31 is a moisture sensor feedback fault. The control board is seeing the sensor signal as too high or otherwise out of range, so Auto Dry and Sensor Dry cycles cannot read fabric moisture correctly. One Electrolux IQ-Touch reference states the moisture sensor feedback frequency is too high for E31. Service documentation describes this code family as a moisture-sensing system fault or moisture sensor failure.

If Timed Dry works normally but Sensor Dry modes trip E31, the moisture-sensing circuit is the primary suspect. The code is model-specific to dryers. One unrelated Electrolux appliance reference ties E31 to a cooktop generator fault, so always verify your appliance type and model before diagnosing.

## Common Causes

- **Residue or film on the moisture sensor bars** Fabric softener, dryer sheets, lint, or other contamination on the sensor bars inside the drum prevent accurate moisture readings.
- **Damaged or loose sensor wiring** Broken, pinched, or corroded wiring or connectors between the sensor bars and the main control board disrupt the sensor signal.
- **Failed moisture sensor bars or sensor strip** Physical damage or electrical failure of the sensor assembly itself causes persistent out-of-range readings.
- **Main control board misreading sensor input** After the sensor circuit checks good, the electronic control board may be interpreting the signal incorrectly or have internal faults.

## Step-by-Step Fix {#fix}

1. **Verify the complaint** by running a Sensor Dry or Auto Dry cycle and confirm E31 appears, then test a Timed Dry cycle to see if it completes without error.
2. **Unplug the dryer** and let it sit for at least two minutes to clear residual power and reset the control board.
3. **Locate and clean the moisture sensor bars** inside the drum (usually two metal strips on the front or rear drum rim) using a soft cloth dampened with rubbing alcohol or mild cleaner, not sprayed directly on the bars.
4. **Inspect the sensor wiring harness and connectors** for looseness, corrosion, breaks, or pinched wires, and repair or replace any damaged wiring or connectors as needed.
5. **Restore power** and run a short Sensor Dry test cycle with a damp load to see whether E31 returns after cleaning and wiring checks.
6. **Replace the moisture sensor bars or sensor strip** if physical damage is visible or the code persists after cleaning and wiring repairs.
7. **Replace the electronic control board** if the sensor bars and wiring are sound, cleaning has been done, and E31 continues to appear in Sensor Dry modes.

## When to Call a Pro

Call a professional if you are uncomfortable working with 240-volt appliances or if E31 persists after you have cleaned the sensor bars, inspected all wiring, and restored power. A qualified appliance technician has the tools to test sensor resistance, trace wiring continuity, and verify control board operation. If the dryer is still under warranty, contact Electrolux or an authorized service center before attempting repairs to avoid voiding coverage.
