## Kenmore Dryer F78 Error Code — What It Means

The F78 error code on a Kenmore dryer indicates a communication fault between the main electronic control board and the keypad or user-interface control. The two control units are not exchanging data correctly. This is an electronic logic problem, not a mechanical or airflow issue.

When F78 appears, the dryer's internal diagnostics have detected that the main control cannot talk to the keypad panel. The fault can be caused by damaged wiring, a loose connector, or a failed control board on either side of the communication path.

## Common Causes

- **Loose or disconnected wire harness** The multi-pin connector between the main control and the keypad assembly has backed out, become loose, or lost contact at one or both ends.
- **Damaged harness or pinched wires** The wire harness running between the two control boards has been crushed, cut, or has broken conductors that interrupt the communication signal.
- **Corroded or damaged connector pins** Moisture, heat, or age has corroded the contact pins inside the harness connectors, preventing reliable electrical contact.
- **Failed keypad or user-interface control assembly** The keypad control board itself has failed and can no longer send or receive communication signals to the main control.
- **Failed main electronic control board** The main control board has suffered component failure or surge damage and cannot communicate with the keypad assembly.
- **Power surge or intermittent power event** A voltage spike or brief power interruption has damaged the communication circuits on one or both control boards.

## Step-by-Step Fix {#fix}

1. **Disconnect power** to the dryer by unplugging it or switching off the circuit breaker before any inspection or repair work.
2. **Remove the console or top panel** to gain access to the keypad assembly and the main control board, following your model's disassembly procedure.
3. **Inspect the wire harness** that runs between the main control board and the keypad control, looking for crushed wires, breaks, or visible damage along the entire length.
4. **Check both connectors** at the main control and at the keypad assembly, ensuring they are fully seated with no backed-out pins, corrosion, or debris inside the connector housings.
5. **Reseat all connectors** firmly, then restore power and run a short test cycle to see if the F78 code clears and stays cleared.
6. **If the code returns immediately**, replace the keypad or user-interface control assembly first, as it is the more common failure point in communication faults.
7. **If replacing the keypad does not resolve F78**, replace the main electronic control board, since the fault lies on one side or the other of the communication path.

## When to Call a Pro

Call a professional if you are not comfortable working with 240-volt appliances, if disassembly of the console or control area is unclear for your model, or if you have replaced both the keypad assembly and the main control board and the F78 code still appears. Communication faults sometimes require service-mode diagnostics and board-level troubleshooting that go beyond typical DIY scope. A qualified appliance technician has the tools and training to isolate intermittent faults and verify proper communication between control boards.
