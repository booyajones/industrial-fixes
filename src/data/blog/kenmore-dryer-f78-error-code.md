## Kenmore Dryer F78 Error Code — What It Means

The F78 code on your Kenmore dryer indicates a restricted communication fault between the main electronic control unit and the keypad or panel control unit. The two boards talk to each other through a wire harness, and this code appears when that conversation is interrupted or degraded.

In most cases the problem is not a failed board but a loose, damaged, or corroded connector in the harness that links the two assemblies. Whirlpool service documentation (Kenmore dryers are often Whirlpool-built) groups F72 through F78 as communication faults and directs technicians to start with a power reset, then check the harness and connectors before replacing any control assembly.

## Before You Replace Anything

Many people replace the main control board first, spending $150 or more, when the real culprit is a $0 fix: reseating the harness plugs at both ends or replacing a $20 damaged harness.

## Common Causes

- **Loose or poorly seated harness connectors (~40%)** Vibration during tumbling can work the plug at either the main control or keypad end loose, breaking the communication path.
- **Damaged or pinched wire harness (~25%)** The harness can be pinched when the control panel is reassembled after service, or wires can fatigue and break internally at the flex points.
- **Corroded or oxidized connector pins (~15%)** High humidity or a leak in the dryer vent can corrode the metal contacts inside the harness plugs, increasing resistance and blocking clean signals.
- **Failed keypad or panel control assembly (~12%)** The keypad board itself can fail, though this is less common than wiring issues.
- **Failed main electronic control board (~8%)** If the harness and keypad both check good, the main control can be the source of the communication fault.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker and wait 5 minutes, then restore power and check whether the F78 code reappears.
2. **Unplug the dryer** and pull it away from the wall so you can access the rear or top control panel.
3. **Remove the control panel cover** by unscrewing the fasteners (typically Phillips screws along the top edge or rear lip) and lifting or tilting the panel forward.
4. **Locate the wire harness** that runs between the main control board (usually mounted inside the cabinet or on the rear panel) and the keypad or user-interface board (mounted behind the front control panel).
5. **Disconnect and reseat both ends** of the harness, pressing firmly until you hear or feel the locking tab click. Inspect each connector for bent pins, corrosion, or cracks.
6. **Examine the harness itself** along its length for pinched insulation, broken wires, or sharp bends. Replace the harness if you find any damage.
7. **Reassemble the control panel** and restore power. Run a test cycle to verify the code is gone. If F78 returns, replace the keypad control assembly, then the main control board if needed.

## When to Call a Pro

Call a technician if you are uncomfortable working inside the dryer's control panel, if you cannot identify the correct harness or control boards for your model, or if the code persists after you have reseated the harness and replaced the keypad assembly. A qualified appliance tech can use a multimeter to trace continuity in the harness and verify whether the main control board is sending or receiving signals properly. Also call if your dryer is still under warranty, because opening the control panel yourself may void coverage.

**Rough cost:** DIY runs about $20-80 in parts (harness or keypad), 30-60 min. A pro service call runs about $150-300.
