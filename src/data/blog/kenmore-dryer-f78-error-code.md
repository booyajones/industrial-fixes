## Kenmore Dryer F78 Error Code — What It Means

The F78 error code on a Whirlpool-built Kenmore dryer indicates a communication problem between the main electronic control board and the keypad or user interface control panel assembly. This code belongs to the F72 through F78 fault family, all of which point to restricted communication between these two control modules rather than an airflow or mechanical issue.

The dryer has detected that signals between the main control and the keypad are not being transmitted or received properly. This can be caused by physical wiring damage, loose connectors, or a failed control board on either end of the circuit. A transient logic glitch can also trigger the code and may clear after a full power reset.

## Before You Replace Anything

Many people replace the main control board or keypad panel without checking the wiring first. Always inspect and reseat the wire harness connectors at both ends before ordering any control boards.

## Common Causes

- **Loose or unseated connectors (~40%)** The wire harness plugs at the main control or keypad assembly are not fully seated, have worked loose from vibration, or have corroded pins that no longer make good contact.
- **Damaged wire harness (~30%)** The ribbon cable or wire bundle between the two boards has been pinched, cut, heat-damaged, or has broken conductors inside the insulation.
- **Failed keypad or user interface control (~15%)** The control panel assembly that houses the buttons and display has an internal fault and can no longer communicate with the main board.
- **Failed main electronic control board (~10%)** The main control unit mounted near the motor or blower has a communication circuit failure and cannot send or receive signals from the keypad.
- **Transient control logic fault (~5%)** A temporary software or memory glitch in one of the control modules triggers the code but clears after a full power-down reset.

## Step-by-Step Fix {#fix}

1. **Turn off power at the circuit breaker** and unplug the dryer from the wall outlet to de-energize the unit completely.
2. **Wait five minutes**, then restore power and check whether the F78 code reappears when you start a cycle. If the code is gone, the fault may have been a transient glitch and no further action is needed.
3. **Open the dryer cabinet** by removing the top panel or console to access the main control board and keypad assembly. Consult your model's service manual for the exact disassembly procedure.
4. **Inspect the wire harness and connectors** that link the main control to the keypad panel. Look for loose plugs, bent or corroded pins, pinched wires, or damaged insulation anywhere along the harness routing.
5. **Unplug and reseat each connector** at both the main control and the keypad board, pressing firmly until you feel or hear a positive click. Check that no wires have pulled out of the connector housings.
6. **Reassemble the dryer**, restore power, and run a test cycle. If the F78 code returns immediately, replace the keypad assembly first (it is usually easier and less expensive to swap). If the code persists after keypad replacement, replace the main electronic control board.
7. **Record your model and serial number** before ordering parts to match the correct control assemblies for your dryer. Verify all wire harness routings are clear of sharp edges and heat sources when you close up the cabinet.

## When to Call a Pro

Call a professional appliance technician if you are uncomfortable working inside the dryer cabinet, if you cannot locate or access the control boards, or if the F78 code returns after you have reseated all connectors and replaced both the keypad and main control board. A technician can use diagnostic software and signal-tracing tools to isolate intermittent faults in the communication circuit that are not visible during a static inspection. Also call a pro if your dryer is still under warranty, since self-repair may void coverage on control assemblies.

**Rough cost:** DIY runs about $80–$250 in parts (control board or keypad assembly), 45–90 min. A pro service call runs about $150–$350.
