## Frigidaire F30 Error Code — What It Means

The F30 code on a Frigidaire electric range signals an open probe fault. The electronic control board cannot read a valid signal from the oven temperature sensor (RTD) circuit. This happens when the sensor itself has failed, the wiring harness between the sensor and control is damaged or loose, or the connector has corroded. Frigidaire treats this as an electrical circuit issue, not a mechanical oven problem.

The control expects to see a resistance value from the RTD sensor at all times. When that circuit appears open or infinite, the F30 code triggers and the oven will not operate normally. A power reset clears the fault temporarily if the problem is intermittent, but a true hardware failure will cause the code to return immediately.

## Before You Replace Anything

Many people replace the electronic control board first. Always test the RTD sensor resistance (should read 1,080-1,100 ohms at room temperature) and inspect the harness connector before replacing any control.

## Common Causes

- **Failed oven RTD sensor (~60%)** The resistance temperature detector inside the oven cavity reads open or far out of the normal 1,080-1,100 ohm range and can no longer signal temperature to the control.
- **Loose or corroded sensor connector (~20%)** The plug between the sensor pigtail and the range harness has worked loose, corroded, or shows carbon tracking from arcing.
- **Broken or chafed sensor wiring (~12%)** The wire bundle between the sensor and control has been pinched, cut by sharp metal, or burned through at a hot spot.
- **Failed electronic oven control (~8%)** The control board input circuit for the RTD has failed even though the sensor and harness test within specification.

## Step-by-Step Fix {#fix}

1. **Kill all power** to the range by unplugging it or switching off the dedicated circuit breaker at your panel.
2. **Reset the control** by leaving power off for 30 seconds, then restore power and observe whether the F30 code returns immediately or during a bake cycle.
3. **Access the oven RTD sensor** by removing the back panel or interior oven panel according to your model, then locate the thin metal probe mounted to the rear oven wall.
4. **Inspect the sensor connector** and harness for loose pins, corrosion, burn marks, or chafed insulation, and repair or replace any damaged wiring.
5. **Measure sensor resistance** with a multimeter set to ohms, probing across the two sensor terminals at room temperature and confirming a reading of approximately 1,080 to 1,100 ohms.
6. **Replace the RTD sensor** if it reads open, infinite, or far outside the normal range, and secure the new sensor in the original mounting location.
7. **Reassemble and test** by restoring power, running a bake cycle at 350°F for 15 minutes, and verifying the F30 code does not return and the oven heats normally.

## When to Call a Pro

Call a professional if you are not comfortable working inside a 240-volt electric range, if the sensor and harness both test correctly but the code remains, or if the electronic control board needs replacement and you lack experience with high-voltage appliance wiring. A technician has the service manual resistance tables, the correct OEM control board, and the tools to verify the control input circuit before ordering expensive parts. Also call if the oven shows additional codes, unusual arcing sounds, or if you smell burning plastic, since those symptoms point to a more complex electrical fault that requires diagnostic equipment.

**Rough cost:** DIY runs about $15-40 for sensor, 20-40 min. A pro service call runs about $120-220 service call and sensor replacement.
