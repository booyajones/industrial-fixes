## Maytag Washer LOC Error Code — What It Means

The LOC or LC code on a Maytag washer means the Control Lock feature is active, not a mechanical failure. When this feature is enabled, the control panel locks to prevent accidental button presses during a cycle. The washer will ignore most inputs until you unlock it. This is a user-interface state, not a fault with fill, drain, or motor systems.

## Common Causes

- **Control Lock was turned on accidentally** The most common cause is pressing and holding the Control Lock button (or a dual-function key like Control Lock/Steam/Extra Rinse) for a few seconds, which activates the lock.
- **Button mapping confusion on older models** Some Maytag models do not label the Control Lock key clearly, and users unknowingly press the correct unlock button without realizing its dual function.
- **Temporary control panel glitch** Occasionally the display gets stuck showing LOC/LC even after the lock should have cleared, requiring a power reset to restore normal operation.
- **Control panel or touchpad membrane issue** If the Control Lock button does not respond or the panel does not register the unlock command, the touchpad assembly may have a fault.

## Step-by-Step Fix {#fix}

1. **Confirm the display shows LOC or LC** and that no other error codes are present, since this is a lock condition rather than a component fault.
2. **Press and hold the Control Lock button for 3 seconds** on most Maytag models to disable the lock (check your owner's manual if no dedicated button is labeled).
3. **Watch for the lock indicator to clear** on the display and try pressing other buttons to verify the panel responds normally.
4. **If the code remains, unplug the washer** or disconnect power at the breaker for a few minutes, then restore power and attempt to unlock again.
5. **Press Pause or Cancel twice, then Power once** if your Maytag front-load model requires this sequence to fully clear the lock state after unlocking.
6. **Test the Control Lock button and other keys** for responsiveness after the reset. If buttons feel stuck or do not register presses, inspect the control panel for damage.
7. **If LOC/LC will not clear after a reset and the panel does not respond**, the touchpad assembly or main control board may need inspection or replacement by a qualified technician.

## When to Call a Pro

Call a technician if the LOC/LC code will not clear after you have held the Control Lock button for 3 seconds and performed a full power reset. Also seek professional help if the control panel buttons do not respond at all, if the display shows additional error codes alongside LOC/LC, or if you are uncomfortable working with the washer's electrical connections. A qualified appliance repair tech can test the touchpad assembly and main control board to determine whether a component replacement is necessary.
