## Maytag Washer LOC Error Code — What It Means

The LOC (or LC) code on a Maytag washer is not a failure code in normal operation. It indicates that the Control Lock feature has been activated, either intentionally or accidentally, and the keypad is locked out to prevent unintended cycle changes or button presses. This is a status message, not a component fault.

If the code will not clear using the standard unlock procedure, the underlying issue is typically a stuck button on the touchpad, a failed user interface panel, or a control board that is not registering the unlock command. The code itself simply confirms the lock state is active.

## Before You Replace Anything

Many homeowners replace the main control board thinking LOC is a fault code, when the real issue is often a stuck button on the touchpad or simply forgetting to hold the unlock button long enough. Always try the unlock sequence and a full power reset before ordering any parts.

## Common Causes

- **Control Lock activated (~75%)** The user or a child accidentally pressed the Control Lock button or key combination, locking the keypad as designed.
- **Stuck or shorted touchpad button (~15%)** A button on the control panel is physically stuck or internally shorted, preventing the lock state from clearing even when the unlock command is issued.
- **Failed user interface or control panel assembly (~7%)** The touchpad membrane or interface board has failed and cannot process the unlock input or clear the lock status.
- **Control board not processing unlock command (~3%)** The main electronic control board is not responding to the unlock signal from the user interface, keeping the lock active.

## Step-by-Step Fix {#fix}

1. **Confirm the display shows LOC or LC.** Check your owner's manual to identify the exact Control Lock button or key combination for your model, as older models may use a different sequence.
2. **Press and hold the Control Lock button** (often labeled with a padlock icon) for 3 to 5 seconds until the LOC or LC indicator disappears from the display.
3. **If the code remains, unplug the washer** from the wall outlet or turn off the circuit breaker supplying power to the machine.
4. **Wait 5 minutes** to allow the control board to fully discharge and reset any stuck lock state in memory.
5. **Restore power** and check if the LOC code has cleared and the keypad responds to button presses.
6. **Inspect the control panel** for any button that feels stuck, does not spring back, or shows visible damage. Press each key gently and confirm it clicks normally.
7. **If the code still will not clear,** replace the user interface panel assembly. If a new panel does not resolve the issue, replace the main electronic control board.

## When to Call a Pro

Call a professional if you are uncomfortable working with 120-volt wiring behind the control panel, if the unlock procedure and power reset do not clear the code and you are unsure which part to replace, or if the washer shows additional error codes or symptoms after the LOC is cleared. A technician can verify whether the user interface or the main control board is at fault, test internal signals between boards, and make sure the replacement part is installed and calibrated correctly for your specific Maytag model.

**Rough cost:** DIY runs about $80-180 for user interface panel if replacement needed, 20-40 min. A pro service call runs about $150-280 including service call and panel replacement.
