## Frigidaire Dryer AL-05 Error Code — What It Means

AL-05 does not appear in published Frigidaire dryer error code documentation. The most similar verified code is E52, which indicates a motor relay stuck closed or motor relay control fault on Frigidaire dryers. If your display shows AL-05, confirm the exact characters and check your model number on the data plate. The fault may be model-specific service code, a misread display, or a control board error that requires reset and testing.

[Jump to Fix](#fix)

## Common Causes

- **Main control board motor relay stuck closed** The most common cause for E52 faults on Frigidaire dryers is a failed relay on the main control board that cannot release the motor circuit.
- **Power interruption or unstable supply voltage** Brief outages, brownouts, or breaker trips can lock the control board relay in a fault state that persists after power returns.
- **Faulty drive motor or start circuit** A motor that draws excessive current or fails to start can trigger relay protection faults if the control board detects abnormal conditions.
- **Control board memory corruption** Older boards may display incorrect codes or lock into fault mode after repeated power cycles or component wear.

## Step-by-Step Fix {#fix}

1. **Turn off the dryer circuit breaker** at your home panel and leave it off for a full five minutes to allow the control board to reset completely.
2. **Restore power** and press the start button to see if the code clears and the dryer begins a normal cycle.
3. **Watch the start behavior** closely: note whether the dryer clicks, the drum tries to turn briefly, or the error returns immediately without any motor sound.
4. **Verify stable power supply** by checking that the breaker is not tripping repeatedly and that you have proper voltage at the outlet using a multimeter.
5. **Record the exact model number** from the data plate inside the door or on the rear panel and confirm the exact characters displayed on the console.
6. **If the code persists** after reset and power is stable, the main control board is the primary suspect and internal testing of the motor relay circuit is required.
7. **Consider the drive motor** if the dryer clicks or hums but the drum does not turn, as motor faults can also cause relay-related errors on some models.

## When to Call a Pro

Call a technician if the error returns after a full power reset, if you cannot verify the exact code against your model's service sheet, or if you are not comfortable testing live voltage and control board relay circuits. Internal diagnostics for motor relay faults require a multimeter and familiarity with control board pinouts. If your dryer is still under warranty or you do not have the exact model documentation, professional diagnosis will save time and prevent incorrect part replacement.
