## LG Range H5 Error Code — What It Means

The H5 error code on LG ranges indicates a problem detected by the oven's control system, though the exact meaning varies by model and year. Some LG ranges use H5 to flag a heating element issue, a temperature sensor fault, or a relay problem on the main control board. Because LG uses different diagnostic codes across its product lines, consult your owner's manual or the wiring diagram inside the control panel for the precise definition on your model.

In general, H5 points to a failure in the oven's heating circuit. The control board expects to see normal current draw and temperature rise during bake or broil cycles. When sensors or elements fall outside expected ranges, the board logs the fault and displays H5. Do not continue to use the oven until you identify and resolve the underlying cause, as operating with a fault can damage the control board or create a fire hazard.

## Before You Replace Anything

Many people replace the main control board first when they see any error code, but a loose wire at the oven temperature sensor or a failed bake element is far more common. Test resistance on the sensor and element with a multimeter before ordering a new board.

## Common Causes

- **Faulty oven temperature sensor (~35%)** The sensor sends incorrect resistance readings to the control board, triggering the H5 fault when values fall outside the expected range.
- **Failed bake or broil element (~30%)** A broken or grounded heating element draws no current or too much current, causing the board to register a heating circuit fault.
- **Loose or corroded wiring connector (~20%)** Poor contact at the sensor plug, element terminal, or relay socket interrupts the signal or current flow the board expects to see.
- **Defective relay on the control board (~10%)** The solid-state relay that switches power to the heating element can fail stuck open or closed, preventing normal operation and logging the error.
- **Control board software glitch (~5%)** A transient memory error or noise spike can log a false H5 code that clears after a full power cycle.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker or unplug the range from the wall outlet before beginning any work.
2. **Remove the rear access panel** or bottom oven panel to expose the oven temperature sensor and wiring, depending on your model's design.
3. **Disconnect the sensor wire harness** and measure resistance across the sensor terminals with a multimeter set to ohms; a good sensor reads 1000 to 1200 ohms at room temperature.
4. **Inspect the bake element** by removing the screws that hold it to the rear oven wall, pulling it forward, and testing continuity across its terminals and from each terminal to ground.
5. **Check all wire connectors** at the sensor, elements, and control board for burns, corrosion, or looseness; clean contacts with electrical contact cleaner and reseat firmly.
6. **Replace the faulty part** if testing reveals an out-of-spec sensor or a broken element; if all components test good, the control board relay is the likely cause.
7. **Restore power and run a bake cycle** to verify the H5 code does not return; if it does, consult the wiring diagram for relay test points or call a service technician.

## When to Call a Pro

Call a professional if you are uncomfortable working with 240-volt wiring, if the oven uses a direct hard-wire connection rather than a plug, or if you have replaced the sensor and elements but the H5 code persists. A technician has the service manual, relay test adapters, and board-level diagnostic tools to pinpoint control-board faults and can often repair the board rather than replace it. Also call a pro if you smell gas, see arcing or scorched wiring, or if the range shares a junction box with other high-current appliances.

**Rough cost:** DIY runs about $25-90 in parts, 30-60 min. A pro service call runs about $150-280.
