## LG Range F3 Error Code — What It Means

The F3 error code on an LG range typically indicates a touch pad sensor key error, meaning the control board detects that a keypad button is stuck, shorted, or being read as continuously pressed. On some LG range models, F3 instead signals an open oven sensor circuit. The exact meaning depends on your specific model platform, so check your model number against LG's documentation. In both cases, the control has detected an input condition it cannot resolve and has halted normal operation to protect the appliance.

## Common Causes

- **Stuck or shorted touch pad button** A keypad input is being held active due to mechanical failure, dirt, or a short in the touchpad panel.
- **Foreign substances around the touch panel** Grease, moisture, or debris on or around the control buttons can cause false continuous-press signals.
- **Open oven temperature sensor circuit** On models where F3 indicates a sensor fault, the oven thermistor or its wiring has an open connection.
- **Faulty main control board** The electronic range control (ERC) may be misreading inputs or have failed internal circuits that trigger the F3 code.
- **Damaged wiring harness or loose connector** Broken wires or poor connections between the touchpad, sensor, and control board can cause intermittent or persistent F3 faults.

## Step-by-Step Fix {#fix}

1. **Perform a power reset.** Turn off the range at the breaker or pull the fuse, wait 30 seconds to 2 minutes, then restore power and check if the code clears.
2. **Inspect the touchpad for stuck keys.** Look at each button on the control panel for visible damage, sticking, or continuous depression.
3. **Clean the control panel.** Wipe away any grease, moisture, or debris from around the touch buttons using a soft damp cloth and let it dry completely.
4. **Check wiring harness connections.** Pull the range out, remove the back panel, and inspect all connectors between the touchpad, control board, and oven sensor for looseness or corrosion.
5. **Test or replace the oven temperature sensor (if applicable).** If your model uses F3 for an open sensor, locate the oven thermistor, disconnect it, and check for an open circuit or replace it.
6. **Replace the touchpad or control board.** If the reset does not clear the code and no physical issue is found, replace the keypad panel first, then the main control board if the fault persists.
7. **Request service if the code returns.** LG directs customers to call a technician if the F3 error reappears after a reset and basic inspection.

## When to Call a Pro

Call a professional if the F3 code returns after you have completed a power reset and cleaned the control panel, or if you are not comfortable working with live electrical connections and control boards. Because the F3 code has different meanings across LG range platforms, a qualified appliance technician can identify the correct fault for your specific model number and safely test the touchpad, sensor circuit, and control board. LG recommends requesting service if the code does not clear after a reset.
