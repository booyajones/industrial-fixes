## What this code means
GE error code F0 indicates a stuck or defective button on the keypad or touchpad. The control board detects a continuous signal from one of the touch keys, as if someone is holding down a button. This fault is grouped with F1 and F7 codes as keypad-related failures in GE service documentation.

If the keypad itself tests good or if disconnecting it does not clear the error, the electronic range control (ERC) or control board is the next suspect. The board may be misreading the keypad input or have an internal fault that mimics a stuck key signal.

## Before You Replace Anything

Many people replace the control board first. Disconnect the keypad ribbon connector and power-cycle the oven. If the F0 clears with the keypad unplugged, the keypad is the problem, not the expensive control board.

## Common Causes

- **Defective keypad or membrane pad (~50%)** An electrically shorted key in the touch panel sends a continuous closed-circuit signal to the control board.
- **Stuck button from contamination (~25%)** Spills, grease, or debris cause a physical or electrical short at the touch surface, triggering a stuck-key fault.
- **Failed control board or ERC (~15%)** If unplugging the keypad does not clear the code, the electronic range control is misreading input or has an internal fault.
- **Ribbon cable or contact issue (~10%)** Loose, corroded, or damaged connections between the keypad and control board create intermittent or false signals.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker and wait at least three minutes to allow the control board to reset fully.
2. **Restore power** and observe whether the F0 code returns immediately or if the oven operates normally.
3. **Access the control panel** by removing the screws on the back or top of the oven to expose the control board and keypad ribbon connector.
4. **Disconnect the ribbon cable** from the control board that links the keypad to the electronics, then power-cycle the oven again.
5. **Check if the code clears** with the keypad unplugged. If F0 persists, the control board is faulty and should be replaced. If the code clears, the keypad is the problem.
6. **Test the keypad resistance** if accessible. One documented test checks for open-loop (OL) at rest and approximately 150 Ω across terminals 13 and 14 on the ribbon cable when the OFF key is pressed. Consult your model's wiring diagram for other terminal configurations.
7. **Replace the defective component**. Install a new keypad or membrane pad if the keypad tests bad, or replace the electronic range control (ERC) if the keypad tests good but the error returns.
8. **Reassemble the control panel** and restore power at the breaker to verify the repair.

## When to Call a Pro

Call a professional if you are uncomfortable working inside the control panel, if the oven is still under warranty, or if you cannot access the ribbon connector safely. A technician can perform resistance and continuity tests on the keypad and control board, confirm the diagnosis with OEM-specific tools, and handle any high-voltage wiring. If the control board requires replacement and you lack experience soldering or handling circuit boards, professional installation will prevent further damage and make sure safe operation.

**Rough cost:** DIY runs about $50–150 in parts, 30–90 min. A pro service call runs about $150–350.
