## Ruud Tankless E87 Error Code — What It Means

The E87 error code on Ruud tankless water heaters indicates a system fault, though the exact meaning varies by model and control board version. Some units use this code to flag a communication error between the control board and a component, while others may use it for a sensor fault or internal diagnostic issue. Because Ruud tankless models span multiple generations with different control logic, you need to consult your specific unit's installation and service manual or the diagnostic chart on the inside cover to confirm what E87 means for your appliance.

In many cases the code appears after a power interruption, a wiring issue, or when the unit detects an out-of-range signal. The code may clear itself after a reset, or it may point to a failed sensor or loose connection that requires replacement or repair.

## Before You Replace Anything

Homeowners sometimes replace the control board when the actual problem is a loose wire harness or a failed thermistor. Check all connectors and measure sensor resistance before buying a board.

## Common Causes

- **Loose or corroded wiring connector (~30%)** A poor connection between the control board and a sensor or component can produce intermittent error codes that reset or return unpredictably.
- **Failed thermistor or temperature sensor (~25%)** A sensor that reads out of range or has an open circuit will trigger a fault code on many Ruud models.
- **Control board firmware or component fault (~20%)** Internal logic errors or a failing board can generate codes that do not correspond to any physical component failure.
- **Power surge or brownout memory (~15%)** Voltage spikes or interruptions can leave a fault logged in memory even after normal power returns.
- **Ground or neutral wiring issue (~10%)** Poor grounding or a floating neutral can cause erratic communication signals and spurious error codes.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the dedicated circuit breaker or service disconnect and wait 60 seconds to allow the control board to fully reset.
2. **Restore power** and observe whether the E87 code reappears immediately or after the unit begins a heating cycle.
3. **Remove the front cover** (typically two screws at the bottom) and locate the control board and attached wire harnesses.
4. **Inspect every connector** on the control board, checking for pushed-out pins, moisture, corrosion, or loose plug retention.
5. **Consult your model's service manual** or the diagnostic chart printed inside the cover to identify which sensor or component corresponds to E87.
6. **Measure sensor resistance** using a multimeter if the manual identifies a thermistor or other sensor, and compare readings to the specification table.
7. **Replace the faulty sensor or control board** only after confirming the fault with measurements, and reset the unit to verify the code clears.

## When to Call a Pro

Call a licensed plumber or HVAC technician if the code persists after a reset and you cannot locate a specific E87 definition in your manual, if you are uncomfortable working with line-voltage wiring, or if sensor testing requires access to gas valves or sealed combustion components. Tankless water heaters integrate gas controls, high-voltage ignition, and digital communication, so misdiagnosis can lead to expensive part swaps or safety hazards. A technician with manufacturer training and diagnostic software can read extended fault logs and perform live sensor tests that are not possible with a basic multimeter.

**Rough cost:** A pro service call runs about $150-350.
