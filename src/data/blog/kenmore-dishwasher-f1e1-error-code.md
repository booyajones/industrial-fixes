## What this code means
F1E1 on a Kenmore dishwasher signals an internal control-board problem or a communication failure between the main control unit and the user interface. On Whirlpool-built Kenmore models the code appears after the drain sequence starts and then the dishwasher stops operation. Technician references describe F1E1 as a stuck relay on the electronic control unit or a loss of communication between the control board and the keypad panel.

The fault can also point to damaged wiring or a failed component connected to the board, but in most service calls the main control board itself is the root cause. The code typically persists after a power reset when the board has failed.

## Before You Replace Anything

Homeowners sometimes replace the user interface or keypad first, but a simple power-cycle test and wiring inspection usually confirm that the main control board is the real problem.

## Common Causes

- **Failed main control board (~60%)** The electronic control unit develops a stuck relay or internal fault and cannot communicate properly with loads or the user interface.
- **Stuck relay on the control board (~20%)** A single relay on the board locks closed or open and triggers the fault code.
- **Damaged or loose wiring harness (~10%)** Connectors between the control board and the keypad or loads are corroded, pinched, or burned.
- **Failed user interface or keypad (~7%)** On models with a separate UI assembly, the keypad or its communication circuit fails and the main board reports the loss.
- **Shorted or open component on a load circuit (~3%)** A pump, valve, or other load connected to the board tests out of specification and causes the board to fault.

## Step-by-Step Fix {#fix}

1. **Disconnect power** to the dishwasher at the circuit breaker or by unplugging the unit, and wait five minutes to allow the control board to fully reset.
2. **Restore power** and check whether the F1E1 code returns immediately or after starting a cycle. If the code clears and does not reappear, the fault was transient.
3. **Remove the dishwasher door panel** by unscrewing the inner door screws to access the control board and wiring harness. Consult your model's service manual for exact screw locations.
4. **Inspect all connectors** at the main control board and user interface for loose pins, corrosion, burn marks, or damaged insulation. Reseat any loose connectors.
5. **Retrieve the tech sheet** from behind the lower toe panel and locate the resistance and voltage test points for components connected to the control board.
6. **Measure resistance** of pumps, valves, and other loads per the tech sheet specifications. Replace any component that tests open, shorted, or out of range.
7. **Replace the main control board** if all wiring and connected components test good and the code returns after the reset. On models with a separate user interface, test or replace the UI first if the wiring diagram confirms a communication fault.

## When to Call a Pro

Call a technician if you are not comfortable working with the dishwasher's 120-volt wiring, if the model-specific tech sheet calls for live voltage measurements you cannot safely perform, or if you replace the control board and the F1E1 code immediately returns. A professional can trace the fault to a specific load circuit or confirm whether the new board is compatible. Technicians also carry multimeters and service software to test communication between the control board and user interface on models where that split exists.

**Rough cost:** DIY runs about $150–$300 in parts, 1–2 hours. A pro service call runs about $200–$400.
