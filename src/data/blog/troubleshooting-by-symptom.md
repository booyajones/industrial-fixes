## Industrial Equipment Troubleshooting by Symptom

Sometimes you know what's wrong with the equipment but don't know the error code. This guide maps symptoms to the most likely error codes and fixes across all equipment types.

## HVAC / Furnace Symptoms

| Symptom | Most Likely Code | Fix |
|---------|-----------------|-----|
| [Furnace runs but no heat](https://www.amazon.com/s?k=Furnace+runs+but+no+heat&tag=errorcodefixes-20) | Code 3-4 (pressure/limit) | Check filter, verify gas |
| [Furnace short cycling](https://www.amazon.com/s?k=Furnace+short+cycling&tag=errorcodefixes-20) | Code 4 (limit) | Dirty filter, blocked airflow |
| [AC runs, no cold air](https://www.amazon.com/s?k=AC+runs%2C+no+cold+air&tag=errorcodefixes-20) | E3 (low pressure) | Low refrigerant — call tech |
| [Furnace flashing red light](https://www.amazon.com/s?k=Furnace+flashing+red+light&tag=errorcodefixes-20) | Any flash code | Count flashes — see brand guide |
| [Pilot won't stay lit](https://www.amazon.com/s?k=Pilot+won%27t+stay+lit&tag=errorcodefixes-20) | E002/E003 (ignition) | Clean flame sensor rod |
| [Mini-split blinking](https://www.amazon.com/s?k=Mini-split+blinking&tag=errorcodefixes-20) | E or CH code | Check drain, filter, sensor |
| [Heat pump not defrosting](https://www.amazon.com/s?k=Heat+pump+not+defrosting&tag=errorcodefixes-20) | E5 (defrost fault) | Check defrost thermostat |

|---------|-----------------|-----|
| [Motor won't start](https://www.amazon.com/s?k=Motor+won%27t+start&tag=errorcodefixes-20) | F3/F4 (power loss/UV) | Check input voltage, fuses |
| [Motor runs hot](https://www.amazon.com/s?k=Motor+runs+hot&tag=errorcodefixes-20) | OL, F7 (overload) | Verify motor FLA parameter |
| [Drive trips on every start](https://www.amazon.com/s?k=Drive+trips+on+every+start&tag=errorcodefixes-20) | OC during acceleration | Extend acceleration ramp time |
| [Drive trips during decel](https://www.amazon.com/s?k=Drive+trips+during+decel&tag=errorcodefixes-20) | OV (overvoltage) | Extend deceleration time |
| [Drive trips under load](https://www.amazon.com/s?k=Drive+trips+under+load&tag=errorcodefixes-20) | F6/F7 (motor stall/OL) | Mechanical overload or wrong parameter |
| [Ground fault](https://www.amazon.com/s?k=Ground+fault&tag=errorcodefixes-20) | GF, F13 | Megohm test motor |

## When the Symptom Has No Error Code

Some equipment problems don't generate error codes:
- Dirty air filters (HVAC)
- Loose electrical connections
- Mechanical wear and vibration
- Low refrigerant before the pressure switch trips

When there's no code, use the symptom tables above combined with physical inspection.
