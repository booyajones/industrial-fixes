## Kenmore Dishwasher E11 Error — What It Means

On Kenmore dishwashers, the E11 error code (also displayed as 1-1 or F1E1 on some models) signals a stuck relay on the main electronic control unit. A relay is a small electromechanical switch inside the control board that routes power to components like the heating element or motor. When a relay sticks closed or welds shut, the control cannot turn that circuit off and it logs the fault.

This code is specific to the dishwasher's control logic and should not be confused with E11 codes on other Kenmore appliances, which can mean entirely different faults such as water-inlet problems on washers or humidity-sensor issues on microwaves. Always verify the meaning against your dishwasher's tech sheet or wiring diagram, because code definitions vary by model and appliance type.

## Before You Replace Anything

Homeowners sometimes replace wiring harnesses or heating elements first. Before ordering parts, disconnect power for five minutes and restore it to see if the code clears. If it returns immediately, the control board relay is usually at fault, not the downstream load.

## Common Causes

- **Stuck or welded relay on the control board (~60%)** The relay contacts inside the main electronic control unit fuse closed and cannot open, keeping a circuit energized and triggering the fault.
- **Corroded or loose wiring connector (~15%)** High resistance or intermittent contact at a harness connector between the control and a load can confuse the relay circuit and set the code.
- **Failed heater or other load component (~15%)** A short or abnormal resistance in the heating element or other controlled device can keep the relay circuit loaded and cause the control to flag a stuck relay.
- **Damaged wiring harness (~10%)** Chafed, melted, or pinched wires between the control unit and the affected load create unexpected current paths that mimic a stuck relay.

## Step-by-Step Fix {#fix}

1. **Disconnect power** at the circuit breaker or by unplugging the dishwasher, then wait five minutes before restoring power to attempt a reset.
2. **Check if the code clears.** Run the dishwasher through a short rinse cycle and observe the display. If E11 returns immediately, proceed with diagnostics.
3. **Remove the lower access panel** (typically held by screws at the bottom front) to expose the main control board and wiring harness.
4. **Inspect all connectors and wiring** for burn marks, melted insulation, corrosion, or loose plugs. Reseat any suspect connectors and clean oxidized terminals with contact cleaner.
5. **Consult the tech sheet** (usually glued inside the door or lower panel) and use a multimeter to measure the resistance of components connected to the control unit, such as the heating element or motor windings. Compare readings to the table on the sheet.
6. **Replace the main electronic control board** if wiring and loads test within specification and the code persists. Transfer all wire connectors to the new board, taking a photo before removal to make sure correct routing.
7. **Restore power and test** the dishwasher through a complete cycle to verify the fault is cleared and all functions operate normally.

## When to Call a Pro

Call a technician if you are uncomfortable working with live or stored voltage, if you cannot locate your model's tech sheet to perform resistance checks, or if the code returns after you have replaced the control board and verified all wiring. A professional has factory diagnostic software and can quickly isolate whether a hidden load fault is mimicking a stuck relay. Also call a pro if you see widespread heat damage or if your dishwasher is still under warranty, since self-repair may void coverage.

**Rough cost:** DIY runs about $150–$250 for control board, 45–90 min. A pro service call runs about $200–$400 including service call and labor.
