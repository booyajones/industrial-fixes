## Samsung Dishwasher tC Error Code — What It Means

The tC error code on a Samsung dishwasher signals a temperature sensor error. Samsung's official documentation describes this as an inaccurate temperature reading condition. The dishwasher's thermistor (temperature sensor) is either sending faulty data to the control board, or the control board is unable to read the sensor signal correctly.

Samsung's support materials do not break down tC into sub-categories the way some other codes are detailed. The manufacturer advises emptying the dishwasher and running a normal cycle. If the code returns after that test cycle, the unit requires service. The error points to a fault somewhere in the temperature-sensing circuit rather than a general heating system failure.

## Before You Replace Anything

Many people replace the main control board first. Test the thermistor's resistance and inspect its harness and connectors for damage or corrosion before buying a new board.

## Common Causes

- **Failed thermistor** The temperature sensor itself drifts out of specification or fails open, sending incorrect readings to the control board.
- **Loose or corroded wiring** The harness or connectors between the thermistor and the main board become corroded, pinched, or loose, breaking the signal path.
- **Poor connector contact** Oxidation or moisture on the sensor plug or board socket creates intermittent resistance that skews temperature data.
- **Control board input fault** The main control board's temperature-input circuit malfunctions, misreading an otherwise healthy sensor signal.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker or unplug the dishwasher to make sure safe access to electrical components.
2. **Empty the dishwasher tub** completely, removing any standing water with towels or a wet vacuum if necessary.
3. **Restore power and run a normal cycle** as Samsung instructs, then observe whether the tC code reappears during or after the cycle.
4. **If the code returns, power off again** and remove the lower access panel or toe-kick to expose the dishwasher's sump and sensor area.
5. **Locate the temperature sensor (thermistor)** near the sump housing or heating element, trace its wiring to the main control board, and inspect the harness and connectors for damage, corrosion, or loose pins.
6. **Disconnect the thermistor connector** and use a multimeter in resistance mode to measure the sensor's resistance at room temperature, comparing the reading to the manufacturer's specification for your exact model if available.
7. **If the sensor reads open, shorted, or far outside the typical range** (consult your model's service sheet or wiring diagram), replace the thermistor assembly with a genuine Samsung part or OEM equivalent.
8. **If the sensor tests correctly**, reconnect it, inspect the main control board's sensor-input circuit for visible damage, and consider board replacement or professional diagnostics if the code persists after reassembly.

## When to Call a Pro

Call a professional if the tC code persists after you've run the Samsung-recommended empty cycle and normal wash, or if you are uncomfortable working with electrical components. Technicians have access to Samsung's service-mode diagnostics, model-specific thermistor resistance tables, and the tools to test the control board's input circuit under load. Because the error can stem from either the sensor, wiring, or the board, a qualified tech can isolate the fault quickly and avoid replacing multiple parts by trial and error. If your dishwasher is still under warranty, contact Samsung support before opening the unit so you don't void coverage.

**Rough cost:** A pro service call runs about $150–$300.
