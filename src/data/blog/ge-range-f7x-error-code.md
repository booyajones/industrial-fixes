## GE Range F7 Error Code — What It Means

The F7 error code on a GE range indicates a keypad or control-interface fault. The control board is detecting a stuck key, multiple simultaneous key presses, or a failed membrane keypad assembly. This is not a cooking sensor or temperature problem. The fault typically traces to the keypad itself, the ribbon cable connecting the keypad to the control board, or the main control board if the error persists after isolating the keypad.

## Common Causes

- **Contaminated keypad or ribbon contacts** Grease, oxidation, or residue on the membrane keypad contacts or ribbon cable contacts can create false signals.
- **Failed membrane keypad assembly** The touch panel can develop internal shorts or intermittent failures that register as stuck or multiple keys.
- **Damaged or loose ribbon cable** The ribbon cable between the keypad and control board can be pinched, corroded, or poorly seated.
- **Failed electronic control board** If the F7 error remains after disconnecting the keypad, the main control board is the likely cause.

## Step-by-Step Fix {#fix}

1. **Disconnect power** at the circuit breaker or unplug the range before opening any panels or touching internal components.
2. **Wait several minutes**, then restore power to see if the code clears. If F7 returns immediately or during use, continue diagnosis.
3. **Access the control compartment** (usually behind the back panel or under the cooktop) and locate the ribbon cable connecting the keypad to the control board.
4. **Inspect and clean the ribbon cable** contacts carefully with a pencil eraser or approved electrical contact cleaner, then firmly reseat both ends of the connector.
5. **Isolate the keypad** by disconnecting the ribbon cable from the keypad assembly and restoring power. If the F7 code disappears, the keypad is faulty. If the F7 remains, the control board is faulty.
6. **Replace the keypad assembly** if disconnecting it cleared the code. Order the correct membrane keypad or touchpad for your model and install per the service instructions.
7. **Replace the main control board** if the F7 error persisted with the keypad disconnected. Order the correct electronic control or clock control for your model and transfer any non-replaceable components per the installation guide.

## When to Call a Pro

Call a professional if you are uncomfortable working with live electrical components or accessing the control compartment. If you have isolated the fault to either the keypad or control board but are unsure about ordering the correct part for your model, a technician can verify the part number and complete the replacement safely. Some GE ranges require transferring programmed components or recalibrating the control after board replacement, which may require service tools or experience.
