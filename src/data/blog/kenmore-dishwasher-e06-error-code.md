## Kenmore Dishwasher E06 Error Code — What It Means

The E06 error code on many Kenmore dishwashers indicates a problem with the water temperature sensor circuit. Kenmore-branded dishwashers are built by several different manufacturers, so the exact meaning can vary by platform. On Midea-based Kenmore models, E06 typically points to an open-circuit thermistor fault, meaning the control board cannot read the water temperature sensor correctly. This prevents the dishwasher from heating water or running a normal cycle.

Because Kenmore uses underlying manufacturer diagnostics rather than a uniform code set, the first step is always to identify your model number and the OEM platform behind it. That said, the most common interpretation of E06 across Kenmore dishwashers is a thermistor or temperature sensor circuit issue.

## Common Causes

- **Failed thermistor** The water temperature sensor itself has failed open or out of range and no longer sends a valid signal to the control board.
- **Loose or corroded connector** The plug at the thermistor or control board is loose, corroded, or has pushed-back pins that break the circuit.
- **Damaged sensor wiring** The harness between the sensor and control has a break, chafe, or cut near the tub base or routing points.
- **Moisture intrusion at the sensor** Water or detergent has seeped into the thermistor housing or connector, causing a short or open reading.
- **Control board input circuit fault** If the sensor and wiring test good, the control board's temperature input circuit may have failed and cannot read a valid sensor.

## Step-by-Step Fix {#fix}

1. **Disconnect power** by unplugging the dishwasher or switching off the circuit breaker, then wait at least one minute to allow the control to reset.
2. **Identify your model platform** by looking up the full Kenmore model number on the door frame or inner tub to determine which OEM (Midea, Whirlpool, or other) built your unit and confirm E06 maps to a thermistor fault.
3. **Inspect the temperature sensor and harness** by accessing the sensor at the base of the tub or sump area, checking for loose plugs, corroded terminals, moisture, or visible wire damage along the harness run to the control board.
4. **Test the thermistor electrically** by disconnecting the sensor plug and measuring resistance across the thermistor terminals with a multimeter (consult your model's service sheet for expected resistance at room temperature), then check for open or infinite-resistance readings that indicate a failed sensor.
5. **Check wiring continuity** from the sensor connector to the control board plug by testing each wire individually for breaks or intermittent contact, and repair or replace any damaged harness sections or corroded pins.
6. **Reinstall or replace the thermistor** if testing shows it is out of specification or open, making sure the new sensor seats fully in its well and the connector locks securely.
7. **Restore power and run a test cycle** to verify the E06 code clears, and if the error persists after confirming the sensor and wiring are good, suspect a failed control board input circuit and consider board replacement.

## When to Call a Pro

Call a technician if you are not comfortable working with electrical testing or if you cannot safely access the sensor and control components inside the dishwasher base. Also call a pro if the thermistor and wiring both test within specification but the E06 code returns, because diagnosing a control board input fault requires specialized knowledge and tools. If your dishwasher is still under warranty or you cannot confirm the OEM platform and correct diagnostic path for your Kenmore model, professional service will save time and prevent incorrect part replacement.
