## State Water Heater E174 Error Code — What It Means

An E174 error code cannot be verified as a manufacturer-defined fault code in State's published documentation. Water heater error codes are not standardized across brands or even across models within the same brand, so an alphanumeric code like E174 requires the exact model number and matching service manual to interpret safely. State directs technicians to scan the QR code on the rating plate or reference the model-specific literature to decode faults correctly.

Without the exact State model and serial number, any attempt to diagnose E174 risks misidentifying the fault, which could involve a sensor, control board, ignition system, or venting component. Record the code exactly as displayed, do not reset the unit before documenting the fault state, and pull the correct manual before proceeding with any component-level troubleshooting.

## Common Causes

- **Model-specific code definition missing** The code meaning varies by State model, and without the service manual the fault cannot be accurately identified.
- **Flame sensor or thermocouple fault** Gas water heaters commonly throw codes when the flame-sensing component fails to confirm ignition or safe combustion.
- **Gas control valve malfunction** A defective gas valve or its internal sensor can trigger lockout codes during ignition attempts.
- **Control board or wiring issue** Electronic control boards may log fault codes when internal diagnostics detect a sensor circuit open, short, or out-of-range signal.
- **Vent obstruction or overheating** Blocked venting or high-limit thermostat trips can cause safety lockout codes on many State models.

## Step-by-Step Fix {#fix}

1. **Record the full error code** exactly as displayed on the control panel and note the model and serial number from the rating plate before resetting or powering down the unit.
2. **Scan the QR code** on the rating plate or visit State's online support to download the service manual and fault-code table specific to your model.
3. **Look up E174** in the manufacturer's code table to determine whether it indicates a sensor fault, ignition failure, limit trip, or control-board diagnostic.
4. **Inspect the suspected component** identified in the manual, checking wiring connections, sensor condition, and any specified test points for opens, shorts, or out-of-range values.
5. **Test electrical values** only against the manufacturer-specified resistance, voltage, or continuity ranges given in the service literature for that exact part.
6. **Clear the fault** according to the manual's reset procedure after verifying the repair, then monitor the unit through a full heating cycle to confirm normal operation.
7. **Document the repair** and keep the service manual on hand for future reference, since model-specific codes and test procedures are not interchangeable across State's product lines.

## When to Call a Pro

Call a licensed plumber or gas technician if you cannot locate the service manual for your exact State model, if the fault code does not appear in any manufacturer documentation you can access, or if the diagnostic requires testing live gas-valve circuits or high-voltage control boards. Professional help is also necessary when the code returns after a component replacement, when you smell gas or detect combustion byproducts in the living space, or when local codes require a permitted repair for gas appliances. Always shut off gas supply at the appliance shutoff valve if you suspect a gas leak or control-system fault.
