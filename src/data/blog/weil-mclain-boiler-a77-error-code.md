## Weil-McLain A77 Error — What It Means

A77 does not appear in published Weil-McLain fault code tables. Weil-McLain boilers use model-specific fault codes documented in each unit's installation and service manual, and the meaning of any code can vary by series (Ultra, AquaBalance, CGa, etc.). If you see A77 on a different brand condensing boiler (for example, an Ariston or Microgenus), it typically indicates unwanted water in the condensate system or a condensate sensor circuit fault. For Weil-McLain units, you must pull the stored fault history from the control panel and cross-reference it with your boiler's own manual to identify the true fault.

## Before You Replace Anything

Homeowners sometimes assume any alphanumeric display is a universal fault code and order parts based on web searches for other brands. Always verify the code against your boiler's service manual before replacing components.

## Common Causes

- **Wrong brand or model assumption (~40%)** A77 is documented for Ariston/Microgenus condensate faults but does not match published Weil-McLain code lists, so the code may belong to a different boiler altogether.
- **Blocked or waterlogged condensate trap (~25%)** If the boiler is a condensing model and the control is borrowing condensate-fault logic, a full or obstructed trap can trigger a water-presence alarm.
- **Condensate sensor circuit fault (~20%)** An open or short circuit in the condensate sensor wiring or connector can flag a fault on systems that monitor trap water level.
- **Heat exchanger or recuperator issue (~10%)** In one reported Ariston case, persistent condensate faults cleared only after replacing the recuperator, suggesting downstream heat-exchanger condensate handling problems.
- **Transient control glitch (~5%)** A momentary power event or control board hiccup can display an unfamiliar code that clears on a proper power cycle or reset sequence.

## Step-by-Step Fix {#fix}

1. **Isolate power and gas** at the breaker and manual gas valve. Wait for the boiler to cool and depressurize.
2. **Locate and photograph the nameplate** with the exact model, serial, and CP (control package) number. Download or retrieve the installation and service manual from Weil-McLain's website or your installer.
3. **Access the stored fault history** through the control panel's diagnostic menu (consult the manual for the button sequence). Write down every fault code and timestamp.
4. **Cross-reference each code** in the manual's fault table. If A77 does not appear, note that the display may be incorrect or the boiler may be a different brand.
5. **If the boiler is condensing, inspect the condensate trap and drain line** for blockage, standing water, or loose connections. Remove the trap, rinse it, and reinstall. Clear the drain path to the floor drain or pump.
6. **Test the condensate sensor circuit** if your model has one. Check connector seating and wiring continuity. Consult the manual for expected resistance or voltage values; do not guess.
7. **Restore power and gas**, then follow the manual's restart procedure. Observe the control display and listen for normal ignition. If the fault returns or ignition fails, shut down and call a technician.
8. **Record the outcome** and keep the fault history printout or notes for the service call if professional help is needed.

## When to Call a Pro

Call a licensed boiler technician if A77 does not appear in your Weil-McLain manual, if the fault persists after clearing the condensate system, or if you cannot safely access the stored fault history. Gas-fired boiler work requires proper combustion testing, venting checks, and pressure diagnostics that are beyond DIY scope. A technician will retrieve the full fault log, test sensor circuits with the correct meters, and replace model-specific components (recuperator, heat exchanger, or control board) if needed. Never bypass safeties or keep resetting a persistent fault. Repeated lockouts can indicate a serious venting, ignition, or pressure problem that will damage the boiler or create a safety hazard if ignored.

**Rough cost:** A pro service call runs about $150-400.
