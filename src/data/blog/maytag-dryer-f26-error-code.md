## What this code means
F26 on a Maytag dryer is a dryer motor control circuit error according to Maytag's published fault-code list. The code signals a problem in the motor control path rather than a simple user condition. The fault typically involves the motor control circuit on the electronic control board, wiring between the control and motor, the motor sensor or tach feedback circuit, or the control board that drives and monitors the motor.

Maytag's help documentation recommends a power reset and retest as a first step, which suggests the code can be transient. If the code returns after a reset, the problem is in the motor control circuit hardware and requires inspection of wiring, the motor sensor path, and the control board itself.

## Before You Replace Anything

Some homeowners replace the motor first when the real fault is a loose wiring harness plug or a failed control board. Always inspect all connectors and run a power-cycle reset before ordering a motor.

## Common Causes

- **Intermittent or failed motor control circuit on the electronic control board (~40%)** The control board's motor drive logic or relay path has failed and cannot operate the motor correctly.
- **Loose, damaged, or corroded wiring harness connections (~25%)** Plugs between the control board and motor circuit components can work loose, suffer heat damage, or corrode over time.
- **Motor sensor or tach feedback circuit issue (~20%)** An open or short in the motor sensor path prevents the control from confirming motor operation.
- **Mechanical motor load problem (~10%)** A seized drum, bad rollers, or worn idler pulley can create excessive drag that triggers a control fault indirectly.
- **Damaged or intermittent motor windings (~5%)** The motor itself may have an internal fault that the control board detects as a circuit error.

## Step-by-Step Fix {#fix}

1. **Turn off the circuit breaker** to the dryer and leave it off for five minutes to clear the control memory, then restore power and start a timed dry cycle to see if F26 returns.
2. **Unplug the dryer and remove the top or rear panel** to access the control board and motor wiring harness (consult your model's service manual for panel removal).
3. **Inspect every connector** between the control board and motor circuit for loose plugs, bent pins, heat damage, or corrosion, and reseat each plug firmly.
4. **Check the motor sensor or tach wiring** if your model uses a motor feedback circuit (look for a small two- or three-wire plug at the motor), and verify the wires are intact and the plug is secure.
5. **Verify the drum turns freely** by hand with the belt on to rule out mechanical binding from bad rollers, a worn idler pulley, or a seized bearing.
6. **Test the motor control circuit on the control board** if wiring and mechanical checks are good, or replace the main electronic control board if the fault persists and all other components test normal.
7. **Reassemble the dryer, restore power, and run a timed dry cycle** for at least one minute to confirm F26 does not reappear before returning the machine to service.

## When to Call a Pro

Call a technician if you are uncomfortable working inside the dryer cabinet, if you cannot locate the wiring harness connectors for your model, or if the fault persists after a power reset and you do not have a multimeter to test circuits. A qualified appliance tech can quickly trace the motor control circuit, verify control board output, and replace the correct component without guesswork. Also call a pro if the drum does not turn freely and you suspect a bearing or structural issue, since those repairs often require specialized tools and disassembly.

**Rough cost:** DIY runs about $100–250 in parts, 45–90 min. A pro service call runs about $180–350.
