## Weil-McLain Boiler A108 Error — What It Means

There is no Weil-McLain boiler error code A108. The code A108 specifically appears on Rheem hybrid heat pump water heaters and means "Condensate Blocked: Unclog Line." The alarm sounds when the condensate rope sensor detects water, indicating a blocked condensate drain line. When this happens, the heating source defaults to electric elements because the heat pump compressor cannot operate safely with blocked drainage.

If you are troubleshooting a Weil-McLain boiler, you likely have a different error code (such as 01, 10, or 12) or you may be misidentifying the appliance. Weil-McLain boiler manuals list error codes that typically relate to ignition failures, flame sensor issues, or pressure anomalies, but A108 is not among them.

## Before You Replace Anything

Some replace the control board when the condensate sensor is simply wet or faulty. Unplug the sensor and run the unit for 24-48 hours; if A108 returns only then is the board bad.

## Common Causes

- **Clogged condensate drain line or pan (~60%)** Dust, mold, mildew, or sludge blocks the PVC line or the drain pan under the evaporator coil.
- **Defective condensate rope sensor (~20%)** The sensor falsely indicates wetness even when dry or reads continuity when it should be open.
- **Frozen condensate line (~15%)** Uninsulated lines in cold weather can freeze and cause a blockage.
- **Defective control board (PCB) (~5%)** A bad circuit triggers the code even when the sensor is unplugged and dry.

## Step-by-Step Fix {#fix}

1. **Verify the appliance** by checking the owner's manual; confirm you have a Rheem hybrid heat pump water heater, not a Weil-McLain boiler.
2. **Inspect the condensate drain line** for clogs by disconnecting the PVC line from the drain pan port and flushing it with water or a shop vac.
3. **Remove the tank top cover** (or pull the filter) to access the condensate drain pan and rope sensor under the evaporator coil.
4. **Check the drain pan and sensor for water** and dry both with a cloth towel if wet; clean sludge and dust from the pan by removing the lid (4 screws around, 4 on top).
5. **Test the condensate rope sensor** with an ohm meter; it should read open (infinite resistance) when dry; if it shows any continuity, replace the sensor.
6. **Unplug the sensor from the PCB** (two grey wires) if the sensor tests good and is dry, then operate the unit for 24-48 hours.
7. **Replace the control board** if A108 returns after unplugging the sensor; otherwise replace the sensor and reconnect it.

## When to Call a Pro

Call a pro if you are uncomfortable removing the tank top cover, working with electrical connections, or diagnosing the control board. Also call if the condensate line is frozen inside a wall or if local codes require a licensed plumber to modify drain routing. A technician can quickly verify whether the sensor, board, or drain line is at fault and perform any needed replacements under warranty if applicable.

**Rough cost:** DIY runs about $15-40 for sensor or drain cleaning supplies, 30-60 min. A pro service call runs about $150-250 for service call and cleaning.
