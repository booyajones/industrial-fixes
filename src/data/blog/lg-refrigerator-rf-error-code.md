## LG Refrigerator rF Error Code — What It Means

The rF code (shown as Er rF or rF) means the refrigerator section evaporator fan motor is not reporting a normal feedback signal to the main control board. The board watches the fan speed, and when it sees no signal for about 65 seconds it logs rF and cooling in the fresh food side drops off.

The two usual triggers are frost packed around the fan blade locking the motor, or a worn out fan motor that no longer spins. Wiring and the control board are less common causes.

## Common Causes

- **Frost around the fan blade** Ice from a defrost problem can build up over the evaporator and jam the fan blade so the motor cannot turn.
- **Failed evaporator fan motor** Worn bearings, moisture damage, or an open winding stop the motor and kill the feedback signal.
- **Loose or damaged wiring** A loose connector between the fan and the main board interrupts the feedback line and triggers rF.
- **Main control board fault** A board that no longer reads the fan signal correctly can log rF even when the motor is good.
- **Underlying defrost failure** A weak defrost heater or sensor lets frost return fast, which re-locks the fan after every reset.

## Step-by-Step Fix {#fix}

1. Unplug the refrigerator or trip the breaker, wait 5 minutes, then restore power to see if the code clears on its own.
2. If frost is visible on the back panel, leave the doors open and let the unit thaw fully (about 8 hours or more) with towels down to catch melt.
3. Pull the rear freezer or fresh food panel and check the fan blade for ice, debris, or a cracked blade.
4. Spin the fan blade by hand. If it grinds, drags, or does not move freely, plan to replace the motor.
5. Unplug power and check the fan motor connector for loose pins or corrosion, then reseat it.
6. Test the fan motor for continuity with a multimeter, and replace the motor if it reads open.
7. If the new motor still throws rF, replace the main control board.

## When to Call a Pro

Call a technician if the code returns after you replace the fan motor, or if frost keeps coming back fast which points to a defrost or sealed system problem. Those repairs need meter testing and sometimes sealed system access that most homeowners are not set up for.
