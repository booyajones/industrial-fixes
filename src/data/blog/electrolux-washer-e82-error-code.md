## Electrolux E82 Error Code — What It Means

E82 on Electrolux washers signals a selector-position fault. The control board sees the cycle selector or user interface in an incorrect, out-of-sync, or invalid reset position. In EWM-series models, Electrolux documents this as 'Error in reset position of selector' and points to a faulty circuit board. On other models, E82 falls into the broader E80–E87 family, which can indicate problems with the user interface, control panel, or even recirculation-pump controls, depending on your exact machine.

Because Electrolux uses E80–E87 differently across product families, always verify your model number and consult the service manual or tech sheet before ordering parts. The error may be a temporary logic glitch, a bad connector, or a failed main control board.

## Common Causes

- **Selector not at reset or zero position** The cycle dial is not in the expected off or reset position when the machine boots or enters diagnostics, triggering the fault.
- **Faulty main control board or PCB** Corrupted configuration data or a failed selector-input circuit on the main board causes the control to misread the dial position.
- **Loose or corroded wiring and connectors** Damaged pins, oxidation, or poor seating between the user interface harness and main board interrupt position signals.
- **Failed user interface or control panel** On some models, the selector assembly or entire UI module sends invalid data to the main board.
- **Recirculation-pump control fault** In models where E80–E87 covers pump subsystems, a related control issue may be logged as E82.

## Step-by-Step Fix {#fix}

1. Verify your exact model number from the data plate and locate the service manual or tech sheet to confirm whether E82 is a selector-position fault or part of the broader E80–E87 group.
2. Turn the cycle selector to the proper reset, off, or zero position, then unplug the washer for at least one minute to clear temporary logic faults and allow capacitors to discharge.
3. Plug the machine back in and attempt a test cycle to see if the error clears after the power reset and correct dial position.
4. If the code returns, disconnect power and remove the top or rear panel to access the main control board and user-interface harness.
5. Inspect all connectors between the selector assembly and main board for loose plugs, bent pins, corrosion, or heat damage, then reseat each connector firmly.
6. Test the washer again; if E82 persists and wiring is good, replace the main control board or the user-interface assembly, depending on which component your model's documentation identifies as the selector-input source.
7. Run a service diagnostic cycle after installation to confirm the fault does not return and the selector position is read correctly by the new board.

## When to Call a Pro

Call a qualified appliance technician if you are uncomfortable working inside live-voltage panels, if the error returns after connector and power resets, or if you lack the service manual to identify which board or assembly controls the selector input on your specific model. Technicians carry multimeters and model-specific fault trees to pinpoint whether the main PCB, user interface, or a related subsystem is at fault. Professional diagnosis is especially important for models where E82 overlaps with recirculation-pump or other control issues, since misdiagnosing the root cause can lead to unnecessary parts replacement.
