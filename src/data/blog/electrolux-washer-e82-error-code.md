## Electrolux E82 Error Code — What It Means

The E82 error code on Electrolux washing machines indicates a problem with the selector position or user interface communication. In Electrolux EWM-series documentation, E82 is specifically defined as an error in the reset position of the selector, typically when the program knob is on zero and the circuit board cannot read the correct position. Electrolux support groups E80 through E82 together as codes related to either the recirculation pump or the user interface, depending on the model family.

The code does not point to a water level, drain, or motor problem. Instead, it signals that the main control board cannot correctly detect or process the selector position, or that communication between the user interface module and the main board has failed. The exact subsystem varies by model, so verify your washer's service manual to confirm whether E82 maps to the control board, the UI assembly, or a related recirculation pump circuit on your specific machine.

## Before You Replace Anything

Homeowners often replace the entire user interface console when the real problem is a loose connector or a failed main control board. Before ordering the UI module, open the top panel and inspect every connector between the interface and the main board for corrosion or a partial seat.

## Common Causes

- **Faulty main control board (~50%)** The PCB cannot correctly read the selector position or has failed internal logic for the reset-position check.
- **Loose or corroded connector between UI and main board (~25%)** Oxidation, moisture, or a partially unseated harness plug interrupts the position signal from the selector to the control board.
- **Damaged wiring harness (~15%)** A wire break, chafe, or heat damage in the harness between the user interface and the main board prevents correct communication.
- **Failed user interface module or selector assembly (~7%)** The rotary selector switch or the UI board itself sends incorrect or no position data to the main control.
- **Recirculation pump circuit fault (~3%)** On some Electrolux model families where E80–E82 is tied to the pump subsystem, a wiring or pump assembly issue can trigger the code.

## Step-by-Step Fix {#fix}

1. **Unplug the washer** and wait three minutes to allow the control board to fully discharge and reset any transient fault memory.
2. **Confirm the program selector** is rotated fully to the zero or off position and is not stuck between detents or mechanically jammed.
3. **Restore power** and attempt to start any cycle. If E82 clears, monitor the machine over the next few uses to see if the code returns.
4. **Remove the top panel** by taking out the screws at the rear edge and sliding or lifting the panel forward and off. Disconnect power again before touching any internal components.
5. **Inspect every connector** on the main control board and the wire harness running to the user interface module. Look for corrosion, moisture, or loose plug shells. Firmly reseat each connector.
6. **Check the wiring harness** for visible breaks, chafing, or heat damage along its length. Replace the harness if any wires are cut or insulation is melted.
7. **Examine the main control board** for burned traces, swollen capacitors, or discoloration. If the board shows physical damage or E82 persists after reseating connectors, replace the main control board with a part that matches your exact model and serial number.
8. **Reassemble the washer**, restore power, and run a short test cycle to verify that E82 no longer appears and the selector position is recognized correctly.

## When to Call a Pro

Call a qualified appliance technician if you are uncomfortable working inside the washer's control area, if you lack a multimeter or the experience to safely handle control boards, or if the error persists after you have reseated connectors and performed a power reset. A technician will use the factory service manual and diagnostic mode to pinpoint whether the fault lies in the main control board, the user interface module, the wiring harness, or (on certain models) the recirculation pump circuit. Professional diagnosis is also advisable if your washer is still under warranty, since opening the cabinet yourself may void coverage.

**Rough cost:** DIY runs about $120–$280 for a control board, 45–90 min. A pro service call runs about $180–$380 including diagnosis and labor.
