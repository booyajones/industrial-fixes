## KitchenAid Refrigerator E6 Error — What It Means

The E6 code on a KitchenAid refrigerator's ice-maker or diagnostics display means Dispenser UI EEPROM Faulty according to the manufacturer tech sheet. The code points to a problem with the dispenser user interface board's nonvolatile memory (EEPROM) or the communication path between the dispenser UI and the main control. This is not a generic refrigerator fault code. It is specific to the dispenser control system.

The code appears in the active error-code menu during service diagnostics, which you reach by pressing SW1 and SW2 together for 3 seconds until you hear a chime. The manufacturer service sheet lists E6 separately from other codes such as Er (Communication Failure), so the fault is localized to the dispenser UI board itself rather than a broader system communication issue.

## Before You Replace Anything

Some technicians replace the main control board first. Always inspect the dispenser UI board and its wiring harness first, because the E6 code explicitly points to the dispenser UI EEPROM, not the main control.

## Common Causes

- **Failed dispenser UI board EEPROM (~65%)** The nonvolatile memory chip on the dispenser user interface board has failed and can no longer store or retrieve configuration data.
- **Loose or corroded wiring harness connector (~20%)** The connector between the dispenser UI and the main control has corrosion or a poor connection that disrupts communication and triggers a memory fault.
- **Moisture intrusion on the dispenser UI board (~10%)** Water or condensation has damaged the EEPROM or related circuits on the dispenser control board.
- **Main control board communication fault (~5%)** The main control is failing to communicate properly with the dispenser UI, which can mimic or trigger an EEPROM fault code on some models.

## Step-by-Step Fix {#fix}

1. **Disconnect power** by unplugging the refrigerator or switching off the circuit breaker and waiting 5 minutes to discharge any residual voltage.
2. **Enter service diagnostics** by reconnecting power, then pressing and holding SW1 and SW2 on the dispenser control panel together for 3 seconds until you hear a chime, and confirm the E6 code is displayed.
3. **Inspect the wiring harness** between the dispenser UI and the main control board by removing the dispenser cover panel and checking each connector for corrosion, moisture, or loose pins.
4. **Order the correct dispenser UI assembly** for your model number by cross-referencing the part number on your existing board or checking the service manual parts list.
5. **Remove the old dispenser UI** by disconnecting the wiring harness, removing the mounting screws behind the dispenser panel, and carefully pulling the board assembly forward.
6. **Install the new dispenser UI** by connecting the wiring harness, securing the mounting screws, and replacing the dispenser cover panel.
7. **Restore power and test** by plugging in the refrigerator, entering diagnostics again with SW1 and SW2, and verifying that the E6 code does not reappear and that all dispenser functions work normally.

## When to Call a Pro

Call a technician if you are not comfortable working with control boards or if the E6 code persists after you have replaced the dispenser UI assembly and verified all wiring connections. A professional can perform advanced diagnostics to determine whether the main control board or another component is contributing to the fault. Also call a pro if your model requires disassembly beyond the dispenser panel or if you see signs of broader electrical damage such as burnt wiring or melted connectors.

**Rough cost:** DIY runs about $80-180 for the dispenser UI assembly, 45-90 min. A pro service call runs about $200-350 including parts and labor.
