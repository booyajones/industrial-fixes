## What this code means
The LG refrigerator CO (or E CO or ER(E) CO) error code signals a communication breakdown between the main control board and the display PCB (user interface board). LG describes this as an inspection code that appears when the two boards cannot exchange data. The fault can be triggered by an unstable power event, a failed main board, a failed display PCB, or a disconnected wire harness between the boards.

This is not a refrigerant, compressor, fan, or defrost fault. It is purely an electronics communication problem. LG recommends a power reset as the first step, and if the code returns, the refrigerator should be inspected by a technician to identify which board or connection has failed.

## Before You Replace Anything

Many people replace the display board first because it shows the error. Check the wire harness connectors and perform a proper power reset before ordering any board.

## Common Causes

- **Unstable power or electrical disturbance (~35%)** A temporary voltage spike or brownout can trigger a false CO code that clears with a proper power reset.
- **Failed main control board (~30%)** The main PCB may lose its ability to send communication signals to the display, causing a persistent CO error.
- **Failed display PCB (user interface board) (~20%)** The display board may stop responding to the main board's signals, breaking the communication link.
- **Disconnected or damaged wire harness (~15%)** Loose connectors or broken wires between the main board and display board interrupt data transfer.

## Step-by-Step Fix {#fix}

1. **Unplug the refrigerator** or turn off its dedicated circuit breaker. Wait at least 5 minutes to allow all capacitors to discharge and the boards to fully reset.
2. **Restore power** and observe the display. If the CO code does not reappear within a few minutes of normal operation, the problem was a temporary power event and no further action is needed.
3. **If the code returns immediately**, unplug again and remove the refrigerator's interior panels or rear access cover (depending on your model) to expose the main control board and display PCB locations.
4. **Inspect the wire harness** that connects the main board to the display board. Look for loose connectors, corroded pins, pinched wires, or any visible damage. Firmly reseat each connector.
5. **Restore power** and check whether the code clears. If it does, secure all panels and monitor the refrigerator for a few days to confirm the fix.
6. **If the code persists**, use a camera or phone to photograph the main board and display board part numbers. Order the replacement board (main board is more often at fault) or call an LG-authorized technician to perform signal-level diagnostics.
7. **Replace the faulty board** by disconnecting power, removing the mounting screws, unplugging all harnesses, transferring any jumpers or settings, installing the new board, reconnecting harnesses, and restoring power. Clear the error and verify normal operation.

## When to Call a Pro

Call a professional if the CO code returns after a proper 5-minute power reset and you cannot locate or safely access the wire harnesses and control boards. A technician has the signal-tracing tools and board-level test equipment to isolate whether the main board, display board, or harness is at fault without guessing. Professional diagnosis is also the right choice if you are uncomfortable working around live PCBs or if your refrigerator is still under warranty, since DIY board replacement may void coverage. LG recommends technician inspection when the code is repeatable.

**Rough cost:** DIY runs about $150–350 in parts (main board or display PCB), 30–60 min. A pro service call runs about $200–450 including diagnosis and board replacement.
