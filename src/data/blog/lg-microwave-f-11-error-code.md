## What this code means
The F-11 code on an LG microwave signals an inverter communication error. This means the main control board cannot properly communicate with the inverter board, which regulates the microwave's cooking power output. LG defines this code as a service-required fault.

The inverter board converts household AC power into the high-frequency energy the magnetron uses to cook food. When communication between the control and inverter boards fails, the microwave cannot safely operate and shuts down with the F-11 code displayed.

## Before You Replace Anything

Some people replace the main control board first when the inverter board is actually at fault. Before ordering parts, check all harness connectors between the boards for looseness or corrosion.

## Common Causes

- **Failed inverter board (~50%)** The inverter assembly itself stops communicating due to a failed component, solder joint, or internal circuit fault on the board.
- **Loose or damaged wiring harness (~25%)** The connector or ribbon cable between the control board and inverter board is loose, corroded, or has broken traces or pins.
- **Failed main control board (~15%)** The control board's communication circuit or processor fault prevents it from sending or receiving signals to the inverter.
- **Intermittent board-level fault (~10%)** Heat cycling, moisture, or component degradation causes an intermittent communication failure that triggers the code sporadically.

## Step-by-Step Fix {#fix}

1. **Disconnect power** by unplugging the microwave from the wall outlet and waiting at least 30 seconds to allow capacitors to discharge.
2. **Reset the unit** by plugging it back in and testing. If F-11 returns immediately or during the next cook cycle, proceed with diagnosis.
3. **Remove the outer cabinet** by taking out the screws that secure the cover (locations vary by model) so you can access the control board and inverter board.
4. **Inspect all wiring harnesses and connectors** between the main control board and the inverter board for looseness, corrosion, burn marks, or broken pins. Reseat each connector firmly.
5. **Test communication signals and voltages** at the inverter board per the service manual if you have the tools and training. Most homeowners should stop here and call a technician.
6. **Replace the inverter board** if wiring is intact and you have verified the inverter is the failed component. Use the exact OEM part number for your model.
7. **Replace the main control board** if inverter diagnostics pass but the control side shows no output or the fault persists after inverter replacement.
8. **Reassemble the microwave** and run a test cycle. If F-11 still appears, a deeper board-level fault exists and professional service is required.

## When to Call a Pro

LG explicitly designates F-11 as a service-required fault. Microwave inverter boards operate at high voltage even when unplugged due to stored capacitor charge, and incorrect handling can cause severe shock or further damage. If you are not trained in high-voltage appliance repair, do not attempt to diagnose or replace boards yourself. A qualified appliance technician has the tools to safely discharge capacitors, test communication signals, and replace the correct board. Call a pro immediately if you see any arcing, burning smell, or if the code returns after a simple reset.

**Rough cost:** A pro service call runs about $150–350 depending on the board and labor.
