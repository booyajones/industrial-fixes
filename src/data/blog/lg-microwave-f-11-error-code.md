## LG Microwave F-11 Error Code — What It Means

The F-11 error code on an LG microwave indicates an inverter communication error. This means the main control board cannot communicate properly with the inverter assembly that regulates cooking power. LG classifies this as a service-level fault, meaning it typically requires component replacement rather than a simple user reset.

The inverter is the section of your microwave that converts household AC power into the controlled output used for heating. When the control board loses communication with the inverter, the microwave cannot operate safely and displays F-11. This code points to a hardware failure in the inverter board, control board, or the wiring that connects them.

## Common Causes

- **Failed inverter board** The inverter assembly has internal component failures or solder cracks that prevent it from responding to control signals.
- **Loose or damaged wiring harness** The connector or wire harness running between the control board and inverter is loose, corroded, or has broken conductors.
- **Defective main control board** The main control board has a failed communication circuit or processor issue that prevents it from sending or receiving signals from the inverter.
- **Burnt or damaged connector terminals** Heat or arcing has damaged the pins or socket at the inverter or control board connection point, breaking the communication path.

## Step-by-Step Fix {#fix}

1. **Unplug the microwave** and wait 2 to 3 minutes to allow capacitors to discharge and perform a hard reset.
2. **Restore power and test** by attempting to run a heating cycle to see if the F-11 code reappears immediately.
3. **Remove the outer cover** by unplugging the unit and taking out the screws on the back and sides to access the internal wiring and boards.
4. **Inspect all harness connectors** between the main control board and the inverter assembly for loose fits, burnt plastic, or corroded pins.
5. **Disconnect and reseat** each connector fully, checking for damaged wires or broken locking tabs.
6. **Replace the inverter board** if connectors are intact and the fault returns, as this is the most common hardware failure for F-11.
7. **Reassemble and test** the microwave under load to confirm normal heating and verify the error code does not recur.

## When to Call a Pro

Call a professional if you are not comfortable working around high-voltage components inside a microwave. Even when unplugged, the high-voltage capacitor can hold a dangerous charge. If you replace the inverter board or wiring and the F-11 code returns, the issue likely involves the control board or a more complex fault path that requires diagnostic tools and board-level testing. LG officially recommends service for this code, so warranty or in-home service may be the safest and most cost-effective route for many users.
