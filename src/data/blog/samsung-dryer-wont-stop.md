## Samsung Dryer Won't Stop — What's Happening

A Samsung dryer that won't stop describes a runaway cycle where the drum keeps tumbling even after the timer should have ended or the door is opened. This is not a single named fault code, but the closest documented Samsung code for a dryer that runs and won't shut off normally is 3C, which factory troubleshooting associates with a control or shorting issue rather than a user setting problem.

If no code appears on the display, the symptom is investigated as a possible stuck start input, door switch fault, or wiring short to the cabinet. Samsung troubleshooting starts with control reset, door latch inspection, and harness checks before replacing any components.

## Most Likely Causes

- **Stuck or shorted start control input** A shorted button on the user interface or a stuck relay on the control board can hold the dryer in run mode continuously.
- **Door switch or door lock fault** A failed door switch or lock assembly can cause the control to misread the operating state and continue running the cycle.
- **Harness damage or loose connections** Pinched, rubbed, or loose wires at the door switch, sensor, or control can create a short or false signal that keeps the dryer energized.
- **Control board fault** If the symptom returns after reset and wiring checks, a failed main control board is the leading replacement candidate.
- **Moisture sensor contamination** Buildup on the sensor bars can cause abnormal cycle behavior, though this more often affects dryness logic than a true won't-stop complaint.
- **Vent restriction causing overheating-related control behavior** A blocked vent can contribute to odd operation and should be checked during diagnosis.

## How to Diagnose and Fix {#fix}

1. Disconnect power completely by unplugging the dryer or switching off the breaker before any inspection.
2. Check the symptom and display. Note whether the drum stays energized, whether it keeps tumbling, and whether code 3C or any other code appears.
3. Reset the control by leaving the dryer without power for at least two minutes, then plug back in and retest.
4. Inspect the door system. Confirm the door closes firmly, the latch area is clean, and the door switch or lock wiring is intact and not pinched.
5. Inspect the main harness for pinched, rubbed, or loose wires at the door switch, user interface, moisture sensor, and main control board connections.
6. Check the moisture sensor bars inside the drum for contamination and clean them with a soft cloth and rubbing alcohol if needed.
7. Run the dryer in diagnostic or test mode if your model supports it to verify sensor and component behavior.
8. Test suspect circuits with a multimeter. If the symptom persists after reset and wiring checks, replace the control board or user interface as confirmed by the failure path.

## When to Call a Pro

Call a tech if you are not comfortable working with live voltage testing, if the symptom persists after a control reset and door inspection, or if you need to run factory diagnostics that require service-mode access. A qualified appliance technician has the tools and training to trace shorts in the harness, test control board outputs with a meter, and replace the correct component without guessing.
