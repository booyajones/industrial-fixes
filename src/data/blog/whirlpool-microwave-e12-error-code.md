## Whirlpool Microwave E12 Error Code — What It Means

The E12 error code on a Whirlpool over-the-range microwave indicates a problem with the gas sensor or the associated wiring. This sensor monitors ventilation conditions, and when the control board cannot receive a valid signal from it, the system logs E12 and may shut down cooking functions. Whirlpool's official remedy starts with a power reset at the breaker. If the code returns, the unit requires service by a qualified technician.

[Jump to Fix](#fix)

## Common Causes

- **Failed gas sensor** The sensor itself can fail internally, preventing the control board from reading ventilation data.
- **Loose or corroded wiring connector** Vibration or moisture can weaken the plug between the sensor harness and the control board, breaking the signal path.
- **Damaged sensor wiring** Pinched, cut, or chafed wires in the sensor harness create an open circuit or intermittent fault.
- **Poor ground or voltage supply to the sensor circuit** If the sensor does not receive stable power or lacks a clean ground, the control board will flag E12.

## Step-by-Step Fix {#fix}

1. **Turn off power at the circuit breaker** for at least one full minute, then restore power and watch the display for one minute to see if E12 clears.
2. **Confirm your model** is an over-the-range Whirlpool microwave, since E12 is specific to that product family.
3. **Unplug the microwave** or lock out the breaker, then remove the outer cover to access the control board and sensor harness.
4. **Inspect the gas sensor connector** on the control board for corrosion, loose pins, or backed-out terminals, and reseat it firmly.
5. **Trace the sensor wiring** from the control board to the sensor body, looking for pinched insulation, cuts, or burn marks.
6. **Test the gas sensor** with a multimeter if your service sheet provides resistance or voltage specifications, or replace the sensor if inspection shows physical damage or if the wiring is intact but E12 persists.
7. **Reassemble the microwave**, restore power, and run a short cook cycle to verify the code does not return.

## When to Call a Pro

Call a qualified appliance technician if the power reset does not clear E12 or if you are uncomfortable working inside a microwave cabinet with live AC circuits nearby. The sensor and wiring checks require removing the outer cover and handling connectors close to the high-voltage transformer and magnetron. A technician will have your model's service data, including any resistance or voltage thresholds Whirlpool specifies for the gas sensor, and can safely order and install the correct replacement part.
