## LG Oven Won't Stop Beeping — What's Happening

When an LG oven won't stop beeping, it's signaling a fault or warning condition on the control panel. The beeping is tied to a specific error code or status message, not a random alarm. LG ranges and wall ovens display codes for different issues: PO or PF after a power interruption, codes 1, 2, or 3 for a thermistor problem, or messages about stuck touch pads, display faults, or low voltage.

The beep won't stop until you clear the condition or reset the control. LG's own documentation directs you to read the exact code on the display first, then follow the matching reset procedure. If the code returns after a reset, the underlying fault is still present and requires further diagnosis or service.

## Most Likely Causes

- **Power outage or power failure (PO/PF code)** After a power interruption, LG wall ovens beep and flash PO or PF to alert you that power was lost, and the control needs a manual reset to clear the alarm.
- **Thermistor failure or sensor circuit fault** LG error codes 1, 2, and 3 all indicate a thermistor error, meaning the oven temperature sensor or its wiring has failed or is reading out of range.
- **Moisture, spilled liquid, or object pressing the touch controls** LG lists prolonged contact with water or metal objects on the touch pad as a fault condition that can trigger beeping and a control error.
- **Display or control board fault** LG flags errors detected with the display itself, which can cause continuous beeping if the control panel electronics or internal communication is disrupted.
- **Low voltage from the electrical supply** LG identifies low voltage as a fault condition that triggers an error and requires a qualified electrician to measure and correct incoming power.
- **Loose or corroded wiring harness or ribbon cable** Intermittent beeping can come from a bad connection between the user interface and the main control board, especially if the fault comes and goes.
- **Defective main control board** If the control logic or power supply section on the board is faulty, the oven may beep continuously even when the display shows no code or the code does not match a known condition.

## How to Diagnose and Fix {#fix}

1. Read and write down the exact error code or message on the display before doing anything else.
2. Press the Power ON/OFF button to attempt the first reset as directed by LG.
3. If the beeping continues or the code reappears, turn off the circuit breaker for the oven, wait 30 seconds, then restore power.
4. If the code is PO or PF, verify that incoming power is stable and that no other appliances on the circuit are cycling, then confirm the alarm clears after reset.
5. If the code is 1, 2, or 3, inspect the oven thermistor and its harness for visible damage, then test the sensor circuit for continuity and proper resistance if a code returns.
6. If the fault is touch-pad related, clean and dry the control surface thoroughly, remove any objects or debris, then retest the panel.
7. For a display fault or low-voltage condition, measure incoming voltage at the terminal block and check all wiring connections at the control board and interface connector.
8. If the beeping is intermittent, inspect the ribbon cable or harness connector between the user interface and main board for corrosion, loose pins, or physical damage.

## When to Call a Pro

Call a pro if the beeping returns after a full power reset, if you see a thermistor code and are not comfortable testing sensor circuits, or if the display shows a low-voltage condition. LG specifically requires a qualified electrician for low-voltage faults. Also call for service if you find no obvious moisture or stuck keys but the touch-pad error persists, or if the beeping is intermittent and you cannot locate a loose connection. Control board and interface work involves live voltage and precise connector handling, so factory-trained service is the safest route when basic resets don't solve the problem. For gas line, burner, or igniter work, or if you ever smell gas, stop and call a licensed technician.
