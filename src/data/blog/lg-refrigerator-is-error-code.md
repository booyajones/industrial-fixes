## LG IS Error Code — What It Means

The IS or 1S error code on an LG refrigerator indicates a problem with the ice maker sensor. LG's official documentation states this code appears when the ice maker sensor has failed or become disconnected. Some LG error-code lists also mention the ice maker fan motor as a related component, but the primary focus is on sensor failure or a wiring disconnection at the sensor harness. Because of display character limitations on certain models, you may see IS, 1S, or 15 on your panel, but all refer to the same fault family.

LG's published guidance makes clear there are no owner-level troubleshooting steps that will resolve the issue. The code requires inspection of the ice maker sensor wiring, electrical testing of the sensor itself, and replacement of the failed component. A simple power cycle may clear the display temporarily, but the code will return if the underlying sensor fault remains.

## Before You Replace Anything

Homeowners sometimes replace the entire ice maker assembly when only the sensor or its connector has failed. Inspect the sensor wiring and connectors for looseness or damage before ordering the full assembly.

## Common Causes

- **Failed ice maker sensor (~50%)** The sensor itself has gone open, shorted, or out of range and no longer reports valid data to the main board.
- **Disconnected or corroded sensor wiring (~30%)** The harness connector at the ice maker sensor has backed out, pins are corroded, or a wire has broken.
- **Ice maker fan motor fault (~10%)** On some LG models the same code family includes fan motor problems, though the sensor disconnection is the documented primary cause.
- **Ice maker assembly damage (~5%)** Physical damage or water intrusion in the ice maker module can cause integrated sensor or fan failures.
- **Main control board misread (~5%)** Rare cases where the main board incorrectly flags a sensor fault due to a board-level communication error.

## Step-by-Step Fix {#fix}

1. **Power off the refrigerator** by unplugging it or switching off the circuit breaker and wait 60 seconds, then restore power to verify the code returns.
2. **Locate the ice maker assembly** in the freezer compartment and identify the ice maker sensor wiring harness (consult your model's service manual or wiring diagram for the exact location).
3. **Inspect the sensor connector** for looseness, corrosion, bent pins, or broken wires, and reseat or clean the connector if any visible damage is found.
4. **Test the ice maker sensor electrically** using a multimeter if you have the model-specific resistance or continuity specification (LG's public guidance does not publish a universal value, so consult your service manual).
5. **Replace the ice maker sensor** or the ice maker assembly if the sensor is integrated and cannot be serviced separately, using the correct LG part number for your refrigerator model.
6. **Clear the error code** by power-cycling the refrigerator again and monitor the display to confirm the fault does not return.
7. **Schedule a service call** if the code persists after connector repair and sensor replacement, as the main control board or ice maker fan motor may require professional diagnosis.

## When to Call a Pro

LG's official video support states there are no owner troubleshooting steps that will resolve the IS or 1S code and that a repair service is required. The repair involves accessing the ice maker compartment, testing electrical connections and sensor values against service specifications, and potentially replacing the sensor or ice maker assembly. If you are not comfortable working with wiring harnesses in a freezer environment or do not have the model-specific service data to test the sensor, call a qualified appliance technician. A pro will also inspect the ice maker fan motor and main control board if the sensor and wiring check out, ensuring the fault is fully diagnosed and resolved.

**Rough cost:** A pro service call runs about $150–$300.
