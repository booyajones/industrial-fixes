## What this code means
The tE1 error code (often written as TE1 or E1) on an LG dryer indicates a thermistor or temperature-sensing fault. The control board has detected a problem reading the temperature sensor and may stop the dryer from operating until the fault is cleared. LG support states that tE1 points specifically to a thermistor issue and recommends a power reset first. If the code returns after the reset, the unit likely needs repair service.

## Before You Replace Anything

Many homeowners replace the main control board when the code persists, but a simple multimeter test of the thermistor (typically 10–50 kΩ at room temperature, though this varies by model) or a visual inspection of the sensor wiring connector usually reveals the real problem.

## Common Causes

- **Failed thermistor or temperature sensor (~50%)** The thermistor itself tests open, shorted, or out of the expected resistance range (field values often 10–50 kΩ at room temperature, though this varies by model).
- **Loose, damaged, or corroded wiring or connectors (~25%)** The plug at the thermistor or control board has corroded pins, loose contacts, or broken wires that interrupt the signal.
- **Airflow restriction or vent blockage (~15%)** Lint buildup, a kinked duct, or a blocked exterior vent causes overheating that triggers abnormal temperature readings and the fault code.
- **Control board fault (~10%)** The main control board misreads or fails to interpret the thermistor signal even though the sensor and wiring test good.

## Step-by-Step Fix {#fix}

1. **Kill power** by unplugging the dryer or switching off the circuit breaker at the panel.
2. **Reset the control** by leaving the unit unpowered, then pressing and holding START/PAUSE for about 5 seconds, restoring power, and running a short test cycle to see if the code clears.
3. **Inspect airflow** by checking the lint filter, the entire vent duct for kinks or crushing, and the exterior vent cover to confirm it opens freely and is not blocked by lint or debris.
4. **Access the thermistor** by removing the rear or top panel (consult your model's service manual for location), then disconnect the sensor plug and visually inspect the connector pins for corrosion or damage.
5. **Test the thermistor** with a multimeter set to ohms. At room temperature non-manufacturer sources report roughly 10–50 kΩ, but consult your model's wiring diagram for the exact specification. An open or shorted reading means the sensor has failed.
6. **Replace the thermistor** if it tests out of range or the wiring harness if the connector is damaged, then reassemble the dryer and retest.
7. **Check the main control board** if the sensor and wiring both test good but the code persists. Verify board operation per your model's service literature and replace if necessary.

## When to Call a Pro

Call a technician if you are uncomfortable working with 240-volt power, if you cannot access or test the thermistor with a multimeter, or if the sensor and wiring both check good but the code returns. A qualified appliance technician has the model-specific wiring diagrams, resistance specifications, and board-level diagnostic tools to isolate a control board fault quickly. Also call for service if the dryer is still under warranty, since DIY repairs may void coverage.

**Rough cost:** DIY runs about $15–40 in parts, 30–60 min. A pro service call runs about $150–250.
