## What this code means
When your Maytag range displays LOC, Lock, or Locked, the control panel has entered Control Lock mode. This is not a fault code. The lock feature disables the user interface so accidental button presses during cleaning or around children do not change settings. The display will show LOC when you try to press buttons, and the oven will ignore your commands until you unlock it.

Maytag provides a specific unlock procedure for each model. Most ranges unlock by pressing and holding the START or ENTER button for five seconds. Some models require you to press Cancel instead. If the lock display appears unexpectedly or will not clear using the normal unlock sequence, a stuck keypad button, a control board glitch, or a recent power interruption may be holding the control in lock mode.

## Before You Replace Anything

Homeowners sometimes replace the electronic control board when the range is simply in Control Lock mode. Always try the unlock button sequence and a one-minute power reset at the breaker before ordering any parts.

## Common Causes

- **Control Lock activated by user or accidental button press (~70%)** The lock feature was turned on intentionally or by pressing the wrong key combination, and the display now shows LOC until you unlock it.
- **Stuck or failing touchpad key (~15%)** A button on the keypad is physically stuck or the touchpad membrane has failed, sending a continuous lock command to the control board.
- **Power interruption or control board glitch (~10%)** A recent power outage, brown-out, or electrical surge left the control in an unexpected locked state that persists after restore.
- **Sabbath mode or special operating mode enabled (~5%)** Some Maytag models lock certain controls when Sabbath or demonstration mode is active, and the manual-specific exit sequence is required.

## Step-by-Step Fix {#fix}

1. **Identify the exact display text.** Confirm the screen shows LOC, Lock, or Locked and not a fault code such as F9 E0. If you see a different code, stop and look up that error instead.
2. **Attempt the unlock sequence for your model.** Press and hold the START or ENTER button for five seconds. On some Maytag ranges, press Cancel to exit Control Lock. Consult your owner's manual if neither method works.
3. **Perform a power reset at the breaker.** Turn off the circuit breaker that supplies the range, wait one full minute, then restore power. This clears temporary control board glitches and resets the lock state.
4. **Check for stuck or damaged keys on the touchpad.** Press each button lightly and feel for resistance. Look for cracks, spills, or debris under the overlay that might cause a key to register continuously.
5. **Verify Sabbath mode is off.** Some models lock controls when Sabbath or demo mode is active. Check your owner's manual for the exit sequence, which often involves holding a specific combination of buttons.
6. **Inspect the touchpad ribbon connector.** With power off at the breaker, pull the range forward, remove the back panel, and confirm the flat ribbon cable from the touchpad to the control board is firmly seated in both connectors.
7. **Replace the touchpad or control board if the lock persists.** If the display still shows LOC after all resets and no keys are stuck, order the touchpad assembly first (more common failure). If a new touchpad does not resolve the issue, replace the electronic control board.

## When to Call a Pro

Call a professional if you are uncomfortable working with 240-volt appliances, if you cannot access the control board behind the back panel, or if you have already replaced the touchpad and the lock display continues. A technician has the tools to measure signals on the control board and can quickly confirm whether the board itself has failed or whether a wiring fault is sending a false lock command. If your range is under warranty, contact Maytag or an authorized service center before opening any panels, because self-repair may void coverage.

**Rough cost:** DIY runs about $0 if no parts needed; $80–$200 for touchpad, $150–$300 for control board if replacement is necessary, 30–90 min. A pro service call runs about $100–$250 service call; $200–$450 if control board or touchpad replacement is required.
