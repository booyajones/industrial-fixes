## Frigidaire Range F18 Error Code — What It Means

The F18 error code on a Frigidaire range indicates an oven relay board failure. Frigidaire's service documentation lists this as 'F18 Oven relay board failure (wiggler)' and points to a fault in the relay board that controls power switching to oven heating elements. The relay board receives commands from the user interface board and energizes the appropriate heating circuits. When the control system detects that the relay board is not responding correctly or has failed, it triggers the F18 code and typically halts oven operation to prevent unsafe conditions.

The fault can originate in the relay board itself, in the wiring harness between the user interface board and the relay board, or occasionally in the control assembly that commands the relay board. Frigidaire's diagnostic flow treats this as primarily a relay board issue, with upstream control problems considered only after verifying connections and power cycling the unit.

## Before You Replace Anything

Many people replace the user interface board or touch panel first because they are more visible. Always inspect the harness connectors between the UI board and the relay board and power-cycle the range before replacing any boards.

## Common Causes

- **Failed oven relay board (~60%)** The relay board's internal components (relays, traces, or driver circuits) fail and cannot switch power to the oven elements.
- **Loose or damaged harness connector (~20%)** The wiring harness or connector between the user interface board and the oven relay board is not seated fully, has corroded pins, or shows physical damage.
- **Failed user interface board (~10%)** The control assembly (UIB and touch panel) sends incorrect or absent commands to the relay board, causing the relay board to appear faulty.
- **Intermittent wiring fault (~5%)** A broken wire or intermittent connection in the harness between boards causes the relay board to lose communication sporadically.
- **Power surge damage (~5%)** A recent power surge damaged the relay board's input or output circuitry, triggering the F18 code.

## Step-by-Step Fix {#fix}

1. **Disconnect power** at the circuit breaker or unplug the range to eliminate electrical hazards.
2. **Wait 30 seconds**, then restore power and observe whether the F18 code reappears on the display.
3. **Pull the range forward** and remove the rear access panel or lower kick panel to expose the oven relay board and user interface board (locations vary by model).
4. **Inspect the harness connectors** between the user interface board and the oven relay board for loose seating, bent pins, corrosion, or burn marks, and reseat all connectors firmly.
5. **Test the range** by selecting an oven function. If F18 persists after connector service, disconnect power again and remove the mounting screws that secure the oven relay board.
6. **Install the replacement oven relay board**, reconnect all harness plugs in the same positions, and verify each connector is fully seated.
7. **Restore power**, run a test bake cycle, and confirm the F18 code does not return and the oven heats normally.

## When to Call a Pro

Call a professional if you are uncomfortable working with 240-volt appliance wiring, if the range is still under warranty, or if the F18 code returns after you have replaced both the relay board and verified all harness connections. A technician can perform voltage and continuity tests on the relay board outputs and the control assembly to pinpoint communication faults that are not visible during a connector inspection. Professional diagnosis is also recommended if you discover burn marks, melted insulation, or other signs of electrical damage during your inspection, as these may indicate a more complex wiring or grounding problem.

**Rough cost:** DIY runs about $100-200 in parts, 45-90 min. A pro service call runs about $200-400.
