## Frigidaire Range F18 Error Code — What It Means

F18 on a Frigidaire range indicates an oven relay board failure, sometimes called the wiggler board. This code appears when the main control board detects a fault in the relay board itself or in the communication path between the user interface board and the relay board. The fault can be caused by a failed relay board, a loose or corroded connector, or less commonly a problem with the control board itself. F18 is not a temperature sensor issue but a board-level fault that usually requires component replacement after verifying all connections are secure.

## Common Causes

- **Failed oven relay board** The relay board itself has failed internally and can no longer communicate with the control board or operate the oven elements correctly.
- **Loose or damaged connector between boards** The harness connector linking the user interface board to the relay board has come loose, corroded, or suffered pin damage, interrupting communication.
- **Faulty user interface board** The control board or UI touch panel has developed a fault in its communication circuit, triggering the relay board error even when the relay board is fine.
- **Oxidized or dirty connector pins** Corrosion or buildup on the connector pins between the two boards prevents reliable signal transmission and triggers the fault code.
- **Intermittent power or wiring issue** A broader electrical problem causes intermittent communication faults between the boards, making the F18 code reappear after resets.

## Step-by-Step Fix {#fix}

1. **Disconnect power** at the breaker or by unplugging the range, then wait at least 30 seconds before restoring power to see if the code clears on its own.
2. **Check the wiring harness** between the user interface board (mounted behind the control panel) and the oven relay board (typically mounted on the back wall of the oven cavity or near the elements) for loose, damaged, or corroded connectors.
3. **Reseat all connectors** firmly, inspecting pins for oxidation or damage, and clean any visible corrosion with electrical contact cleaner if needed.
4. **Power the range back on** and observe whether the F18 code returns immediately or after a heating cycle.
5. **Replace the user interface board and touch panel assembly** first if the service flow for your model prioritizes control-side faults when connectors are secure but the code persists.
6. **Replace the oven relay board** if the code remains after verifying or replacing the control assembly, following your model's service guidance for the correct part number.
7. **Run a full heating cycle** after replacement to confirm the oven heats normally, the elements cycle as expected, and the F18 code does not reappear.

## When to Call a Pro

Call a professional if you are uncomfortable working with live 240-volt circuits, if you cannot safely access the boards behind the control panel or inside the oven cavity, or if the F18 code returns after you have verified all connections and replaced the relay board. Board-level diagnostics can require a multimeter and familiarity with your model's wiring diagram. Because Frigidaire error codes vary by model family, a technician with access to your specific service sheet can confirm the exact diagnostic sequence and avoid unnecessary part replacement.
