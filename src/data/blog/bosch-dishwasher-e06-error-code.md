## Bosch Dishwasher E06 Error — What It Means

The E06 code on a Bosch dishwasher is most consistently reported as a door sensor or door latch circuit fault. The dishwasher control is detecting a problem with the door not being properly closed or latched, or with the wiring and sensor that prove the door is secure. On some models the code may also relate to an aqua sensor (turbidity sensor) issue, but the door-related explanation is dominant across reported cases. Because Bosch uses model-specific code maps, verify the exact meaning for your E-Nr in the service data or owner's manual if you need certainty.

When the door does not latch correctly or the sensor circuit is broken, the dishwasher will not start a cycle and will display E06. The fault can be mechanical (a misaligned or obstructed door, a broken latch) or electrical (a failed sensor, damaged wire, or loose connector between the door assembly and the main control board).

## Before You Replace Anything

Many people replace the main control board when the code persists, but a damaged wiring harness or loose connector between the door sensor and the board is often the real problem. Always inspect and wiggle-test the harness plugs and wiring before condemning the control board.

## Common Causes

- **Door not closing or latching fully (~40%)** Racks, dishes, or debris block the door from seating, or the latch mechanism is misaligned, bent, or broken so the sensor never sees a secure close.
- **Faulty door sensor or switch (~30%)** The sensor or switch that proves the door is latched has failed internally and no longer signals the control board correctly.
- **Damaged or loose wiring harness or connector (~20%)** Wires between the door sensor and the main control board are pinched, broken, corroded, or the connector has backed out of its socket.
- **Failed main control board (~8%)** When the door hardware, sensor, and harness all check good, the control board itself may have a fault in the door-sensor input circuit.
- **Contaminated or failed aqua sensor (model-specific) (~2%)** On some Bosch models E06 can point to the turbidity sensor, which may be fouled or broken, though this interpretation is less common.

## Step-by-Step Fix {#fix}

1. **Remove power** by unplugging the dishwasher or switching off the breaker for 30 seconds, then restore power to clear any transient fault.
2. **Open and close the door** several times and listen for a solid latch click. Pull out both racks and check for dishes, utensils, or debris blocking the door from seating fully.
3. **Inspect the door latch and strike** for cracks, bends, or misalignment. If the latch does not engage cleanly, adjust or replace the latch assembly.
4. **Access the wiring harness** by removing the lower kick panel and the front control-panel cover (consult your model's service manual for fastener locations). Locate the connector running from the door sensor to the main control board.
5. **Check all connectors and wiring** for loose plugs, corrosion, pinched insulation, or broken strands. Wiggle each connector gently to confirm it is fully seated.
6. **Test or replace the door sensor** if the wiring is intact. On some models you can verify sensor operation with a magnet or by manually actuating the switch. Replace the sensor assembly if it does not change state or shows visible damage.
7. **Replace the main control board** only after confirming the door hardware, sensor, and harness are all sound but the E06 code still appears. Install the new board and reassemble the dishwasher, then test a short cycle.

## When to Call a Pro

Call a professional if you are not comfortable removing the control-panel covers or working around the control board, or if you have tested the door latch, sensor, and wiring but the code persists and you want to avoid guessing between the sensor and the board. A technician can use a multimeter and the factory wiring diagram to pinpoint whether the sensor circuit is open, shorted, or whether the board input has failed. Also call a pro if your dishwasher is still under warranty, since self-repair may void coverage.

**Rough cost:** DIY runs about $15-80 in parts (sensor or latch assembly), 30-90 min. A pro service call runs about $120-250 service call and part.
