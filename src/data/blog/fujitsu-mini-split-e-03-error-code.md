## Fujitsu E:03 Error Code — What It Means

On Fujitsu mini-split systems, the E:03 error code indicates a room sensor short or sensor fault. The indoor unit's thermistor (temperature sensor) has either shorted, opened, or is reading out of range. This prevents the system from accurately reading room temperature and controlling operation. Some other mini-split brands use E3 for different problems, so always confirm the code against your specific Fujitsu model documentation.

## Common Causes

- **Room thermistor open or shorted** The temperature sensor itself has failed internally or drifted out of specification range.
- **Loose or corroded sensor connector** The harness plug at the indoor PCB or sensor has poor contact, moisture intrusion, or backed-out pins.
- **Damaged or pinched sensor wiring** The wire between the sensor and controller board is cut, pinched, or shorted to chassis ground.
- **Indoor controller PCB failure** The sensor input circuit on the main board has failed even though the sensor and wiring test good.

## Step-by-Step Fix {#fix}

1. **Power down the system** at the breaker or disconnect switch before opening the indoor unit cover.
2. **Locate the room sensor** inside the evaporator unit (typically a small thermistor mounted near the return-air intake or clipped to the evaporator coil).
3. **Inspect the sensor harness and connector** for loose pins, corrosion, pinched wire, or signs of moisture damage at the indoor PCB.
4. **Measure the thermistor resistance** using a multimeter and compare the value to the resistance chart in your model's service manual (values vary by model).
5. **Substitute a known-good room sensor** if available to confirm whether the thermistor is the fault or the controller board circuit is bad.
6. **Replace the indoor controller PCB** if the code persists after installing a good sensor and verifying clean wiring connections.
7. **Restore power and test** the system to confirm the E:03 code clears and normal temperature control resumes.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working with low-voltage wiring, if you do not have a service manual with the correct thermistor resistance table for your model, or if the fault persists after replacing the sensor and inspecting connections. Refrigerant-circuit work is not required for E:03, but accurate diagnosis of PCB-level failures and proper thermistor testing require a multimeter and familiarity with Fujitsu control boards.
