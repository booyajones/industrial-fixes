## Amana Dryer F3 E4 Error Code — What It Means

The F3 E4 code appears when your Amana dryer has run five consecutive cycles without detecting any moisture sensor data. The control board expects to see feedback from the moisture sensor bars inside the drum during automatic drying. When it doesn't receive valid readings across multiple loads, it throws this fault to alert you that the sensing circuit isn't working.

This code does not point to a heating or voltage problem. It is strictly a moisture-sensor feedback issue. Amana's reset procedure is to power the unit down for five minutes, restore power, and run a test cycle to see whether the code returns.

## Common Causes

- **Very small loads or single items** Clothes that don't make consistent contact with the sensor bars inside the drum won't generate a valid moisture reading.
- **Dryer not level** An out-of-level cabinet can prevent the load from tumbling across the sensor strips properly during the cycle.
- **Lint or residue on sensor bars** Buildup of lint, fabric softener film, or dryer sheet residue insulates the sensor electrodes and blocks moisture detection.
- **Loose or corroded sensor wiring** The harness connections between the sensor bars and the control board may be damaged, loose, or corroded.
- **Failed moisture sensor bars** The sensor electrodes themselves can crack, pit, or lose continuity over time.
- **Control board not reading sensor input** If the board's sensor circuit has failed, it won't register data even when the bars and wiring are intact.

## Step-by-Step Fix {#fix}

1. **Power cycle the dryer** by unplugging it or switching off the breaker for five minutes, then restore power and clear the code.
2. **Run a test cycle** with a normal-size mixed load (not a single towel or very small batch) on an automatic dry setting to confirm the code is gone.
3. **Check that the dryer is level** by placing a bubble level on top of the cabinet front-to-back and side-to-side, and adjust the leveling feet as needed.
4. **Locate the moisture sensor bars** inside the drum (usually two metal strips on the rear bulkhead or drum wall) and clean them with a soft cloth dampened with rubbing alcohol to remove lint, residue, and film.
5. **Inspect the sensor wiring harness** from the bars to the control board for loose connectors, frayed wires, or corrosion, and reseat or repair as needed.
6. **Test sensor continuity** with a multimeter if you have the service manual's resistance values for your model, or consult a technician if you lack those specs.
7. **Replace the failed component** (sensor bars, harness, or control board) if the code persists after cleaning, leveling, and wiring checks, then run another test cycle to verify the repair.

## When to Call a Pro

Call a technician if the code returns after you've cleaned the sensor bars, verified the dryer is level, and tested with a proper load size. Diagnosing open circuits or intermittent harness faults requires a multimeter and your model's wiring diagram. If you're uncomfortable working inside the cabinet or don't have resistance specs for the sensor, a qualified repair service can test the circuit accurately and replace the correct component the first time.
