## What this code means
The F3 E4 code on Amana dryers signals an intermittent airflow or vent restriction fault. Amana's own documentation links this code to restricted airflow conditions and recommends power-cycling the unit as the first corrective action. The related code AF or F4E3 explicitly describes restricted airflow caused by a clogged lint screen, blocked exhaust vent, or vent routing problems such as crushing, kinking, or too many turns. The dryer may continue to run while the code is displayed, but drying performance will suffer until the airflow problem is resolved. If the code persists after airflow checks and power reset, the control may have detected a broader system problem that requires professional service.

## Before You Replace Anything

Homeowners sometimes replace the control board or thermal sensors when the real problem is simply a blocked vent or lint screen. Always clean the entire exhaust path and power-cycle the dryer before ordering any parts.

## Common Causes

- **Lint screen clogged (~40%)** A lint screen packed with debris restricts airflow and triggers the F3 E4 fault.
- **Exhaust vent clogged, crushed, or kinked (~35%)** Blockage or physical damage in the vent duct prevents proper air discharge and causes the code.
- **Too many bends or turns in the vent run (~15%)** Excessive elbows or long vent runs reduce airflow below the threshold the control expects.
- **Improper electrical supply (~5%)** An electric dryer requires a 240-volt, 30-amp separate circuit fused on both sides of the line; inadequate power can cause intermittent faults.
- **Control or sensor fault (~5%)** If airflow and power checks pass, the control board or an associated sensor may have failed and require service.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker and wait five minutes, then restore power to reset the control.
2. **Remove and clean the lint screen** under running water with a soft brush to clear any residue or fabric softener film.
3. **Disconnect the exhaust vent** from the back of the dryer and inspect the duct for lint buildup, crushing, kinks, or excessive bends.
4. **Clean the entire vent run** using a vent brush or vacuum attachment, and check the outdoor termination for blockage or a stuck damper.
5. **Verify the dryer is plugged into a dedicated 240-volt, 30-amp circuit** fused on both sides of the line, and confirm all connections are tight.
6. **Reconnect the vent** with smooth, straight runs where possible and minimize the number of elbows or turns.
7. **Run a test cycle** and observe whether the F3 E4 code returns. If it does, consult the service manual or call a technician to inspect the control board and airflow sensors.

## When to Call a Pro

Call a professional if the F3 E4 code persists after you have thoroughly cleaned the lint screen and exhaust vent, verified the power supply is a dedicated 240-volt, 30-amp circuit, and power-cycled the dryer. A technician will use diagnostic tools to test airflow sensors, temperature components, and the control board. Also call a pro if you discover a long or complex vent run that requires rerouting, if the outdoor vent termination is inaccessible, or if you lack confidence working with 240-volt appliance circuits. Professional vent cleaning or system diagnostics typically run between one hundred and two hundred fifty dollars depending on your location and the extent of the repair.

**Rough cost:** DIY runs about $0-30 if only cleaning; $15-50 for replacement vent sections, 30-90 min. A pro service call runs about $100-250 for vent cleaning or minor vent repair.
