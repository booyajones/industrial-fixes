## Whirlpool Range FC E2 Error — What It Means

FC E2 does not appear in Whirlpool's published range fault code lists. The two most common Whirlpool cooking-appliance codes that are easily misread are F3 E2 and F2 E2. F3 E2 means the control has detected a problem with the oven temperature sensor, the warming drawer sensor if your range has one, or the wiring between the sensor and the control board. F2 E2 means the keypad or user interface is not communicating with the main control, usually because of a loose or corroded ribbon cable. Before going further, double-check the exact characters on the display and write down your full model number from the tag inside the oven door or on the back. Whirlpool advises that many error codes can be cleared by cycling power off for one minute, but if the code returns the appliance has an active fault that needs repair.

## Before You Replace Anything

Many people replace the electronic control board first when they see a sensor or keypad code. Before ordering a board, confirm the exact code displayed, inspect all harness connectors for corrosion or loose pins, and test the oven temperature sensor or keypad ribbon cable depending on which code you actually have.

## Common Causes

- **Misread or miswritten code (~50%)** FC E2 is not a documented Whirlpool range code and the display probably shows F3 E2 or F2 E2.
- **Failed oven temperature sensor (if F3 E2) (~25%)** The oven temperature sensor has drifted out of range, opened, or shorted and the control cannot read a valid resistance.
- **Loose or corroded sensor or keypad wiring (~15%)** Connector pins at the sensor, warming drawer, or keypad ribbon cable are loose, corroded, or heat-damaged.
- **Disconnected keypad ribbon cable (if F2 E2) (~7%)** The flat ribbon cable between the touchpad and the main control board has worked loose or the connector latch is broken.
- **Failed electronic control board (~3%)** The control board is reporting a sensor or keypad fault even when the wiring and component test good.

## Step-by-Step Fix {#fix}

1. **Verify the exact code and model number.** Look at the display and confirm whether it shows FC, F3, or F2, and write down the full model number from the tag inside the oven door or on the range back.
2. **Power-reset the range.** Turn off both circuit breakers (or unplug if accessible) for one full minute, restore power, and check whether the code returns.
3. **Inspect all wiring connectors.** For F3 E2, locate the oven temperature sensor (usually at the top rear of the oven cavity) and the warming drawer sensor if equipped. For F2 E2, locate the ribbon cable behind the control panel. Check each connector for loose fit, corrosion, heat damage, or bent pins.
4. **Test or replace the oven temperature sensor (F3 E2).** Disconnect the sensor, measure its resistance at room temperature, and compare to the value in your model's service sheet (consult your wiring diagram if you do not have the spec). If the sensor reads open, shorted, or far out of range, replace it.
5. **Reseat or replace the keypad ribbon cable (F2 E2).** Unplug the range, remove the control-panel screws, lift the panel, and firmly reseat the flat ribbon cable into both the touchpad and the main control board connectors. If the cable or connector is damaged, replace the user interface assembly.
6. **Clear the code and test.** Restore power, press Cancel or Clear, and run the oven through a bake cycle to confirm the repair.
7. **Replace the electronic control board only if needed.** If the code persists after confirming good wiring and a known-good sensor or keypad, the control board is suspect and should be replaced by a qualified technician or advanced DIYer.

## When to Call a Pro

Call a pro if you are not comfortable working inside the range with the breakers off, if you cannot locate the sensor or keypad connectors, or if the code persists after you have verified good wiring and replaced the sensor or keypad assembly. A qualified appliance technician has the model-specific service sheets, resistance tables, and board-test procedures to isolate control-board faults without guessing. Also call a pro if your range is still under warranty, because manufacturer coverage often requires factory-authorized service.

**Rough cost:** DIY runs about $20–80 in parts, 30–60 min. A pro service call runs about $150–300.
