## GE Range F2 Error Code — What It Means

On GE ranges and wall ovens, the F2 or F20 error code indicates that the oven control has detected an over-temperature condition. GE's support page describes this as the oven temperature exceeding a preset threshold for an unknown reason. Repair sources call this a runaway heat condition, where the control sees the oven climbing beyond safe operating limits during normal bake or self-clean cycles.

When F2 appears, the range typically shuts down the oven until the fault is cleared. The code can be triggered by an actual overheating event, a faulty temperature sensor sending incorrect readings, damaged wiring, or a defective control board misinterpreting sensor data. In some cases it is a simple control glitch that clears after a power reset.

## Before You Replace Anything

Many people replace the electronic range control board first, but the oven temperature sensor fails far more often. Always measure the sensor resistance at room temperature with a multimeter before ordering a new board.

## Common Causes

- **Failed oven temperature sensor (~50%)** The RTD probe in the oven cavity sends incorrect resistance values to the control, causing the board to read a runaway temperature that does not exist.
- **Damaged or intermittent wiring harness (~20%)** Corroded connectors, broken wires, or loose terminals between the sensor and the control board produce erratic signals that trigger an over-temperature fault.
- **Defective electronic range control (ERC) board (~15%)** The control board itself misinterprets valid sensor data or develops an internal fault that falsely reports runaway heat.
- **Clogged ventilation or actual overheating (~10%)** Blocked oven vents, a failed convection fan, or heavy soil buildup during self-clean can cause genuine over-temperature events.
- **Control glitch or transient fault (~5%)** A temporary software error or voltage spike sets the code even though all hardware is working properly.

## Step-by-Step Fix {#fix}

1. **Kill all power** at the circuit breaker or unplug the range completely before removing any panels or touching internal wiring.
2. **Reset the control** by leaving power off for at least three minutes, then restore power and check whether the F2 code reappears immediately or during a short test bake.
3. **Locate the oven temperature sensor**, a small metal probe that extends into the oven cavity near the top or back wall, and trace its wire harness to the rear connector at the control board.
4. **Measure the sensor resistance** using a multimeter set to ohms. Disconnect the sensor plug, touch the leads to the two terminals on the sensor, and compare the reading to the expected value of approximately 1,080 to 1,100 ohms at room temperature.
5. **Inspect the wiring harness** and connector for burns, corrosion, loose pins, or broken wires if the sensor resistance is within range but the code persists.
6. **Replace the oven temperature sensor** if the resistance is out of range, reconnect the harness, restore power, and run a test bake to verify the code does not return.
7. **Replace the electronic range control board** if the sensor and wiring both test good and the F2 fault continues after all other checks are complete.

## When to Call a Pro

Call a professional if you are uncomfortable working with 240-volt power, if you cannot safely access the back of the range to remove panels, or if the sensor and wiring both test good but the code persists and you need the control board diagnosed and replaced. A technician has the tools to verify harness continuity end-to-end and can confirm that a new board will solve the problem before you invest in the part. Also call a pro if the oven shows signs of actual overheating, such as discolored interior enamel or a smell of burnt insulation, since that may indicate a ventilation blockage or convection-fan failure that requires deeper disassembly.

**Rough cost:** DIY runs about $20–50 in parts, 30–60 min. A pro service call runs about $150–250.
