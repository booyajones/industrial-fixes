## Whirlpool Dryer F28 Error Code — What It Means

The F28 error code on Whirlpool dryers typically signals a communication fault between the main control board and another component, such as the user interface or motor control. The exact meaning can vary by model, so consult your owner's manual or the wiring diagram on the back panel to confirm what F28 indicates for your specific dryer.

This code usually appears when signals between boards are interrupted, corrupted, or not sent at all. It can be caused by a loose wire harness, a failed connector, or a board that has stopped responding. In some cases the error is temporary and can be cleared by a power reset.

## Before You Replace Anything

Many people replace the main control board first when the real problem is a loose connector or corroded pins in the wire harness. Reseat and inspect every harness plug between the user interface and the main control before buying a board.

## Common Causes

- **Loose or corroded wire harness connector (~50%)** Vibration and heat can loosen plugs or corrode pins, breaking communication between the main control and user interface.
- **Failed main control board (~25%)** The control board may lose its ability to send or receive signals due to component failure or power surge damage.
- **Failed user interface control board (~15%)** The touchpad and display board can stop communicating if internal circuits fail or solder joints crack.
- **Damaged wire harness (~10%)** Wires can fray, short, or break inside the insulation where the harness flexes near hinges or pulleys.

## Step-by-Step Fix {#fix}

1. **Unplug the dryer** and wait two minutes to allow the control to reset and discharge stored power.
2. **Remove the console or top panel** by taking out the screws along the back edge or releasing spring clips, depending on your model.
3. **Locate the wire harness connectors** between the user interface board and the main control board, usually a white or black multi-pin plug.
4. **Unplug each connector** and inspect the pins for corrosion, soot, or bent contacts, then spray with electrical contact cleaner if needed.
5. **Reseat every connector** firmly until you hear or feel a click, making sure no wires are pinched or tugged.
6. **Restore power and run a test cycle** to see if the F28 error returns.
7. **If the error persists**, test the wire harness for continuity with a multimeter or replace the main control board if the harness and connectors are good.

## When to Call a Pro

Call a technician if you are not comfortable opening the console, working with multi-pin connectors, or using a multimeter to test boards and wiring. A pro can quickly identify whether the fault is in the harness, the main control, or the user interface and replace only the failed component. If the dryer is still under warranty or you need the repair done the same day, professional service is the faster and safer choice.

**Rough cost:** DIY runs about $80-180 in parts, 45-90 min. A pro service call runs about $150-300.
