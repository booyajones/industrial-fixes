## GE Oven F20 Error Code — What It Means

The GE F2 or F20 error code means the control has detected that the oven temperature has exceeded a preset threshold. GE groups F2 and F20 together for this condition, stating that for an unknown reason the oven temperature has exceeded a safe limit. The code does not always mean the oven cavity truly reached a dangerous temperature. Often the control board is reading incorrect data from a failed sensor or a relay has stuck closed and kept the heating element powered when it should have shut off.

## Before You Replace Anything

Many people replace the main control board first when the real fault is the inexpensive oven temperature sensor. Always test the sensor resistance with a multimeter before ordering a new board.

## Common Causes

- **Faulty oven temperature sensor (~50%)** The RTD sensor sends incorrect resistance readings to the control, causing it to believe the oven is dangerously hot when it is not.
- **Failed or stuck relay on the control board (~30%)** The bake or broil relay contacts can weld together and keep the heating element energized continuously, creating a true over-temperature event.
- **Electronic control board failure (~15%)** Damaged solder joints or internal circuit faults on the main control can cause false over-temperature readings even when the sensor and relays are normal.
- **Temporary electronic glitch (~5%)** A power surge or momentary control lockup can trigger the code once without indicating a real component failure.

## Step-by-Step Fix {#fix}

1. **Cut power at the breaker** or unplug the range completely before touching any components.
2. **Reset the control** by leaving power off for at least five minutes, then restore power and clear the code to see if it was a transient fault.
3. **Locate the oven temperature sensor** at the upper rear or side wall of the oven cavity, usually a metal probe about 4–6 inches long with a two-wire connector behind the rear panel.
4. **Test sensor resistance** with a multimeter set to ohms. Disconnect the sensor wiring harness and measure across the sensor terminals. A room-temperature reading of approximately 1,080–1,090 Ω is normal. Readings significantly higher or open circuit indicate a faulty sensor.
5. **Inspect the sensor wiring and connector** for breaks, burns, or loose pins. A poor connection can mimic a sensor failure.
6. **Check the control board relays** if the sensor tests good. Remove the control board and visually inspect the bake and broil relays for welded or discolored contacts. You can also measure continuity across relay contacts with power off to confirm they open and close correctly.
7. **Replace the failed part** (sensor, control board, or relay) and restore power. Run a bake cycle to verify the code does not return and the oven heats normally.

## When to Call a Pro

Call a trained service technician if you are uncomfortable working with 240 V wiring behind the range or inside the control panel. GE recommends professional diagnosis and repair for fault codes. A technician has relay testers and board-level diagnostic tools that can isolate intermittent faults and confirm whether a relay can be replaced individually or whether the entire control board is required. If the fault returns after sensor replacement or if you see signs of arcing or burnt wiring, stop work and call for service to prevent fire risk.

**Rough cost:** DIY runs about $25-80 in parts, 30-60 min. A pro service call runs about $150-300.
