## Kenmore Dryer F71 Error Code — What It Means

F71 is a control-system communication fault. The dryer's main electronic control board (ECB) is not communicating correctly with another control board, typically the user interface control board (UICB) or, on some platforms, the motor control unit. This is an electronic fault, not a venting or airflow issue. The exact board architecture depends on your model family, since Kenmore is a rebadged brand using Whirlpool or Maytag platforms.

When F71 appears, the manufacturer recommends powering the dryer down at the breaker, waiting five minutes, then restoring power and running a Time Dry cycle. If the code returns immediately, the fault is in the control system rather than a transient power glitch.

## Before You Replace Anything

Many owners replace the main control board or user interface board first. Instead, de-energize the dryer and carefully inspect and reseat every harness connector between the boards and motor control unit for looseness, corrosion, or pin damage before ordering a board.

## Common Causes

- **Loose, corroded, or damaged harness connectors (~40%)** Wiring connections between the main control board, user interface board, or motor control unit become loose, oxidized, or suffer heat damage, breaking the communication link.
- **Failed main electronic control board (ECB) (~25%)** The main control board has failed and can no longer send or receive signals to the user interface or motor control unit.
- **Failed user interface control board (UICB) (~20%)** The console or user interface board has failed and cannot communicate with the main control.
- **Failed motor control unit (MCU) (~10%)** On platforms where F71 involves motor-control communication, the MCU itself has failed or lost its connection to the main board.
- **Damaged power supply or terminal-block wiring (~5%)** Unstable incoming 240 V supply, loose terminal-block connections, or damaged power-cord wiring can mimic or trigger control-communication faults.

## Step-by-Step Fix {#fix}

1. **Disconnect all power** by switching off both legs of the 240 V circuit breaker that feeds the dryer, then unplug the power cord if accessible.
2. **Wait five full minutes** to allow the control capacitors to discharge, then restore power and press the start button to run a Time Dry cycle and watch whether F71 returns.
3. **Remove the dryer's top or rear panel** (consult your service manual for fastener locations) to gain access to the main control board, user interface board, and motor control unit.
4. **Inspect every harness connector** between the boards for looseness, corrosion, melted plastic, bent pins, or moisture intrusion, and firmly reseat each plug.
5. **Measure incoming voltage** at the terminal block with a multimeter set to AC volts, confirming approximately 220–240 volts between the two outer (hot) terminals.
6. **Isolate the failed module** by disconnecting the user interface board harness and checking for continuity or by substituting a known-good board, depending on your model's architecture and available test equipment.
7. **Replace the defective board or harness** and reassemble the dryer, then run a full timed cycle to confirm the F71 code does not return and the machine completes normally.

## When to Call a Pro

Call a professional if you are not comfortable working with 240 V power or removing control panels to trace wiring. The diagnostic process requires verifying supply voltage at the terminal block, isolating which of several control boards has failed, and handling high-voltage connections safely. If you lack a multimeter or experience with continuity and voltage testing, a technician can identify the faulty board without replacing parts by trial and error. A pro visit typically costs less than buying multiple boards on speculation.

**Rough cost:** DIY runs about $80-250 in parts, 1-2 hours. A pro service call runs about $150-400.
