## Kenmore Oven F04 Error Code — What It Means

The F04 error code on a Kenmore oven typically indicates a problem with the oven temperature sensor circuit. The control board is detecting either an open circuit (broken wire or disconnected sensor) or a short circuit (wires touching or a failed sensor probe). The exact meaning can vary slightly by model, so consult your owner's manual or the wiring diagram inside the oven for your specific model number.

When this code appears, the oven usually stops heating and locks out until the fault is cleared. The sensor probe is a small metal bulb mounted inside the oven cavity that monitors temperature and sends resistance readings back to the control board. If the sensor reads out of range or the wiring is damaged, the control triggers F04 to protect the oven from overheating or operating blindly.

## Before You Replace Anything

Many people replace the electronic control board first when they see F04, but the sensor probe and its wiring are far more likely to fail. Test the sensor resistance with a multimeter before spending money on a control board.

## Common Causes

- **Failed oven temperature sensor probe (~55%)** The sensor element inside the probe degrades over time from heat cycling, causing resistance to drift out of spec or the probe to short internally.
- **Damaged or pinched sensor wiring (~20%)** Wires running from the sensor to the control board can be pinched by racks, burned by spills, or corroded at the connector.
- **Loose or corroded sensor connector (~15%)** The push-on connector at the rear of the oven cavity can work loose from vibration or develop corrosion that breaks the circuit.
- **Failed electronic control board (~8%)** The control board's sensor input circuit can fail, misreading a healthy sensor as open or shorted.
- **Shorted or grounded wiring harness (~2%)** Insulation on the sensor wires can melt or rub through, allowing bare copper to touch the oven frame and create a short to ground.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the circuit breaker and unplug the oven from the wall outlet if accessible.
2. **Locate the oven temperature sensor probe** inside the oven cavity, usually on the upper rear wall. It is a small metal tube about the diameter of a pencil.
3. **Remove the rear access panel** or bottom panel on the back of the oven to reach the sensor wire connector and control board.
4. **Disconnect the sensor wire connector** from the control board or junction block and use a multimeter set to ohms to measure resistance across the two sensor pins at room temperature. Consult your model's wiring diagram for the expected resistance range, typically around 1,100 ohms at 70°F.
5. **Inspect the sensor wiring harness** for burns, cuts, or pinch points. If damaged, repair or replace the harness. If the wiring looks good but the sensor reads out of range, replace the sensor probe.
6. **Unbolt or unclip the old sensor** from the inside oven wall and pull the wire through the mounting hole. Install the new sensor in the same position, making sure the probe does not touch the oven wall or any metal parts.
7. **Reconnect the sensor wire** to the control board, restore power, and run a test bake cycle. The F04 code should clear if the sensor was the problem. If the code persists, test wiring continuity and consider replacing the control board.

## When to Call a Pro

Call a professional if you are uncomfortable working inside the oven's electrical cabinet or if you have replaced the sensor and inspected the wiring but the F04 code still appears. A technician can perform detailed continuity tests on the wiring harness and determine whether the electronic control board needs replacement. Also call a pro if the oven shares a high-voltage direct-wire connection without a plug, or if you lack a multimeter and are unsure how to safely test electrical components.

**Rough cost:** DIY runs about $25-60 in parts, 20-40 min. A pro service call runs about $120-220.
