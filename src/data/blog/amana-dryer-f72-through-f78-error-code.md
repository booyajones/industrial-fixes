## Amana Dryer F72–F78 Error Code — What It Means

F72 through F78 on an Amana dryer indicates a communication failure between the main electronic control board and the user interface (keypad) control assembly. The dryer has detected that these two components cannot talk to each other properly, or one of them has failed internally. This prevents the dryer from accepting commands or operating normally.

The fault can stem from a loose or damaged wire harness connecting the two boards, a failed user interface assembly, or less commonly a failed main control board. Because the error involves control electronics rather than a sensor or mechanical part, diagnosis focuses on connections and the boards themselves.

## Common Causes

- **Loose or damaged wire harness** The connector or wiring between the main control board and the user interface assembly is not fully seated, pinched, broken, or corroded.
- **Failed user interface control assembly** The keypad and display board has stopped communicating or has an internal electronic fault.
- **Failed main electronic control board** The main control board that manages communication with the UI has failed or cannot send or receive signals.
- **Transient electrical glitch** A power surge or static event has temporarily corrupted the communication link between the two boards.

## Step-by-Step Fix {#fix}

1. **Turn off power at the circuit breaker** for a full 5 minutes to reset both control boards, then restore power and check if the code clears.
2. **Unplug the dryer and remove the top or front panel** to access the main control board and user interface assembly.
3. **Inspect the wire harness and connectors** between the main control and the keypad assembly for any loose plugs, damaged insulation, pinched wires, or broken conductors, and reseat both ends firmly.
4. **Check for visible damage** on the user interface control board and the main control board, including burn marks, corrosion, or loose solder joints.
5. **If wiring is intact and the code returns**, replace the user interface control assembly first, as it is the most commonly failed component for this fault.
6. **If a new UI assembly does not resolve the code**, replace the main electronic control board.
7. **Reassemble the dryer, restore power, and run a test cycle** to confirm the error code is gone and communication is restored.

## When to Call a Pro

Call a professional if you are not comfortable working with live 240-volt circuits or removing control panels. If the power reset and connector reseating do not clear the code, an appliance technician can use diagnostic tools to isolate whether the fault is in the user interface assembly or the main control board before you invest in parts. A pro is also the right choice if you find no obvious wiring damage but lack confidence in board-level diagnosis or if your dryer is still under warranty.
