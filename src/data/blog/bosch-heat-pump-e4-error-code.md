## Bosch E4 Error Code — What It Means

On Bosch air-to-air heat pumps (IDS and IDP systems), the E4 error code signals a temperature sensor fault in the outdoor unit. The affected sensors are T3, T3L, T4, T5, or TF, all of which monitor outdoor system temperatures. Some displays show the specific sensor name alongside the E4 code. If your display shows a sensor name, that is the sensor triggering the fault.

The error appears when a sensor reading falls out of its expected range. This can happen because the sensor itself has failed, wiring to the sensor is broken or loose, or the sensor connection to the control board is poor. In rare cases, extreme ambient conditions (above 125°F) or a failed outdoor fan can also cause sensor readings to drift out of range and trigger E4.

## Common Causes

- **Broken or damaged sensor wire** Wiring to the temperature sensor can be cut, chafed, or corroded, breaking the signal path to the control board.
- **Failed temperature sensor** The sensor itself can fail internally, causing resistance readings that do not match the actual temperature.
- **Loose or corroded board connection** The sensor connector at the control board can be loose, dirty, or corroded, interrupting the signal.
- **Outdoor fan not running** If the outdoor fan fails, heat builds up around sensors and causes readings to drift out of range.
- **Extreme ambient temperature** Ambient air above 125°F can push outdoor sensor readings beyond normal limits and trigger the fault.

## Step-by-Step Fix {#fix}

1. **Check the display** for the full error code. If the code shows E4 plus a sensor name (for example, E4 T4), that named sensor is the one reporting the fault. Write down the sensor name.
2. **Verify the outdoor fan is running.** Turn on the system and confirm the outdoor unit fan spins. If the fan does not run, diagnose and repair the fan circuit before continuing with sensor diagnostics.
3. **Measure ambient air temperature** at the outdoor unit. If the air is above 125°F, wait for cooler conditions and see if the fault clears. If the fault persists in normal temperatures, continue to the next step.
4. **Inspect sensor wiring and connectors.** Trace the wiring harness from the outdoor control board to each outdoor sensor. Look for broken wires, damaged insulation, and loose or corroded terminals. Repair or replace damaged wiring.
5. **Test sensor resistance.** Disconnect the suspect sensor and measure its resistance with a multimeter. Compare the reading to the temperature at the sensor location using your model's resistance-to-temperature table. If the reading is out of range by more than 10%, replace the sensor.
6. **Check the T4 sensor reading** on the control board display. If the displayed ambient temperature is not within 10°F of the actual ambient temperature you measured, replace the T4 sensor.
7. **Replace the identified sensor** if testing confirms it is out of range. If all sensor readings test within range and wiring is intact, contact Bosch technical support for board-level diagnostics.

## When to Call a Pro

Call a licensed HVAC technician if you are not comfortable working with low-voltage wiring, do not own a multimeter, or cannot locate the sensor wiring and connectors in the outdoor unit. A technician has the model-specific resistance tables, diagnostic tools, and replacement sensors needed to identify and replace the correct sensor quickly. If all sensor readings test normal and wiring is sound, the fault may lie in the control board itself, which requires professional board-level diagnostics and parts that are not sold to homeowners.
