## Navien E228 Error Code — What It Means

The E228 code on Navien tankless water heaters typically indicates a communication problem between internal control boards or a sensor signal issue. Because Navien does not publish a single universal definition for every error code across all models, the exact meaning of E228 can vary by unit type and firmware version. Consult your owner's manual or the wiring diagram inside the front cover to confirm the specific definition for your model. In general, E228 points to a fault in how components are talking to each other or how a sensor is reporting data to the main board.

## Before You Replace Anything

Many homeowners replace the main PCB or a sensor board without first inspecting connectors and reseating cables. Clean and reseat every harness plug on the control board before ordering parts.

## Common Causes

- **Loose or corroded wiring connector (~45%)** Vibration, moisture, or installation handling can loosen plugs between sensors and the main board, breaking the signal path.
- **Intermittent sensor failure (~25%)** A temperature or flow sensor may send erratic signals due to internal wear or water scale buildup on the probe.
- **Main control board glitch (~15%)** The PCB may lock up after a power surge or firmware hiccup, storing a false error that clears with a full power cycle.
- **Damaged wire harness (~10%)** Rodent chewing, pinching during installation, or heat exposure can break conductors inside the insulation without obvious external damage.
- **Failed main PCB (~5%)** The control board itself can develop solder cracks or component failures that disrupt internal communication buses.

## Step-by-Step Fix {#fix}

1. **Turn off power** at the unit's front switch and at the circuit breaker to make sure safe work.
2. **Remove the front cover** by lifting it up and off the mounting clips, exposing the control board and sensor connectors.
3. **Photograph the wiring** with your phone so you have a reference for connector positions and wire colors.
4. **Reseat every connector** on the main PCB by pulling each plug straight out, inspecting the pins for corrosion or bent contacts, and pushing firmly back into place.
5. **Inspect the sensor wiring harnesses** that run to the heat exchanger and flow sensor for pinched insulation, scorch marks, or rodent damage.
6. **Restore power** and press the reset button or wait for the unit to self-test; observe whether E228 returns immediately or after a heating cycle.
7. **If the code persists**, use a multimeter to check sensor resistance values against the table in your manual, or schedule a service call for board-level diagnostics.

## When to Call a Pro

Call a licensed technician if the error returns after reseating connectors and a full power cycle, if you lack a multimeter to test sensor resistance, or if you discover burnt or melted wiring that requires tracing through the cabinet. Professionals have factory diagnostic software that reads real-time sensor values and can pinpoint whether the fault is in a sensor, harness, or the main board without trial-and-error part swaps. Also call a pro if you are uncomfortable working near gas lines or if your unit is still under warranty, since self-repair may void coverage.

**Rough cost:** DIY runs about $0-80 in parts, 20-45 min. A pro service call runs about $150-350.
