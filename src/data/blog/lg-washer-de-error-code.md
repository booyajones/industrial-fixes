## LG Washer dE Error Code — What It Means

The dE error code on an LG washer means the control system has detected that the door cannot be locked. LG washers will not spin unless the door is completely locked, so this fault stops the cycle. On front-load models, LG distinguishes dE (generic door-unable-to-lock fault) from dE1 (door not closed properly) and dE2 (drawer closed but not locked). All three variants indicate the lock circuit is not confirming a secure lock state.

The code appears when the door latch, lock actuator, or strike mechanism fails to engage fully. It can also trigger if the control board does not receive the correct signal from the lock assembly, even when the door appears closed. The washer will typically display the code at the start of a cycle or when attempting to enter the spin phase.

## Common Causes

- **Door not fully closed or misaligned** If the door is not pushed shut firmly, or if hinges have sagged and shifted the door out of alignment with the strike, the latch cannot engage.
- **Laundry or debris caught in the gasket** Clothing, small objects, or buildup trapped in the door boot prevent the door from seating completely against the frame.
- **Worn or damaged door lock assembly** The lock actuator, latch hook, or strike mechanism can crack, bend, or wear over time and fail to lock mechanically or signal the control board.
- **Loose or corroded wiring at the lock circuit** Vibration, moisture, or age can loosen connectors or corrode terminals between the door lock assembly and the main control board.
- **Faulty main control board** If the door hardware and wiring pass all checks but the fault persists, the PCB may not be processing the lock signal correctly.

## When to Call a Pro

If you have checked the door for obstructions, confirmed the hinges are square, and replaced the lock assembly but the dE code returns, the fault likely lies in the wiring harness or the main control board. Tracing intermittent shorts or diagnosing PCB-level failures requires a multimeter and familiarity with your model's service mode. A qualified appliance technician has access to LG service manuals with model-specific resistance and voltage tables, can safely test live circuits, and will warranty the board replacement if that is the root cause.
