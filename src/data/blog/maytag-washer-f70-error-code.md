## What this code means
The F70 error code on a Maytag washer signals a communication failure between the Central Control Unit (CCU or main control board) and the user interface (console or UI board). When these two boards can't exchange valid data over the wiring harness, the washer stops or refuses to start. This is not a drain, door-lock, or motor-speed fault. It is purely a control-system communication problem.

The code appears most often on electronic-platform Maytag front-load and top-load washers built with separate CCU and UI boards. Because the machine's brain can't reach its display, you lose control of cycles and settings. Fixing F70 usually means finding the broken link in the CCU-to-console chain, whether that is a loose connector, a damaged wire, or a failed board.

## Before You Replace Anything

Homeowners often replace the main control board first without checking the wiring harness. Inspect and reseat every connector between the CCU and console before ordering a board.

## Common Causes

- **Loose or damaged wiring harness (~40%)** Vibration, moisture, or improper reassembly can unseat or corrode the connectors between the CCU and user interface board.
- **Failed main control board (CCU) (~30%)** Power surges, moisture intrusion, or component fatigue can kill the CCU and block all communication to the console.
- **Failed user interface or console board (~20%)** Burned traces, failed ribbon cables, or water damage to the UI board prevent it from responding to the CCU.
- **Temporary software glitch (~10%)** A transient fault in the control firmware can lock up communication until you fully power-cycle the washer.

## Step-by-Step Fix {#fix}

1. **Unplug the washer** and wait five minutes to clear any transient glitch in the control firmware, then restore power and check whether F70 returns.
2. **Remove the top or rear panel** (consult your model's service manual) to expose the main control board and the back of the console.
3. **Inspect every connector** on the wire harness running between the CCU and the user interface board for loose pins, corrosion, melted plastic, or incomplete seating.
4. **Unplug and reseat each connector** firmly, then power the washer on and run a test cycle to see if communication is restored.
5. **Examine both boards** for burned components, cracked solder joints, or moisture stains that indicate a failed board.
6. **Replace the failed component**: if the wiring is intact and reseating did not help, swap the main control board or the UI board depending on which shows visible damage or which the decision tree isolates.
7. **Reassemble the washer**, run a diagnostic cycle if your model supports it, and verify that all cycle selections respond normally without throwing F70.

## When to Call a Pro

Call a technician if you are uncomfortable working inside a live appliance, if the wiring diagram for your model is hard to follow, or if you have already replaced one board and F70 persists. A pro can use a multimeter and service-mode diagnostics to isolate whether the fault is in the CCU, the UI board, or an intermittent harness short. You should also call if you see burn marks or smell electrical odor, since that points to a deeper power-supply or ground fault that needs expert diagnosis.

**Rough cost:** DIY runs about $80–250 in parts (control board or UI board), 30–90 min. A pro service call runs about $150–350 including labor.
