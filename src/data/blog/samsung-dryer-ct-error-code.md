## Samsung Dryer CT Error Code — What It Means

The CT code on a Samsung dryer signals an airflow or venting test fault. The dryer has detected restricted exhaust airflow during its built-in vent blockage check. This is not a direct component failure but a warning that the vent system is not moving enough air. The dryer flagged a vent system problem rather than a bad sensor or control board.

In some Samsung documentation the code is described as the dryer temperature being either too high or too low to run the test, which still points to an airflow or venting condition during the diagnostic cycle rather than an internal electrical fault. A blocked or restricted vent system is the starting point for diagnosis, not a failed thermistor or other internal part.

## Before You Replace Anything

Homeowners sometimes replace the thermistor or temperature sensor first, but the CT code usually means a blocked vent. Clean the entire duct path and test airflow before buying any parts.

## Common Causes

- **Lint buildup in filter, blower path, or vent duct (~50%)** Accumulated lint restricts exhaust flow and triggers the airflow test fault during the dryer's self-check.
- **Crushed, kinked, or disconnected vent hose (~25%)** The flexible exhaust connector behind the dryer can become pinched against the wall or pulled loose, blocking airflow.
- **Blocked outside vent hood or stuck damper flap (~15%)** Lint, bird nests, or a frozen damper at the exterior termination prevent hot air from exiting.
- **Long, restricted, or poorly designed duct run (~8%)** Excessive length, too many bends, or undersized ducting reduce exhaust flow enough to trip the test.
- **Thermistor or temperature sensor issue (~2%)** If airflow checks out but the code persists, a faulty sensor may be reporting incorrect temperature data to the control.

## Step-by-Step Fix {#fix}

1. **Turn off the dryer** and unplug it from the wall outlet before starting any work.
2. **Remove and clean the lint filter** completely, then use a vacuum or long brush to clear any lint from the filter housing and the opening below it.
3. **Pull the dryer away from the wall** and disconnect the flexible exhaust hose from the back of the machine and from the wall duct stub.
4. **Inspect the hose and duct** for kinks, crushing, or heavy lint accumulation, and clean or replace any damaged sections.
5. **Check the outdoor vent hood** by walking outside and confirming the damper flap moves freely and no lint or debris blocks the opening.
6. **Reconnect the vent hose** securely, push the dryer back (leaving a few inches of clearance so the hose does not kink), and plug the machine back in.
7. **Run a short test cycle** and verify strong airflow at the outdoor hood; if the CT code clears and drying performance is normal, the repair is complete; if the code returns with good airflow, consult your model's service manual or check the thermistor and related wiring.

## When to Call a Pro

Call a professional if you have cleaned the entire vent system and confirmed strong airflow but the CT code still appears. A technician can test the thermistor, inspect internal blower components, and verify the control board's diagnostic logic. Also call for help if your duct run is very long, passes through walls or ceilings, or if you are uncomfortable disconnecting the dryer or working with electrical connectors. If the dryer shows signs of overheating or unusual smells along with the code, shut it down and get a qualified repair visit to avoid fire risk.

**Rough cost:** DIY runs about $0-30 and 1-2 hours if only vent cleaning is needed; $30-60 if hose or hood replacement required. A pro service call runs about $100-200 for vent cleaning and diagnostics.
